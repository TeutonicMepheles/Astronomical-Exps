# 光具座插画资源整合

检查点：`2e00470`；整合分支：`feat/rail-lab-art-integration`。

## 当前版本 coherent-v4

先生成包含导轨、完整电源线光源、空夹具的母图，再拆为保留原画布坐标的透明图层。安装状态基于同一夹具生成。提示词见 `coherent-v4/prompts.json`。旧版本保留对照，旧 Canvas 设备补绘已经移除。

- master.png：统一透视、光照和磨砂插画材质的母图。
- rail.png：连续导轨与端座。
- emitter.png：光源、立柱、滑座与延伸至画布左边界的完整电源线。
- holder.png：空夹具、立柱、滑座。
- plane.png、concave.png、convex.png：完整安装状态，含夹持结构。

背景沿用 background-stationery-v2.png；桌面镜片沿用 *-readable-v3.png。标题、导航及第二、第三阶段资源不因本次设备分层改变。

## 定位与交互

js/optical-art.js 只定位与切换独立 PNG，不再绘制设备、线缆延长段或滑座补丁。光源固定，镜片组件水平移动；换片与取下时按反射边相对夹具的偏移换算，保持滑座位置连续。

透明图均为 1672×941。设备等比缩放 0.8，导轨等比缩放 0.88，按原图 y=625 的接触线对齐，再随 1600×900 舞台统一缩放。原图光源出口为 (576,330)，空夹具中心为 (1243,330)。平面、凹面、凸面反射边在 y=330 的 x 分别为 1121、1094、1018。电源线图层左边界位于视窗外。

黄色光路仍由 mirror-optics.js 和 beam-visual.js 实时计算。平面镜为 45°，水平入射向上反射。曲面采用近轴轮廓校准，凹面固定焦距 440 mm，凸面固定焦距 270 mm；栅格插画与解析曲线为近似配准，不宣称逐像素严格重合。第一阶段不显示参数滑块。

rail-lab.browser.cjs 覆盖鼠标/触屏拖放、限定安装区、移动边界、固定光源、键盘微调。rail-profile.browser.cjs 检查 45° 反射、解析曲面、线尾越界、换片与取下时滑座连续。course.browser.cjs 检查完整三阶段、共享标题、缩放和离线打开。截图保存在被忽略的 artifacts/。
