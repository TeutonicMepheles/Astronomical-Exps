# 参数光与动态层

静态2K资产用于材质、暗底、灯具外形、墙/地接收面和遮挡；变化的罩型与移动光源用局部参数光。不要为每个滑块值或车流时刻重新生成整景图。

## 可换灯罩

- 固定杆身/墙座与安装点，灯头变体以相同的接点、发光开口、可见面和画布配准。各灯罩用独立透明2K素材，不让模型分别重画整根灯杆。
- 罩型不仅是一张图片或一个光晕透明度。配置可见发光面、向上/侧向/向下的角分布、遮光截止、边缘软度、透射与反射演示增益。区分灯头、空气散射、接收面光斑、镜头光晕。
- 同一参考亮度下切换罩型，灯头可见性与上射光改变；地面/墙面光斑重新求值。不要把“全遮光”实现为整张光效统一变暗，也不无条件把被挡能量全加到地面。
- 配光用归一化视觉模型或已获授权的实际资料；没有光度学数据时不声称 IES、真实照度或节能比例。既有 open/cap 同贡献仅是历史演示近似，不能沿用成物理结论。
- 按需熄灯与感应逻辑分开；当前页面的 sensor 是手动演示熄灯，不自动声称有人体检测。

## 接收面与遮挡

每个光源记录安装点、发光面、朝向、局部基向量、所属建筑/路段、接收面集合、遮挡和控制组。在接收面的局部坐标计算距离/方向衰减与软截止，再投影回场景；不要直接把水平地面椭圆贴到竖直墙面。

墙灯的窗内发光与墙面受光属于不同通道：窗灯关闭时墙灯仍可能在玻璃上形成反射，这不等于窗内发光串控。检验独立性时应分清两者。

灯罩改变时仅失效本光源的局部光缓存及相关接收面。缓存键覆盖罩型/配光版本、强度/颜色、灯位/朝向、源图与接收面/遮挡变换。零强度直接跳过该光，不修改暗底。

## 动态车辆和眩光

- 先清除环境暗底里固定的车、车影与烘焙车光，再添加动态车体，不能让旧车留在背景里。
- 每个车型/方向记录轮胎接地点、左右车灯/尾灯锚点、尺度和朝向。车体、车灯、路面受光共用同一姿态；镜头眩光另按观察方向和遮挡求值。
- 复用已有调度、车道相位与防追尾思路；新构图必须重新定义路径、深度、循环边界和车辆方向素材。旧全景的固定消失点、尺寸与 x(y) 曲线约束不可原样复制。
- 急转弯不靠任意旋转一张斜视车图解决；使用匹配朝向的素材，必要时限制路径曲率或切换方向资源。
- 对向车才产生强前向眩光，背向车主要尾灯。高/低光束影响前照方向与路面分布；禁止远光保留普通照明和行车。鬼影是镜头效果，不是地面投影。
- 遮挡前照来源时同时抑制其光晕、射线与鬼影；空间表面上的受光仍由该表面自己的遮挡判断。按车体深度和前景遮挡排序，不把眩光永远画在最上层。
- 每车样式固定或确定性采样，不逐帧随机闪变；运动、命中、光照使用同一帧姿态快照。会话时间不进入每帧存档或撤销历史。

## 分层和性能

静态暗底/建筑窗光可缓存；灯罩光用局部参数场与接收面蒙版；车体、移动受光和镜头效果用独立动态 pass。沿用统一 scheduler，隐藏/暂停/编辑时停推进，重新显示重置时差。冻结后没有其它动画时不应持续重绘。

源资产保持2K；可按原像素裁切局部包围盒或复用图集，避免“每盏灯/每辆车/每种灯罩一张整景2K缓存”。不要每帧上传所有静态纹理、重建路径查表、写存储或构建历史。动态 pass 与静态光应明确统一颜色空间与混合方式，不能把 Canvas screen 和线性加光的系数当作同一模型。

验收覆盖罩型的灯头/上射/地面或墙面差异、零强度、遮挡、历史与旧草稿，及车辆路径/接缝/接地点/相向背向/远近光/隐藏恢复。功能像素检查与整页性能、白板和长期验收分开报告。
