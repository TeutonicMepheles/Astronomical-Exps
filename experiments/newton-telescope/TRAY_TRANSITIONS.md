结论：有通用方向和阶段转场先例，**此前没有统一且已实现的托盘切换规范**。以下三版补齐本场景的具体规则。

## 三版共同规则

- 网格背景、标题、光源、导轨、主光轴刻度与课程导航固定，不随托盘滑动。
- 镜座、已安装镜片及玻璃是同一设备组，同步退场 / 入场；玻璃不能悬空晚到。只改整组透明度，不拉伸器材，不做弹跳、旋转、模糊或全屏扫光。
- 旧光路及焦点先淡出；新光路只在新设备可识别后淡入。光路使用对应页的真实状态重算，禁止将旧光路直接变形为新光路；过渡不代表光学过程。
- 旧页全部退出后才换入新页，避免两种镜座同时叠影。桌面已安装原件的淡态仍保留，不被动效重置。
- 退出使用 `cubic-bezier(.4,0,1,1)`，进入沿用已有阶段转场的 `cubic-bezier(.22,.7,.25,1)`；纯光路透明度也可采用同一曲线。
- 点击立即给箭头一次 80ms 轻亮反馈，按钮位置不因按下反馈改变。进入切换后置 `aria-busy=true`；暂停翻页、拖放、安装、取下、调形和沿轨移动，完成后恢复。连续点击忽略，最多一轮切换，不排队；切换期间离开阶段则取消动效，清理锁定并以最新阶段为准。
- 等待目标图片解码后开始退场；加载失败留在旧页，恢复操作。无白屏闪图，不显示半加载设备。
- 两页独立保存镜片、位置、曲率及观察进度；过渡只控制呈现，不清空状态、不计入完成条件。焦点、控件、名称气泡、描边和拖放提示都在切换边界统一清理 / 恢复，避免旧描边残留。
- 完成后更新导航状态、读屏播报与可操作热区；键盘焦点落在返回箭头。所有位移以 1600×900 逻辑像素定义，随整个舞台等比缩放。
- 系统启用 `prefers-reduced-motion: reduce` 时直接完成一次原子换页，不等待固定计时器，不移动对象；仍更新状态与焦点。演示页提供手动开关和 2 倍慢放供比较。

## A · 原位淡换（对照）

**总时长 200ms，无位置变化。** 最贴近已有 150–200ms 的建议，适合频繁往返观察。

| 分组 | 退出 | 进入 |
| --- | --- | --- |
| 设备组 | 0–90ms，透明度 1 → 0 | 90–200ms，透明度 0 → 1 |
| 桌面镜片组 | 0–90ms，透明度 1 → 0 | 90–200ms，透明度 0 → 1 |
| 光路 / 焦点 / 参数控件 | 0–60ms，透明度 1 → 0 | 140–200ms，透明度 0 → 1 |

90ms 为状态交接点。镜座保持同一安装位置，淡出之后原位显示新设备；返回时采用完全相同节奏。

适合：克制、稳定的实验操作，尽量少打断比较。取舍：翻页方向依靠左右箭头表达。

## B · 定向轻滑（已选用）

**总时长 300ms，只有托盘轻移 16px，镜座原位淡换。** 提供更明确的左右页关系，避免整套设备像沿导轨自行运动。

| 分组 | 退出 | 进入 |
| --- | --- | --- |
| 设备组 | 0–120ms，原位淡出 | 120–300ms，原位淡入 |
| 桌面镜片组 | 0–120ms，向左 16px 并淡出 | 120–300ms，从右侧 16px 回到原位并淡入 |
| 光路 / 焦点 / 参数控件 | 0–80ms，淡出 | 220–300ms，淡入 |

120ms 为状态交接点。以上为向右翻页，返回时托盘位移方向反转；动画结束才恢复拖放热区，热区不跟随可见图像移动。

适合：需要清楚表达“还有另一页器材”。取舍：比建议的普通状态过渡长 100ms，仅用在页级切换。

## C · 分组错峰

**总时长 380ms，托盘轻降退出、轻升进入，镜座保持原位。** 用时间顺序强调先换设备再观察光路。

| 分组 | 退出 | 进入 |
| --- | --- | --- |
| 光路 / 焦点 / 参数控件 | 0–70ms，淡出 | 300–380ms，淡入 |
| 桌面镜片组 | 0–110ms，下移 10px 并淡出 | 190–350ms，从下方 10px 回到原位并淡入 |
| 设备组 | 40–150ms，原位淡出 | 150–300ms，原位淡入 |

150ms 为状态交接点。返回保持同样的“退出 → 换设备 → 镜片入场 → 光路恢复”顺序。

适合：课堂讲解时强调器材类别更换。取舍：三版中节奏最明显，频繁切换时稍慢；不建议进一步加长或增加逐片大幅飞入。

## 验证与落地边界

正式接入使用 `js/tray-transition.js`，由 `table-specimens.js` 请求切换：先解码目标资源，设备及托盘用 120ms 退场，在不可见时提交目标页，然后用 180ms 入场；光路在入场后延迟 100ms、用 80ms 恢复。托盘位移为 16 个逻辑像素，镜座不移动。主光轴和刻度不参与淡出。`BeamVisual` 的透明度 uniform 与普通光线材质统一受控，回到正常状态后恢复原透明度与材质属性。

切换期间舞台设置 `inert` 与 `aria-busy` 并拦截输入，连续点击不排队。外部重置或离开阶段会取消动画、清除锁定；课程重置版本也使托盘回到第一页。系统减少动态效果时直接提交目标页。镜座及玻璃绑定在同一时序，保留各页的镜片、凹陷 / 凸起程度及光路状态。

正式专项检查：`node experiments/newton-telescope/tests/tray-paging.browser.cjs`，支持 `EXPERIMENT_URL` 指向离线导出。独立三版对照继续保留，正式入口不加载预览快照。

演示检查：三版前进 / 返回 / 重播、忙碌时重复点击、慢放、减少动态效果、资源完整加载、键盘与触屏点击，以及 16:9 与留边窗口。正式接入时，还需核对：空座 / 已安装两态、两页各自保存状态、玻璃与镜框同步、旧描边消失、拖放取消、离开阶段取消动效、导轨与光路固定注册、离线页面。

专项浏览器验证：`node experiments/newton-telescope/tests/tray-transitions.browser.cjs`。涵盖三版全过程中的镜座不叠影、固定背景 / 导轨层不移动、双向切换、重播、防重复、系统及手动减少动态效果、键盘、缩放触屏和本地资源。
