# 早期光学设备资源

本文件记录早期设备组的来源与呈现方式。第一阶段已改用[光具座资源](../rail-lab/README.md)，以下曲率重投影和网格背景说明不代表当前实现。离线交付通过根目录导出工具完成。

来源：用户提供的 `ComfyUI_temp_exgpd_00020_.png`。使用内置 imagegen 提取并补绘，而非逐像素裁剪；保留参考图的深蓝金属材质、细夹具、银蓝反射面与柔和网格纹理。参考图原本含发射器和凹面镜；平面镜、凸面镜为按同一风格补绘的配套资源。完整提示词见 prompts.json。

- grid.png：清除设备、文字、操作台和光轴后的网格背景。
- emitter.png：带出光口、通风槽、螺钉、线缆与底座的透明设备图。
- plane.png、concave.png、convex.png：含夹具和支架的透明镜面侧视图。

运行时以普通图片和 Canvas 呈现，支持 file:// 离线打开。网格作为第一阶段 Viewport 的背景；发射器出光口的归一化位置约为(0.856, 0.43)，对齐计算中的 source + 0.46。五条平行光限制在该出光口的有效高度内。

mirror-optics.js 负责反射计算，optical-art.js 依据镜面曲率重投影资源图的行，令反射边缘与实时光路表面位置一致。资源包含的支架保持完整；文字和主光轴刻度由界面绘制。两类曲面镜使用抛物面近似模型，并由局部法线计算反射。其他阶段的望远镜模型保持原有实现。
