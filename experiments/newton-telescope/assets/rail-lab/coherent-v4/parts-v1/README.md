# 曲面镜分件素材 v1

2026-10-20 按用户要求拆分凹面镜、凸面镜；使用内置 `image_gen.imagegen` 编辑原 PNG，输出真实 RGBA 透明图层。原图 `../concave.png`、`../convex.png` 保留。

## 文件

每个 `concave/`、`convex/` 子目录各有：

- `mirror.png`：银色反射镜面，不含螺钉和夹具。
- `back.png`：背壳、镜片端部螺钉与连接架；凸面版本另含中央连接轴。
- `mount.png`：固定夹具、立柱、调节旋钮和滑座底座；凸面版本保留夹具中央转轴螺钉。

`preview.html` 提供原图、单层及三层叠合对照，可切换底色、隐藏图层。页面展示使用原 PNG 加等比缩放和平移；不改写图片像素。

## 使用与限制

这些是生成式分层提取/局部补全素材，**不是原图的无损像素分割**。模型改变了少量材质细节、尺寸和注册位置，输出宽度也在 1670–1672 像素间变化，高度均为 941。不能不经定位直接同坐标叠加，或作为原图逐像素还原依据。

`manifest.json` 保存实际尺寸、Alpha 边界、叠放顺序及预览定位参数。统一坐标基准为 1672×941，单层定位为 `x'=scale*x+xOffset`、`y'=scale*y+yOffset`（字段分别为 `scale`、`x`、`y`）。仅使用等比缩放与平移，坐标为视觉校准起点，后续与真实参数曲面结合时仍需调整连接位置与遮挡。

本轮只交付分件素材与预览，尚未接入实验，也没有修改原先的运行时镜片形变。下一步可固定 mount，将 mirror 的曲面与 back 的器件结构分别处理，避免把螺钉和支架随镜面整体拉伸。

完整提示词及生成文件来源见 `prompts.json`。不得把本素材拆分宣称为光学或整页教学验收完成。
