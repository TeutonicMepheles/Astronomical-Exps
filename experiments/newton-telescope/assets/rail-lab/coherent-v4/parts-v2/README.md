2026-10-20 按用户进一步确认，从“镜面/背壳/底座”三层调整为“可变镜体/固定结构”两层。使用内置 `image_gen.imagegen` 从原始 `../concave.png`、`../convex.png` 提取并补全，上一版 `../parts-v1/` 保留。

## 分层边界

每个 `concave/`、`convex/` 目录各包含：

- `deformable.png`：银色反射面与紧贴镜面的蓝色背壳合为连续镜体。无螺钉、上下长方体端块、连接架、连接轴或底座。
- `fixed.png`：上下两个长方体端块、全部螺钉、弓形/三角连接架、水平连接轴、U 形夹具、立柱、旋钮与滑座。此层不参与形变。

先绘制可变镜体，再覆盖固定结构；端块在前景遮住镜体的两个连接端。

## 预览与定位

打开 `preview.html`：有原图、可变层、固定层与两层组合；两个镜片各有独立的曲率滑块。默认选择抛物面，也可切换球面，并叠加理论曲线。固定层只做一次等比定位，始终使用原图层直接绘制。

镜面前缘由 `profile-geometry.js` 的解析方程决定，不再对原轮廓叠加任意弯曲权重。`preview.js` 读取已定位素材的 Alpha 前后边界，并根据红绿通道从银色到蓝色的持续下降定位交界。每行银色带保持源图宽度，平移到理论前缘；银蓝交界随前缘同步移动。只有蓝色背壳内部沿行缩放，衔接固定的最外背缘及其前方 3 像素纹理带。原始 PNG 文件不被改写。

这里保持的是图中银色带的**横向可见宽度**，并未声称三维法线厚度恒定。镜面首尾连接点固定，背壳内部的可见宽度随曲率变化；这是形状设计预览，不是材料力学仿真。

交界后的渐变纹理最多再保留 4 像素，端部按可用背壳空间收窄，避免渐变区的缩放使银色带看起来忽厚忽薄。

候选曲率范围为基准弓高的 0.6–1.4 倍；对每种镜子、每种面型检查全部纹理行，自动收窄到银色带与固定背缘之间仍保留至少 1.5 像素可变蓝色背壳的范围。滑块在有效范围内连续变化，避免银色带挤穿背壳。基准弓高取素材中点相对前缘端点弦的距离，滑块 0% 也先将素材前缘校正为解析曲线，因此不保证与原 PNG 的全部轮廓重合。

按用户“凸面镜整体更平缓”的调整，凸面镜单独使用 `previewShape`：基准弓高取原素材的 0.3 倍，银色带初始可见宽度取原素材的 0.4 倍，使较平的前缘仍能与固定背缘衔接。银色带在后续曲率变化中保持这个新宽度。当前凸面镜滑块为 -60%–60%（`sliderMax=60`），保留用户认可的最平缓端约 13.2 px 和初始约 22.0 px，以之前 60% 的形状作为最大弯曲，弓高约 48.5 px。内部正向映射保留 `highFactor=3`，没有重新归一化为 100%。这些仅为视觉预览参数。凹面镜仍为 -60%–100%，保留用户已满意的效果。

`manifest.json` 保存实际 PNG 尺寸、Alpha 边界、层顺序、连接点及相似变换矩阵。矩阵为 Canvas 的 `[a,b,-b,a,x,y]`，注册定位只含统一缩放、小角度旋转和平移。PNG 未在本地重新采样或改写，四个文件都保留真实 Alpha。

## 曲线模型与资料

“凹面 / 凸面”描述反射面的朝向，不能唯一指定其函数曲线。轴对称球面镜的轴向截面为圆弧，抛物面镜的轴向截面为抛物线。当前实验主光路使用抛物面，预览沿用它作为默认模型；球面选项用于比较，尚不改变主光路。

以镜面顶点为原点，`u` 沿口径方向、`z` 沿曲面开口方向：

- 抛物线：`u² = 4|f|z`。轴上平行光的反射光线（凸面取反向延长线）通过焦点。三维对应 `u² + v² = 4|f|z` 的旋转抛物面。
- 圆弧：`u² + (z − R)² = R²`，或 `z = R − sqrt(R² − u²)`。球面镜仅在近轴条件下满足 `|f| ≈ R/2`，不能将大口径球面镜描述为严格共焦。

实现以两端固定的弦为基准，半弦长 `h`、弓高 `s`：抛物线的 `|f| = h²/(4s)`；圆弧的 `R = (h²+s²)/(2s)`。圆弧和抛物线分别镜像为凹、凸方向，整体可随原素材小角度旋转。坐标求值包含旋转，不假定屏幕水平即光轴。所有数值均为预览像素，没有擅自设定实际口径或毫米标尺。

资料（2026-10-20 查询）：[OpenStax：Spherical Mirrors](https://openstax.org/books/university-physics-volume-3/pages/2-2-spherical-mirrors) 说明球面 / 抛物面、球差和近轴焦距；[Edmund Optics：All About Aspheric Lenses](https://www.edmundoptics.com/knowledge-center/application-notes/optics/all-about-aspheric-lenses/) 给出通用圆锥曲面 sag 方程，圆锥常数 `k=0` 为球面、`k=-1` 为抛物面。

## 限制与下一步

这些是 AI 提取/局部补全素材，**不是无损像素分割**，与源图存在细节、尺寸和位置差异。已按固定层的端块校准镜体两端，定位仍作为后续工程接入的起点。

预览滑块控制严格曲线的弓高，不是经过实际毫米标定的焦距值。固定端点与改变曲率会影响镜面顶点位置；接入实验时需要一起确定曲面基准、光线交点和焦点，不能只替换图片而沿用不匹配的光路。球面与抛物面是候选模型，素材本身不足以判断原装置的实际加工面型。

四张分件 PNG、连接点数据和结构预览现已接入实验首页第一阶段。`js/mirror-parts-config.js` 保存用户确认的抛物线端点、弓高上下限及 PNG 定位快照，`js/mirror-parts.js` 适配纹理映射并向镜面渲染与光路提供同一解析曲线。主实验以焦距驱动，凸面镜采用预览 -60%–60% 的确认范围；预览的球面比较选项不接入主实验。后续若修改本预览几何，应同步更新生产配置并重新验证光路。完整生成提示词见 `prompts.json`。

主页面另有主光轴校准：保留确认的曲率和纹理带宽度，将抛物线对称轴设在素材 y=330；在原前缘内作数像素的定位校正以保持固定背缘。素材的微小定位倾斜只属于插画透视，不代表光学倾角。此校准使中央光线沿主光轴原路返回，上下反射光对称，实 / 虚焦点均在轴上。因此生产前缘与本素材预览可有数像素位置差异，曲率范围与固定结构保持一致。
