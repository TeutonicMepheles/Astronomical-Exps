# 凸透镜原图参数化

使用用户本轮明确提供的两张图，保留原文件，不引入生成式重建素材。

- `holder.png`：`镜框02.png` 原样复制。镜框、旋钮、支柱、底座和随图滑轨不参与玻璃形变；正式页面沿用已有显示裁切，避免重复滑轨。
- `installed-source.png`：本轮第二张附件的原始副本，作为可追溯来源。
- `glass.png`：只选取第二张图中实际可见的玻璃。原图 2048×1152 的尺寸、位置、RGB、高光及内部透明度保持不变，只在选区切边使用覆盖率透明蒙版。未补全被镜框遮挡的内容。
- `extraction.json`：输入路径、SHA-256、贝塞尔选区和原像素校验记录。

`js/convex-original-profile.js` 保存 298 行可见玻璃的左右边界，`js/convex-original-shape.js` 使用这些边界逐行重采样。形状参数 s 为 92–100%，默认 100%；100% 直接绘制提取图层，浏览器验证逐像素等于直接绘制原玻璃素材。低于 100% 时，右边界 R 固定，左边界 `L'=R-(R-L)*s/100`，高光和透明度随同一行原纹理一起压缩。形变严格限制在原可见范围之内，上下安装端点保持原位。

玻璃须叠在固定镜框前面：原图可见的左侧反光覆盖了镜框内侧深色侧壁，放在镜框后面会遮掉这部分真实反光。金属图层自身始终不变形。

控制项名称为“凸起程度”。比例表示可见玻璃的形变，不是实测曲率或器材焦距。示意光路随比例变平而减弱会聚，仍使用薄透镜示意和“实焦点 F（示意）”标签。凹透镜和第一页三种反射镜不使用本轮形变参数。

对比入口：实验目录 `convex-original-preview.html`，含较平、原形与交互调节三栏，以及单独玻璃显示和恢复原图按钮。正式实验安装凸透镜后也可操作竖向滑块，取下、换片和翻页保留设置；重置恢复 100%。

验证：`node experiments/newton-telescope/tests/convex-original.browser.cjs`，支持 `EXPERIMENT_URL` 指向离线导出；包含原始像素恒等、固定镜座、变形边界、焦点联动、鼠标、键盘、缩放触屏和状态保存检查。
