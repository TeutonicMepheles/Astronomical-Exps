# 第二页桌面镜片

来源为用户于 2026-10-22 提供的 `凹桌2.png`、`凸桌2.png`。原始副本保存为 `concave-table.png` 和 `convex-table.png`，内容与透明通道保持不变。

同日按用户“不要黑色底，透明即可”的要求，经内置 imagegen 编辑为 `concave-table-transparent-v2.png`、`convex-table-transparent-v2.png`。去除玻璃内的黑色背底及画布标签，保留蓝色镜框与曲面反光；镜片内部透明处能透出桌面。页面及拖动预览均使用 v2，原始副本不覆盖。提示词见 `transparency-v2-generation.json`。

`contours.json` / `js/table-lens-contours.js` 是按 v2 素材离线计算的物件外轮廓，供公共 AffordanceHint 显示描边，不在浏览器中读取像素。

箭头使用 `assets/arrow-options/gold-left.png`，它是 05 号候选的既有透明单箭头；向右按钮水平镜像，返回按钮保持向左。

这两片接入第二页桌面选择、鼠标原生拖放及触屏拾取，复用第一页的白色拖动描边、安装提示、夹具目标和取下控件。无效放置回桌面，Esc 或取消手势清理预览。安装后原件变淡并禁用，可换片或取下；翻页分别保留透镜与反射镜，阶段重置和重新开始清空透镜。按用户后续要求增加理想薄透镜光路示意，三种原反射镜的安装和完成条件保持原有语义。

第二页镜座使用用户提供的 `镜框02.png`，原样保存为 `round-holder-source.png`。图片本身带透明通道；仅在显示层裁去随图附带的滑轨横条，以免出现双重滑轨。以原图的光轴 y=400、滑轨顶边 y=771 和底座中心 x=1577 对齐现有舞台。`js/round-holder-contour.js` 的预计算闭合轮廓保留圆环内孔，支持选中与拖动。

安装态使用同日用户提供的 `凸02.png`、`凹02.png`，原样保存为 `convex-mounted.png`、`concave-mounted.png`。两张素材分别为 2048×1152 和 1280×720，采用相同的归一化画布注册；显示层裁去左上画布标签及物件之外的杂点，不改原始 PNG。完整镜框、立柱和滑块随镜座一起移动；取下恢复 `round-holder-source.png`。`js/round-holder-contour.js` 同时保存三种状态的预计算轮廓。

第二页空圆环显示直行光束；安装凸透镜后显示会聚实焦点，凹透镜后显示发散光束与蓝色反向延长线、虚焦点。折射平面使用原图 y=400 处孔径中点 x=1563，图像和光路共用注册常量。焦点距离采用一倍素材内孔直径作为示意布局，标签标明“示意”；未确认实际器材焦距，不显示毫米焦距。安装后显示与第一页相同的取下按钮。返回第一页恢复先前反射镜及反射光路。第二页两片桌面图按约 134×119 逻辑像素的可见轮廓对齐第一页镜片，透明画布尺寸不作为物件大小。

后续按用户确认的原图方式将凹、凸透镜安装态拆为固定镜框和独立玻璃，凸透镜使用 92%–100%、凹透镜使用 85%–100% 形状范围，分别记忆设置；变平时示意折射减弱。当前实现和提取记录见 [凸透镜](convex-original/README.md) 与 [凹透镜](concave-original/README.md)。旧完整安装态保留作来源记录。
