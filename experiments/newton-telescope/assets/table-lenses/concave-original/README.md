# 凹透镜原图参数化

`installed-source.png` 是用户提供的 `C:/Users/59249/OneDrive/桌面/新建文件夹/凹02.png` 原样副本，1280×720。`glass.png` 只提取原图实际可见的玻璃，不补绘被遮挡部分；保留 RGB、反光及内部透明度，仅选区边缘使用覆盖率蒙版。输入 SHA-256、贝塞尔选区及原像素校验见 `extraction.json`。

固定镜框复用 `../convex-original/holder.png`（用户的 `镜框02.png` 原始副本）。玻璃自然画布保持 1280×720，与镜框的 2048×1152 使用同一归一化坐标注册；玻璃显示在镜框前面，保留原图覆盖内侧侧壁的反光。镜框、旋钮、支柱和底座均不变形。

`js/concave-original-profile.js` 记录 194 行选区边界。`js/concave-original-shape.js` 在 100% 时直接绘制原图层。85–100% 的新模型固定完整外周：每行左右各 10 个原始像素以及上下安装区域始终原样绘制，只对内部纹理作平滑深度映射。内部位移采用横向与纵向均为 `(1-u²)²` 的衰减场，在固定圈内侧位移及一阶变化归零；中央变化最大。85% 时中央朝浅凹方向移动 12 个素材像素，100% 为原凹面。该距离是画面形变布局，不是器材尺寸。逆向采样覆盖每个目标像素一次，避免叠加透明度；不读本地图片像素，预览仍可直接离线打开。

与上一版不同，本模型不再压缩玻璃外轮廓；周围整圈的 RGB、透明度、位置均保持原样，只有中间凹面与反光随深度连续改变。

控制项为“凹陷程度”，85% 为较平形态，100% 为原始形态。与凸透镜分别保存设置，取下、换片与翻页保留数值，重置恢复 100%。形状比例为示意参数，不是实测曲率；变平时示意发散减弱，蓝色反向延长线的虚焦点远离镜片，不显示未经确认的毫米焦距。

对比入口：实验目录 `concave-original-preview.html`，包含 85%、100% 和交互三栏，可单独显示玻璃、恢复原图。正式实验安装凹透镜后使用竖向滑块。

验证：`node experiments/newton-telescope/tests/concave-original.browser.cjs`，支持 `EXPERIMENT_URL` 指向离线导出。检查原始像素恒等、镜框固定、周围整圈像素恒等、中央深度变化、虚焦点联动、键盘/鼠标/触屏和独立状态保存。
