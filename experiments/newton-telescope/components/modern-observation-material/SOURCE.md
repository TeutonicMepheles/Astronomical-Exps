# 第三阶段现代涂装材质

来源版本：本仓库 b9556d9ee87ec3c9c193ffb6be0db16786535b14 的 `shared/components/globe-shader-renderer/renderer.js`。复用傅科摆地球仪的 hash31、vnoise3、fbm3 程序噪声、.895 + .210 × brush 颜料调制，以及笔触驱动的粗糙度变化。球面专用公共 API 无法接收 Three.js BufferGeometry，故在本实验 components 中建立独立适配器，不跨实验引用私有实现。

2026-11-11 用户明确只复用渲染效果，不复用贴图。本模块不加载任何傅科摆或第二阶段手绘贴图。第三阶段原模型 BaseColor 仅用作表面分类依据：暖色区域结合原 ORM 金属度映射为白色涂装或银灰金属，丢弃原木纹颜色与法线扰动；黑色五金与光学表面保持原分类。原图集文件保留，不覆盖源资源。网格、UV、光路和科学参数不变。

程序化笔触采用双层噪声；颗粒固定在模型空间，按屏幕导数衰减高频以避免远处摩尔纹。Three.js 线性颜色空间下颗粒幅度为 .028。只复用笔刷和颗粒相关效果，保留原有场景光照，不接入球面投影或地球贴图。

适配器串联已有 onBeforeCompile，保留剖面墙体透明度逻辑和原金属掩码。主材质、剖面、筒壁、目镜及脚架克隆分别接入；预热变体继续复制钩子和程序缓存键。无新增贴图、后处理、动画时钟或 GPU 资源，沿用现有材质生命周期。
