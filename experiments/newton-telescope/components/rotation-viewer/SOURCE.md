# 360° 查看器来源

来自已验收的本地 Newton-360-ThreeJS-Optics（72帧、Three.js光路、代表帧校准）。复用正式页现有 Three.js，不重复引入。适配仅包括模块作用域、显式本地帧清单、开关生命周期及1600×900布局。透明光路仍为教学示意，未声称实测角度或精密标定。原72张WebP逐张复制。


# 桌面观察材质来源

2026-11-10：`viewer.js` 的 NEWTON_PIGMENT 原样复用本仓库 `shared/components/globe-shader-renderer/renderer.js` 在提交 ccfd9ea 中的 hash31、vnoise3、fbm3、hash21；这是傅科摆地球仪默认程序化笔触/纸纹模式所使用的算法。保留双层噪声权重；笔触调制采用地球双频笔刷模式的 0.65 + 0.70 × 噪声。Three.js 在线性颜色空间处理材质，因此纸纹幅度适配为 0.025，避免将原地球显示空间中的 0.14 直接叠加导致黑白噪点。球面专用公共渲染器不能接收任意 Three.js 网格，故以实验私有材质适配器接入 onBeforeCompile；没有跨实验运行依赖，也没有修改公共组件。

保留原木纹、原配色和正常光照/深度测试；模型空间缩放 0.30 对齐望远镜尺寸，粗糙度至少 0.82、金属度至多 0.16，抑制塑料感亮斑。无需新增贴图、后处理或动画循环。

桌面环视仅改变 Y 轴方位，俯角锁定为原构图约 7.5°，交互距离固定。入场拉近动画保留，但不改变俯角；竖拖、上下键、滚轮、双指缩放及 setView 的旧俯角/距离参数不能改变桌面透视。


2026-11-10 第二轮材质细化：继续使用上述算法、原贴图与配色，按原材质类别用 uniforms 区分表面。木材保留全幅笔触，纸纹降至 0.012；金属笔触权重 0.35、纸纹 0.006，粗糙度下限 0.68；镜面/玻璃权重 0.12、纸纹 0.002，粗糙度下限 0.38。非木材金属度上限 0.28。避免所有表面呈现相同砂粒感，同时保留克制高光。共用同一 shader 程序，无新增贴图或后处理。即时绘制先取消待执行帧，防止自动环视产生重复调度。验证见 `../../review/step2-refinement-20261110/REPORT.md`。


2026-11-10 用户随后要求采用埃拉托色尼式“重绘贴图再映射”的处理方式。当前 `viewer.js` 已用独立生成的木材与雾蓝金属 albedo 替代上述程序颗粒；历史算法说明保留用于追溯，不再是当前运行路径。来源、完整提示词与使用范围见 [手绘贴图](../../assets/step2-handpaint/README.md)，实际验证见 [报告](../../review/step2-handpaint-20261110/REPORT.md)。原始模型、UV 和内嵌贴图未修改。


## 当前：手绘贴图 + 地球式颗粒/光照 + 接触阴影

2026-11-10 后续用户明确要求叠加傅科摆效果。当前 private adapter 复用基线 ac8412f 的 `shared/components/globe-shader-renderer/renderer.js` 中 hash31、vnoise3、fbm3 算法，以及默认 .895 + .210 × brush 调制、粗糙度扰动、softWash/edgeWash 和 coolSide/rim 思路。地球公共 API 只接受球面投影，不能渲染任意 BufferGeometry，故保留在本实验私有 viewer 内，独立 `newton*` uniforms，不修改公共组件或跨实验加载私有实现。

Three.js 在原有 GGX 光照上适配粗糙度，不另算一份 GGX；将地球的浅色洗染改成保留原 albedo 的微弱暖色增益，避免雾蓝变灰。纸纹采用模型空间 hash31 网格并按像素导数抗混叠，而不是地球的屏幕空间 hash21：环视时附着模型，静止和回到原视角不闪烁。纸纹幅度 .022（线性空间），光学表面颗粒权重为0。

傅科摆 `style.css` 的 ring-contact-ao 和 `IMPLEMENTATION.md` 的软接触阴影使用径向渐变。望远镜相机可环视，故适配为模型坐标水平平面：实际最低顶点下0.008，紧层 .62、宽层 .24，方向背离主光；深度测试开启、深度写入关闭。底座下缘额外 .16 近地AO。无需阴影贴图、模糊pass或独立动画。Bloom 发光提取期间暂时隐藏接触阴影，避免整个透明平面成为黑色遮挡矩形；正常渲染时保留。

资源增加：1个平面、2个三角形、1次普通绘制、1个GPU程序；纹理仍3张。销毁时一并释放平面几何和材质。`setSurfaceStyle({grain,lighting,contactShadow})` 是本私有查看器的可选诊断接口，用于实际像素开关比较，不增加产品调参面板。最终报告见 [地球式表面验证](../../review/globe-lighting-20261110/REPORT.md)。
