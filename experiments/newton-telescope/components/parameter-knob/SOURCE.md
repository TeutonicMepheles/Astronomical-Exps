# 参数旋钮 · 2026-11-11

实验私有组件，适配原有 focal / eyepiece / aperture range 的 input 事件与 store 订阅，不修改共享组件。横拖全行程为舞台内 240 px，输入按 rAF 合并，抬手提交最后一帧；取消、窗口失焦或阶段离开恢复起始值。原参数范围和步长保留。取消所有目镜吸附/锁定。外圈相对旋转270°覆盖全行程，跨越角度边界连续；中心按起手主方向锁定横拖或纵拖（右/上增大），横纵拖全行程240舞台像素。每次增量立即限幅，到顶/到底反向即响应，不累计越界空行程。指针捕获保证离开圆盘仍可继续拖动。固定三角在正上方，金点和指针按有限 270° 范围转动，不循环。
