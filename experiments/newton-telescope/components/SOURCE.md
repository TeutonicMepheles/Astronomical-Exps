# 第三阶段点击提示

2026-11-05 扩展到土星、月球、木星及昴星团四个按钮，依据公开的观测进度依次显示，沿用同一延迟/间歇 CSS；每个提示锚定自己的按钮，不改动其点击事件。

`observation-click-hint.js` 沿用本项目 `shared/components/gesture.js` 与 `components.css` 在 2026-11-05 的手指、点击光圈及深色胶囊文字样式，通过公开的 `ExperimentHints.handIcons` 目录复用与开头相同的本地 `grab` 手指图片。

本实验需要自定义说明、三维网格投影锚点，以及随剖面/观测阶段、拖动和土星选择隐藏提示。共享 GestureHint 当前仅提供 DOM 目标和固定文案，因此本地独立实现这些行为，使用 `observation-click-*` 作用域，不访问共享组件内部 DOM、不修改共享文件。模型位置在既有绘制结束时更新，复用相机和部件矩阵；土星提示直接锚定按钮以跟随窗口入场，不另开持续 JavaScript 动画循环。
