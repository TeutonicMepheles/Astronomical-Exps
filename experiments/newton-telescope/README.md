# 牛顿反射式望远镜实验

当前处于开发中。功能要求见 [REQUIREMENTS.md](REQUIREMENTS.md)，修改范围见 [AGENTS.md](AGENTS.md)。下面记录现有页面，不代表整页已验收。

## 运行和检查

在仓库根目录运行：

```sh
npm run dev -- --experiment newton-telescope
```

打开终端显示的地址，默认是 [本地页面](http://127.0.0.1:8793/experiments/newton-telescope/)。浏览器需支持 WebGL。

```sh
npm run check
npm test
npm run test:browser
npm run export -- newton-telescope
```

离线文件为 `dist/newton-telescope/index.html`。自动检查后，仍需试玩三阶段解锁、拖放、错误安装、返回、重置和观测记录。

观测联动的补充回归检查（仓库根目录执行；浏览器检查需先启动上面的本地服务）：

```sh
node experiments/newton-telescope/tests/preview.test.cjs
node experiments/newton-telescope/tests/observation.browser.cjs
node experiments/newton-telescope/tests/mirror-curvature.browser.cjs
```

两个浏览器脚本也支持设置 `EXPERIMENT_URL` 为导出文件的 `file:///` URL，在断网浏览器上下文中验证。观测脚本覆盖控件的真实点击、键盘端点、预览冻结和记录流程；阶段初始化及重置使用公开课程 API。镜面脚本覆盖真实拖放、凹面镜 300/600 mm 与凸面镜 300/1200 mm 端点、渲染像素与反射面配准、夹具稳定、缩放后的触屏滑块及阶段往返。这些检查不代替整页人工试玩。

## 现有流程

认识镜面阶段，桌面右侧的暖金箭头可切换到第二页，显示用户提供的凹透镜、凸透镜，同时滑轨上的镜座变为圆环镜座；左箭头返回原三种反射镜与原镜座。点击选择后持续显示名称与轮廓提示，鼠标或触屏拖入镜座后显示对应的完整安装态；无效放置回到桌面，Esc 可取消。安装后桌面原件变淡且不可重复拾取，可换片、取下或沿导轨移动镜座，也可选中镜片后点击镜座安装。两页分别保留安装状态；第二页空镜座显示直行光束，凸透镜会聚、凹透镜发散，返回第一页恢复反射光路。两片新镜片的可见尺寸及桌面基线与第一页一致；重新开始实验后返回第一页并清空透镜。

两片透镜使用 `js/lens-optics.js` 的理想薄透镜光路示意，不计入三种反射镜的完成条件。凸透镜后的平行光在右侧实焦点交会并继续传播，凹透镜后发散的光束以蓝色虚线反向延伸到左侧虚焦点；中央光线不偏折，光子只沿实际光路传播。光路与焦点随镜座移动，取下后恢复直线并隐藏焦点。依据：[OpenStax 薄透镜光路](https://openstax.org/books/university-physics-volume-3/pages/2-4-thin-lenses)。

素材没有实际折射率、表面曲率与焦距；光路呈现定性示意，不从图片推算器材参数。原始焦点距离取注册素材的内孔直径，单位仅用于画面布局，标签标明“示意”，不显示焦距毫米值，也不复用反射镜焦距。折射位置与原图 y=400 的孔径中点 x=1563 对齐。安装态使用用户提供的 `凹02.png`、`凸02.png`。素材来源与显示裁切说明见 [第二页镜片资源](assets/table-lenses/README.md)。翻页、安装及光路浏览器检查：`node experiments/newton-telescope/tests/table-specimens.browser.cjs`，也支持 `EXPERIMENT_URL` 指向离线导出页面。

凸透镜按用户最新提供的空镜框与安装态两张图实现[原图参数化控制](assets/table-lenses/convex-original/README.md)，不使用生成式玻璃素材。镜框为独立固定原图，玻璃从本轮安装态提取实际可见像素并叠在前方；玻璃默认 100% 原图，可调到 92% 较平形态，右边界与上下端点固定，颜色、高光和透明度随原纹理连续变形。示意焦点随形态变平而远离。凹透镜以相同方式提取原图玻璃，保持独立的 85%–100% 形状范围；凹透镜周围整圈固定，仅中央凹面和反光随深度变化；变平时发散减弱，虚焦点远离镜片。详见[凹透镜原图参数化](assets/table-lenses/concave-original/README.md)及[凹透镜对比与调节页](concave-original-preview.html)。取下与翻页保留设置，重置恢复原形。[打开原图对比与调节页](convex-original-preview.html)。专项验证：`node experiments/newton-telescope/tests/convex-original.browser.cjs`。

1. 认识镜面：把平面镜、凹面镜、凸面镜依次放入光具座，移动夹具观察光路。右侧“进入组装”按钮起初禁用，三种镜面都实际放入后启用；画面继续停留，学生可自由调焦、换片和比较。主动点击按钮后才显示“镜面观察完成”说明，确认后进入组装；选择“留在本阶段”或按 Esc 可继续观察，之后可再次点击进入。
2. 组装望远镜：选择或拖动主镜、副镜到安装位；错误安装会提示，正确安装后显示相应光路。
3. 参数观测：调节光学参数、目标和光源，比较 25/10/5 mm 目镜并记录。对照组要求主镜焦距、口径、目标和光源一致。

第一阶段安装凹面镜或凸面镜后，可拖动右侧竖向焦距滑块，观察镜面侧视轮廓和光路同步变化：焦距越短，弯曲越明显；焦距越长，轮廓越平缓。已接入用户确认的 `coherent-v4/parts-v2` 两层素材：银色带可见宽度稳定，最外背缘、端块与支架固定，内部蓝色背壳衔接变化。

主页面使用抛物线截面。按用户要求，凹面镜焦距范围为 300–600 mm，凸面镜为 300–1200 mm；两者每次放入镜座时都从最低值 300 mm 开始。与原有形态相比，只在端点附近小幅扩展曲率。沿用每场景单位 300 mm、每单位 125 素材像素的教学比例，以 `|f| = h²/(4s)` 让曲率和焦距双向对应，镜面形状、光路和焦点使用同一数值。这些仍是示意值，不是实际器材规格或正式科学参数；平面镜不显示焦距控件。

改变曲率会使顶点水平移动。前缘、切线法向、反射光及实 / 虚焦点均使用同一条解析曲线。主页面将该曲线的对称轴校准到素材 y=330，即工作台水平主光轴；素材透视中的轻微倾斜不会转变为器件的光学倾斜。保持确认的曲率，将前缘作数像素的对齐校正，连接端仍在固定端块遮挡范围内，背缘与支架不动。中央光线沿水平原路返回，上下光束对称，实 / 虚焦点均位于主光轴。该演示表示比较不同曲率的镜片，不表示实际镜片会自行变形。

观测图像、倍率与视场使用同一组光学计算。预览以默认 32 倍示意图为基准，随倍率连续缩放，不在高低倍率处截断；目标和背景星点的相对间距同步变化，超出画面的部分被裁切。程序图中的天体尺寸及间距未按真实角尺寸标定，只用于比较同一目标在不同设置下的变化。

预览卡中的目标、倍率和“图像视场”对应当前图像。关闭实时预览后，这些内容随画面一起冻结；控制区仍显示当前参数。点击“按当前参数更新画面”可获取一次图像，开启实时预览后恢复联动。为避免记录与冻结图像不一致，记录按钮仅在实时预览开启时可用。

任务菜单可返回已解锁阶段。重置当前阶段会清除本阶段及依赖它的后续进度；重新开始清空全部进度。状态保存在页面内存中，刷新后重新开始。

第一阶段通过任务菜单请求进入组装时，同样需要主动确认完成说明；安装第三种镜片本身不触发弹窗或跳转。取下镜片不清除安装经历，按钮继续可用。重置认识镜面后按钮重新禁用，旧弹窗的确认不能绕过新的门槛。后两个阶段沿用各自完成提示流程。

认识镜面时可直接按住托镜座（立柱或底座）左右拖动，也可拖两侧箭头；空夹具和安装后的三种镜片都支持，移动始终限制在导轨上。点击仍为选中，小于等于 4 屏幕像素的横向抖动不触发移动；键盘左右方向键保留微调。拖动采用原抓取点偏移和指针捕获，不会跳到指针中心，松开、触摸取消或离开阶段后结束拖动。

观测支持模型旋转、缩放、光源切换和预览冻结。舞台按 1600×900 等比缩放，窗口比例不同时居中留边。

## 模型说明

镜面、光路和望远镜使用教学示意尺度。近轴成像采用 `1/f = 1/u + 1/v`；图像模糊表达离焦趋势，不是波动光学模拟。角度调整改变模型姿态，入射光仍与望远镜同轴。

目镜预览为程序绘制，不提供真实天空位置、卫星轨道或星等测量。视场读数假设目镜视场为 60°，相对集光能力以 7 mm 人眼瞳孔为基准；不据此定量渲染扩展天体表面亮度。参数记录见[实现记录](../../Function-Spec/NEWTON_BASELINE.md)，未确认事项见[待确认问题](../../Function-Spec/OPEN_DECISIONS.md)。

## 托盘切换动效

正式翻页已接入用户选定的 B“定向轻滑”：约 300ms 完成，托盘沿翻页方向轻移 16px，镜座原位淡换，新光路在最后 80ms 恢复，背景、光源、导轨及主光轴不变。切换期间防重复操作，支持取消、状态保存及减少动态效果。正式专项检查：`node experiments/newton-telescope/tests/tray-paging.browser.cjs`。三版独立对照：[可点击演示](tray-transition-preview.html)、[候选规范及文件核对](TRAY_TRANSITIONS.md)。A 为 200ms 原位淡换，B 为 300ms 定向轻滑，C 为 380ms 分组错峰；B 已接入正式课程翻页，A、C 仅保留作对照。演示使用当前已注册设备图层和光路快照，不依赖历史归档页面。

## 透镜焦距与镜框遮挡

第二页两种透镜均使用“焦距”栏，凸透镜为 +600–+1200 mm，凹透镜为 −600–−1200 mm，滑块调节焦距绝对值，步长 10 mm。焦距为教学示意值，不代表原素材器件的实测参数。原图形态对应焦距绝对值 600 mm，较平形态对应 1200 mm；焦点距离变化为两倍。形状范围保持凸透镜 92%–100%、凹透镜 85%–100%，原有纹理变形算法不变；显示读数、光路斜率及焦点均取自同一焦距映射。

镜框原图的后侧镜体另在光线前方以 85% 不透明度合成：穿过前侧开口和前缘的光线保持亮度，只有经过后侧镜体的光线、箭头与光子显示为淡淡的示意痕迹。遮挡轮廓沿原图镜片右侧内缘裁切，随拖动、缩放、翻页及阶段切换同步更新。凹透镜的虚焦点圆点和标签位于光路前方。
