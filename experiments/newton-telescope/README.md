# 牛顿反射式望远镜实验

当前处于开发中。功能要求见 [REQUIREMENTS.md](REQUIREMENTS.md)，修改范围见 [AGENTS.md](AGENTS.md)。下面记录现有页面，不代表整页已验收。

## 运行和检查

在仓库根目录运行：

```sh
npm run dev -- --experiment newton-telescope
```

打开终端显示的地址，默认是 [本地页面](http://127.0.0.1:8793/experiments/newton-telescope/)。浏览器需支持 WebGL。

```sh
npm run check
npm test
npm run test:browser
npm run export -- newton-telescope
```

离线文件为 `dist/newton-telescope/index.html`。自动检查后，仍需试玩三阶段解锁、拖放、错误安装、返回、重置和观测记录。

观测联动的补充回归检查（仓库根目录执行；浏览器检查需先启动上面的本地服务）：

```sh
node experiments/newton-telescope/tests/preview.test.cjs
node experiments/newton-telescope/tests/observation.browser.cjs
node experiments/newton-telescope/tests/mirror-curvature.browser.cjs
```

两个浏览器脚本也支持设置 `EXPERIMENT_URL` 为导出文件的 `file:///` URL，在断网浏览器上下文中验证。观测脚本覆盖控件的真实点击、键盘端点、预览冻结和记录流程；阶段初始化及重置使用公开课程 API。镜面脚本覆盖真实拖放、200/1200 mm 端点、渲染像素与反射面配准、夹具稳定、缩放后的触屏滑块及阶段往返。这些检查不代替整页人工试玩。

## 现有流程

1. 认识镜面：把平面镜、凹面镜、凸面镜依次放入光具座，移动夹具观察光路。右侧“进入组装”按钮起初禁用，三种镜面都实际放入后启用；画面继续停留，学生可自由调焦、换片和比较。主动点击按钮后才显示“镜面观察完成”说明，确认后进入组装；选择“留在本阶段”或按 Esc 可继续观察，之后可再次点击进入。
2. 组装望远镜：选择或拖动主镜、副镜到安装位；错误安装会提示，正确安装后显示相应光路。
3. 参数观测：调节光学参数、目标和光源，比较 25/10/5 mm 目镜并记录。对照组要求主镜焦距、口径、目标和光源一致。

第一阶段安装凹面镜或凸面镜后，可拖动右侧竖向焦距滑块，观察镜面侧视轮廓和光路同步变化：焦距越短，弯曲越明显；焦距越长，轮廓越平缓。已接入用户确认的 `coherent-v4/parts-v2` 两层素材：银色带可见宽度稳定，最外背缘、端块与支架固定，内部蓝色背壳衔接变化。

主页面使用与预览一致的抛物线截面，保留凹面镜确认范围，以及凸面镜 -60%–60% 对应的形状范围。沿用已有的每场景单位 300 mm、每单位 125 素材像素的教学比例，以 `|f| = h²/(4s)` 从半弦长和弓高计算焦距边界，取整后凹面镜为 317–576 mm（初始 346 mm）、凸面镜为 333–1219 mm（初始 732 mm）。这是现有示意比例下的派生值，不是实际器材规格，也不是已确认的正式科学参数。为使曲线与光路一致，不再对两种镜子统一套用旧的 200–1200 mm 范围；平面镜不显示焦距控件。

改变曲率会使顶点水平移动。前缘、切线法向、反射光及实 / 虚焦点均使用同一条解析曲线。主页面将该曲线的对称轴校准到素材 y=330，即工作台水平主光轴；素材透视中的轻微倾斜不会转变为器件的光学倾斜。保持确认的曲率，将前缘作数像素的对齐校正，连接端仍在固定端块遮挡范围内，背缘与支架不动。中央光线沿水平原路返回，上下光束对称，实 / 虚焦点均位于主光轴。该演示表示比较不同曲率的镜片，不表示实际镜片会自行变形。

观测图像、倍率与视场使用同一组光学计算。预览以默认 32 倍示意图为基准，随倍率连续缩放，不在高低倍率处截断；目标和背景星点的相对间距同步变化，超出画面的部分被裁切。程序图中的天体尺寸及间距未按真实角尺寸标定，只用于比较同一目标在不同设置下的变化。

预览卡中的目标、倍率和“图像视场”对应当前图像。关闭实时预览后，这些内容随画面一起冻结；控制区仍显示当前参数。点击“按当前参数更新画面”可获取一次图像，开启实时预览后恢复联动。为避免记录与冻结图像不一致，记录按钮仅在实时预览开启时可用。

任务菜单可返回已解锁阶段。重置当前阶段会清除本阶段及依赖它的后续进度；重新开始清空全部进度。状态保存在页面内存中，刷新后重新开始。

第一阶段通过任务菜单请求进入组装时，同样需要主动确认完成说明；安装第三种镜片本身不触发弹窗或跳转。取下镜片不清除安装经历，按钮继续可用。重置认识镜面后按钮重新禁用，旧弹窗的确认不能绕过新的门槛。后两个阶段沿用各自完成提示流程。

认识镜面时可直接按住托镜座（立柱或底座）左右拖动，也可拖两侧箭头；空夹具和安装后的三种镜片都支持，移动始终限制在导轨上。点击仍为选中，小于等于 4 屏幕像素的横向抖动不触发移动；键盘左右方向键保留微调。拖动采用原抓取点偏移和指针捕获，不会跳到指针中心，松开、触摸取消或离开阶段后结束拖动。

观测支持模型旋转、缩放、光源切换和预览冻结。舞台按 1600×900 等比缩放，窗口比例不同时居中留边。

## 文件分工

| 文件 | 用途 |
| --- | --- |
| `index.html`、`css/styles.css`、`css/course.css` | 页面结构、基础样式与课程布局 |
| `js/course-state.js`、`js/course-ui.js` | 学习进度、阶段规则和控件事件 |
| `js/course-interactions.js`、`adapters/` | 公共提示、任务菜单与实验状态的连接 |
| `js/lab-scene.js`、`js/camera-director.js` | 实验场景、安装动画和镜头 |
| `js/telescope.js` | 望远镜模型、旋转缩放和渲染 |
| `js/optics.js`、`js/mirror-optics.js`、`js/preview.js` | 光路计算和成像示意 |
| `js/mirror-parts-config.js`、`js/mirror-parts.js` | 已确认分件的定位、曲率范围、纹理映射与共用解析几何 |
| `js/stage.js` | 固定比例舞台缩放 |
| `js/background.js`、`js/sky-defaults.js` | 星空和默认参数 |

学习状态由 `Newton.course` 管理，光学参数由 `Newton.store` 管理。公共组件来自根目录 `shared/components/`，使用规则见[组件文档](../../docs/COMPONENT_POLICY.md)。

## 模型说明

镜面、光路和望远镜使用教学示意尺度。近轴成像采用 `1/f = 1/u + 1/v`；图像模糊表达离焦趋势，不是波动光学模拟。角度调整改变模型姿态，入射光仍与望远镜同轴。

目镜预览为程序绘制，不提供真实天空位置、卫星轨道或星等测量。视场读数假设目镜视场为 60°，相对集光能力以 7 mm 人眼瞳孔为基准；不据此定量渲染扩展天体表面亮度。参数记录见[实现记录](../../Function-Spec/NEWTON_BASELINE.md)，未确认事项见[待确认问题](../../Function-Spec/OPEN_DECISIONS.md)。
