# 开发者模式 · 2026-11-05

从 2026-10-29 阶段三备份继续开发。每次打开/刷新页面默认关闭开发者模式并隐藏入口。单独持续按住左或右 `Ctrl` 3 秒显示右下角按钮，点击按钮进入开发者模式；再次长按 `Ctrl` 3 秒退出模式、关闭面板并隐藏按钮。同一次按住只切换一次，须松开后才能再次触发。中途松开、按其他键、窗口失焦或页面隐藏会取消计时。旧 `Ctrl + Alt + D` 和 `?dev=1` 自动开启已取消。

主镜焦距显示为 400–1600 mm，步长 10 mm，默认显示 800 mm；面板输入、导入和已保存配置均按此范围约束。右侧成像和读数使用显示值；左侧模型输入独立线性映射为 540–800（400→540，1600→800），保持原模型及形变范围。

## 可以调节的内容

- **步骤跳转**：反射镜页、透镜页、组装望远镜、参数观测均可直接进入；也能直接打开目镜预览。跳转不补写已观察镜片、已安装零件或观测记录。退出调试时，若当前阶段不满足真实进度要求，则返回已解锁阶段。
- **元素布局**：下拉列表选择当前阶段的元素，或开启「画布点选 / 拖动」。支持水平和垂直位移、缩放、旋转、透明度；位移按 1600 × 900 舞台坐标保存。方向键微调，Shift + 方向键移动 10 px，Esc 结束点选。各阶段布局独立。
- **文字数值**：修改各阶段主标题、说明，以及部分按钮文案。输入作为纯文本显示，支持换行。可调主镜焦距、目镜焦距、口径、角度；第一阶段安装曲面镜后，可调对应焦距与镜座位置。数值沿用当前演示模型与已有范围。
- **交互效果**：调节托盘和组装转场速度、光子流动速度、光束亮度、镜座拖动阈值，以及夜空羽化、亮度、星场、闪烁和流星参数。转场速度 0 表示即时切换，光子速度 0 表示暂停流动。系统减少动态效果设置仍优先。

光学实验台提供整体移动，保持器材、光路和点击区域联动。组装安装位移动、缩放后，拖放命中区域按实际屏幕位置计算。公共任务组件通过其宿主整体调节，保持公共接口边界。

## 保存与恢复

配置自动保存在当前浏览器的 `localStorage`，刷新后继续保留，但模式启用状态和入口显示不持久化；需重新长按并点击入口才能应用调试配置。请使用同一浏览器和相同本地服务端口。离线文件和 HTTP 页面通常使用不同的存储空间，二者可通过「导出配置 / 导入配置」互相迁移。

「恢复此元素」「恢复此处原文」「恢复全部默认」支持撤销。收起面板继续保留调试状态；退出调试恢复原版布局、文案和交互效果，同时保留配置供下次使用。课程的实际数值与学习进度仍由实验原有状态管理。

导出文件为 `newton-developer-settings.json`，包含布局、文字、演示参数和交互效果；不包含学习记录，也不执行代码或任意选择器。镜片安装状态、镜座位置和当前镜片焦距为即时课程状态，不随配置导出。设置仅保存在浏览器或导出的 JSON 中，**不会自动改写工程默认值**。确定最终方案后，可据此将选定配置固化到源文件。

## 验证

在仓库根目录执行：

```sh
npm run check
npm test
node experiments/newton-telescope/tests/developer-settings.test.cjs
node experiments/newton-telescope/tests/developer-mode.browser.cjs
npm run export -- newton-telescope
npm run test:browser
```

浏览器脚本支持 `BROWSER_CHANNEL=msedge` 或 `chrome`，以及 `EXPERIMENT_URL=file:///.../dist/newton-telescope/index.html`。未设置 URL 时自行启动临时本地服务；离线 URL 使用断网浏览器上下文验证。

此模式服务于页面开发调节，当前实验的正式科学参数与整页验收状态仍见本目录需求文档。
