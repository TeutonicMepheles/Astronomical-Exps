# 第二阶段左右15°过程动画

原按钮直接修改 yaw 并绘制一帧，导致突转。现每次点击累计15°目标，使用 smoothstep 插值，标准单步时长450ms，到达后停止。连续点击从当前已显示角度平滑接续到累计目标；减弱动态效果直接到达。俯角、距离及左右按钮位置保持固定。

复用查看器 schedule/render，不增加独立动画循环。单帧动画推进最多50ms，低帧率时延长实际时长，防止整段转动被一帧吞掉；后台暂停。开始拖动、复位、setView、介绍动画或自动观察会取消按钮动画；关闭查看器取消待绘制帧。

专项 `tests/rotation-buttons.browser.cjs` 已通过：减少动态效果下触控/键盘步进，正常动画没有立即改角度、至少两个中间角度、单调无超调、最终精确15°，三次点击累计45°，复位取消动画，自动观察按钮锁定，固定构图，静止停绘，关闭期间取消及重新打开。证据见 motion.json 和 rotation.png。

性能专项检查：涉及相机动画与WebGL绘制。Chromium 156.0.8078.4、headless、1600×900 记录10个角度样本；本机较低帧率下实际转动约1483ms，未宣称450ms实测完成。停止后两次采样 renderCount 同为49，几何130、纹理3，与转动前一致。无新增几何、纹理和持续渲染；未完成白板实机、完整前后GPU性能对照或长期验收。
