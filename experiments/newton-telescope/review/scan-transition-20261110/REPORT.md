# 第二阶段扫描溶解转场 · 2026-11-10

用户指出2D切出被裁切，要求改用扫描/溶解。旧 adapter 将完整1600×900组装层放大至1.62，再交叉淡化并从近景拉出3D；舞台边界因此截去放大的望远镜。

## 改动

- `adapters/newton-rotation-adapter.js` 改为1200ms左到右羽化扫描。2D/3D使用同一舞台坐标的互补遮罩，过渡带80逻辑像素，避免大面积双影。两者全程保持原尺寸，3D直接使用最终观察距离与固定俯角。
- 只在开始时读取布局、准备3D最终姿态。转场期间rAF只更新两层CSS mask，无逐帧相机、几何或WebGL重绘。背景与桌面稳定；不支持mask时退化为普通交叉淡化。
- `css/ken-v123.css` 禁用旧的3D入场平移与2D残余淡出；资源未就绪时保留原2D，转场中隐藏热点；工具与标题在结束后显现。
- 返回、退出阶段及页面离开均取消rAF并恢复原遮罩/透明度；减少动态效果时直接切换。镜头参数、手绘贴图、颗粒光照、接触阴影及光路保持。

## 验证

`scan-transition.browser.cjs` 已通过正式HTTP入口：逐帧2D边界恒定1600×900、transform为none；3D距离/俯角/方位全程恒定；遮罩持续推进，完成清理；中途Esc取消、等待后不误完成、再次打开、减少动态效果均通过。87个采样帧中WebGL额外绘制0次，无页面/控制台错误。截图包括组装、中途和完成状态。重新导出的 file:// 离线包同样通过上述检查，证据存于 `offline/`。

`npm run check` 通过。`npm test` 通过（23项工具测试及光学、五类镜片课程/完成门槛单元测试）。`npm run test:browser` 仍失败于 `previews/components/progress.test.cjs:12`：旧三类镜面测试与另一Agent正在交付的五类镜片门槛不一致；没有改动共享预览、降级断言或回退并行实现。

风险：CSS mask合成、动画取消与WebGL重复绘制。Chrome157.0.8103.39，1600×900、前台且有焦点，串行对照；旧adapter由HEAD注入，CSS和材质保持当前，主要比较移除镜头运动后的调度开销。每次从转场开始采样3.2秒，包含旧2.92秒/新1.2秒转场及余下静止时间。
