# 第二阶段 2D 光路与目镜剖面

正确安装两面镜后，按入射、主镜反射、副镜折转、目镜出光四段渐显，沿用第一阶段分段移动光点；3.2 秒完成后停绘，稍作停留再进入原 360° 观察。错误安装或只装一面镜不显示完整路径。通过 OpticalBeam 的 constructor/addSegment/setOpacity/dispose 公开接口复用柔光，不读取组件内部材质。

新增 imagegen 目镜纵剖图，原素材保留；前景在目镜区域裁切露出通道，其余前景遮挡关系保留。主副镜安装锚点未变。射线路径采用插画坐标，平行入射、主镜会聚、副镜折转到目镜，属于教学投影示意，不是按 3D 网格求交或测量的光学数据。

有限时长动画只在可见状态推进；重置/阶段离开取消 Promise 与跳转，释放渲染器、几何和材质。减少动态效果模式直接显示完成光路。独立正交画布按需创建，DPR 上限 1.5；20 条柔光线段与5个共享几何的光点，不新增持续循环，完成后不再重绘。新增约 1.3 MiB 本地素材，无运行时网络依赖。白板实机与长期性能未验收。

专项 tests/assembly-optics.browser.cjs 覆盖实际安装按钮、错误/部分安装、2D 先于 3D、绘制终止及动画中途重置。已查看在线完整光路截图，修正前景覆盖目镜及完成提示框位置。

最终验证：在线 1600×900 与断网离线 960×540 专项均通过，已查看两种尺寸的完整光路截图。`npm run check`、`npm test`、范围检查和 `git diff --check` 通过；`npm run test:browser` 首次因火箭实验 orbital-model.js 请求失败未通过，独立重跑通过，未修改火箭实验。离线版本已重新导出。未提交或推送。
