# 地面接触与镜头推近


### 2026-11-11 外观落地与背景推近
按用户截图微调：外观相机中心由 y=1.3 调至 1.62，观察高度偏移由 1.2 调至 1.5，脚端落在前景地面（1600×900 下约 y=771–811）。依据三脚架真实最低顶点分出三个脚端，各自附加一次生成的径向接触阴影，原整体投影减淡并贴合脚底高度。模型、腿长与望远镜科学参数不变。

远景、地面、星云和装饰星空按 exteriorSpan/currentSpan 与摄像机同步缩放，围绕地面接触区 (800,780) 放大；返回外观恢复 1。固定观测目标保留原指向坐标映射。相机俯角过渡与原转场共用插值，没有增加动画时钟。

验证：grounded-camera.browser.cjs 检查三个接触点、逐帧背景/镜头缩放与返回复位；auto-focus.browser.cjs 验证四天体自动对准及记录。已查看 grounded-exterior.png、grounded-section.png。性能适用项：三个共享材质/纹理的小平面与 CSS 合成缩放，纹理仅创建一次，无新增逐帧几何重建；目标白板与长期运行未验收。
