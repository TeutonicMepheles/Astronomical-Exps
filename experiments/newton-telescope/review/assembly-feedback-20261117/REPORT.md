# 古典望远镜组装反馈与名称

原错误判定将文字写入隐藏的组装说明区，且旧样式隐藏了所有桌面镜片名称。现将状态提示移动到本实验舞台中的独立可见区域，保留 `role=status` 与 `aria-live=polite`；错误凸面镜、错误镜位、安装位外和重复安装均有反馈。提示持续到下一次操作、状态更新或离开阶段，没有额外自动消失计时器。

三种镜片统一采用第一阶段的 22px/28px 居中名称样式，托盘上移 44px，保证标签完整位于 1600×900 舞台内；安装后保留名称并附加“已安装”。点选凸面镜后点击安装位不再沿用先前有效镜片。

专项测试 `node experiments/newton-telescope/tests/assembly-feedback.browser.cjs` 通过，覆盖 1600×900、960×540，真实指针拖放凸面镜至两处镜位、平面镜误放主镜位、错误后正确安装、点选错误项、镜片名称可见和边界、离开阶段清理、无残留拖拽图像和页面错误。已查看 `wrong-convex-1600.png`，提示与三种名称可读，不遮挡安装位或镜片。

性能专项检查：本次只调整事件触发的文本、可见性和布局，沿用现有 pointer 事件及拖拽销毁路径。没有新增动画循环、纹理、图片或计时器；错误拖放后检查无残留 ghost 节点，离开阶段提示隐藏。长期运行、真实白板触控和帧时间未测，不等于整页设备验收。
