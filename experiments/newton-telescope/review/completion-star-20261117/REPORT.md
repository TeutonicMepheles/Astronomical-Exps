# 天空完成星芒

成功记录目标时，在其现有天空热区中心播放一次 1.2 秒星芒亮起、缩放与淡出，结束自动移除动画类，保留原完成勾选。复用目标坐标与投影容器，不添加独立坐标或新素材。普通参数更新、重复查看和重新进入不重播。离开观测、隐藏页面或重置时清理。

减少动态效果模式只短暂显示静态星芒，不缩放。星芒不可点击、不参与辅助名称，不写入观测 Canvas。

性能适用项：每目标一个小型 DOM 元素，仅记录成功时执行有限 CSS opacity/transform 动画，没有新增动画循环、定时器、纹理或网络请求。白板实机和长期运行未验收。

专项沿用 observation-criteria.browser.cjs，新增四目标分别触发、仅正确位置触发、动画自动结束、参数更新不重播检查；在线采用普通动画，离线采用减少动态效果模式。
