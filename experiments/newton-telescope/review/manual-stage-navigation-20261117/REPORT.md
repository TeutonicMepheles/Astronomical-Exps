# 三阶段手动切换

用户于 2026-11-17 确认允许在三个阶段中手动切换。正式页面右上角任务菜单启用手动导航；顺序教学按钮及公共组件预览继续使用原有完成条件。手动导航只切换阶段，不补写完成进度，也不清空镜片、安装或观测记录。

验证：`node experiments/newton-telescope/tests/manual-stage-navigation.browser.cjs`，1600×900、Playwright Chromium，普通动效与减少动态效果均通过。覆盖初始直接进入组装和观测、阶段间反复往返、部分认识和安装进度保留、非法阶段拒绝，以及离开组装查看器后节点销毁且无延迟重开。减少动态效果下，先关闭原有组装完成提示，再点击菜单切换。课程单元测试验证已保存的四天体图像与参数在手动切换后保持不变。

性能专项检查：适用风险为阶段切换时的事件、延迟回调和查看器生命周期。沿用原阶段订阅与销毁逻辑，没有新增动画循环、纹理或逐帧计算；专项验证反复切换后界面解除 inert，查看器关闭，且无页面脚本错误。未测量帧时间、长期内存趋势或白板硬件性能；自动化结果不代表整页人工及设备验收。

根目录验证：`npm run check`、`npm test`、`npm run test:browser` 通过；实验范围检查与 `git diff --check` 通过。浏览器总检查覆盖八个实验入口、组件预览及离线导出。
