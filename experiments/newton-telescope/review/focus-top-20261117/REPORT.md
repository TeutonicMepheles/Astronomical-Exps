# 焦距框上移与自然星点接入

焦距控制框固定在视口上方中央（设计坐标 y=64），拖动圆仍投影在真实焦点。沿用原按钮、焦距模型与交互。已检查凹面镜、凸面镜、凹透镜、凸透镜的上方布局及按钮点击，并查看凸透镜截图；另有 960×540 缩放截图。

天空圈中心采用用户确认的自然星点透明素材，平时 0.48 透明度，记录时约 1.2 秒柔和增亮及微扩光晕，再恢复常亮。完成勾选移到边缘，避免盖住星核。沿用现有单次动画和清理机制。

性能适用项：焦距框复用原投影更新，无新增循环或布局测量；四个星点共享一个约 973 KiB 本地图片，缓存加载，动画仅 opacity/transform，无逐帧像素读取。白板实机与长期性能未验收。

验证通过：`npm run check`、`npm test`、`npm run test:browser`，在线与断网离线四天体观测专项，实验修改范围检查及 `git diff --check`。已导出离线版本。未提交或推送。
