# 可视化观测完成条件

用户要求用目标大小圆圈、清晰度和亮度表达观测完成条件。本轮使用独立的 `ObservationCriteria` 视图与本实验专用 CSS：目镜内显示最低大小虚线圈，下方三项卡片显示当前状态及对应调节方式。记录按钮未达标时可见禁用，达标后手动保存。实验记录入口移至左上退出按钮旁，避免遮挡条件卡片。

大小圈由现有倍率下限、插画尺寸函数和已解码精灵的 alpha 外缘共同生成；绘图与圈使用同一尺寸函数，不改四个目标的原尺寸或倍率范围。亮度沿用原口径响应，只将 0.85–1.20 作为本轮新增的相对显示亮度接受区间；这属于教学设计，不是测光标准。完整参数及边界见 `../../docs/OBSERVING_SETUP.md`。

在线专项 `tests/observation-criteria.browser.cjs` 通过四目标流程，验证未达标禁止记录、实际口径减小按钮使亮度恢复、太暗与太亮、提示层不写入 Canvas、名称披露、正确记录及条件卡/按钮不重叠。已查看在线月球与土星截图。课程单元测试还验证直接调用记录接口无法绕过亮度门槛；观测配置测试保留原倍率边界与多解，并覆盖亮度多个合格设置。

离线导出后的 960×540 页面同样通过四目标专项流程，已查看离线木星截图，条件卡片与记录按钮无重叠。`npm run check`、`npm test`、`npm run test:browser`、实验目录范围检查及 `git diff --check` 均通过。根浏览器测试为回归检查，不代表全部页面视觉验收。

用户已确认“手动调亮度，纳入完成条件”；当前通过主镜口径旋钮调整示意亮度。

性能专项：新增 DOM 只使用现有预览绘制和状态订阅，不增加动画循环、WebGL draw call 或纹理。每个 512×512 精灵只在加载时扫描一次 alpha 并缓存单个外缘数值；后续按常数次算术更新尺寸，状态文本/样式仅在变化时更新。无新的运行时图片、网络依赖或持续读像素。白板实机与长期性能尚未验收。
