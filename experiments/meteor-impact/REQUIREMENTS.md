## 正式功能、参数与核对项

固定镜头显示月面局部。选择质量、速度和角度后，点击“开始模拟”，播放陨石飞向月球、撞击扬尘、烟尘散去的过程，再显示对应陨石坑图片、坑径和深度。完成后可点击“重新开始”再模拟。

| 参数 / 指标 | 原文明确要求 | 待确认 |
| --- | --- | --- |
| 撞击物质量 | 3 选 1 | 三档数值、单位、默认档 |
| 撞击速度 | 3 选 1 | 三档数值、单位、默认档 |
| 撞击角度 | 3 选 1 | 三档角度、参考方向、默认档 |
| 输入组合总数 | 3 × 3 × 3 = 27 | 每一组合的数据映射 |
| 结果形态数 | 不超过 27 种 | 是否复用图片、具体资源清单 |
| 坑径、深度 | 结果必须显示 | 每组值、单位、精度、数据依据 |

核对项：27 种输入组合均有结果映射；动画顺序完整；烟尘散去后结果与所选参数一致；可重新模拟。“不超过 27 种”不等于必须提供 27 张不同图片。未要求实时地形物理仿真，不能自行将其作为交付指标。

## 开发和检查

本实验面向智慧白板，采用 16:9 横屏，以点击、拖拽为主；核心流程不依赖悬停或滚动。不使用复杂悬浮和滚动动效，悬停与选中效果一致（选中即悬浮）。详见[共通展示与交互约定](../../Visual-Spec/VISUAL_SPEC.md#展示与交互约定)。

总规范第 11 节的具体设备与浏览器、像素分辨率、性能阈值、科学模型与误差、刷新或跨实验状态、参数变更规则、交付验收条件仍需确认；不自行写入 60 FPS、100 MB 等阈值。

项目工程规范仍适用：资源默认可离线交付、只通过公共 API 使用 shared、独立实验配色、遵循[字体规范](../../shared/typography/README.md)。视觉资料见 [Visual-Spec](../../Visual-Spec/README.md)，其中示例页面的方案不自动成为本实验需求。

在仓库根运行 `npm run check`、`npm test`；实现或修改页面后还需 `npm run test:browser` 和实际试玩。没有页面时不得声称本实验通过了浏览器或视觉验收。
