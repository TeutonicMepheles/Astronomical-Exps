整理日期：2026-11-12。状态：第一版可运行流程原型，不是完工验收结论。

2026-11-13 续作：用户要求沿用程序化坑体、明确呈现输入差异，并改善过曝与暗部。飞书原文链接 `https://golajahfarm.feishu.cn/docx/JD8ndzaQdoexJjxP5jecEXohnbd` 本次通过 CLI 读取时返回 OAuth 服务连接 EOF，未能核对线上最新正文；本版依据本目录《陨石坑撞击实验-页面功能规格.md》制作。该整理稿的三阶段、地月对比与总规范仍有差异，本版作为可评审流程实现，不将这些差异宣称为已解决，也不填入未批准的科学数据。

### 信息覆盖与披露时机

1. 设置：当前研究因素、三档选择及其外形预览；两个固定条件；地球/月球及大气状态；只有选档后开放发射。
2. 运行：锁定输入；按接近、撞击、扬尘、成形反馈当前进程，以场景作为主视觉。
3. 结果：坑口尺度、坑深、坑形、溅射四项定性结论；俯视与剖面同时显示；提供换档重试与下一阶段两个动作。
4. 回看：每轮自动保存研究因素、全部条件、环境与结果，以及同一观察尺度下的俯视和剖面图；三条一页，支持删除上一轮。
5. 教师数据：正式口径、深度、溅射距离、坑型及深径比仍需可靠模型与数值来源，本版未开放定量展开区，不能视为正式功能已全部验收。

### 3D 与结果差异

- 延续原程序化坑体与本地 Three.js，不新增图片依赖。
- 固定地形种子、主镜头和俯视范围，避免随机背景与自动缩放抵消档位差异。
- 降低曝光与主光强度，改用较低角度侧光并保留半球补光；地表改为中灰，保留坑缘和暗部层次。
- 速度三档同步影响可视坑径、坑深与溅射，定性结果三档可区分；地球演示使用较小的坑体尺度。
- 45°保持近圆，30°采用椭圆示意；不再因斜入射自动增加中央隆起。
- 上述尺寸与环境缩放仅是定性演示参数，不是经过科学标定的撞击预测。剖面也是定性示意，不用于量取深径比。

## 2. 页面状态

```text
选择变量档位
    ↓
发射陨石（锁定控件）
    ↓
接近 → 撞击 → 扬尘 → 成形
    ↓
结果页（俯视 + 剖面 + 定性结论）
    ├─ 换一档再试 → 回到本阶段选择
    ├─ 下一阶段 → 重置非研究变量
    └─ 完成三阶段 → 实验记录册
```

切换阶段、场景或重新选择变量会清除当前尚未完成的撞击动效。已完成记录保留；删除记录只影响记录册。

## 3. 反馈规则

- 档位按钮使用持续选中状态，悬停与选中视觉一致。
- 只有当前阶段开放的变量可调；其他条件以“固定”标签持续可见。
- 三维场景使用固定近景镜头；地形平面远大于可视范围，不露出星空边界或方块星球轮廓。
- 发射期间锁定场景与档位，阶段入口保持可用并支持取消本轮。
- 阶段轨显示当前焦点与已完成标记；各阶段均可直接进入，运行中切换阶段会取消本轮且不写入记录。
- 结果页替换整块参数台，减少“结果出现后仍可误改参数”的干扰。
- 不强制弹出课程完成弹窗；学生自行选择继续尝试、切换阶段或查看记录。

## 6. 性能适用项

- 新增一个 Three.js 主场景；动画结束、取消或离开运行阶段后停止，静止状态下不持续渲染。
- 地形纹理、陨石网格、尘土贴图与高度场只初始化一次；坑体只在一轮开始时恢复、尘云遮挡后重建一次。
- 扬尘、飞砂和碎屑使用固定数量数组，不创建逐帧 DOM。
- 俯视结果复用同一 3D 地形和渲染器；侧剖面从当前坑体网格中心行采样，在完成时绘制一次。
- 已纳入专项测试：动画结束停止更新、重复运行、阶段切换取消、降低动态效果时即时完成。
- 未验证：真实智慧白板 GPU 耗时、长时间多次重复实验、触控笔输入。

## 8. 2026-11-13 并排对照与真实剖面改版

用户本轮明确要求可自由返回重选、同阶段并排对照，并使用程序化 3D 坑体的实际剖面；这覆盖了上一版顺序解锁的交互决定。

- 每轮完成后主视口分为 3D 与中心剖面两栏。3D 上的截线直接由网格中心行的顶点生成，剖面读取同一组顶点高度，不再使用独立的示意碗形曲线。剖面横纵使用相同绘制倍率，不自动拉深。
- 3D 结果用固定正交相机位置、朝向和视野捕获为 600×400；剖面固定横向范围与基线。同阶段各档位不自动缩放，便于肉眼对比。
- 下方固定排列三档结果，地球与月球分别比较；未运行档位以可点击空位呈现，不将预测图伪装成已完成实验。
- “放大对比”把三档展开为三列，每列上方 3D、下方剖面。点击已完成档位回看；点击未完成档位直接运行。
- 记录自动保存每轮的 3D、真实网格剖面、俯视备份、完整输入和定性输出；删除记录同步刷新对照槽位。
- 各阶段可自由切换；撞击中切换会取消动画并使旧回调失效。返回重选或换档重试保留此前记录。
- 静态溅射射纹复用原坑体高度场与顶点颜色，范围随演示档位变化；不新增长期动画循环。
- UI 使用程序化结果和既有组件，不需要新增图片资源，未调用 LibTV。

性能专项检查：新增截图读取发生在每轮结束时，复用现有 WebGL renderer；截图临时截线几何与材质立即释放。没有新增常驻 renderer 或动画循环。结果与记录使用静态 PNG，不在每帧重算剖面。需继续验证真实白板 GPU、长时记录积累与多轮内存增长。
