# 课堂对照记录卡片

按本轮用户截图要求移除记录表格及重复缩略图，每组以两张并排卡片展示。卡片包含实验编号、场景、全部输入条件及四项定性结果；突出研究变量。两侧同步切换 3D 坑体／立体剖面，复用本实验结果标注组件公开 render 接口及该次记录的投影坐标。没有修改科学参数、结果映射或图片生成方式。

## 验证

- `npm run check`、`npm test`、`npm run test:browser` 通过。系统 Python 别名不可用，运行时 PATH 使用本机 uv 已安装的 Python 3.12；测试所需浏览器和临时目录在获准的沙箱外运行。
- `tests/record-cards.browser.cjs` 通过：空记录、大小／地月对照、历史输入、两种视角的历史图片与标注、翻页、删除、1280×720 和 1920×1080 弹窗无滚动溢出、页面无脚本错误。
- 本次专项以 `BASE_URL=http://127.0.0.1:63081` 运行；首次 file 入口初始化超时，未计为通过。
- 人工查看工具截图：`record-cards-whole.png`、`record-cards-cutaway.png`；图片 decode 并等待绘制后截图。未进行智慧白板触控或整页教学验收。

## 性能专项检查

适用项为 DOM 布局、图片展示及反复开关的资源生命周期。每组同时展示图片由 8 张减为 2 张；沿用已有 Blob 缓存，未新增 Canvas、WebGL、计时器或持续动画，记录中的 SVG 标注为静态。

Chromium 156.0.8078.4 无头模式：两组记录后反复打开／翻页 5 次，图片资源保持 4 个结果对象，两个引擎均无活动动画。最后一次采样打开处理函数耗时约 1.5–2.0 ms。该数值只测同步处理函数，不是 INP 或完整绘制耗时；没有前后完整性能基线，不代表长期内存或真实白板性能验收。

## 2026-11-19 全屏分屏调整

按用户指定参考月面环形山的左右全屏布局方式，在本实验内独立实现。主舞台保持 1600×900 等比缩放，两侧画布分别为 800×900，去掉星空背景、圆角边框和中间间隙，以不接收输入的 96px 静态渐变过渡；操作栏浮在画面上方。背景资源文件保留，但不再被页面引用。长画幅的溅射标注下移，避开控件。

已运行发射、结果与剖面切换，截图核对双侧尺寸和地表基线；记录卡片回归通过，5 次打开处理函数约 1.5–2.4 ms，资源数保持 4。性能适用项为画布面积、结果截图比例及静态合成：没有新增绘制循环、计时器或纹理，结果态两个引擎均停止活动。画布增大后 GPU 填充负载可能上升，未做旧设备前后帧时序对比，不据此宣称性能验收完成。
