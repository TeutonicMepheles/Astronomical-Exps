# 双实验对照设计 · 2026-11-13

本轮用户明确要求：两侧先选好条件、同时发射；同场景只改变一个因素；地月对照保持所有输入相同；采用切开后有厚度的 3D 剖面，并放大坑体、用虚线强化溅射范围。这覆盖了先前串行三阶段与二维网格轮廓的交互方案。

## 信息与操作

1. 顶部选择两种对照方式；左侧集中放条件，右侧一直保留实验 1 / 2 两个视口。
2. 单变量模式提供大小、速度、角度三个研究入口；每侧各选一档，其余条件固定且可见。允许在任意研究因素之间切换。
3. 地月模式提供一组共用条件，分别应用于地球与月球，不开放两个独立的参数表，防止混杂变量。
4. 同时发射后同步展示进入、撞击、扬尘与成形；可取消或改条件，旧回调不可写入记录。
5. 完成后默认看两个完整坑体，可同步切换立体剖面。三档总览只显示做过的档位，未做的可选为实验 2 补做。
6. 记录以对照组保存：每组两个实验、全部输入、四项定性结果与四张图片。切换或重试不丢记录，删除上一组同时移除其两侧数据。

## 立体剖面与尺度

继续使用本实验现有 Three.js / 程序化地形适配层。结果捕获用固定正交画幅，两个实验及不同轮次保持同一尺度，较上一版更近。切面模式使用固定斜视角，裁去前半部、限定地块后用网格真实中心行和边缘行顶点封闭前切面与侧壁，底部延伸到演示地层深度。地层分界线仅用于读出立体厚度，不代表真实地质分层。

切面顶部逐点匹配原地表，保留三维后坑壁与坑底；不再使用二维 Canvas 剖面渲染。溅射边界使用世界坐标下的虚线轮廓，大小来自同一组程序化结果参数。所有尺寸均为定性演示尺度，未声明物理单位。

## 复用与性能专项检查

- 复用本地程序化坑体、陨石、进入光尾、扬尘与地表纹理，不引入跨实验运行依赖。
- 使用两个固定 renderer 承载同时运行的两个视口，避免每帧截图传输。两个现有动画循环共用同一开始时间；完成与取消均停止，未增加第三个常驻时钟。
- 记录只在结束时各捕获完整坑体及实体切面。截图阶段临时创建切面网格、边界线与地层线，捕获后全部移除并释放 geometry / material；清除 clippingPlanes 恢复原场景。
- 第一次切换地球会按需上传土壤贴图，后续重复运行检查 GPU 几何和纹理数量稳定，不能将合法首次上传当作泄漏。
- 未验证真实白板 GPU、长时间多轮截图记录积累、低配设备帧尾耗时。自动化结果不代表这些验收完成。
- 未使用外部插画，界面内图片均为当前程序化结果捕获，无需 LibTV 生成资源。

科学边界：地球/月球的输入严格一致，但本版大气减速、消融和坑体缩放仍为定性演示；未引入已批准的空气阻力、消融、空爆或靶材模型，不能据此声称定量因果已科学验收。
