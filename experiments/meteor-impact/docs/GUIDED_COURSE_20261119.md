# 固定顺序体验

后续用户明确要求 index2 也实现固定顺序：已同步 `index2.html` 的步骤布局和 `app2.js` 流程；仅引擎构造仍为 `MeteorScene3DPreview`，保留 `style2.css` 及圆弧绘制实现。两个入口都采用五步流程。专项通过 `METEOR_ENTRY=index2.html` 验证预览入口，截图以 `guided-index2-` 单独保存，避免覆盖默认页证据。性能适用项仍为切换、取消和记录资源；未新增渲染器、纹理或动画循环。

用户提出用固定顺序替代选择研究因素，并明确选择“固定顺序，但允许直接跳到下一步”。默认 `index.html` 按大小、速度、入射角、地面疏松程度、地球／月球排列五步；不设完成门槛，不自动推进。最后一步的前进按钮改为查看记录。

两侧只显示当前变量的档位按钮，固定条件集中为一行文字。沿用已有默认中档大小／速度、90°、紧致地面及月球场景；地月对照输入保持一致，没有新增科学数值。返回步骤保留两侧所选档位；已完成结果从记录查看，允许重新发射。进度勾来自真实记录，跳过不打勾，删除该步所有记录后取消勾选。

切换步骤调用原有取消路径，令旧 token 失效，停止当前两侧动画，避免异步截图在新步骤提交旧结果。初始化完成前禁用导航，运行中允许导航。`index2.html`、`app2.js` 与其视觉预览保持独立，两个入口通过 `.guided-course` 使用相同流程样式。

## 本地验证

index2 同步专项已通过同一套五步、跳过、返回、异步取消、记录与尺寸回归；额外断言预览渲染器脚本及 `style2.css` 仍在加载。Chromium 156.0.8078.4 下记录重复打开耗时约 1.1–1.6ms，图片资源保持 4 个结果对象；截图为 `guided-index2-setup.png`、`guided-index2-world-result.png` 及两个记录视角。该耗时仅为同步处理函数，不是完整交互延迟。

`tests/record-cards.browser.cjs` 覆盖：五步顺序、无结果直接跳过、跳过不记完成、仅当前变量可选、相同档位禁止发射、返回保留选择、五步实际生成记录、运行中切换取消、异步准备中切换取消、地月输入一致、历史视角与图像匹配、翻页删除及空记录。1280×720 / 1920×1080 检查记录无滚动溢出，1280×720 下检查主工具栏和地面选项栏无横向溢出。浏览器无脚本异常。

人工查看截图 `guided-setup.png`、`guided-world-result.png` 和两种记录视角；核对进度、选项与引线没有重叠。未进行智慧白板触控、长期运行或完整教学验收。

## 性能专项检查

适用项为步骤切换时的 DOM 更新、预览重建、取消后的资源生命周期。沿用原地形缓存、截图缓存、预览渲染与动画循环；新增导航本身不创建计时器、贴图或 WebGL 对象。Chromium 156.0.8078.4 无头模式、1600×900、减少动态效果：记录反复打开 5 次的同步处理耗时约 1.1–1.5ms，图片资源保持 4 个结果对象；切换取消后两侧 active=false。此耗时不是 INP，没有完整前后性能基线，不据此声明白板性能通过。
