# 双栏结果生成与交互性能优化

2026-11-13。用户要求保留双栏对照、立体切面和表现效果，优化同时发射、重选、重试及记录操作；切面镜头正对剖面。修改限于本实验。

## 原因与改动

- 原版撞击阶段在同一任务内重算两个完整地形，形成约 915 ms 的长任务；结束回调还连续执行四次完整渲染与同步 PNG/base64 编码。
- 首次地形计算改为独立 CPU 数组上的分片任务，每个任务预算约 3 ms，飞行时提前计算；原网格密度、噪声函数、坑形、纹理、粒子与截图分辨率均保留。只在数据完整时提交到可见网格，不显示半成品。
- 每侧地形缓存最多四份，其中两种环境的平地数据保留，避免反复重选时重新计算；其余两份保存撞击地形。取消会使尚未完成的计算失效。
- 截图改用异步 `toBlob` 与 Blob URL，分任务生成并预解码后再显示；不再在结果回调中同步生成四份 base64。完整图和实体切面均保留 800×700 捕获设置。
- 结果索引缓存最多八个输入组合，课堂记录仍持有它们使用的结果；删除记录时释放已不在缓存或其他记录内的 Blob URL，离页时全部释放。
- 两种场景的平地和剖面着色器在初始准备阶段预热，避免第一次切换地球或查看剖面时临时编译；准备完成才启用发射。冷启动准备与交互采样分开记录。
- 合并参数修改中的两次 reset/render，停止取消时的冗余重建与绘制；未变化的画布不反复 resize。
- 异步阶段允许取消、重新选参数、查看此前记录。版本 token 在每个异步边界检查，未完成的一组不写入课堂记录。解码失败和过期截图回收 URL。
- 切面相机位于 (0, -2, 44)，沿 (0, 0, -1) 垂直正对 z=0 切面，既无左右偏转，也无俯视角。两侧采用相同正交视锥与画幅，横纵世界单位使用相同比例；真实 3D 切体、封闭切面、背后坑壁和原网格均保留。

[交互采样](INTERACTION-PERFORMANCE-20261113.json)覆盖首轮双发、改中档、重试、切换地月、运行中取消、截图生成中取消、查看记录、翻页、删除与关闭。事件发生到后续第二个 rAF 的时间约 14.4–24.3 ms；这不是正式 INP，也不是物理触屏测量。一次约 51 ms 长任务仍存在，不声称所有任务均低于 50 ms。

- 同时运行最多两个已有 renderer；最终两侧动画停止。
- 每侧 8 个 GPU geometry；纹理在预热及首次进入效果上传后稳定。CPU 地形缓存每侧不超过四份；本次使用四份结果资源，索引不超过八份。
- 取消截图阶段的测试在观察到 preparing 的同一任务内触发重选，避免把结果已合法完成后才到达的测试点击误算成取消失败。
- 实体切面、完整坑体、三档对照和地月输入锁定继续由专项浏览器回归覆盖；截图核对正面视角。
