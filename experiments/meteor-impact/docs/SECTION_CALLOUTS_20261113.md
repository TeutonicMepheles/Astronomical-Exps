# 放大剖面与动画标注

2026-11-13 用户要求剖面再放大、减少上下留白、左右保持同尺度和地表基线，并对坑宽、坑深、溅射与坑形使用动效标注。

- 继续用真实 3D 切体，沿切面法线直视，无俯角；不是重新画二维坑体。
- 同一研究因素按三档中的最大几何范围设置固定正交画幅。默认大小对照半宽由 23.5 缩至 14，主体约放大 1.68 倍；相机中心移到 y=-3，减少上下无效空间。
- 左右共用同一画幅与相机；三档总览中同因素同场景的各档也使用同一画幅。地月模式按双方共同的最大范围设置画幅，避免分别适配放大造成误判。
- 横纵保持同一世界单位/像素换算，不拉深坑体。全局 y=0 投影为统一地表基线；自然地表微小起伏仍保留。
- 剖面显示坑宽尺寸线与坑深尺寸线。端点投影来自当前 3D 坑体网格，深度终点为中心剖面最低顶点；所有标签仅显示已存在的定性档位，不新增米或千米读数。
- 完整坑体显示指向同一溅射虚线边界的引出线，以及指向坑缘的坑形引出线。
- 描线后显示标签，持续约 0.8 秒后停止；减少动态效果时立即完整显示。标注按 800×700 图像坐标叠加，与结果图使用相同居中等比适配，不随白板缩放漂移。
- 结果缓存键纳入画幅，防止跨研究因素或跨场景复用不同尺度的截图；记录保留结果图及对应投影数据。
