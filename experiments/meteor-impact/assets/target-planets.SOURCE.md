# 撞击目标预览素材

地球与月球均在本机将项目已有的等距圆柱纹理投影为带光照的正射圆盘，压缩为透明 WebP。两张圆盘各自作为对应半屏的过肩目标，画面大小为构图示意。

- 地球源纹理为 e390b86 的 experiments/solar-lunar-eclipses/assets/earth/earth-eq-redraw-1152x576.png，沿用原素材来源记录。预览添加云纹和大气边缘光。
- 月球源纹理为 e390b86 的 experiments/solar-lunar-eclipses/assets/moon-eq-1024.png，原始数据来自 NASA SVS / LROC CGI Moon Kit，公有领域。

页面仅加载本目录的静态圆盘，左右半屏使用独立裁切。不新增 WebGL 贴图或独立动画循环。
