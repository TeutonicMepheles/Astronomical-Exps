# EXP-03 陨石坑 · 控制变量对照实验

2026-11-19 预览入口：[index2.html](index2.html)。默认 `index.html` 已恢复大圆弧修改前的平面月表与柔和灰色过渡；较平缓的模糊圆弧仅在副本中试验。副本使用 `app2.js`、`style2.css` 和独立命名的 `MeteorScene3DPreview`，后续视觉试验不修改默认入口。按用户后续要求，index2 也已同步下述固定五步流程，允许直接前进及返回；圆弧和地表过渡继续使用预览实现。

> 当前入口（2026-11-13）：[index.html](index.html)；从仓库根运行 `npm run dev -- --experiment meteor-impact`。根入口 smoke 已覆盖本页，通用离线导出与贡献者协作登记尚未接入；完整教学、科学和设备验收仍需分别完成。

默认入口：[index.html](index.html)。从仓库根启动 `python -m http.server 8398 --bind 127.0.0.1`，打开 `http://127.0.0.1:8398/experiments/meteor-impact/`。模型资源通过 HTTP 加载，请使用本地服务打开。

- 两个入口均按大小 → 速度 → 入射角 → 地面疏松程度 → 地球／月球的五步顺序体验，可直接上一步／下一步，不要求完成当前步才能前进。
- 每步只显示当前变量的两侧档位按钮，其他条件固定并集中说明；选择相同档位时不能发射。地月一步固定相同输入，分别在地球与月球运行。
- 两个视口保持相同相机、画幅与尺度。主画面显示完整坑体，实验记录中可同步切换 3D 坑体 / 立体剖面；虚线显示定性溅射边界。
- 立体剖面裁去现有 3D 坑体的前半部，用原网格顶点生成实体切面及侧壁，保留后半坑壁与坑底；不是二维轮廓图。
- 每组自动记录全部条件、定性输出、两侧 3D 与立体切面图。可分页、删除上一组；顶部三档总览入口已移除，各次结果通过实验记录查看。
- 返回步骤保留该步选择，允许再次发射。切换步骤取消未完成运行，保留已完成记录；进度勾只表示已有该步记录，跳过不会打勾。最后一步提供查看记录入口。

启动本地服务后，设置 `BASE_URL` 为服务地址，运行 `node experiments/meteor-impact/tests/record-cards.browser.cjs` 做当前界面专项回归。交付仍需根 `npm run check`、`npm test`、`npm run test:browser`。

本版没有科学标定的物理数值；地球/月球只以演示尺度表现大气影响，不用这些输出推断真实撞击预测。三档数值、空气阻力/消融模型、可能空爆条件及正式结果映射仍待确认。

来源见 [SOURCE.md](components/meteor-3d/SOURCE.md)，最新设计与验证见 [PAIR_COMPARISON.md](docs/PAIR_COMPARISON.md)。旧流程记录只供变更追溯，不作为当前交互规范。
