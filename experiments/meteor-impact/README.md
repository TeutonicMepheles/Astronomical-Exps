# EXP-03 陨石坑 · 控制变量对照实验

> 当前入口（2026-11-13）：[index.html](index.html)；从仓库根运行 `npm run dev -- --experiment meteor-impact`。根入口 smoke 已覆盖本页，通用离线导出与贡献者协作登记尚未接入；完整教学、科学和设备验收仍需分别完成。

默认入口：[index.html](index.html)。从仓库根启动 `python -m http.server 8398 --bind 127.0.0.1`，打开 `http://127.0.0.1:8398/experiments/meteor-impact/`；也支持直接 file:// 打开。

- 单变量对照：选大小、速度或入射角，再分别选实验 1 / 2 的档位，同时发射；其他条件固定。两边相同档位时提示重新选择。
- 地月对照：两边共用同一组大小、速度、角度输入，分别在地球与月球运行；只改变环境。
- 两个视口保持相同相机、画幅与尺度。完成后可同步切换 3D 坑体 / 立体剖面；虚线显示定性溅射边界。
- 立体剖面裁去现有 3D 坑体的前半部，用原网格顶点生成实体切面及侧壁，保留后半坑壁与坑底；不是二维轮廓图。
- 每组自动记录全部条件、定性输出、两侧 3D 与立体切面图。可分页、删除上一组；三档总览汇集同场景同因素下已经完成的三档结果。
- 可随时重选、取消运行、改变量或切换对照方式，保留已完成记录，没有阶段解锁。

运行 `node experiments/meteor-impact/tests/flow.browser.cjs` 做本实验专项回归。交付仍需根 `npm run check`、`npm test`、`npm run test:browser`。

本版没有科学标定的物理数值；地球/月球只以演示尺度表现大气影响，不用这些输出推断真实撞击预测。三档数值、空气阻力/消融模型、可能空爆条件及正式结果映射仍待确认。

来源见 [SOURCE.md](components/meteor-3d/SOURCE.md)，最新设计与验证见 [PAIR_COMPARISON.md](docs/PAIR_COMPARISON.md)。旧流程记录只供变更追溯，不作为当前交互规范。

2026-11-13 结果生成优化见 [性能记录](docs/RESULT_PERFORMANCE_20261113.md)：分片地形计算、异步 PNG/Blob 记录、有限缓存与初始着色器预热；剖面镜头沿切面法线垂直直视，无俯仰或左右偏转；双栏采用完全一致的正交比例。
