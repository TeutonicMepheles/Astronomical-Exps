# EXP-03 陨石坑 · 控制变量对照实验

2026-11-23 确认的交互分镜已接入默认 [index.html](index.html)。从闪烁星空中的旋转陨石开始，五个因素任选。地面类型和撞击目标类型自动分组并进入分屏，再点击“开始实验”发射。其余三个因素逐组分配不同档位。点击另一组已用的档位时显示提示，原选择保留。太空分屏到位后，两颗陨石在 500 ms 内向下掠出画面，星空同步出现上掠拖影，随后切到各自地表，以同一时钟开始下落。两侧撞击结束后生成带模型读数的三维坑体和立体剖面，并保存为一组课堂记录。[storyboard.html](storyboard.html) 保留独立视觉预览。

## 参数预览（2026-11-23）

默认入口的因素和参数档位在画面下方横排。首次选定档位即进入左右分屏，已配置的组各自显示陨石和参数预览。选定组保持激活，可直接点击其他可用档位替换。描边使用当前 3D 画面的透明轮廓及组色。大小为清晰可辨的示意比例。初速度箭头在陨石正下方竖直向下，入射角箭头沿飞行方向从陨石视觉中心出发，与地表基线相交。发射前的地面类型分屏在陨石下方显示带标题、科普插画与孔隙说明的干石英砂正视剖面小窗。左侧松散砂层保留较明显的颗粒间隙，右侧密实砂层的颗粒更紧密。素材由 LibTV CLI 的 Seedream 5.5 同图生成后等尺度裁切为本地 WebP，源节点为 `cea03ce1-64ed-4771-aace-c64545d01293`，位于上方图标源画布。撞击目标以左右过肩分屏展示，地球和月球分别占据各自半屏的左下方，陨石拖尾沿飞向各自目标的方向倾斜。星空补片遮住背景原有的小地球。

参数预览复用现有陨石动画，描边仅在参数页有选值时合成。箭头和角度只在参数变化或箭头纹理首次就绪时重绘，箭头染色缓存最多两份。地面和天体使用本地静态图片，减少动态效果时直接呈现终态。

星空开场、参数预览和分屏过渡共用竖直向上渐隐的白色火焰尾迹。尾迹为本地绘制的透明图层，沿用陨石已有的起伏和预览缩放。渲染复用原有动画时钟，只更新图层变换，不新增 WebGL 纹理。

每组对照的左右两侧使用同一比例尺。观察页、3D 坑体和立体剖面均显示同一标尺，保留大小差异。尺度在发射前计算一次，沿用原有地形缓存键和网格分片生成。

开场时陨石从画面上方落入，减速到中央后保持悬停。星空拖影随落入过程出现并渐隐，仅使用一次性的 CSS 合成动画。减少动态效果时直接显示中央陨石。

## 太空背景

默认入口采用双侧星云。可用 `?sky=galactic-band` 或 `?sky=dust-arc` 预览另两版。地月预览共用整幅底图，开场拖影继续独立播放。

默认背景叠加 1,100 颗程序化星点。星点层参考光污染实验 `city-night/sky-model.js` 的固定种子星表（`bf19d5c`），在陨石坑目录适配为全画幅 Canvas 2D，一次绘制，无新增逐帧更新、WebGL 或跨实验运行依赖。画布为 1920 × 1080，按 RGBA 估算像素缓冲约 7.9 MiB。

陨石尾流在太空分镜复用陨石悬停帧调度，单颗最多绘制 36 条主尾流和 24 条侧缘粒子流线，另有 2 条中段弧形尾翼，分屏最多 124 条路径。下落入场的尾流更长，切入地表或隐藏页面后不推进；减少动态效果时绘制静止帧。三个 520 × 690 Canvas 2D 像素缓冲合计约 4.1 MiB。

### 银灰月面底纹

大小、速度、入射角和地面类型对照共用银灰月面底纹。地月对照分别使用既有地球与月球地表外观。底纹为视觉示意，覆盖地表底色通道，沿用各组坑形、地形起伏、坑壁法线和粗糙度。地面类型对照仍按地球条件计算。

底图来自 [Poly Haven Moon Flat Macro 01](https://polyhaven.com/a/moon_flat_macro_01) 的 CC0 模拟月壤色彩图。使用 LibTV CLI 在「陨石坑实验 · 银灰月面材质」个人画布中做图生图干刷与颗粒处理，再将同一底纹导出为本地 WebP。贴图随分镜预加载，按现有世界坐标平铺，无逐帧合成或新增网格。每个渲染器使用一张 1024 × 1024 底色贴图，含 mipmap 的 RGBA 估算约 5.3 MiB。

密集旧坑背景从 [Solaris 月球贴图](https://solaris.cuvii.dev/moon/#textures) 的 LROC 色彩图和 LOLA 打包高程取月背高地区域（94°E–152°E、24°S–34°N），源数据来自 [NASA CGI Moon Kit](https://svs.gsfc.nasa.gov/4720)。裁片用高程生成柔和明暗，与 LibTV 银灰干刷底纹离线合成。中心降低旧坑对比度，每个场景覆盖一张 1024 × 1024 WebP。背景旧坑属于示意底色，运行时沿用同一个预加载纹理槽，无额外纹理、网格或逐帧合成。
