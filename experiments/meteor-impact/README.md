# EXP-03 陨石坑 · 控制变量对照实验

2026-11-23 确认的交互分镜已接入默认 [index.html](index.html)。从闪烁星空中的旋转陨石开始，五个因素任选，再逐组分配参数，两组可以选同一档。发射后中央陨石分向左右中心并放大，太空分屏到位后停留 500 ms，随后切到各自地表，以同一时钟开始下落。两侧撞击结束后生成带模型读数的三维坑体和同尺度立体剖面，并保存为一组课堂记录。[storyboard.html](storyboard.html) 保留独立视觉预览。

分镜沿用现有档位和本地星空、GLB、地形及扬尘资产。启动只加载一个视口，进入任务后准备第二个。开场、参数和撞击复用两个画布，进入地表时停止漂浮绘制和星点闪烁。星点仅使用 CSS 透明度动效。隐藏文档暂停漂浮，降低动态效果时使用静态星空和无位移分屏。

五项因素图标由 LibTV CLI 的 Seedream 5.5 同批生成，按视觉规范约束几何轮廓、浅立体和冷暖关系。源画布 UUID 为 `79f36f72250e4d35ace4340eeb0d21e7`。源图为实底，已分别取形并处理成透明 PNG，运行时从 [本地图标目录](assets/storyboard-icons/) 加载。

2026-11-19 圆弧预览入口为 [index2.html](index2.html)，使用 `app2.js`、`style2.css` 和独立命名的 `MeteorScene3DPreview`，按固定五步流程体验，允许直接前进和返回。

> 当前入口（2026-11-13）：[index.html](index.html)；从仓库根运行 `npm run dev -- --experiment meteor-impact`。根入口 smoke 已覆盖本页，通用离线导出与贡献者协作登记尚未接入；完整教学、科学和设备验收仍需分别完成。

默认入口：[index.html](index.html)。从仓库根启动 `python -m http.server 8398 --bind 127.0.0.1`，打开 `http://127.0.0.1:8398/experiments/meteor-impact/`；多孔陨石 GLB 通过本地 HTTP 读取，请使用上述服务；直接 file:// 不是当前受支持入口。

- 默认入口支持任选一个研究因素，给两个实验各分配档位，发射前可以重新选择。地月对照固定相同输入，分别在地球与月球运行。圆弧预览 `index2.html` 仍按五因素固定顺序体验。
- 两个视口保持相同相机、画幅与尺度。主画面显示完整坑体，实验记录中可同步切换 3D 坑体 / 立体剖面；虚线显示模型估算的溅射边界。
- 模型与动效：多孔岩石、不同初始自转、画外入射及分档匀速动画、体积扬尘和独立碎屑节奏；速度和地形为教学预设。
- 立体剖面裁去现有 3D 坑体的前半部，用原网格顶点生成实体切面及侧壁，保留后半坑壁与坑底；不是二维轮廓图。
- 每组自动记录全部条件、模型读数、两侧 3D 与立体切面图。可分页、删除上一组；顶部三档总览入口已移除，各次结果通过实验记录查看。
- 调整参数保留当前选择，允许再次发射。取消运行或生成结果时返回参数页，保留此前完成的记录。

默认分镜入口的专项回归运行 `node experiments/meteor-impact/tests/storyboard.browser.cjs`，脚本自行启动本地服务。圆弧版可设置 `BASE_URL` 后运行 `node experiments/meteor-impact/tests/record-cards.browser.cjs`。交付仍需根 `npm run check`、`npm test`、`npm run test:browser`。

分镜版采用参考 HTML 的模型估算坑径、坑深与溅射范围。陨石直径为 20、50、300 m，进入速度为 10、20、40 km/s，入射角为 90°、45°、20°。地面材质对照固定在地球，两组均使用 300 m、20 km/s、90°，共用比例尺。疏松坑深按参考模型的 1.6 倍做教学演示，记录同时注明模型原值。地面形态与材质已通过用户视觉确认，模型的科学标定、教学试用和白板实机仍待验收。详见 [实验需求](REQUIREMENTS.md)。

2026-11-13 结果生成优化见 [性能记录](docs/RESULT_PERFORMANCE_20261113.md)：分片地形计算、异步 PNG/Blob 记录、有限缓存与初始着色器预热；剖面镜头沿切面法线垂直直视，无俯仰或左右偏转；双栏采用完全一致的正交比例。

2026-11-23 分镜入口在开场准备平地、两种地表的材质和撞击效果，转场期间分片预生成选中的坑体。太空和地表共用固定画布缓冲尺寸，地形缓存复用不受撞击影响的远处平地，阴影仅在投影对象或地形变化时更新。地形网格、截图分辨率与撞击特效沿用原实现。

本机 Chrome 157、RTX 5080、DPR 1，在 1600×900 和 1920×1080 下分别串行采样五个因素各一组，涵盖发射、撞击、扬尘、坑体替换和两侧剖面记录生成。采样最大 rAF 间隔分别为 13.5 ms 和 13.6 ms，未观察到 50 ms 以上长任务。智慧白板与长期运行仍待实机验收。
