## 1. 生成任务与依据

请沿用已选方案 C 的安静科普插画气质、观测厅空间与简洁摆体，按本文重新组织为**同一实验页面内的连续视图切换**：

**选地点 → 厅内认识摆 → 调节摆长／摆重 → 返回厅内开始模拟 → 观察进动 → 换地点或参数再次比较。**

不是把所有内容放在同一张屏幕，也不是生成五套互不相关的页面。每个视图只突出当前操作对象；地点、参数、尺度参照和运行读数按任务分时出现。

依据优先级：本轮用户明确要求 → 本文已确认设计内容及正式功能需求 → 已选方案视觉特征 → 历史候选图。图与文字冲突时按本文修正。旧图中的错误文字、参数默认值、复杂机械和新增控件不得直接沿用。

E6-D 是本轮摆长视图的重点构图依据，不能仅用早期方案 C 代替。保留暖白大留白、正面剖面、完整简洁悬挂座、深青摆线与暖色摆锤、左摆右建筑的并置、低对比建筑、共用地面、1.7 m 人形和独立高度标尺。E6-A／B／C 只辅助三档内容，不新增布局方案。

**必须重新校正**：原图并非精确比例母版，E6-D 木塔明显小于与67 m摆线应有的近等高关系。不能保留错误像素比例、人物大小或机构顶部起算的标尺。建筑高度/摆线长度依次为26.92/28、67.31/67、90/100，人形为1.7/L。各对象同比缩放，建筑和人物共用地面，摆长止于球心。图中巴黎、50 kg和67 m只代表参考图状态；不批准默认参数。原图“旋转周期”必须在运行页改为双周期及偏转角。

原尺寸与辅助图详见 [E6 参考说明](references/e6-scale-design-20261102/README.md)，不把旧生成提示词中的常驻UI要求继续传给LibTV。

## 2. 统一视觉与页面框架

- 智慧白板大屏，16:9 横屏，整体等比缩放，其他比例窗口居中留边。具体像素尺寸尚未确定。
- 安静、有探索感的科普插画：简化几何、清晰轮廓、大色块、柔和明暗、克制纸感；避免写实金属高光、复杂机械细节及装饰堆叠。
- 延续方案 C 的蓝灰／青蓝空间、暖白信息面板与少量暖色摆锤重点；具体色值由后续视觉稿确认。
- 顶部：实验名、当前任务名、当前地点简短文字。中央：最大面积的当前场景。右侧：当前任务面板。底部仅在运行观察时显示加速控制。
- 展厅不画天花板，上部墙体延伸出画面，保持室内感；不能用露天场景替代。
- 人物与建筑退后，摆体、尺度关系或轨迹根据当前任务成为视觉主体。
- 以点按、拖拽操作；核心流程不依赖悬停、滚轮、自由镜头或页面滚动。选中与悬停使用相同高亮，点按后保持选中；焦点可见。
- 使用简短中文标签、系统无衬线字体；数值与单位留空格。文字、标尺、读数由界面或程序绘制，不烘焙进场景素材。

| 起点 | 动作 | 终点 / 要求 |
| --- | --- | --- |
| S1 | 拖转地球、点选地点或输入纬度 | 留在 S1，更新选点反馈和定位；不自动开始模拟 |
| S1 | 进入观测 | S2，携带当前地点与参数 |
| S2 | 调节摆长 / 调节摆重 | S3 / S4 |
| S3 / S4 | 切换档位 | 留在当前视图，立即更新对应几何与选中反馈 |
| S3 | 调节摆重 | S4，保留地点与摆长 |
| S4 | 调节摆长 | S3，保留地点与摆重 |
| S3 / S4 | 返回厅内 | S2，保留所有设置，恢复稳定厅内构图 |
| S2 | 开始模拟 | S5，才显示运行轨迹、双周期、偏转角与调速栏 |

镜头切换短暂、平稳，只用于建立空间连续性。返回不改变地点与参数。准备阶段的参数切换与运行中修改参数必须分开设计，不能把后者的未决规则暗中写成自动重置或自动续播。

## 5. 四个镜头预设

| 镜头 | 构图 | 变化约束 |
| --- | --- | --- |
| K1 地球总览／地点定位 | 地球占主体，选中点与纬度清楚 | 选点后自动转到斜侧，表达摆锤与当地地表垂直，再由“进入观测”进入展厅 |
| K2 厅内观察 | 摆锤与完整地面轨迹区突出；上部墙体出画，不绘制天花板 | S2、S5 共用；返回厅内恢复构图；不随摆动或轨迹增长自动追踪；摆长变化不必改变此观察框架 |
| K3 摆长全景剖面 | 完整悬挂座、摆线、摆锤、建筑、人形与标尺 | 先改变真实摆线长度，再按整体包围范围取景；所有对象统一尺度，不独立缩小建筑或放大人物 |
| K4 摆重近景 | 对准摆锤、1.7 m 人形、局部摆线与地面 | 进入时推近，之后三档共用锁定镜头；球体大小变化时摆锤中心与长度测量终点稳定，不重新自动取景抵消变化 |

摆体保持同一对象身份、造型、材质与悬挂轴关系。悬挂座和摆线沿用简洁样式，不增加铰接、滑轮组或工程机械。K3 的长度变化不能只靠缩放整张背景图片伪装。

## 6. 摆长尺度参照

以下建筑及标注口径由本轮用户指定，用于设计生成；不代表另行完成史料或测绘核验。中国建筑参照固定使用，不随上海、巴黎等观测地点替换。

| 当前摆长参考档位 | 对应建筑剪影 | 界面标注口径 |
| --- | --- | --- |
| 28 m | 太和殿殿身 | 26.92 m，不含台基 |
| 67 m | 应县木塔 | 约 67.31 m，通行公布高度 |
| 100 m | 上海海关大楼 | 约 90 m，含钟楼 |

- 建筑与人形各自为独立资源，和摆体采用统一世界尺度、同一地面基线。建筑只降低对比，不为构图独立缩小。
- 摆长从**实际悬挂点量到摆锤中心**，不包含悬挂座、不量到地面或球体底端。标尺两端必须对准真实端点。
- 人形固定 1.7 m，不为看清而单独放大，可以用引线标注。
- 28 m 档必须容纳较宽的太和殿殿身；允许镜头整体拉远，不要求摆线填满高度，不随意裁掉建筑主体。
- 尺度建筑与窗外地点地标语义分开。厅内若保留地点地标，仅承担地点识别；不把巴黎地标当作摆长标尺。
- 生成图若无法正确呈现统一比例，应标记为待修正概念图，不能用“示意”掩盖比例错误并直接投产。

## 7. 参数、读数与科学边界

| 项目 | 当前用于设计的内容 | 状态 |
| --- | --- | --- |
| 摆长 | 28 / 67 / 100 m；参考默认 67 m | 三档已确认；数值与默认值仍待最终确认 |
| 摆重 | 25 / 28 / 50 kg；参考默认 28 kg | 三档尺寸已确认；质量数值、命名、默认值和大小映射待定 |
| 初始地点 | 上海；参考 31.23°N、121.47°E | 可用于设计样稿，不作为正式默认值批准 |
| 纬度输入 | 支持任意纬度；参考范围 −90～90°、步长 0.1° | 功能已确认，范围／精度／校验待定 |
| 运行读数 | 摆动周期、进动周期、偏转角度 | 三项必须同时清楚呈现；公式、单位和精度待定 |
| 加速 | 两种方式及 ×1 / ×10 / ×100 / ×1000 | 选项已确认，默认档、时钟含义和切换连续性待定 |

生成效果图的运行读数统一用“—”，不生成看似精确的周期、角度或虚拟时间结果。参数参考数值可用于档位排版，需在图外说明其参考性质。不要在学生界面堆放项目评审说明。

质量档位可表达球体大小有变化，但不得自行推定精确直径、密度或质量换算；摆重近景中人形不变，大小差异只代表待确认映射。质量对摆动周期的作用尚待统一，不从视觉稿推定；摆长和质量都不得改变进动周期。

开始后，摆锤运动与地面投影轨迹同步；轨迹应能清楚展示完整进动过程，不闪烁、不出现擦除式锯齿伪影。轨迹由程序绘制，概念图中的轨迹只说明视觉层级，不充当模型或生产轨迹数据。

不再使用“旋转周期”统称两个周期。赤道、两极、南北半球的周期与方向、偏转角累计或取模等未定时，不自行写入结果。精确赤道 0° 必须有独立可到达状态。
