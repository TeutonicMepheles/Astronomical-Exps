# E6 系列尺度参考：LibTV 交付选图

E6-D「留白并置」为本轮明确纳入的摆长主构图参考；E6-A（28 m，太和殿，短摆修正版）、E6-B（67 m，应县木塔）、E6-C（100 m，上海海关大楼，轮廓修正版）仅辅助三档尺度表达，不代表另选三种页面布局。user-E6-D-selection.png 是用户提供的选图截图，E6-D.png 是对应原尺寸图。

## 保留

暖白留白、正面剖面、完整简洁悬挂座和摆体、左摆右建筑的并置关系；低对比中国建筑、同地面基线、1.7 m 人形、从真实悬挂点到球心的摆长标尺、建筑自身高度与“尺度参照”标注。摆锤暖色、摆线深青色，读数与标尺由程序绘制。

## 移除与调整

- 移除调参页左侧地点列表、经纬度卡片和小地球，地点仅在顶部文字保留，中央场景扩展。
- 移除摆长页的质量三档控件，改为“调节摆重”入口；保留本任务三档摆长与“返回厅内”主出口。
- 移除调参页“开始模拟”、运行读数与底部加速栏；开始只在厅内准备，读数和加速只在运行观察出现。
- 移除图中地面环形轨迹／动态投影装饰；开始前不显示运行轨迹。
- 不复用装饰标语、学科栏和多余页签；顶部采用实验名、当前任务、当前地点。
- “旋转周期”不沿用；运行页必须分为摆动周期、进动周期与偏转角度。
- 巴黎、50 kg、67 m 的图中选中状态不是默认值批准。人物、建筑、摆体不得按旧图像素尺寸照抄。

## 比例修正是必须项

这组图是构图参考，尚未通过统一比例验收。E6-D 中木塔相对摆线明显偏矮，人物也不能直接按图复制。统一米制尺度重建：建筑高度/摆线长度分别为26.92/28、67.31/67、90/100；人物高度/摆线长度为1.7/L。建筑与人物起于同一地面，摆锤中心高于地面，不能强行对齐建筑顶与悬挂点。摆长标尺从实际悬挂点到球心；不得包含座体。短摆需容纳太和殿殿身宽度，整体拉远，所有对象同比缩放。
