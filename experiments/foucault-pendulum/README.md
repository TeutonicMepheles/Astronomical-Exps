## 球面摆架方案预览

[独立对比页](pendulum-pin-preview.html)用于评审单臂图钉、双脚门架和拱形观测架。三个视图同步切换地点和旋转，半透明摆平面随摆动方向偏转，底部记录摆锤掠过轨迹。轨迹按固定间隔采样，最多保留 480 个点，切换地点时清空。摆动与偏转使用演示时标。方案 C 已接入默认实验入口。

三个视图共用一份地球位图，视角改变时才重采样纹理。摆动使用一个动画循环，标签页隐藏时停止调度。已在桌面浏览器查看南极并切回上海，白板触控和长期运行未测。

正式入口在选点后显示拱形观测架，绕当地竖直方向布局。小摆采用独立演示时钟，摆幅与偏转速度均为夸张的演示值。地点卡片横排图标、地名与纬度，选中高亮由摆线和扫掠留痕承载。轨迹随时间累积，成形速度取决于纬度。切换地点或应用参数后重画轨迹。

观测架沿用整页帧调度，隐藏标签时随整页停帧；参数弹窗打开期间不绘制。底部路径按 25 毫秒间隔采样，最多保留 480 个点，转动地球或淘汰旧点时重新投影留痕。未在智慧白板实机做性能验收。

## 教学楼白描方案预览

[三档教学楼白描对比](school-facade-preview.html)沿用现有参数页的 28 / 67 / 100 m 档位和每层约 3 m 的类比口径。已接入正式参数页。每栋只标总层数，门窗、楼板和楼梯仍逐层绘制。每档 SVG 仅在切档时生成，转场沿用现有揭示和缩放，未增加动画循环或远程资源。

对比小窗素材由 LibTV Seedream 5.5 参考学生示意图和教学楼标准层生成。画布为“傅科摆-教学楼蓝图参照-20261117”，出图节点为“学生与标准层 · 浅线蓝图大图 1123”。正式小窗使用两张本地透明 WebP，按 1.6∶3 等比缩放，共用基线。

## 地面方案评审

[A 银灰罗盘](floor-review.html?variant=a) 已确认并接入默认入口，刻度数字已缩小并调为柔和的蓝灰色。[B 先贤祠镶嵌](floor-review.html?variant=b) 和 [C 简洁蓝灰](floor-review.html?variant=c) 保留为独立预览。底图由 LibTV Seedream 5.5 生成，仅合成地面，使用默认摆心和现有地面投影比例校准。刻度保留原图的近侧零点，每 5° 一个刻线、每 30° 标注一次。

默认入口和各候选页各加载一张本地静态背景，沿用实验现有动画循环。桌面浏览器用于本批评审，白板实机和长时性能待验收。
