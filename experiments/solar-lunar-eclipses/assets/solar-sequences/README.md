# 日食实拍素材

地面观测小窗按模拟食相从日全食、日环食各 11 张及日偏食 26 张实拍照片中选帧，页面标识“实拍示意”。照片经过逐帧裁切、居中和缩放。照片采样时刻与模拟接触时刻不同。日全食首尾使用源图最接近的偏食画面。亮环开始和结束使用相邻照片，全食及环食期间使用中间帧。太阳在地平线下、自由模式、无日食和月食沿用原有模拟。

全食和环食事件的偏食区共用此序列，按各自模拟食程映射取帧。偏食图集由原图裁切、居中、缩放及重新排布，依原许可 CC BY-SA 2.0 分发。

三张 WebP 图集按需加载，同类日食复用已解码的图集，使用现有帧调度和 2D 小窗，无额外动画循环或 WebGL 纹理上传。图集加载失败时显示模拟画面。
