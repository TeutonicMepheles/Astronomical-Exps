## 正式功能、参数与核对项

### 场景与模式

日地月大小和距离允许为教学演示调整，**不追求精确仿真**。演示三者位置关系，并动画呈现地影、月影的范围。

| 窗口 | 内容 | 交互边界 |
| --- | --- | --- |
| 窗口 1 | 日地月关系 | 原文总则允许旋转、推拉镜头 |
| 窗口 2 | 地球观察视角 | 自由模式可点选窗口 3 观察点；演示模式旋转角度固定 |
| 窗口 3 | 地球表面观察视角 | 原文总则允许旋转、推拉；演示模式地表观察点固定 |

演示模式的明确限制优先于“三个窗口均可旋转推拉”的总述；固定观察点是否还允许局部转向和缩放，需要确认。

| 模式 | 控制 | 行为 |
| --- | --- | --- |
| 自由探索 | 地球公转轨道位置滑块 | 改变日地月位置关系 |
| 自由探索 | 月球公转轨道位置滑块 | 改变日地月位置关系 |
| 自由探索 | 沙罗周期滑块 | 改变原文所述“沙罗周期”参数，具体含义待确认 |
| 自由探索 | 地球自转开关 | 控制地球自转 |
| 自由探索 | 在窗口 2 点击地球 | 设置窗口 3 观察点 |
| 日食演示 | 播放 / 暂停 / 重启 | 播放一次特定日食的完整过程；窗口 2 旋转角度及窗口 3 观察点固定 |
| 月食演示 | 播放 / 暂停 / 重启 | 播放一次特定月食的完整过程；相同视角限制 |
| 两类演示 | 速度 ×1、×5、×10 | 调整播放速度 |

待确认：两次特定食象的日期与类型；轨道位置滑块的单位、范围、默认值；“沙罗周期”控制的是时间、周期内进度还是其他教学参数；地影/月影模型；各窗口缩放范围；模式切换是否保留状态。

核对项：三个窗口与三种模式齐全；自由模式位置、自转和观察点控制有效；两类演示完整播放且可暂停、重启；三个倍率可选；固定视角限制按模式生效。
