## 正式功能、参数与核对项

### 场景与模式

日地月大小和距离允许为教学演示调整，**不追求精确仿真**。演示三者位置关系，并动画呈现地影、月影的范围。

| 窗口 | 内容 | 交互边界 |
| --- | --- | --- |
| 窗口 1 | 日地月关系 | 原文总则允许旋转、推拉镜头 |
| 窗口 2 | 地球观察视角 | 自由模式可点选窗口 3 观察点；演示模式旋转角度固定 |
| 窗口 3 | 地球表面观察视角 | 原文总则允许旋转、推拉；演示模式地表观察点固定 |

演示模式的明确限制优先于“三个窗口均可旋转推拉”的总述；固定观察点是否还允许局部转向和缩放，需要确认。

| 模式 | 控制 | 行为 |
| --- | --- | --- |
| 自由探索 | 地球公转轨道位置滑块 | 改变日地月位置关系 |
| 自由探索 | 月球公转轨道位置滑块 | 改变日地月位置关系 |
| 自由探索 | 沙罗周期滑块 | 改变原文所述“沙罗周期”参数，具体含义待确认 |
| 自由探索 | 地球自转开关 | 控制地球自转 |
| 自由探索 | 在窗口 2 点击地球 | 设置窗口 3 观察点 |
| 日食演示 | 播放 / 暂停 / 重启 | 播放一次特定日食的完整过程；窗口 2 旋转角度及窗口 3 观察点固定 |
| 月食演示 | 播放 / 暂停 / 重启 | 播放一次特定月食的完整过程；相同视角限制 |
| 两类演示 | 速度 ×1、×5、×10 | 调整播放速度 |

待确认：两次特定食象的日期与类型；轨道位置滑块的单位、范围、默认值；“沙罗周期”控制的是时间、周期内进度还是其他教学参数；地影/月影模型；各窗口缩放范围；模式切换是否保留状态。

核对项：三个窗口与三种模式齐全；自由模式位置、自转和观察点控制有效；两类演示完整播放且可暂停、重启；三个倍率可选；固定视角限制按模式生效。

## 2026-11-12 两视角方案（当前默认入口）

用户确认两张灰度构图后，默认 `index.html` 改为公转总览与地月观测两视角。此项取代上文五章导航作为首页的安排；旧五章入口保留为 `course-preview-20261112.html`，不占用默认入口。

- 首页仅保留日期、公转进度及进度行内的播放/暂停按钮；普通状态无常驻说明、章节、读数面板或 Tips。
- 日期对应无年份平年中的年度位置，独立调节；当前不声明真实日历食象或未经确认的月年周期比。月球默认自动公转（系统减少动态效果时暂停），月面同步自转，同一侧始终朝向地球。
- 继承当前模型的 5.145° 倾角及教学几何，不放大物理倾角。低仰角投影、蓝灰黄道面、金色倾斜轨道、虚实线和两交点共同表达两平面关系。
- 当前日期下，前方 18° 内的新月/满月位置通过已有三维遮挡判据时才出现 Tips。18° 是交互提前量，不是食象科学阈值；日期变化、离开临近区、进入观测时提示重新计算或隐藏。
- 点击提示进入对应日/月食地月观测，保留月球相位和年度位置，暂停以供观察；返回总览保留相同状态。观测页只保留返回、当前食象和公转播放/进度。
- 天体半径与距离为教学展示比例。影锥纵向距离压缩、横向半径保持可读，球面遮挡仍由原三维模型判定，不把示意影锥当作真实比例测量图。
