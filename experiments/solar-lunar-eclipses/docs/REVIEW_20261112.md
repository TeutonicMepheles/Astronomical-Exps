# 日月食 Demo 评审与优化 · 2026-11-12

依据：用户本轮要求；飞书《日月食实验-页面功能规格》（2026-11-12 读取）；仓库正式规范与待确认项。

## 发现与处理

| 差距 | 本轮处理 |
| --- | --- |
| 功能按钮平铺，缺少课程推进和总结 | 五章导航、前后推进、条件回顾，可直接返回任一章 |
| 完整公转仅斜视开放；斜视又换成另一月份 | 独立轨道条件章，统一月球相位与地球公转相对方向；两个 0–360° 控制，支持播放一周 |
| 倾角难读、为什么不是每月有食不清楚 | 黄道面、月球轨道、交点线、5.1° 局部剖面、交点对齐/错开对照 |
| 地月近景不够大 | 调整相机，提供影区放大，保持天体同框 |
| 光路本影/半影无法对应地球投影 | 受影面正视地球，以三维地表采样计算太阳可见比例；同一状态展示地表本影和渐变半影 |
| 半影只靠颜色，不解释原因 | 固定术语与直射光遮挡说明，影锥直接标注名称 |
| 月全食红光成因不明确 | 保留红月与影区红光，补充大气折射光路示意及讲解 |
| 缺少重播与速度控制 | 增加重播、×1/×5/×10；修正暂停时插值仍继续的问题 |
| 自由拖天体与会议要求冲突 | 取消直接拖天体，使用固定轨道时间滑块 |

## 仍未作为已完成功能

- 未采用真实日期与观测地点的事件回放；地面观测点沿用原有月下点模型，不能声称是固定地理地点的一场真实日食。
- 环食、独立偏食课程和半影月食不作为本轮已批准必做项。
- 历史三窗口、自由模式、沙罗周期与会议新要求的关系尚未正式确认。
- 完整公转章用于发生条件教学，食象五节点章使用原有压缩几何，两者不宣称统一精密天文仿真；接近交点不是保证全食的判据。
- 原有地球纹理仍引用另一实验的 assets，属于既存离线打包依赖，未扩展为代码引用；日月食尚未接入根导出工具。

## 同日返修：倾角、交点与真实入影条件

用户要求完整公转时，两种主视图均清楚呈现月球轨道与黄道面的倾角、交点，并比较经过/偏离交点，解释新月和满月不必然出现食象。

### 实现与模型边界

- 主视图加入蓝色虚线黄道面边界、暖色月轨、绿色交点与交点线、月球到黄道面的连线、约 5.1° 的局部剖面，以及离交点角距/黄纬读数。另可切换轨道全景，不改变当前公转进度。
- 交点对齐/错开按钮比较日地连线与交点线的相对方向；定位新月/满月保持同一相位方便对照。这是发生条件教学，不是沙罗周期或真实月份预报。
- 旧 4.6 RE 共面几何即使增加 5.145° 也会让离交点的月球仍落入巨大的压缩影区，不能用于此因果教学。主几何改为三维圆轨道：倾角 5.145°，月轨半径 20 RE、太阳距离 200 RE、太阳半径 2.5 RE、月球半径 0.2646 RE；除倾角外均属于明确的教学几何，不宣称是真实比例或精密预报参数。
- 遮挡、球面影斑、地影横截面、月球红光和地面小窗均基于同一三维位置，包含离黄道面高度。显示层另做球间距离压缩；近景保留横向入影尺寸，全景按距离压缩月球显示大小，防止把放大的月面误画成跨越原本错开的影区。显示投影不参与科学判定。
- 节点预设始终在对齐条件下求解，求解后恢复原朝向。错开时禁用不适用的五节点及旧专项视角，不能用不存在的“初亏/食甚”覆盖无食状态。
- 新轨道与遮罩缓存键包含交点朝向、月球三维坐标、尺寸或材质就绪状态，避免同一公转角切换朝向时仍显示上一状态。仍使用既有单一动画时钟，有限尺寸的单张遮罩缓存。

### 验证

- `test-inclination-model.cjs`：验证轨道平面法向确为 5.145°、两个交点、节点求解不改变朝向；对齐新月/满月为全食、错开时无食；只在交点但并非满月不发生月食；地表照明一致。
- `test-inclined-orbit.cjs`：两种主视图对齐/错开对比、18 个整圈位置、10 个食相快捷定位、禁用节点恢复、无浏览器异常。
- 既有完整公转、课程、月面同步专项已随实际三维投影更新预期位置，原有无滚动、像素同步、食象状态断言保留并通过。
- 已检查近景及轨道全景截图。Chrome 157 短时整圈调轴采样仍约中位数 13.3 ms、P95 13.4 ms；不代表低端白板、长期内存或科学模型标定完成。


## 同日返修：连续地球公转

用户要求交点朝向不能仅用预设切换，应连续调节一年地球公转，观察日地连线与交点线关系，并与月球完整公转、影区和小窗同步。

- 日食/月食主视图底部加入 0–360° 地球公转轴，步长 0.1°，保留原月球周期轴。两个参数可以独立调节；预设按钮仅快捷定位到年度 0°/90°。
- 在地心随日地连线转动的主视角中，交点线相对角度为地球年度角的相反数；一年俯视示意同时显示地球绕太阳的位置、日地连线和近似固定的交点线，避免把节点预设误解为随意旋转月轨。
- 0°、180°、360° 都回到日地连线与交点线对齐；90°和270°为错开。食象与月面由连续三维几何计算，不做四个季节贴图切换。
- 年度对比播放明确标为“定相位”：固定当前月球相位比较一年内相同新月/满月条件；并非真实月球逐月事件序列，也未假定未经确认的月/年播放比例、真实日期或沙罗周期。该教学模型暂不计交点进动。
- 年度和月球手动拖动均暂停播放。章节间共享年度状态，首章原年度控制也接到同一来源。月球位置、影区、地表遮罩、观察点、地面月面及年度示意在同一既有 rAF 中更新。
- 未新增时钟或无限缓存；年度角纳入既有遮罩及三维月面缓存键。保留近景/全景选择，调轴不会反复重置相机或缩放。
- 新增 `test-annual-orbit.cjs`：两种模式连续角度（含 12.3°、72.4°）、半年对齐重现、错开无食、月球/年度独立调节、定相位年度播放及终点、主图/地面月面颜色同步、跨章状态及 4:3/16:9 无滚动。
