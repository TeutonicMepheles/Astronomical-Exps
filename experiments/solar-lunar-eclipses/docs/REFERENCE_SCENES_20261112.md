# 科普视频典型影区与公转总览（v17）

参考用户提供的 139.76 秒科普视频及五张截图，查看了 00:49、01:21、01:32、01:40、01:52 的画面。仅借鉴其本影/半影/伪本影和观察点食象的对应关系，保持本实验原相机、地月位置、球径、轨道及页面布局。视频没有复制到发布资源；提取帧仅用于本地核对。

## 已实现

- 观测调节内增加“典型场景（示意）”：日全食、日环食、日偏食及自由观测。全食的 A 点位于本影，环食的 A 点位于伪本影，偏食的 A 点位于半影。偏食场景表达观察点看到偏食，不宣称整个地球都没有本影。
- 影锥分为连续的半影、本影和锥尖后的伪本影。伪本影从本影顶点向外展开，紫色轮廓；本影保持金色，半影保持青色。到接收球的首次交点后截断，同一母线不能在球后重现。未进入接收球的母线仍保留其完整几何。
- 典型场景的体积网格、球面阴影、交线、A 点、观察小窗、食相节点及 ×2/×4 放大共用一套展示几何；环食有“环食始/环食终”节点。A 点标记缩小，避免盖住小本影边界。只有伪本影确实露在接收球前时才显示其引线标签。
- 公转总览在原视角、平视及垂直黄道面三个视角持续绘制地影与月影，不限于新月/满月。两锥轴分别从实际绘制的太阳指向相应遮挡球，并进行两球深度遮挡及接收球首次截断；远端按画面边界淡出，不移动天体来容纳影锥。
- 修正本影顶端淡出参数的逆序 smoothstep；完整本影在真实顶点收束，不依赖未定义的逆序插值。

## 展示参数及范围

原自由观测沿用 EclipseModel，未改变其太阳、半径、距离、倾角或运动周期。典型场景通过 `reference-scene.mjs` 使用原屏幕中球体的三维中心与半径，刚性映射到同一展示坐标，避免重定向锥轴来对准球体。全食的太阳/月球角半径比例由原模型交点对齐时的比例导出，环食将该比例倒置；据此计算示意光源半径。偏食移动 A 点进入半影，不移动地月。上述是明确标识的教学构图参数，不是真实日月距离变化、历法食象预测或新的天文测量值。

总览的纵向锥长是教学显示压缩，太阳图标大小也不构成统一比例测量图。旧自由观测中主图接触与原模型食相时刻不完全一致的问题仍保留在 [v16 记录](LIGHT_DIRECTION_20261112.md)；不能把典型场景一致性通过表述为旧自由模式全部问题已修复。

## 验证

- `test-reference-scenes.cjs`：48 个总览状态（3 相机 × 4 年度位置 × 4 月球相位），两影锥都附着于源球且背向画面太阳；三个典型场景分别判为全食、环食、偏食，主图真实 GPU 球面阴影与 A 点视圆遮挡的明暗一致。保存三个食甚、全部食相节点、三个 ×4 放大，以及六张总览整页图。两种白板视口无页面滚动，原地球中心、半径不变。
- `test-antumbra-raster.cjs`：20 个锥尖后接触案例。专门关闭普通球体遮挡，以独立射线/球面首次交点校验实际 GPU 伪本影裁切，没有泄漏或有效片元缺失。
- `test-shadow-raster.cjs`：原本影/半影 144 个接触案例通过。
- `test-shadow-layout.cjs`：30 个原视角/布局状态通过。
- `npm run check`、`npm test`、`npm run test:browser` 通过。后者仍是根项目公共浏览器冒烟检查，EXP-06 使用上述专项。
- `test-observation-audit.cjs` 的功能检查执行到了返回首页，但最后 PNG 完全相等失败，重复执行仍有差异；失败对照中为约 31 个像素、每通道最大 1 色阶。`test-overhead-camera.cjs` 首次在少数锥面线条像素处最大差 4，原断言重跑通过。原断言全部保留，不能宣布所有浏览器/像素回归通过；也未证明差异的具体底层成因。最后新场景与裁切专项重新通过。

性能专项检查适用项：总览从无影锥增加为两源锥面，伪本影增加第三段网格，典型场景增加展示几何求交与小窗计算。复用一个影锥上下文、buffer、program 和原动画时钟；A 点寻找缓存最多 8 项，放大窗仍复用球面场渲染器。最后串行本机采样（其他浏览器测试已结束），总览 2.5 秒 p95 14.1ms、max 14.4ms；环食放大 p95 7.3ms、max 14.1ms，均未记录 long task。此为 rAF 采样，不是绘制 FPS 或正式 INP；不能替代白板、低端设备或长期运行验收。原始状态、浏览器版本与采样见 [review.json](reference-scenes-v17/review.json)。
