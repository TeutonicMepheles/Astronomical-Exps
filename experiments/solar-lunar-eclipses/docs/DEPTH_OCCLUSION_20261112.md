# 首页遮挡修正

用户反馈：月球与地球重叠处的遮挡关系不正确。

原首页仅按月球中心深度排列两个球体，轨道整体提前绘制，自转轴则直接覆盖自身球体。导致前半圈轨道也消失在地球后方，轴穿过不透明球体。

修正：日地月使用统一的相机空间显示深度排序。年度轨道、月球轨道、黄道轮廓、交点连线与自转轴按球面前表面深度裁切，保留可见线段；月球完全被地球遮住时隐藏月球文字。透明辅助面先绘制，不给球体染色。首页布局、天体大小、轨道倾角与统一时间倍率保留；观测视角使用原有渲染路径。

## 验证

- `test-overview-depth.cjs`：前后遮挡、球面深度（非仅中心深度）、球缘线段分割。
- `test-overview-depth-browser.cjs`：后方月球位置与无遮挡地球像素比对，前方月球覆盖地球像素断言，整圈 36 个位置，无页面错误。截图 `overview-depth-front-v5.png` / `overview-depth-back-v5.png`。
- `test-uniform-time-browser.cjs`：自动运动、共同暂停、日期同步、两行控件。
- `test-observation-audit.cjs`：双模式食相节点、播放控制、观察点同步、返回首页像素一致。

- 项目级 `npm run check`、`npm test`、`npm run test:browser` 全部通过。

## 性能专项检查

适用风险为每次重绘新增少量线段的深度计算。沿用单一约 30 Hz 调度，无新增 WebGL 上下文、纹理、循环或逐像素全屏深度缓冲。按 0.75 个逻辑像素细分线段，最多对三个球面检查；输出线段只在本帧使用，不持久累积。

本机 Chrome 157、1600×900 短时整圈交互采样无长任务、无页面错误，原始记录 `overview-depth-perf-v5.json`。前次统一时间短样本同样无长任务；场景不同，不能作为帧率提升结论。已目视检查前后两张截图；智慧白板触控、低端设备及长时间运行未验收。
