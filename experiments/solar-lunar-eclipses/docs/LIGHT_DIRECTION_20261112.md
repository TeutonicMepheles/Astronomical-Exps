# 影锥与背景入射光方向统一（v16）

工作树：`B:/GithubProject/Astronomical-Exps-eclipse-course`；分支 `experiment/solar-lunar-eclipses/course-20261112`，基于 b37d493；服务 127.0.0.1:9012。已有未提交工作保留，本次没有提交或推送，只修改 EXP-06。

## 原因与修改

v15 虽然保持每条母线连续，却使用接收球位置重新计算整个锥轴，造成月球移动时地影转向、背景光和影锥不同向。现在取消接收球对轴向的影响；轴向只由太阳到遮挡球的向量决定。`shadowAxisVector` 为影锥与背景光共用的投影，纵向压缩只影响长度，不再为命中接收球转动轴向。

背景箭头按同一方向和垂线构造，去掉与斜向光线不符的横向文字箭头。观察球体受光使用相同入射轴；球面阴影、两色描边和放大窗使用修改后的连续锥面。原相机、地月中心、半径、轨道与缩放复位均保留。模型中的太阳、半径、距离、轨道和食相算法未改。

`shadowAxis` 和 `shadowSource` 诊断数据改为实际锥面映射的结果；旧诊断用天体投影，不能证明旧版网格方向正确。

## 验证

- `test-light-direction.cjs`：42 个日/月食状态，年度 0/60/90°、食甚前后 ±5/15/25°；实际锥轴、背景光与独立太阳到源球投影的单位方向逐项吻合，三维分量误差小于 1e-11；地球原中心和半径不变。
- `test-shadow-axis.cjs`：27 个季节/全食/半影/错过状态，月食地影不再随接收月球转向。
- `test-shadow-layout.cjs`：30 个原布局浏览器状态、20736 条直母线、7988 个球面求交通过。
- `test-shadow-surface.cjs`：18 个状态的球面描边，没有越出球面，亮芯与独立场的误差小于 2 像素。
- `test-smooth-shadow.cjs`：140544 个顶点连续性、48 张接触前/接触/接触后截图、×2/×4、主场景不变、无残留及渲染器复用通过。接触搜索范围扩为食甚 ±40°，避免仍用旧偏转锥面的较窄接触范围漏测。v15 证据保留，新截图另存 `smooth-shadow-v16/`。
- `test-overhead-camera.cjs`、`test-observation-audit.cjs`、`npm run check`、`npm test`、`npm run test:browser` 均通过。这些自动检查不覆盖下述食相一致性缺陷。

性能专项检查：本次减少接收球重定向计算，没有增加网格、上下文、buffer、纹理、缓存或动画时钟。所有其他浏览器测试结束后串行采样，Chrome 157.0.8103.39、1600×900、本机 2.5 秒：普通观察 193 帧，p95 13.4ms、max 13.7ms；放大观察 192 帧，p95 13.4ms、max 13.8ms；未观察到 long task。不是白板、低端 GPU、长期运行验收。原始数据见 [方向检查及独立性能采样](light-direction-v16/review.json)。`smooth-shadow-v16/review.json` 的采样期间存在其他浏览器测试，不用于性能比较。
