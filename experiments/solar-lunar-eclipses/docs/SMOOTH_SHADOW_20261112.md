# 连续影锥、球面描边与受影面放大（v15）

本次只修改 EXP-06。原观测相机 yaw=.75、elevation=.16、地球中心（日食 900,435；月食 570,435）、半径 148、月轨映射和缩放复位均保留。总览原视角、平视与垂直黄道面切换保留。

## 修正

旧版按每条母线是否命中接收球单独重定向，命中/未命中相邻顶点会拉出尖刺。现在整个锥面共用一个连续仿射映射，所有母线保持直线、同轴截面保持圆形；网格不按命中状态搬动顶点。教学场景的天体距离与半径本来采用不同缩放，该影锥显示适配不能称为统一比例物理相机或科学模型标定。

GPU 对每个片元计算显示球首次交点，删去进入球内及穿出球后的同一母线片元；另保留两球的深度遮挡，源球投影内不再叠加影锥。没有命中接收球的母线仍属于完整锥面，不把它们硬拉到球边。锥面用连续径向法线着色，远端淡出，未增加接触时的扇形封口。

球面阴影和描边共用锥面映射的逆变换，重建可见半球，求本影/半影隐式交线。金色本影、青色半影采用抗锯齿窄亮芯、微弱光晕和暗色衬线。只显示首次入射交线；月球完全位于本影内部时，不凭空补一个不存在于球面的边界环。未跨实验引用牛顿实验的私有线条实现。

“受影面放大”暂停当前运动，打开同方向 ×2/×4 观察窗；仅放大接收球及阴影，不调整主场景相机、缩放或天体位置。关闭按钮及 Escape 均可返回。无食象时清除旧阴影；重复打开复用原渲染器。阴影与描边按观察窗分辨率重新计算，底层天体纹理沿用原球渲染结果。

## 验证及边界

- `test-smooth-shadow.cjs`：140544 个锥面顶点覆盖日/月食、年度位置 0/60/90°；相邻角向弦长最大误差 2.94e-13。保存 48 张显示球接触前/恰好接触/接触后整页截图，另有食甚、×2/×4 和半影月食截图。检验主图几何不变、暂停、关闭、无食象无残留及渲染器复用。
- `test-shadow-layout.cjs`：30 个浏览器状态逐一对照原相机/球体布局，20736 条连续母线与 1311 个独立球面求交通过；包含模型球与显示球分离时的实际 GPU 裁切。
- `test-shadow-raster.cjs`：144 个独立 GPU 接触案例，无被截断部分漏出或有效部分丢失。
- `test-shadow-surface.cjs`：18 个日/月食状态，描边没有离开接收球；颜色亮芯与独立锥面/球面场的偏差均小于 2 逻辑像素，食甚两色边界均存在。
- `test-overhead-camera.cjs`：垂直投影、相机往返、原观测几何与像素回归通过。曾定位到源球边缘叠加片元造成差异，补源球遮挡后通过；未降低原像素断言。
- `test-observation-audit.cjs`：旧控件、两模式食相节点、上/下一步、重播、倍速、暂停、键盘、年度/交点、原缩放及返回首页像素全等通过。
- `npm run check`、`npm test`、`npm run test:browser` 通过。工作树复用主仓库本地 Playwright 依赖（NODE_PATH），不引入运行时外部资源。

性能专项适用：有界网格上传、透明混合、解析球面着色、缩放窗复用与生命周期。仍只有一个动画时钟；影锥和球面场各持有固定 WebGL 上下文、buffer/program，pagehide 释放。观察窗不会按开关次数创建渲染器。最终本机 2.5 秒采样：普通观察 192 帧，p95 13.4ms、max 13.9ms；放大窗 192 帧，p95 13.4ms、max 13.5ms；两者均未观察到 long task。不能据此声明白板、低端设备或长时间运行验收通过。

接触与脱离截图已人工查看，包含日/月食及半影月食；自动几何与像素检查不等于用户最终视觉认可。原科学参数和食相判据未改。完整状态、截图名与采样见 [review.json](smooth-shadow-v15/review.json)。
