# 观测点连续移动（覆盖此前渐变方案）

用户明确要求与相机切换一样连续运动，拒绝淡入淡出。删除两张画面快照和透明度合成。A／B／C 与球面点选统一驱动 1 秒 smoothstep 球面最短弧插值，插值对象为固定于地球表面的观测位置；主画面的选中环随位置移动，当地天空小窗从同一个中间位置实时求解。

已选点之间切换保留当前相位、自转与模拟日期，暂停播放并取消旧阶段目标，避免切点造成月球与地球跳回各地初始时刻。首次选点仍初始化该点事件起点。右侧阶段属于目标点，移动完成前锁定阶段与播放控制，之后使用目标地点自己的接触时刻。中间位置只用于过渡画面，不新增可选或保存地点。

快速改选从当前插值位置接续；重复当前目标不重启。相机与观测位置可以同时连续运动，互不取消；切换食象取消位置移动。减少动态效果偏好下直接到达固定目标。

性能专项：沿用原单 rAF 与绘制节流，每帧仅插值坐标、绘制选中环并刷新当地天空；移除原两张大画布快照，无新增时钟、WebGL 实例或逐帧快照分配。结束后停止额外绘制。未做白板设备或长时性能验收。

专项 test-observer-transitions.cjs 验证三类日食的真实中间经纬度／天空状态、固定模拟时间、目标地点与标签、连续改选、相机同时转场、月食重置与减少动态效果；证据 continuous-results.json 和 continuous-*.png。此前 results.json 与 midpoint.png 为已废弃渐变方案记录，不代表当前效果。

项目检查 npm run check（0 errors）、npm test、npm run test:browser 均通过。球面插值另核验起终点及中断后起点连续性，使用浮点容差。当前只修改本实验，未提交或推送。
