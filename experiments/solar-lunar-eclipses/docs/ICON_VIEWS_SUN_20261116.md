# 独立图标相机、太阳轮廓与公共光线 · 2026-11-16

用户最新要求覆盖之前的无太阳双栏方案：两个 ICON 按钮分别显示侧视／俯视；地球必须渲染影锥；太阳巨大化，仅在一侧露出部分轮廓；太阳平行光复用公共组件并降低透明度。

默认单画面侧视，右上两个独立 SVG 图标按钮具有“侧视／俯视”的可访问名称、title 和选中状态，点击不改变食象、地点、进度或播放状态。侧视／俯视继续使用正交相机与地心居中适配，小数 DPR 的画布尺寸取整修复继续保留。

地球影锥原先仅在月食模式绘制，本轮将它改为所有食象持续存在的独立锥面：有限太阳与同一地球半径计算本影、半影，日食同时保留月球影锥。月球伪本影仍只在环食显示。完整包络纳入相机适配。太阳左缘轮廓的显示中心为 (-950,450)、显示半径 1115，仅为用户要求的巨大化构图，不将该显示轮廓替换科学模型太阳半径或用于接触求解。

光线通过 shared/components/optical-beam.js 的公开 OpticalBeam API 生成，setOpacity(0.10)。js/sun-rays.mjs 仅负责宿主线段端点、正交相机、透明画布合成、缓存与销毁，不再自行绘制线条、箭头或光晕。Three.js r160 独立离线副本及 MIT 许可证放在本实验 vendor；无跨实验运行时依赖，不修改公共组件。平行光方向取同一太阳向量；固定方向和尺寸的光场缓存，不在每一帧重建几何。

## 验证及性能专项

test-observation-icons.cjs 覆盖 4 食象 × 5 阶段 × 2 相机 × 3 DPR，共 120 组：两个图标按钮、状态保持、地球影锥、巨大太阳轮廓、公共 OpticalBeam 标识、实际球体像素、C 观察点播放中切换及放大窗。页面异常和 HTTP 错误均为 0。截图与结果在 icons-20261116/。旧单按钮、无太阳、并排对照测试记录属于被本次明确要求取代的历史方案；test-observation-camera.cjs 路由到本轮专项。

性能适用项为新增一套地球体积绘制、共享 OpticalBeam 的 Three.js WebGL 实例、光场几何缓存与销毁。只使用原来的动画调度，固定光场按方向和尺寸缓存；clear/dispose 仅使用公共 API，页面卸载时销毁 renderer 和 context。不探查公共组件内部 DOM，不改 shader 或材料制服。短时性能证据另存 icons-20261116/performance.json；白板触控、真实设备与长期运行仍待验收。

用户要求同时显示黄道面与月球公转平面，允许侧视夹角放大到 10°。当前默认入口调用本实验模型的 setTeachingInclination(10)，两个平面采用蓝灰／金色半透明填充与独立轮廓、名称。实际月轨、月球位置、影锥及接触求解共用该教学倾角，两个相机切换不改变食象状态；不通过单独拉斜辅助线制造与月球位置不同的平面。真实平均轨道倾角约 5.145° 仍为基础模型默认值，当前入口明确使用 10° 教学值。太阳和天体半径等既有常量不变，不声明真实日期或时长预测精度。

实测教学轨道法线夹角 9.999999999999975°，侧视对照截图为 icons-20261116/planes-10-degree.png；基础模型 test-inclination-model.cjs 继续通过，当前入口的 120 组专项也验证 teachingInclination=10 和两个平面均存在。

最终串行短时采样：本机 Chrome 无头、1600×900、DPR 1，两种相机各连续播放约 2.5 秒；侧视 rAF 平均 13.30 ms、P95 13.40 ms；俯视平均 13.28 ms、P95 13.40 ms；均无长任务。rAF 回调频率不等于保留原节流的场景绘制 FPS，不能据此替代真实设备及长期运行验收。数据见 performance.json。

同轮用户进一步修正：侧视黄道面只以太阳可见边缘到地心的一根直线表示，不绘制黄道面的封闭轮廓或填充，避免与金色月球公转轨道混淆；取消角度数字标注。当前侧视使用两个端点的实线，太阳端点取巨大太阳轮廓与地心水平线的交点，地球端点为地心；球体仍自然遮挡其后的线段。金色月球公转平面独立保留，角度数值不再显示，教学几何仍使用已授权的 10°。俯视保留原平面表达。专项增加侧视两端点、太阳到地心连线和俯视闭合轮廓的断言；本项只改变辅助图形和文本，不改变科学参数或渲染调度，因此不要求重做完整性能基准。
