# 日月食实验 · 第一版演示页（2026-11-09）

独立评审页，暂不接正式实验路由。文件与打开方式见文末。

## 这一版解决什么

按 2026-11-04 会议需求与逐字稿，做一版可点的「三球仪太空视角 + 分步定格」：

- 太阳只作为光源：画面里没有太阳实体，只有左侧暖色光晕与平行光线；
- 地球、月球两个球体常驻，各自带本影锥与半影锥；
- 观察者小窗同步显示「从地球看」的现象（正午看日食、午夜看月食）；
- 日食 / 月食各 5 个节点（初亏 → 食既 → 食甚 → 生光 → 复圆），可播放/暂停、上一步/下一步、点节点跳转；
- 节点名称、一句话说明、当前食象类型常驻左上与右上；其余信息用折叠面板收纳。

## 几何做法（不是手调动画）

`js/eclipse-geometry.js` 只算数，不碰 DOM：

- **影锥**：对「太阳圆 + 天体圆」求两组切线。外切线收敛到锥尖 = 本影，内切线发散 = 半影。
  两个锥都用同一套函数算，地球与月球没有特例。
- **五个节点**：不写死角度。以观察点看到的分离角与两个视半径做判据，
  二分求解 `分离角 = 视半径和`（初亏/复圆）与 `分离角 = 视半径差`（食既/生光），食甚取 0。
  假设改了半径或轨道，节点角度会自动跟着变。
- **月食红色**：由「月面落在地球本影内的面积比」驱动，红色叠加与该比例同源，
  小窗读数「本影 xx%」用的是同一个量。
- **日面遮挡**：两圆交叠面积 ÷ 日面面积，读数「遮挡 xx%」。
- **平行光**：水平射线遇球体即止，并用两张影锥多边形做遮罩，光线不会穿进本影/半影。

## 交互节奏

- 进场：光线 → 影锥 → 标注 → 节点轨依次淡入，约 1.5s 后自动推进到「初亏」。
- 播放：沿轨道运行，到每个节点减速停住约 0.8s，再继续；暂停随时可停。
- 上一步/下一步：停在相邻节点，带缓动；节点轨可直接点。
- 键盘：← → 切节点，空格播放/暂停。
- `prefers-reduced-motion`：所有移动改为瞬时到位，只保留状态切换。
- 16:9 舞台 1600×900 等比缩放，无滚动、无悬停依赖。

## 已知取舍与待确认

1. **教学比例，不是真实尺度**：页面右上角标注「比例示意」。太阳半径/日地距离已压缩，
   月球轨道也压到地球半径的 3.7 倍；本影锥长度、遮挡比例都按压缩后的尺寸自洽计算。
2. **观察点固定**：日食取日下点（正午），月食取夜半球中点（午夜），不做地表城市定位。
3. **未做地球公转**：画面只呈现地月系统，太阳方向恒定从左射来。
4. **节点命名**：初亏/食既/食甚/生光/复圆沿用会议提议，逐字稿只明确了初亏与食甚。
5. **食象类型**：本页按「日全食 / 月全食」演示；未见环食、偏食的切换要求。
6. 小窗里月球的比例、整体色板、标注文案都可以再调，本版优先验证光影与节奏。

## 第二轮修订（2026-11-09 晚，按验收意见）

1. **观察点标出来了**：地球上新增标记「观察点」（点 + 环 + 引线），小窗标题改为
   「观察点所见 · 正午/午夜」。初亏时本影已落在地球另一侧、而观察点报 0%，不是矛盾，
   是「观察点」与「影锥落点」分处两处；原先没有标记，读者无从判断。
2. **日面视半径 300 → 420**（视半径 4.0°，月面 5.9°）：本影变窄，地面落影从约 27px 收到约 15px，
   月面/日面视比从 2.0 降到 1.4，小窗里的日全食更像日全食而不是「小黑球压小太阳」。
3. **小窗等比尺改为固定值**（由初亏那一帧反解）：原先 62/日面视半径 逐帧换算，
   初亏/复圆时月面半径 125px、中心偏移 187px，整个月面被 520px 画布切掉一半。
4. **日食小窗改成白昼天空**：遮挡 <90% 时是蓝天、无星；接近全食才压暗并浮出星点。
   原先正午强光下也画星空，是错的。月食窗口本就是午夜，保持星空。
5. **初亏/复圆的对称性**：两端的判据都是 `分离角 = 视半径和`，画出来的两帧严格相切
   （沿画布中线取样：月面下缘 y=200、日面上缘 y=201，间隔 1px）。验收时看到的「初亏留空隙」
   来自第 3 条的裁切，不是判据不对称。

### 一条几何约束（不是可以调参解决的）

「初亏时让落影刚擦到地球边缘」在这个尺度下做不到。设观察点在日下点、月心横向偏移 y，
接触条件给出 `y = 月半径 + 日视半径 × 月地距`；而地球半径 `R = 月半径 / 0.273`（真实比例）。
代入得 `y/R = (1 + 日视半径×月地距/月半径) × 0.273`。日面视比若 ≤1（能发生日全食的必要条件），
该比值恒 ≤ 0.55 —— 也就是初亏那一刻，本影锥必然已落在地球盘面内约半个地球半径处。
真实世界也是如此：初亏时影锥轴距观察点约 3550 km，而地球半径 6371 km。
要让它「擦边」，只能把太阳视半径做到月面的 2.6 倍以上，那样就只剩环食。**故不改，改用观察点标注消歧。**
Web-Designer 那版把太阳视半径放到 6°，锥尖正好落地表，代价是太阳视半径远超真实、本影斑退化成一个点。
