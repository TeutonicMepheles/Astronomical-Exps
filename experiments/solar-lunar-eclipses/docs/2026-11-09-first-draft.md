# 日月食原理演示 · 首版实现说明（2026-11-09）

分支 `experiment/solar-lunar-eclipses/first-draft-20261109`。
入口 `experiments/solar-lunar-eclipses/index.html`，纯静态、无依赖、离线可跑。

## 已实现

- 两种模式：日食 / 月食，各五个关键节点（初亏、食既、食甚、生光、复圆）。
- 主视角 1600×900：太阳（仅左缘光晕 + 平行光，不画实心天体）、地球、月球、地影锥（本影/半影）。
- 左侧「地面观察」小窗，与主场景共用同一套几何：日食时看太阳被咬、全食的日冕环；月食时看月面变暗、整轮入本影后转红。
- 交互：模式切换、单点节点、上一步/下一步、播放（逐节点定格约 0.9s）、键盘 ←/→/空格、`prefers-reduced-motion` 即时切换。
- 界面只有模式、阶段名 + 食型、进度、节点、播放控制，没有说明文字和图例。

## 几何怎么算出来的

- 影锥边界由「同一太阳半径 + 同一段距离」解析求出（内外公切线），不是画上去的装饰。
- 五个节点由二分求解接触条件：初亏/复圆 `sep = 日面视半径 + 月面视半径`（外切），食既/生光 `sep = 月面视半径 − 日面视半径`（内切），食甚取对日点。
- 地面本影斑只在「影锥轴真的切到地表且该处本影半径 > 0」时绘制，观测点标记、锥尖、斑心三者同点。
- 月面变红只由「本影深度」控制：半影内灰暗，整轮进入本影才转红。

## 参数与取舍

单位：地球半径 = 1。

| 参数 | 值 | 真实值 | 说明 |
| --- | --- | --- | --- |
| 地球半径 | 1 | 1 | 基准 |
| 月球半径 | 0.2646 | 0.273 | 接近真实 |
| 月球轨道半径 | 4.6 | 60.3 | 教学压缩 |
| 日地距离 | 22 | 23481 | 教学压缩 |
| 太阳半径 | 1.30 | 109 | 教学压缩 |

- 食甚时：日面视半径 3.55°、月面视半径 4.22°、**月/日视比 1.19**（真实 1.03–1.08）。
- 视比与「地面本影斑大小」反向相关（几何关系，不是参数选择）：`SUN_R` 调到 1.43 视比进真实区间（1.08），但初亏斑从 6.8px 掉到 2.1px、食甚 3.9px；1.50 时初亏/复圆斑归零；1.543 是能否成食的界（视比 1.00）；再大即非全食且节点二分退化。
- 当前交付档位取 **1.19**：五个节点都有可见地面斑，代价是日冕环比真实偏宽。这是为了「影锥落到地面、地面的人看到日食」这条主线成立。

## 已知限制（重要，不要当成缺陷清单以外的东西）

1. **地球不公转**。太阳与地球的相对位置固定，画面上的运动只有月球绕地球公转。真实世界地球同时绕日公转；一个食过程（数小时）内这项影响很小，但「不同月份的日地位置变化」不在本演示内。
2. **没有月球轨道 5.1° 倾角**。因此本演示中每个新月都会发生日食；真实世界绝大多数新月月球从太阳上方或下方掠过，不成食。这是本演示最大的一处简化。
3. **没有椭圆轨道**。月球轨道按圆形、匀角速处理，因此各阶段时长比例固定；真实的近地点/远地点会造成食时长短与全食范围变化。
4. **距离为教学压缩**（见上表）。若按真实比例，月球本影在画面上细成一条线、地面斑不可见，演示反而不可读。
5. **观察点取「月下点」并随月球移动**，相当于观者始终位于最理想的位置；真实观者固定在地面某点，多数时候只看到偏食，看不到全食。
6. **太阳只画左缘光晕 + 平行光**，不画实心天体（设计前提）。

## 与正式需求（REQUIREMENTS.md）的范围差异

本版是「两类食象的分步演示」，尚未实现正式需求里的：自由探索（地月轨道位置滑块、沙罗周期滑块、地球自转开关、点选观察点）、三个窗口、播放倍率 ×1/×5/×10。这些属于后续迭代，不在本版范围。
