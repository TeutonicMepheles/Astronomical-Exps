# 日月食原理演示 · 首版实现说明（2026-11-09）

分支 `experiment/solar-lunar-eclipses/first-draft-20261109`。
入口 `experiments/solar-lunar-eclipses/index.html`，纯静态、无依赖、离线可跑。

## 已实现

- 两种模式：日食 / 月食，各五个关键节点（初亏、食既、食甚、生光、复圆）。
- 主视角 1600×900：太阳（仅左缘光晕 + 平行光，不画实心天体）、地球、月球、地影锥（本影/半影）。
- 左侧「地面观察」小窗，与主场景共用同一套几何：日食时看太阳被咬、全食的日冕环；月食时看月面变暗、整轮入本影后转红。
- 交互：模式切换、单点节点、上一步/下一步、播放（逐节点定格约 0.9s）、键盘 ←/→/空格、`prefers-reduced-motion` 即时切换。
- 界面只有模式、阶段名 + 食型、进度、节点、播放控制，没有说明文字和图例。

## 增补（同日，第二轮反馈）

甲方三条反馈 + 一条范围补充，落在同一页里：

1. **星球材质复用已有风格化材质**。地球与月球都改由 `shared/components/globe-shader-renderer` 绘制：地球用 `earth-circumference` 那套四张贴图（等距投影 / 颗粒 / 颗粒笔刷 / 陆地浮雕）+ 经纬网格；月球用新引入的等距月面贴图，同一套着色器出两版——侧光版给主场景，正光版给地面小窗。做法是把 WebGL globe 按 320×320 **一次性烘焙成 2D 精灵**（`js/planet-materials.js`），每帧只是 `drawImage`，不在渲染循环里跑 WebGL；`globe-texture-ready` 事件到了再烘焙一次。着色器自带的 0.75 环境光原本是给浅色纸背景星球用的，在深色场景里地球会发白，所以精灵之上另叠一层按地球圆盘裁剪的夜面渐变。
2. **公转进度可连续调节**。底部新增进度条（0–1000 对应一圈 φ），条下五个刻度就是五个关键节点；也可以直接在场景里拖月球。拖动时不跑二分（节点窗口只在模式切换时算一次），观测点的呼吸环在拖动时冻结，避免「拖到哪都在闪」。自由位置不落在节点上时，阶段名按规则显示：落在节点 ±0.35° 内用节点名，否则按食甚前后显示「全食 / 偏食」（月食同理）。
3. **观测点标注**。原先 `drawObserver` 已经有「月下点」位置但只在日食模式画、且无标注。现在两种模式都画，并加引线和「观测点」标签（小窗标题同步改为「地面观察 · 观测点」），鼠标进入小窗或拖动月球时引线加亮——标注和地面小窗的对应关系就此显式化。
4. **日地月三球联动视角**（甲方「至少要有一个日地月视角」）。相机拆成两个预设、状态完全共用：

   | 视角 | 相机 | 说明 |
   | --- | --- | --- |
   | 地月 | ex 912, ey 432, px 82 | 原样，太阳仍在画外，只有左缘光晕 |
   | 日地月 | ex 1240, ey 372, px 45 | 视野约 29.2 地球半径，太阳（−22 RE）与月球轨道（4.6 RE）同框 |

   日地月视角下才把太阳画成实心过曝天体（日冕 + 白热圆盘），地月视角保持「太阳只是光源」这条设计前提不变。影锥、平行光、轨道的绘制都按相机参数推导，不是两套图。切视角不重置进度、不重置节点名/食型、小窗内容也不变；切**模式**才回到初亏。

## 增补（同日，第三轮：食相轨）

甲方给了一篇讲「星轨式目录」控件的文章截图，希望用同样的包装形式讲日食/月食的几个阶段。原站只写了设计意图，没给实现，所以按它可观察到的四条口径自己实现：**读过的实线、未读的点线、琥珀点=当前位置、文字按距离衰减**（原站是三档：已过 / 当前 / 未到，这里叠了一层弱的距离衰减）。

1. **位置与避让**。轨道竖排在右缘，替换掉原来底部那条横向节点轨；底部的连续进度条（`scrub`）保留——竖轨讲「阶段」，进度条停「任意时刻」，上一轮的连续进度验收不受影响。

   | 元素 | 舞台坐标 | 避让对象 |
   | --- | --- | --- |
   | 轨道（弧） | x 1540→1566，y 180→744 | 右下播放控制顶边 y 784 |
   | 标签 | 右缘 1522，最小左边 1463 | 日地月视角轨道圆最右 1447 |
   | 顶部读数 | y 122（底 141） | 视角切换底边 y 100 |

   左侧不放的原因：日地月视角里太阳圆心 x=250、日冕外扩到约 200px，左列 y≈150 起就被占；再往下 y 448–800 是观测卡。

2. **刻度间距按 √跨度 加权，不按角度真值**。日食真实偏食段 : 全食段 = 10.6 : 1，照真值摆会把食既/食甚/生光挤成 24px 三连；开方后是 3.25 : 1，仍然不对称、看得出全食很短，但三个节点分得开。落在轨道上的位置：日食 0 / 38.3 / 50 / 61.7 / 100%，月食 0 / 23.6 / 50 / 76.4 / 100%（月食本来就接近等分，阻尼后基本不变）。节点之间按 φ 线性插值，所以琥珀点是**连续**的，实线/点线的分界就在点上。

3. **高亮挂在「已越过的最后一个节点」**，不挂「最近的节点」：点停在两节点之间时，琥珀高亮和读数里的阶段说明仍有归属，不会在中间点跳变。

4. 顺带修了一处旧逻辑：自由拖动时，落在两节点之间的阶段名原先按「最近节点」判段，生光之后那一半会误显示「全食」。现在按已越过节点判段（全食段 = 食既→生光，即已越过节点 1 / 2），生光之后显示「偏食」。

5. 无障碍与降级：标签是真 `<button>`，带 `aria-label` 与 `aria-current="step"`，可 Tab 聚焦、回车/空格跳转；顶部读数是 `aria-hidden`（`#live` 仍负责播报阶段名 + 食型）；`prefers-reduced-motion` 下不画尾迹、标签无过渡。键盘：焦点在按钮上时 ←/→ 仍可切换阶段，空格留给按钮本身。

## 几何怎么算出来的

- 影锥边界由「同一太阳半径 + 同一段距离」解析求出（内外公切线），不是画上去的装饰。
- 五个节点由二分求解接触条件：初亏/复圆 `sep = 日面视半径 + 月面视半径`（外切），食既/生光 `sep = 月面视半径 − 日面视半径`（内切），食甚取对日点。
- 地面本影斑只在「影锥轴真的切到地表且该处本影半径 > 0」时绘制，观测点标记、锥尖、斑心三者同点。
- 月面变红只由「本影深度」控制：半影内灰暗，整轮进入本影才转红。

## 参数与取舍

单位：地球半径 = 1。

| 参数 | 值 | 真实值 | 说明 |
| --- | --- | --- | --- |
| 地球半径 | 1 | 1 | 基准 |
| 月球半径 | 0.2646 | 0.273 | 接近真实 |
| 月球轨道半径 | 4.6 | 60.3 | 教学压缩 |
| 日地距离 | 22 | 23481 | 教学压缩 |
| 太阳半径 | 1.30 | 109 | 教学压缩 |

- 食甚时：日面视半径 3.55°、月面视半径 4.22°、**月/日视比 1.19**（真实 1.03–1.08）。
- 视比与「地面本影斑大小」反向相关（几何关系，不是参数选择）：`SUN_R` 调到 1.43 视比进真实区间（1.08），但初亏斑从 6.8px 掉到 2.1px、食甚 3.9px；1.50 时初亏/复圆斑归零；1.543 是能否成食的界（视比 1.00）；再大即非全食且节点二分退化。
- 当前交付档位取 **1.19**：五个节点都有可见地面斑，代价是日冕环比真实偏宽。这是为了「影锥落到地面、地面的人看到日食」这条主线成立。

## 已知限制（重要，不要当成缺陷清单以外的东西）

1. **地球不公转**。太阳与地球的相对位置固定，画面上的运动只有月球绕地球公转。真实世界地球同时绕日公转；一个食过程（数小时）内这项影响很小，但「不同月份的日地位置变化」不在本演示内。
2. **没有月球轨道 5.1° 倾角**。因此本演示中每个新月都会发生日食；真实世界绝大多数新月月球从太阳上方或下方掠过，不成食。这是本演示最大的一处简化。
3. **没有椭圆轨道**。月球轨道按圆形、匀角速处理，因此各阶段时长比例固定；真实的近地点/远地点会造成食时长短与全食范围变化。
4. **距离为教学压缩**（见上表）。若按真实比例，月球本影在画面上细成一条线、地面斑不可见，演示反而不可读。
5. **观察点取「月下点」并随月球移动**，相当于观者始终位于最理想的位置；真实观者固定在地面某点，多数时候只看到偏食，看不到全食。
6. **太阳只在日地月视角画成实心天体**；地月视角仍只有左缘光晕 + 平行光，这是刻意的设计前提（太阳在这条主线里是光源，不是观察对象）。
