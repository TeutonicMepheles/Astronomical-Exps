# 四视角连续转场

四个 ICON（日食观察、原侧视、正视、俯视）互切统一使用 1.4 秒 smoothstep 时间曲线。相机方向用四元数最短路径插值；缩放、画面中心及太阳轮廓、轨道辅助线透明度同步插值。日食观察保留右侧略高的月球过肩构图，月食默认原侧视。

连续点击会捕获当前插值后的相机基向量与实际绘制的中心、缩放、辅助线透明度，作为新转场起点。复用原单一 rAF、绘制节流及公共光场实例，不增加时钟或每帧光线几何。转场结束后暂停状态恢复按需绘制。系统偏好减少动态效果时直接抵达目标机位。

`test-camera-transitions.cjs` 通过全部 12 个有向视角组合，验证存在中间姿态、地轴相对黄道法线始终 23.44°、相位／自转／地点／地面小窗不变；另验证中途改向连续、播放不中断和减少动态效果偏好。证据为 `camera-transitions-20261116/results.json`，正视截图已回看。

适用性能专项：Canvas/WebGL 绘制、单时钟与空闲停止、资源复用。本轮未新增渲染实例或持续缓存；自动化不替代白板设备、长时性能或用户视觉验收。

最终回归：npm run check（0 errors）、npm test、npm run test:browser 均通过；日食过肩机位 45 个当地阶段、原三视角 180 组食象／阶段／DPR 组合均通过。专项采用串行浏览器执行。
