# 纠正弯管状影锥与验收覆盖

> 历史方案，已被用户后续“恢复原视角和地月布局”的明确要求替代。当前实现见 [SHADOW_LAYOUT_RESTORE_20261112.md](SHADOW_LAYOUT_RESTORE_20261112.md)。

## 原问题及判断修正

用户指出月食出现脱离地球、向上弯折的巨大管状影锥。该反馈成立。此前使用径向压缩后的天体位置，又把锥轴分段拼接到接收球附近，以保持局部球面交线贴合；这一非线性映射破坏了直母线和固定地影方向。月球在偏离交点的位置移动时，地影本身被牵引，出现弯折、悬空的管道。

v11 的首次交点数学检查与局部接触截图不能证明整景几何正确；此前“当前采样未发现”不应被当作整体视觉通过。原来的图集把接收球作为局部裁切重点，也遗漏了根部与全长轴线的问题。本轮不再沿用该整体结论。

## 改动

- 删除分段拼接、径向距离压缩及各对象不同的横向比例。地球、月球、轨道、影锥、截面参考圈和球面交线共用同一个正交三维投影，影锥直接投影模型中的三维点。
- 为了在相同视口看到真实地月几何，观测镜头改为接近日地轴方向的斜视角，通过视角缩短屏幕上的地月间距。大幅偏离食相时按可用画幅连续调整比例；“轨道全景”使用全轨道比例，放大按钮回到近景。总览镜头不变。
- 不修改 `EclipseModel` 的太阳/月球/地球半径、距离、轨道和遮光算法。显示取景不再改变影锥自身几何；地影轴永远沿背向太阳的方向，不能随月球公转或年份偏转。
- 减弱半影的蓝色与不透明度，降低黑色本影对整个画面的压盖；对非物理的显示范围末端渐隐，消除人为截取终点像硬质管口的效果。真实本影锥尖保留，入射球面的截断、描边与深度遮挡保留。
- 标签位置跟随同一投影，避免“月球轨道”文字在近景左边被裁掉。
