## 实现

- `shadow-volume.js` 用本影、半影的圆周截面生成三角曲面，圆周 96 段、轴向 32 段；共享当前动画调度，没有新增动画时钟、远程依赖或 Three.js 副本。
- `shadow-geometry.mjs` 解析求解锥面母线与球面交点。地表线直接投影这些三维交点，不再放大原 96×96 位图中的轮廓。柔和阴影单独保留为 192×192 有界缓存。
- 亮芯与轻微光晕采用牛顿望远镜第一阶段所用公共 `shared/components/optical-beam.js` 的 Gaussian 分布：宽度指数 9、38、550，权重 .18、.24、.65。此处为实验内独立适配，因为公共 OpticalBeam 接口依赖 Three.js 直线 Mesh，而本场景使用 Canvas 合成和球面曲线；没有跨实验运行依赖或修改公共组件。DPR=1 下再叠加连续 1px 矢量亮芯，避免窄 Gaussian 采样断续。
- 修正初版把整锥画在地球后的合成错误：锥面每个片元携带相机深度，与地球/月球的可见球面深度比较，后方片元丢弃，前方锥面保留。透明曲面先背面后正面，球面交线只绘制可见半球。
- 教学距离压缩只在天体之间过渡；源球与受影球附近恢复与球面相同的局部投影，使锥面裁切和地表交线接合。太阳/月球/地球参数与遮光计算没有修改。仍属现有教学模型，非真实食象预报；原锥体线性半径与有限视圆判定的微小近似差异仍存在。

## 性能专项检查

适用项：Canvas/WebGL 绘制、透明曲面合成、逐帧几何计算、位图缓存失效及 GPU 生命周期。保留统一 rAF 与隐藏页面暂停；一个新增 WebGL 上下文、一个 GPU buffer 与一个 shader program，pagehide 销毁。未新增缓存列表、纹理上传、存储写入或解码任务。反复进出复用同一资源。

原始证据：`shadow-depth-perf-v9.json`。本机有窗口 Chrome、1600×900、DPR=1、每模式 3 秒，均在放大影区下播放，GPU/浏览器版本记录在 JSON 中。日食 rAF p95 13.4ms、最大 13.6ms；月食 p95 13.4ms、最大 13.5ms，均未观测到 long task。此为显示刷新采样，应用自身仍沿用约 30Hz 绘制调度，不等于应用达到 75 FPS。没有同环境修改前基线，不能据此声称性能提升。未验证白板触控、低端 GPU、长期内存趋势或全部设备表现。


## 后续修正：在受影球面首次相交处终止

上一轮 v9 只做相机深度遮挡，锥面仍在地球内部及后方延伸，位于地球轮廓之外的后段会再次露出。v9 的遮挡像素测试不能证明影锥已被地球截断，该轮“修正遮挡”结论不覆盖这一问题。

本轮在 `coneFirstHit` 中沿每条母线求球面二次方程的较小非负根：本影和半影各自独立计算，网格在第一个入射交点结束，不能选用背面的出射根；地表描边同样只保留入射交线，不再绘制出射交线。接收球没有相交时保持该母线。片元着色器再次按物理坐标检查首次入射交点，避免部分接触的相邻母线三角形跨过球面。相机深度遮挡同时保留。日食接收球为地球，月食接收球为月球，源天体不被误当作接收球。

`test-shadow-volume.cjs` 新增两类锥面 96 个角度的入射半球断言，并在真实 GPU 上关闭相机球遮挡，单独验证截断：未截断时球后采样点有锥面；截断后球内、球后及球投影轮廓外的后段 alpha 均为 0，入射前的锥面仍可见。这区别于上一版只验证相机深度的测试。测试通过，太阳/月亮两类食相放大、重复进出页面无异常。

新证据 `shadow-stop-solar-v10.png`、`shadow-stop-lunar-v10.png`、`shadow-stop-perf-v10.json`。已查看截图：日食地球背面多出的半影圆弧已消失；月食没有击中月球的地影外层母线仍然延伸，击中月球的部分在月面截断。仍沿用既有教学几何和参数，没有将投影裁切反写成科学模型。

性能专项沿用同一机器/浏览器/视口/绘制质量：本轮日食 p95 13.4ms、最大 26.7ms，月食 p95 13.4ms、最大 13.5ms，均未观测到长任务；短时采样不代表低端设备、白板或长期运行验收。

本轮 npm run check、npm test、npm run test:browser、完整 test-observation-audit.cjs 均重新通过；新增部分擦边/完全错过球体的母线检查通过。
