# 可拖动双视图分隔线（2026-11-13）

用户要求在讲解时拖动中间分隔线，调整两栏大小并同步缩放画面。

在原分隔线处加入44逻辑像素宽的触控区域和可见把手，使用原生 Pointer Events 与指针捕获。左右比例为30%—70%，避免一栏失去基本展示空间。两栏各自按可用宽度和高度中的较小缩放比例等比适配，完整源画面居中留边。用户指出初版只按宽度放大导致影锥被裁，现已移除该裁切路径。源画面范围同时覆盖既有日地月、轨道和两道影锥的完整投影包络，外留12逻辑像素，不改变原相机方向。

分隔线具备 separator 语义、竖向方向、当前比例和键盘操作：左右键每次2%，Home/End 到边界，Enter 恢复均分。拖动中 Escape 或 pointercancel 取消本次拖动并恢复先前比例。单双视图切换保留所选比例；食相观测不显示分隔手柄。

状态只增加展示比例，不改变相机方向、场景几何、相位、日历或自转。比例同步更新两栏标题位置。继续复用两张有界离屏快照及原请求重绘入口，不添加独立动画循环。快照仅在实际场景范围扩大时增长，拖动分隔线不会重新分配；范围来自两端半影椭圆的解析极值，包含母线之间的完整本影、半影及伪本影。
