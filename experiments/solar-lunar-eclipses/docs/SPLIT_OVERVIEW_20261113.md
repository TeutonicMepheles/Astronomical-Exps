# 总览双视角对照（2026-11-13）

本次按用户要求，将“平视黄道面”“垂直黄道面”两个文字按钮合并为一个原生 SVG 图标按钮。点击进入左右双栏，再次点击或按 Escape 回到原总览。按钮具有可访问名称、按下状态和键盘操作。

两栏共用日期、公转、自转与播放时钟，同一帧分别投影到平视及垂直黄道面的相机。进入食相观测隐藏双栏及对应控件，原观察相机、地月布局和自转逻辑保留；返回总览保留双栏选择。

双栏复用两个有界的离屏画布。总览影锥保留 192 个角向分段，将直线母线上共面的重复轴向网格合并，使用解析法线保持锥面平滑；球面首次入射截断仍逐片元计算。食相观测沿用原网格路径。

## 验证

- `test-split-overview.cjs`：16 组日期/公转状态，双栏时刻完全一致、平视投影与正投影方向、地/月影背离太阳、原视角及当前时刻恢复、播放切换、键盘、进入观测及返回、1024×768 和 1920×1080 无页面滚动，通过。
- `test-reference-scenes.cjs`：48 个总览相机/日期/公转组合及全食、环食、偏食教学场景回归通过。
- `test-shadow-raster.cjs`：原网格及总览合并网格各 144 个解析球面首次入射遮挡样本，通过。
- Chrome 157、1600×900，单栏及双栏各连续播放 2.5 秒：95% 帧间隔均约 13.4ms，最大分别 13.5/13.7ms，未记录长任务。这是本机短时采样，不代表智慧白板设备性能验收。首次双栏采样曾出现约 53ms 尾帧，优化后复测如上。

原来的 `test-overhead-camera.cjs`、`test-overview-camera.cjs` 等双按钮脚本保留为历史覆盖，入口已被单图标交互替代；不能声称这些旧脚本全部通过。当前相机切换覆盖以 `test-split-overview.cjs` 及更新后的 `test-reference-scenes.cjs` 为准。

补充回归：`test-lunar-unified.cjs` 五节点、固定自转 A 点及主图/地面 GPU 影区检查通过；`npm run check`（0 errors）、`npm test`、`npm run test:browser` 通过。根浏览器测试是组件/入口冒烟，不替代本页截图和交互检查。
