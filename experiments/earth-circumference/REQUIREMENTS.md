## 正式功能、参数与核对项

2026-11-03 用户明确确认采用单观测点模型。页面保留“地面正午观测”和“地球定位与经线测距”两个视图，但只测量一根立杆；另一个位置是根据日期和太阳位置计算出的同经度参考点。

1. 学生选择观测地点和日期，并输入杆长。
2. 地面视图显示观测点当地正午的立杆、平行光线、影长和杆影角。
3. 系统根据日期计算太阳直射纬度 `δ`，用户不能直接修改 `δ`。
4. 地球视图显示观测点 `(φ, λ)` 和同经度参考点 `(δ, λ)`，并突出同一经线。
5. 学生沿当前经线完成地图测距，得到观测点到参考点的距离 `d`。
6. 点击计算后，使用杆影角 `θ` 或纬度差 `Δφ = |φ − δ|` 与距离 `d` 展示计算过程和地球周长。
7. 日期或地点改变后，太阳直射点、参考点和杆影更新，原测距结果失效并需要重测。

| 项目 | 已明确 | 待确认 |
| --- | --- | --- |
| 观测地点 | 单地点；快捷选择、地球点击或经纬度输入 | 地点清单、默认地点、坐标精度 |
| 观测日期 | 可选择 | 日期范围、默认日期、输入控件 |
| 太阳直射纬度 `δ` | 由日期、时间和太阳位置模型计算，只读 | 算法、精度和极值处理 |
| 杆长 | 一根立杆，`10 cm–1 m` | 步长和默认值 |
| 杆影角 `θ` / 影长 `s` | 当地正午测量，影长使用 `cm` | 测量精度和显示方式 |
| 同经线参考点 | `(δ, 观测点经度 λ)` | 极点及两点重合的特殊提示 |
| 经线距离 `d` | 学生沿同一经线地图测距 | 单位、步长、吸附和显示精度 |
| 计算过程 | 点击计算，展示 `θ` 或 `Δφ`、`d` 与代入关系 | 学生公式输入与结果校对方式 |
| 地球周长 | 使用 `C ≈ 360° ÷ Δφ × d` | 单位、精度、参考值和误差容限 |

核对项：页面只有一个实际观测地点；日期决定 `δ` 且用户不能直设；参考点始终为 `(δ, λ)`；测距只沿同一经线；日期或地点改变后旧 `d` 失效；计算过程能追溯所有输入；`φ = δ` 时禁止除法计算。

### 2026-11-04 会议反馈

1. 界面不绘制完整太阳实体，使用明确方向的平行光；地球沿公转轨道移动，自转轴维持同一倾斜方向。
2. 需要同时表达公转原理、地面测量和影子观察，避免三个割裂窗口；可采用单/双/三视图切换，但课堂讲解中应能方便返回完整信息。
3. 面向 5–7 年级，不要求用三角函数计算夹角；直接呈现木棍、阳光、影子和角度，再代入最终周长公式。
4. 只使用一个实际观测点；另一位置由日期和太阳位置计算，仅用于同经线参考距离，不要求当作第二根立杆重复测量。
5. 地面场景采用无行政边界、无明确地标的抽象实景，地球纹理和形态可在系列实验间复用。

### 2026-11-09 用户确认的选点到观测展示流程

1. 初次进入地球模式仅显示太阳直射点标记，隐藏内部预设观测点及其读数。
2. 用户点选地球位置后，先将该点转到当地正午；对齐完成后显示可点击的实景观测提示。
3. 点击提示进入测量参数：地球缩小并移至左侧，日地轨道缩小并移至右侧，中间展开实景观测面板，提供同步过渡和减少动态效果支持。
4. 返回选点保留已选位置；观测点与直射点提示分别打开对应现有实景视图。直射点仅作为参考说明，进入其页签即记录已阅读。


### 2026-11-09 观测入口与推进条件补充确认

- 太阳直射点不显示观测 Tips，仅保留太阳标记。观测点 Tips 为方形实景缩略图，点击后测量面板从该位置放大展开。
- 第二步只要求观测点测量完成即可继续；太阳直射点页签可选查看，不以阅读记录作为推进条件。本条取代此前必须阅读直射点提示的条件。
