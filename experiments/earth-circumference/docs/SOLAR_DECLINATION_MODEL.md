# EXP-04 太阳直射纬度简化模型

整理日期：2026-11-04。状态：教学近似公式，用于由日期确定太阳直射纬度和地球周长实验中的同经线参考点；不得冒充高精度天文历表。

## 1. 定义

太阳直射纬度即时太阳赤纬 `δ`。在理想球体和教学近似下，太阳直射点纬度在一年中于南北回归线之间往返：

```text
北回归线附近：约 +23.44°
赤道：0°
南回归线附近：约 -23.44°
```

北纬为正，南纬为负。

## 2. 一年中的第几天

设：

- `N`：日期在当年中的序号，1 月 1 日为 `1`；
- `D`：当年总天数，平年 `365`，闰年 `366`；
- `δ`：太阳直射纬度，单位为度。

可采用 Cooper 型教学近似：

\[
\delta(N)=23.44^\circ\sin\left(
\frac{360^\circ}{D}(N+284)
\right)
\]

也可以写成从春分附近开始计算的形式：

\[
\delta(N)=23.44^\circ\sin\left(
\frac{360^\circ}{D}(N-81)
\right)
\]

两式等价，均以 `N ≈ 81` 作为简化模型中的零赤纬位置。

## 3. 闰年规则

- 平年：`D = 365`。
- 闰年：`D = 366`。
- `N` 必须使用当年真实日历序号；闰年 3 月 1 日之后不能继续使用平年日期偏移。
- 日期范围只接受当年 `1～D`。

## 4. JavaScript 参考实现

```js
function dayOfYear(date) {
  const utc = Date.UTC(date.getFullYear(), date.getMonth(), date.getDate());
  const start = Date.UTC(date.getFullYear(), 0, 1);
  return Math.floor((utc - start) / 86400000) + 1;
}

function daysInYear(year) {
  return new Date(year, 1, 29).getMonth() === 1 ? 366 : 365;
}

function solarDeclination(date) {
  const n = dayOfYear(date);
  const d = daysInYear(date.getFullYear());
  return 23.44 * Math.sin((2 * Math.PI * (n + 284)) / d);
}
```

计算太阳直射点：

```js
const delta = solarDeclination(observationDate);
const referencePoint = {
  latitude: delta,
  longitude: observationLocation.longitude,
};
```

以下阶段按太阳直射点的运动定义，不代表气象季节：

| --- | --- | --- | --- |
| 春分附近 | 约 `N=80–81` | `0°` 附近 | 由南向北穿过赤道 |
| 春分 → 夏至 | `N≈81–172` | `0° → +23.44°` | 从赤道移向北回归线 |
| 夏至附近 | 约 `N=172` | 约 `+23.44°` | 到达最北位置 |

| 冬至附近 | 约 `N=355` | 约 `-23.44°` | 到达最南位置 |
| 冬至 → 春分 | `N≈355–365/366` | `-23.44° → 0°` | 从南回归线移回赤道 |

## 7. 与观测点和参考点的关系

观测点：

```text
P_obs = (φ, λ)
```

当天太阳直射纬度：

```text
δ = solarDeclination(date)
```

在观测点当地太阳正午条件下，取同经线参考点：

```text
P_ref = (δ, λ)
```

纬度差：

\[
\Delta\varphi=|\varphi-\delta|
\]

沿经线测量 `P_obs` 到 `P_ref` 的距离 `d`，即可计算：

\[
C\approx\frac{360^\circ}{\Delta\varphi}\times d
\]

## 8. 数据约束

- `δ` 是系统计算值，不提供用户可拖动的太阳直射纬度控件。
- 日期变化后必须重新计算 `δ`、参考点和模拟杆影。
- 日期变化后，原有同经线测距结果失效。
- 用户不能直接输入太阳直射纬度替代日期。
- 经度只决定参考点所在经线，不能用于计算 `δ`。
- 只有当地太阳正午条件下，才能将参考点直接取为 `(δ, 观测点经度)`。
- 极点情况下经线退化，必须单独处理。

## 9. 精度边界

该公式只是年度周期近似。

- 不适合作为高精度天文历表。
- 不处理太阳视运动、时差、光行差、章动等精细修正。
- 春分和秋分附近的小角度误差可能对 `C ≈ 360° ÷ Δφ × d` 产生较大相对影响。
- 正式页面的精度要求、允许误差和是否改用太阳位置算法仍待确认。
- 页面应保留模型版本和计算日期，便于复核。
