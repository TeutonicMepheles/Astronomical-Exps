记录、失效与边界

  • 当前只在页面内存保存两地点的端点、是否记录和图像距离；刷新丢失，无 obs_id、导出或持久记录表。
  • 地点或直射纬度变化时清除两组记录；相同场景往返保留。失效键为地点经纬度和直射纬度，未包含日期、时刻、杆长。不同季节若得到同一 δ，不能保证按“日期变化”失效。
  • Δφ=0 可记录零影长；无“零角度无效”提示与最终计算门禁。当前没有最终计算按钮，不能把这算作已实现禁止零角计算。
  • 太阳高度≤0、影端超出面板时已有禁测提示；无极点专门提示，亦无完整数据不足 / 超差状态。
  • 两场景为程序绘制的示意图。源码中有“非当地实景”“不代表真实日期”的文字，但 CSS 隐藏了它们；实际页面缺明确“模拟值”来源标注。
  • 文档的一处实际观测点可对应当前选点；直射点场景是对照模拟。不过目前两场景都可记录图像距离，未与正式“实地测量”数据模型分离。
