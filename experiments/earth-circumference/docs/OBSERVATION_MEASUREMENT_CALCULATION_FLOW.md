# EXP-04 观测—测量—计算流程说明

整理日期：2026-11-09；更新日期：2026-11-10。
适用范围：埃拉托色尼地球周长测量实验的课堂交互与功能实现。
需求依据：[REQUIREMENTS.md](../REQUIREMENTS.md)、[数据采集顺序](DATA_COLLECTION_FLOW.md)、[2026-11-04 甲方反馈](2026-11-04-client-feedback.md)。

## 1. 一句话流程

学生选择一个观测地点和日期，通过日期/时间双轴将当地太阳时调到正午，用一根立杆测量一次影长；系统给出对应的杆影角和当日太阳直射点，学生再固定点选观测点与太阳直射点完成经线测距，最后按角度、距离、周长三步计算地球周长。

```text
选择地点和日期
    ↓
用24小时轴手动对齐当地正午
    ↓
设置一根立杆的长度
    ↓
测量一次影长
    ↓
系统给出杆影角和太阳直射点
    ↓
固定点选观测点和太阳直射点，沿同一经线测距
    ↓
核对角度并分三步计算地球周长
```

## 2. 核心模型

本实验采用已确认的“单观测点模型”：

- 只有一个实际观测地点。
- 只测量一根实际立杆和一次影长。
- 太阳直射纬度和太阳直射点由日期、时间和太阳位置模型计算。
- 观测点到达当地正午后，真正的太阳直射点与“同经参考点”重合，不额外创建第二个“同经直射点”标记。
- 太阳直射点不是第二个实际观测地点，不需要在那里重复插杆或测量影子。
- 经线距离必须从观测点沿共同经线量到参考点。

## 4. 分步流程

### 第一步：设置观测条件

1. 学生选择观测地点。
2. 系统记录观测点纬度 `φ` 和经度 `λ`。
3. 学生使用底栏日期容器选择观测日期；日期轴和当地时间轴由两个独立容器切换。
4. 学生使用底栏时间容器调整当地太阳时；调节任一轴时暂停公转播放并保持暂停。
5. 系统根据日期、时间和太阳位置计算太阳直射纬度 `δ`。学生不能直接拖动或输入 `δ`。

界面要求：

- 同一个观测点在总览地球、地面场景和测距场景中使用一致标识。
- 太阳直射点使用不同颜色、形状或文字，与观测点明确区分。
- 改变日期或地点后，旧太阳直射点、参考点、杆影和测距数据按规则失效。

### 第二步：对齐当地正午并进入观测

1. 用户点选地球位置后，系统保持当前自转，显示该经度的当地太阳时。
2. 选点尚未到当地正午时，隐藏太阳直射点图标、黄色纬线、纬度读数及对应引线，并在时间轴上方持续提示学生手动对齐。
3. 用户通过底部24小时时间轴调整自转，把当地时间调到正午。系统不自动播放对齐动效，也不自动转到正午。
4. 到达正午后显示太阳直射点与正午经线，先显示观测窗口提示，再以一次性有限反馈强调黄道剖切线和正午经线；减少动态效果时直接呈现最终状态。
5. 反馈结束后显示“点击观测点，开始测量”。点击观测点标记进入地面观测；进入观测、离开正午或切换视图时收起该提示。
6. 返回选点时保留已经选好的地点；点选之后改变日期时也不把地球自动拉回正午。

太阳直射点不是第二个实际观测地点，不要求在那里重复插杆或测量影子。观测阶段可由用户主动点击球面太阳直射点标记查看直射点实景，但不通过面板内页签切换。

### 第三步：设置杆长并测量影长

1. 学生确认或输入一根竖直杆的长度 `L`。
2. 杆长范围为 `10 cm–1 m`。
3. 在当地太阳正午前后观察立杆和影子，以正午最短影长作为测量对象。
4. 未进入测量且没有结果时，在尺子按钮旁提示“点击右上角尺子，开始测量影长”；点击尺子后测量影长的起点和端点并确认。
5. 系统在画面中同时显示杆长 `L`、影长 `s` 和对应角度。

数据规则：

- 杆长必须大于零。
- 杆长改变后，原影长测量失效，必须重新测量。
- 观测地点、日期或测量时刻改变后，原影长和杆影角失效。
- 进入影长测量状态后隐藏背景平行光和地球外围太阳箭头，退出测量后恢复。
- 系统模拟值不能覆盖学生实际测得的影长，必须标明来源。

### 第四步：得到杆影角

杆影角定义为太阳光线与竖直立杆之间的夹角：

```text
θ = arctan(s ÷ L)
```

面向 5–7 年级时，不要求学生手动计算三角函数。页面应直接显示角度弧、角度数值和文字说明，学生只需读取或确认结果。

同时可以显示太阳高度角：

```text
α = 90° − θ
```

其中：

- `θ` 是杆影角，也是后续与纬度差对应的角度。
- `α` 是太阳高于地平线的角度，用于直观看阳光与地面的关系。
- 周长公式使用的是 `θ`，不能把 `α` 直接代入。

### 第五步：确定同经参考点

系统根据观测日期计算太阳直射纬度 `δ`。学生把观测点调到当地正午后，系统显示的太阳直射点恰好位于观测点所在经线：

```text
观测点： (φ, λ)
同经参考点： (δ, λ)
```

参考点必须与观测点保持同一经度。当地正午时，该参考点与真实太阳直射点重合，页面不创建独立参考标记。观测点、太阳直射点和共同经线应在当前地球视图中保持可区分、可追溯。

特殊状态：

- `φ = δ`：观测点当天被太阳直射，`Δφ = 0`，提示无法进行除法计算。
- 观测点位于极点时，经线退化，需要显示专门提示。
- 太阳直射点转到球体背面时按可见性规则弱化或提示，不能让学生误点不可见目标。

### 第六步：沿同一经线测距

1. 第三阶段角度动画结束后，若尚未测距，系统自动进入固定点测距提示，不要求用户再点击“沿经线测距”行。
2. 提示为“测量观测点到直射点在经度方向上的距离”。
3. 学生依次点击观测点和太阳直射点。只有这两个点会被接受；空白点击和错误顺序不推进。
4. 系统沿共同经线播放有限连接动画，动画结束后显示距离 `d`。
5. 距离取观测点到太阳直射纬度的经线弧长，不使用屏幕直线。
6. 右侧距离行保留为重播入口，不显示测量尺或自由扫描流程。

测距结果规则：

- 曲线动画结束前的距离不是正式值。
- 动画结束后才记录正式距离。
- 日期或地点改变后，原距离失效，必须重新测距。
- 重新测距会影响后续计算结果，但不能改写已经完成的杆影测量。

### 第七步：核对角度关系

系统计算观测点与太阳直射纬度的纬度差：

```text
Δφ = |φ − δ|
```

在理想球体、当地正午、立杆垂直地面和地面水平的条件下，应有：

```text
θ ≈ Δφ
```

页面可以同时显示：

- 实地测量得到的杆影角 `θ`；
- 系统计算得到的纬度差 `Δφ`；
- 两者的差值。

如果差值较大，应保留并明确提示，不能静默用一个值覆盖另一个值。是否允许超出某个误差后继续计算，以及容差大小，仍待确认。

### 第八步：计算地球周长

点击“计算地球周长”后，优先使用学生实际测得的杆影角：

```text
地球周长 C ≈ 360° ÷ θ × d
```

其中：

- `360°` 表示完整圆周对应的角度。
- `θ` 使用度数。
- `d` 是观测点到同经参考点的距离。

也可以用系统纬度差进行模型核对：

```text
地球周长 C ≈ 360° ÷ Δφ × d
```

两条路径的含义不同：

- 使用 `θ` 的结果来自学生的实地杆影测量。
- 使用 `Δφ` 的结果来自系统太阳位置模型。
- 页面必须标明每个数值的来源。

是否同时保留两种结果、最终只展示哪一种，以及结果精度和误差容限，仍需甲方确认。

## 5. 计算呈现顺序

右侧计算面板按三个可重播步骤呈现：

1. 显示杆长 `L`、影长 `s`、杆影角 `θ = 90° − α` 和相等球心角；
2. 显示观测点到太阳直射点的同经线距离 `d`；
3. 显示周长公式 `C ≈ 360° ÷ θ × d`，依次代入角度、距离并显示地球周长结果。

三步各自显示完成勾选。第一步完成后可自动进入距离提示；第二步完成后高亮周长公式并等待用户点击计算。切换步骤、离开计算或输入变化时取消待完成动画；角度和距离路径在后续步骤中保留。

## 6. 数据失效规则

| 用户操作 | 影长 `s` / 杆影角 `θ` | 太阳直射纬度 `δ` | 同经距离 `d` | 周长结果 |
| --- | --- | --- | --- | --- |
| 只改变杆长 `L` | 失效，必须重测 | 不变 | 保留 | 失效 |
| 改变日期 | 失效 | 重新计算 | 失效，必须重测 | 失效 |
| 改变观测地点 | 失效 | 纬度不变，关系重新计算 | 失效，必须重测 | 失效 |
| 改变测量时刻 | 失效 | 重新计算 | 失效，必须重测 | 失效 |
| 重新测量影长 | 更新 | 不变 | 保留 | 失效 |
| 重新测量距离 | 不变 | 不变 | 更新 | 失效并重新计算 |

## 7. 展示要求

- 地球沿公转轨道移动，地轴保持固定倾斜方向。
- 太阳方向使用固定方向的平行光，不绘制贴近地球的完整太阳实体。
- 地面场景使用无行政边界、无明确地标的抽象实景。
- 公转、地面杆影、地球定位和测距应具有明显空间或状态联系，避免互相割裂。
- 同一个观测点在所有视图中保持一致标识。
- 观测点和太阳直射点不能只靠颜色区分。
- 核心流程在 16:9 单屏内完成，不依赖页面滚动、悬停或滚轮。
- 选中状态在移开指针后保持；触屏无需悬停也能完成全部操作。

## 8. 当前仍需确认

- 地点选择采用快捷地点、地球点击、坐标输入，还是组合方式。
- 默认地点、日期范围、坐标精度和日期控件形式。
- 经线距离的单位切换和显示精度。测距操作已确认为依次点击观测点和直射点，不再使用沿经线拖动的测距尺。
- 杆影角由学生拖动影子测量，还是由系统根据日期和杆长直接演示。
- 是否同时保留“实测角度支路”和“模型纬度差支路”。
- 公式由学生填空、逐步揭示，还是系统直接展示。
- 地球周长参考值、允许误差和结果展示精度。
- 真实日期太阳位置是否继续使用教学近似，还是采用正式太阳位置算法。

## 9. 验收核对

- [ ] 只有一个实际观测地点和一根实际立杆。
- [ ] 只测量一次观测点影长，不重复测量太阳直射点。
- [ ] 日期决定太阳直射纬度，用户不能直接设置 `δ`。
- [ ] 当地正午时参考点为 `(δ, λ)`，并与真实太阳直射点重合；不显示独立的同经直射点标记。
- [ ] 测距只沿观测点与参考点的共同经线。
- [ ] 画面同时显示杆长、影长和相关角度。
- [ ] 学生不需要使用三角函数才能推进流程。
- [ ] `θ` 与 `Δφ` 的来源和关系清楚可见。
- [ ] 日期、地点、杆长或测量时刻变化后，旧数据按规则失效。
- [ ] 第三阶段不实例化自由测量尺，必须按固定顺序点选观测点和太阳直射点。
- [ ] 角度、距离、周长三步可重播，完成状态和数据失效同步。
- [ ] 计算结果能够追溯到 `L`、`s`、`θ`、`δ`、`d` 及各自来源。
- [ ] `φ = δ` 时禁止除法并显示明确提示。
