# EXP-04 埃拉托色尼实验页面 Layout

整理日期：2026-11-03。状态：已按 2026-11-03 用户确认的单观测点模型纳入 EXP-04 正式需求。

## 1. Layout 目标

- 在同一屏内讲清“地面杆影—地球定位—同经线测距—计算周长”的关系。
- 面向 16:9 智慧白板，以点击和拖拽为主。
- 核心流程不使用页面滚动、悬停或滚轮。
- 地面观测和地球空间关系同时可见，避免学生在两个独立页面之间来回切换。
- 未确认数值使用占位符，不把会议演示值写成科学定值。

## 2. 逻辑舞台

采用 `1600 × 900` 作为本文的布局示意坐标系，按 16:9 等比缩放并居中留边。它是设计栅格，不是已确认的白板物理分辨率，也不是其他实验必须复用的统一尺寸。

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 顶部标题栏：实验名称 / 当前步骤 / 简短任务提示                          │  80px
├───────────────────────────────┬──────────────────────────────────────┤
│                               │                                      │
│  地面正午观测                 │  地球定位与经线测距                   │
│                               │                                      │
│  立杆、影子、太阳光线          │  观测点、太阳直射点、同一经线          │  560px
│  杆影角 θ、影长 s              │  经线弧 d                            │
│                               │                                      │
├───────────────────────────────┴──────────────────────────────────────┤
│ 观测条件                  │ 测量证据                 │ 计算与结果      │  172px
│ 地点 / 日期 / 杆长        │ θ / s / d                │ 计算按钮 / 公式  │
└──────────────────────────────────────────────────────────────────────┘
```

外边距 24px；顶部标题与主舞台、主舞台与底部工作区各留 20px；主舞台左右两个面板等宽，中间间隔 24px。

## 3. 区域定义

### 3.1 顶部标题栏

左侧：

- 实验标题：`埃拉托色尼地球周长测量`；
- 当前任务短句，例如“先确定观测点和日期”。

中间或右侧：

- 四个步骤提示：`设置观测 → 观测杆影 → 沿经线测距 → 计算周长`；
- 只突出当前步骤，不增加完成分数或游戏化装饰。

标题栏不得放置关键测量结果。

### 3.2 左侧：地面正午观测

区域职责：

- 展示一个观测地点；
- 展示当地正午的一根竖直杆和影子；
- 展示平行太阳光线；
- 显示杆长 `L`、影长 `s` 和杆影角 `θ`；
- 日期或杆长改变时同步更新杆影。

视觉要求：

- 灰白或实验独立配色下的手绘科普插画；
- 地面水平线清楚，立杆垂直于地面；
- 光线使用平行箭头，不绘制太阳实体；
- 杆影方向和长度是主视觉，不使用照片背景抢夺焦点；
- 角度弧和影长标注不得遮挡杆底。

不在此区域放置地图、城市列表或地球周长结果。

### 3.3 右侧：地球定位与经线测距

区域职责：

- 展示抽象地球；
- 显示观测点和日期决定的太阳直射点；
- 显示两点所在同一经线；
- 启动测距后高亮经线弧 `d`；
- 日期变化时更新直射点，地点变化时更新经线。

初始构图：

- 地球占面板主要面积；
- 点选后保持当前自转，先显示当地时间和同经直射点；学生对齐正午后才进入观测；
- 观测点和直射点采用不同颜色、形状和标签；
- 赤道、南北回归线和约每 `10°` 的纬线可读；
- 不显示政治边界。

测距构图：

- 计算阶段可把共同经线转到可见视角；
- 依次点击观测点和太阳直射点后，沿经线显示连接弧；
- `d` 在连接动画结束后出现，读数靠近经线弧，不放在球体外的远端。

### 3.4 底部：观测条件

占底部工作区约 35%：

- 地点选择：快捷地点、地图点击或经纬度输入；
- 日期选择；
- 杆长输入，范围候选为 `10 cm–1 m`，待正式确认；
- 必要时显示“恢复最佳地球视角”。

控件按“地点 → 日期 → 杆长”顺序排列，与实验流程一致。

### 3.5 底部：测量证据

占底部工作区约 35%：

- 纬度 `φ`；
- 太阳直射纬度 `δ`，只读；
- 杆影角 `θ`；
- 同经线距离 `d`；
- `Δφ` 在计算阶段显示或由学生填写，是否直接展示待确认。

任何读数必须标明来源，不把“计算得到”和“用户测量得到”混成同一组数字。

### 3.6 底部：计算与结果

占底部工作区约 30%：

- 初始状态显示“等待测量数据”；
- 数据齐全后启用“计算地球周长”；
- 点击后展示：
  1. 使用的观测角度或纬度差；
  2. 使用的同一经线距离；
  3. 代入关系；
  4. 计算出的地球周长。
- 结果保留来源链，学生可以回看每个数值来自哪里。

学生应参与数据收集和代入；不能页面加载后直接自动给出最终答案。具体的公式输入方式待确定。

各字段的采集顺序、来源标签和失效规则见[数据采集顺序](DATA_COLLECTION_FLOW.md)。

## 4. 页面流程

| 状态 | 主舞台 | 底部工作区 | 可用操作 |
| --- | --- | --- | --- |
| S1 设置观测 | 地球显示默认视角，杆影待定 | 地点、日期、杆长可用 | 选择地点和日期 |
| S2 观测杆影 | 左侧显示立杆和影子，右侧定位观测点 | 显示杆长、影长和 `θ` | 改日期或杆长 |
| S3 定位直射点 | 右侧出现同经度参考点和经线 | 显示 `δ`，测距待完成 | 检查空间关系 |
| S4 沿经线测距 | 右侧进入当前经线的测距构图 | 依次点击观测点和直射点，经线连线结束后冻结 `d` | 点选两个标记、重测 |
| S5 计算 | 左右证据保持可见 | 显示代入过程和周长结果 | 修改条件后重新计算 |

### 状态保留规则

- 仅改变杆长：更新影长和 `θ`，保留地点、日期和 `d`。
- 改变日期：更新 `δ`、参考点、影长和 `θ`，同时使 `d` 过期。
- 改变地点：更新观测点、经线、影长和 `θ`，同时使 `d` 过期。
- 返回上一步：保留已确认值；依赖后续数据的结果标记为过期。

## 5. 视觉层级

层级从高到低：

1. 当前被操作的点、经线、杆影或经线距离；
2. 地面观测和地球空间关系；
3. 测量数值和计算按钮；
4. 步骤提示与辅助说明；
5. 背景装饰。

要求：

- 选中状态与悬停视觉一致，选中后移开指针仍保留。
- 观测点和直射点不能只靠颜色区分。
- 地球经纬线保持低对比；当前经线和测距弧提高对比。
- 文字、刻度和读数不能被插画纹理、光束或地球遮挡。
- 主舞台不使用滚动容器、长页或复杂悬浮动效。

## 6. 非 16:9 窗口

- 整个逻辑舞台等比缩放并居中留边。
- 不压缩文字、地球或按钮的相对关系。
- 不通过隐藏底部工作区适配窄屏。
- 如果白板可视区域不足，优先缩小整个舞台，而不是让底部控件进入滚动区域。
- 具体最小分辨率与观看距离待确认后再设定硬阈值。

## 7. 特殊状态布局

### 观测点与太阳直射点重合

- 右侧两点合并显示为“直射观测点”；
- 经线距离显示 `0 km` 或 `不可测`；
- 计算按钮禁用；
- 底部证据区明确说明 `Δφ = 0`，不能进行除法。

### 测距尚未完成

- 提示“测量观测点到直射点在经度方向上的距离”；
- 只接受观测点和太阳直射点两次点击；
- 经线连接动画结束前不记录正式距离；
- “计算”保持禁用。

### 日期或地点改变

- 原测距值降低对比并标记“已过期”；
- 不得继续使用原值计算；
- 用户确认重测后清除过期样式。

## 8. 验收清单

- [ ] 在 16:9 舞台内同时看见地面杆影、地球定位、同一经线和计算区。
- [ ] 核心流程不需要页面滚动、滚轮或悬停。
- [ ] 观测条件、测量证据、计算结果具有稳定的固定区域。
- [ ] 日期或地点变化后，旧距离不会被静默复用。
- [ ] 地球旋转或自动聚焦时，观测点与参考点保持对应。
- [ ] 测距只沿当前经线连接观测点和直射点，动画结束后才记录距离。
- [ ] 文字、角度、距离和结果在目标观看距离下可读。
- [ ] 鼠标、触屏和键盘均可完成完整流程。
- [ ] 页面始终按单观测点正式需求实现，不出现第二个实际测量地点或第二根测杆。
