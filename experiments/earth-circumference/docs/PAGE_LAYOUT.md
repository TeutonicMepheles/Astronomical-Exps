# EXP-04 埃拉托色尼实验页面 Layout

整理日期：2026-11-03；交互更新：2026-11-10。状态：单观测点模型、日期/时间双轴、手动正午对齐和三步计算已纳入正式需求；科学参数和整页验收仍未完成。

## 1. Layout 目标

- 在同一屏内讲清“地面杆影—地球定位—同经线测距—计算周长”的关系。
- 面向 16:9 智慧白板，以点击和拖拽为主。
- 核心流程不使用页面滚动、悬停或滚轮。
- 地面观测和地球空间关系同时可见，避免学生在两个独立页面之间来回切换。
- 未确认数值使用占位符，不把会议演示值写成科学定值。

## 2. 逻辑舞台

采用 `1600 × 900` 作为本文的布局示意坐标系，按 16:9 等比缩放并居中留边。它是设计栅格，不是已确认的白板物理分辨率，也不是其他实验必须复用的统一尺寸。

当前三阶段布局：

| 阶段 | 主舞台 | 底部与操作区 |
| --- | --- | --- |
| 1 选择观测点 | 左侧/中央放大地球，右侧显示公转轨道、太阳和当前地球 | 左侧日期/当地时间双容器，中间时间轴，右侧播放、暂停、复位及公转/自转图标按钮 |
| 2 测量参数 | 左侧保留地球空间关系，中央为观测点影长测量面板，右侧保留公转轨道和观测日期控制 | 底栏隐藏；返回和下一步固定在安全边缘 |
| 3 计算地球周长 | 左侧保留地球、杆影角与经线距离证据，右侧显示三步计算面板 | 底栏隐藏；返回固定在左下角 |

外边距与面板尺寸以实际 CSS 为准，不在本文复制正在调整的像素值。16:9 舞台必须单屏容纳当前阶段全部核心操作。

## 3. 区域定义

### 3.1 顶部标题栏

左侧：

- 实验标题：`埃拉托色尼地球周长测量`；
- 当前任务短句，例如“先确定观测点和日期”。

右侧：

- 三个步骤提示：`选取观测点 → 测量参数 → 计算地球周长`；
- 只突出当前步骤，不增加完成分数或游戏化装饰。

标题栏不得放置关键测量结果。

### 3.2 第一阶段：选择观测点

- 中央放大地球显示经纬网、观测点候选和空间辅助线；初始未选点时，时间以 `0°` 经线为参考。
- 右侧显示太阳、公转轨道、当前地球和特写摄像机；公转播放、暂停和复位保留。
- 点按地球选择观测点；选点后保持当前自转，显示该经度的当地太阳时。
- 观测点尚未到当地正午时，使用公共 `OperationTip` 提示学生拖动时间轴；隐藏太阳直射点图标、黄色纬线、纬度读数和对应引线。
- 到达正午后显示太阳直射点与正午经线，并播放一次有限反馈；开启减少动态效果时直接显示最终状态。
- 正午反馈结束后显示“点击观测点，开始测量”，该入口只有在当地正午开放。

### 3.3 底部日期与时间

- 日期和当地时间使用两个独立容器；点击容器分别切换一年周期轴和 24 小时轴。
- 首次选点默认进入时间轴，之后保留用户选择；两类视图均保留底栏，测量阶段隐藏。
- 点击、拖动日期/时间轴或使用键盘调轴时暂停公转播放，并保持暂停；再次点击播放才恢复。
- 未选点时允许调整 `0°` 经线当地太阳时；无观测点时达到正午不开放观测入口。
- 时间轴支持触控拖动和键盘方向键、Shift、Home/End；时间使用教学太阳时模型，不宣称 UTC 或高精度历表。

### 3.4 第二阶段：测量观测点影长

- 中央面板标题固定为居中 `h2`“观测点影长测量”，不再使用“观测点/太阳直射点”互切页签。
- 场景中只绘制观测点一根立杆；杆长按固定比例同步改变立杆高度和几何影长。
- 背景持续显示等间距平行太阳光；进入影长测量状态后隐藏平行光与外围太阳箭头，退出测量后恢复。
- 未进入测量且没有结果时，在尺子按钮旁提示“点击右上角尺子，开始测量影长”。
- 太阳直射点实景只由用户主动点击球面标记打开；直射点不显示立杆，也不重复测量。
- 右侧公转轨道上方显示当前日期，下方提供日期控制；改日期时保持观测点当地正午，并更新直射纬度、杆影和射向。

### 3.5 第三阶段：计算地球周长

- 右侧以角度、距离、周长三个公式块呈现计算，数值与变量使用等宽/数学字体并支持减少动态效果。
- 第一步显示杆影角 `θ = 90° − α` 和相等球心角；计算阶段显示球心导航点，测量阶段隐藏。
- 第二步固定提示依次点击观测点和太阳直射点，沿共同经线连线后刷新 `d`；不显示测量尺、扫描流程或自由选点。
- 角度动画结束且尚未测距时自动进入距离提示；距离完成后高亮周长公式，等待用户点击计算。
- 三步均记录完成状态，支持重复点击重播；修改日期、地点、杆长或杆影会使依赖数据失效并更新进度。

各字段的采集顺序、来源标签和失效规则见[数据采集顺序](DATA_COLLECTION_FLOW.md)。

## 4. 页面流程

| 状态 | 主舞台 | 底部工作区 | 可用操作 |
| --- | --- | --- | --- |
| S1 选择观测点 | 地球与公转轨道同屏；未选点时显示 `0°` 经线时间基准 | 日期/时间双容器、时间轴、播放/暂停/复位和视图按钮可用 | 点选地点、改日期、手动对齐正午 |
| S2 测量参数 | 地球、观测面板和公转轨道同屏；面板显示杆影与日期控制 | 底栏隐藏 | 调杆长、测量影长、查看直射点、返回或下一步 |
| S3 计算 | 左侧保留角度和经线距离证据，右侧显示三步公式 | 底栏隐藏 | 重播角度、重新点选距离、计算或返回 |

### 状态保留规则

- 仅改变时间：保持日期；仍在正午时保留已测影长，离开正午后关闭观测入口并使相关下游数据失效。
- 仅改变杆长：更新影长和 `θ`，清除旧杆影测量并保留地点、日期。
- 改变日期：更新 `δ`、参考点、影长和 `θ`，同时使 `d` 过期。
- 改变地点：更新观测点、经线、影长和 `θ`，同时使 `d` 过期。
- 返回上一步：保留已确认值；依赖后续数据的结果标记为过期。

## 5. 视觉层级

层级从高到低：

1. 当前被操作的点、经线、杆影或经线距离；
2. 地面观测和地球空间关系；
3. 测量数值和计算按钮；
4. 步骤提示与辅助说明；
5. 背景装饰。

要求：

- 选中状态与悬停视觉一致，选中后移开指针仍保留。
- 观测点和直射点不能只靠颜色区分。
- 地球经纬线保持低对比；当前经线和测距弧提高对比。
- 文字、刻度和读数不能被插画纹理、光束或地球遮挡。
- 主舞台不使用滚动容器、长页或复杂悬浮动效。

## 6. 非 16:9 窗口

- 整个逻辑舞台等比缩放并居中留边。
- 不压缩文字、地球或按钮的相对关系。
- 不通过隐藏底部工作区适配窄屏。
- 如果白板可视区域不足，优先缩小整个舞台，而不是让底部控件进入滚动区域。
- 具体最小分辨率与观看距离待确认后再设定硬阈值。

## 7. 特殊状态布局

### 观测点与太阳直射点重合

- 右侧两点合并显示为“直射观测点”；
- 经线距离显示 `0 km` 或 `不可测`；
- 计算按钮禁用；
- 底部证据区明确说明 `Δφ = 0`，不能进行除法。

### 测距尚未完成

- 提示“测量观测点到直射点在经度方向上的距离”；
- 只接受观测点和太阳直射点两次点击；
- 空白点击、错误顺序和错误目标不推进；
- 键盘 `Enter`/空格与点按使用同一固定端点流程；
- 经线连接动画结束前不记录正式距离；
- “计算”保持禁用。

### 选点尚未到当地正午

- 不显示太阳直射点图标及其纬线、纬度读数和引线；
- 不开放观测点实景入口；
- 持续提示学生通过时间轴对齐正午，不自动转正。

### 日期或地点改变

- 原测距值降低对比并标记“已过期”；
- 不得继续使用原值计算；
- 用户确认重测后清除过期样式。

## 8. 验收清单

- [ ] 三个阶段都能在 16:9 单屏内完成，不需要页面滚动。
- [ ] 核心流程不需要页面滚动、滚轮或悬停。
- [ ] 日期和时间容器可独立切轴，触控拖动与键盘调时行为一致。
- [ ] 选点非正午时不开放观测入口；到达正午后显示直射点及操作提示。
- [ ] 测量阶段只显示观测点一根立杆，直射点不重复测量。
- [ ] 日期或地点变化后，旧距离不会被静默复用。
- [ ] 地球旋转或自动聚焦时，观测点与参考点保持对应。
- [ ] 测距只沿当前经线连接观测点和直射点，动画结束后才记录距离。
- [ ] 角度、距离、周长三步可重播，完成状态与数据失效同步。
- [ ] 文字、角度、距离和结果在目标观看距离下可读。
- [ ] 鼠标、触屏和键盘均可完成完整流程。
- [ ] 页面始终按单观测点正式需求实现，不出现第二个实际测量地点或第二根测杆。
