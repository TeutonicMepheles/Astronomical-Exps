# EXP-04 地球控件功能需求

整理日期：2026-11-03。状态：已按 2026-11-03 用户确认的单观测点模型纳入 EXP-04 正式需求。

## 1. 文档范围

本文只定义埃拉托色尼地球周长测量实验中的“地球控件”，包括：

- 地球的空间展示；
- 观测地点选择；
- 日期变化后的太阳直射点；
- 观测点、直射点与同一经线的关系；
- 地图测距；
- 控件向实验输出什么数据。

本文不定义杆影长度、太阳角、地球周长等实验业务计算；这些由实验层负责。

完整字段、实地测量顺序和数据失效规则见[数据采集顺序](DATA_COLLECTION_FLOW.md)。

日期到太阳直射纬度的教学近似公式、对照表和闰年规则见[太阳直射纬度简化模型](SOLAR_DECLINATION_MODEL.md)。

## 2. 教学目标

地球控件必须帮助学生建立以下空间关系：

1. 观测地点能用纬度和经度表示。
2. 同一天太阳直射点位于一个确定的纬度。
3. 当观测点处于当地正午时，可取观测点所在经线与太阳直射纬度的交点作为参考点。
4. 观测点与参考点位于同一经线，因此两点距离只有南北方向分量。
5. 观测地点与参考点的纬度差，对应地球表面上的一段经线弧长。

## 3. 核心数据

| 数据 | 来源 | 是否允许用户直接修改 |
| --- | --- | --- |
| 观测点纬度 `φ` | 地点选择或数值输入 | 是 |
| 观测点经度 `λ` | 地点选择或数值输入 | 是 |
| 观测日期 | 页面日期控件 | 是 |
| 太阳直射纬度 `δ` | 根据日期、时间和太阳位置模型计算 | 否 |
| 参考点 | `(δ, λ)` | 否 |
| 纬度差 `Δφ` | `abs(φ − δ)` | 否，计算输出 |
| 经线距离 `d` | 用户沿同一经线测距得到 | 只能沿经线修改 |

太阳直射纬度不能作为独立滑块由用户设置。用户改变日期后，直射点和参考点随日期更新。

## 4. 地球展示

### 4.1 基础画面

- 地球采用科普插画风，不显示政治边界、行政区或领土归属。
- 不要求高精度卫星地图。
- 可显示简化陆地和海洋色块，但不得影响经纬线、测点和测距读数。
- 地球默认以斜侧视角展示，保证南北方向、赤道和当前经线可辨。

### 4.2 必须显示的图层

| 图层 | 要求 |
| --- | --- |
| 赤道 | 清楚可辨，标注 `0°` |
| 南北回归线 | 标注名称及约 `±23.44°` 纬度 |
| 纬线 | 建议每 `10°` 一条；非关键纬线降低对比 |
| 观测点 | 独立颜色、形状和名称 |
| 同一经线 | 从观测点经过参考点，突出显示 |
| 太阳直射点 | 由日期计算；与观测点使用不同形状和标签 |
| 测距弧 | 只沿同一经线绘制，并显示距离读数 |

颜色不能作为唯一区分方式。观测点、直射点和测距弧还需使用不同形状或文字标签。

## 5. 地点选择

地球控件必须提供以下入口：

1. 点击地球选择地点。
2. 选择快捷地点。
3. 输入纬度和经度。

三种入口更新同一份地点状态，不能产生三套互不一致的数据。

### 5.1 点击选择

- 点按地球表面后命中最近的有效地点。
- 选择结果立即显示在地球、地面观测区和数据区。
- 拖动超过点击阈值时执行旋转，不触发选点。

### 5.2 数值输入

- 纬度范围：`-90°～90°`，北纬为正、南纬为负。
- 经度范围：`-180°～180°`，东经为正、西经为负。
- 输入非法值时显示明确提示，并保留上一有效地点。
- 数值输入不依赖悬停或滚轮。

### 5.3 快捷地点

- 快捷地点只是输入辅助，不改变实验模型。
- 最终城市或观测点清单待确认。
- 默认地点及其坐标待确认。

## 6. 视角与旋转

- 拖动地球可以改变观察角度。
- 点选地点后保持当前自转，先显示该经度的当地时间和同经直射点。学生用自转进度对齐当地正午，点选本身不自动转正。
- 进入周长计算后，镜头转到能同时看到观测点和同经直射点的视角。
- 如果观测点和参考点距离很近，可自动拉近或切换到经线局部视图。
- 计算阶段的镜头移动应连续、可中断；用户拖动后不得立即被自动动画抢回。
- 核心流程不依赖缩放；如提供缩放，必须有按钮或触控入口，不能只依赖滚轮。
- 控件需提供明确的“恢复最佳视角”操作。

## 7. 日期与太阳直射点

### 7.1 数据来源

- 用户选择日期。
- 太阳直射纬度 `δ` 由太阳位置模型计算。
- 教学版本可使用日期近似公式；正式版本应采用确认后的太阳位置算法。
- 用户不能直接输入或拖动 `δ`。

### 7.2 参考点位置

在观测点当地正午条件下：

```text
观测点：φ，λ
参考点：δ，λ
```

参考点必须位于观测点所在经线上。

### 7.3 日期变化

- 直射纬度变化后，参考点沿当前经线移动。
- 原有测距结果立即失效，并标记为过期。
- 页面提示需要重新测距。
- 不得把新日期计算出的 `Δφ` 与旧日期测得的 `d` 混合使用。

## 8. 同一经线测距

### 8.1 进入条件

以下条件满足后才能启动测距：

- 已选择观测点；
- 已选择日期；
- 已生成太阳直射点；
- 观测点与直射点不重合。

### 8.2 测距操作

1. 点击“沿经线测距”。
2. 提示“测量观测点到直射点在经度方向上的距离”。
3. 学生先点击观测点，再点击太阳直射点。只有这两个标记会被接受。
4. 系统沿共同经线播放曲线连接。
5. 动画结束后显示距离 `d`。结束前的读数不是正式值。

距离取观测点到同经直射纬度的经线弧长，不使用屏幕直线，也不沿纬线或任意大圆计距。

### 8.3 结果状态

- 未测量：显示“沿经线测距”。
- 等待两次点选或正在播放经线连接：不记录正式距离。
- 动画结束：将 `d` 输出给实验层。
- 日期或地点变化：退回“沿经线测距”。

距离单位建议使用 `km`，是否允许切换单位待确认。

## 9. 状态机

| 状态 | 地球控件表现 | 允许操作 |
| --- | --- | --- |
| 未选地点 | 显示默认地球，观测点和经线隐藏 | 拖动、选点、输入坐标 |
| 已选地点 | 显示观测点、纬度和经线 | 改地点、旋转、恢复视角 |
| 未选日期 | 参考点隐藏，测距不可用 | 选择日期 |
| 已选日期 | 显示直射点和同经度参考点 | 改日期、开始测距 |
| 测距中 | 高亮共同经线，等待依次点选观测点和直射点 | 点选两个标记、取消 |
| 已测距 | 显示 `d` 和确认状态 | 重测、计算 |
| 过期 | 保留旧值但明显标记 | 按新条件重测 |
| 无效 | 直射点与观测点重合或数据不足 | 修改日期或地点 |

## 10. 控件输出

地球控件应向实验层提供：

```text
observer: { latitude, longitude, label }
date
declination
reference: { latitude: declination, longitude: observer.longitude }
latitudeDifference
measuredDistance
measurementStatus
```

地球控件不负责：

- 杆长与影长的换算；
- 太阳角计算；
- 地球周长结果；
- 公式是否正确；
- 将未确认的近似值伪装成精确结果。

## 11. 特殊与异常状态

- `φ = δ`：两点重合，不显示可测距离，提示“太阳直射观测点”。
- 观测点位于极点：经线退化，需给出专门提示；是否禁止极点待确认。
- 参考点在地球背面：自动转动到可见角度。
- 两点距离过小：切换局部经线视图，避免两个标记重叠。
- 加载或计算失败：保留用户地点和日期，显示重试入口。

## 12. 输入与无障碍

- 点击、拖拽、数值输入和键盘操作必须得到相同实验结果。
- 悬停与选中使用同一视觉反馈；选中后移开指针仍保留。
- 所有关键操作具备文字标签，不只依赖图标。
- 读数变化使用可被辅助技术感知的状态提示，但不在拖动每一帧重复播报。
- 目标场景为 16:9 智慧白板，控件保持足够大的点按区域。

## 13. 验收清单

- [ ] 点击、快捷地点和经纬度输入都更新同一地点状态。
- [ ] 选择地点后，地球自动转到能看见观测点和参考点的位置。
- [ ] 日期改变后，直射纬度更新，用户不能直接修改 `δ`。
- [ ] 参考点始终使用 `(δ, 观测点经度)`。
- [ ] 同一经线、观测点、直射点和测距弧始终可见、可区分。
- [ ] 测距只接受观测点和同经直射点，距离沿共同经线计算，动画结束后才成为正式值。
- [ ] 日期或地点变化后，旧测距值失效，不能继续参与计算。
- [ ] 观测点与直射点重合时阻止除法计算。
- [ ] 核心流程可用鼠标、触控和键盘完成，不依赖悬停或滚轮。
- [ ] 控件输出可以被实验层追溯，不从画面像素反推科学数据。
