# 窗户透视、灯光窗帘联动与水体分层功能说明

日期：2026-10-27。状态：讨论整理稿，尚未实施。

基于分支 `experiment/light-pollution/maintainer-refinement`、版本 `f26d3ab`。本文整理本轮讨论，不替代 REQUIREMENTS.md 的正式实验要求；实现方案和美术参数仍需在样例中验证。

## 1. 目标与范围

解决当前窗帘矩形填充不贴合建筑透视、纹理重复和拉合生硬的问题。建立可在本页面复用的“表面几何＋遮挡＋效果层”机制，同时支持窗帘、窗内灯光和广告屏等平面内容。

先在光污染实验目录内实现；跨实验公共组件提取另行处理。

补充范围：前景与背景水体分别列入独立生图资源，用于水面动态及灯光倒影联动。

## 2. 透视与遮挡编辑

- 编辑模式下选中表面，拖动左上、右上、右下、左下四个角，匹配背景中的窗户或屏幕；内容纹理随表面一起变形，不能仅裁切外轮廓。
- 支持编辑窗洞可见轮廓，以及窗框、横梁、树木、栏杆等遮挡区域。四角负责透视，遮罩负责精确边界，两者独立。
- 一扇窗的灯光与窗帘共用几何定位；共用适用的前景遮挡，并允许各效果层有独立遮罩。
- 提供灯光、窗帘预览并保存配置。正式展示模式不显示角点和编辑工具；配置使用统一场景坐标，不随窗口缩放或全景拖动漂移。

## 3. 同窗灯光与窗帘联动

每扇窗保留独立的灯光状态（亮度、色温）和窗帘状态（覆盖比例、材质、动画进度）；住宅组可以统一下发参数。

合成顺序由后向前为：室内背景与发光层 → 窗帘 → 窗框及更前方遮挡物。

- 亮度、色温只影响发光效果及明确设计的布料受光部分，不统一施加到整个窗户容器。
- 拉帘不重置亮度、色温；调光不改变图层顺序，也不清除窗帘遮罩。先拉帘再调光与先调光再拉帘应得到相同最终画面。
- 窗帘和灯光遮挡使用同一个实时覆盖形状，动画过程中同步更新，避免漏光或灯光反向覆盖窗帘。
- 关灯后窗帘、窗框仍可见，窗口仍可选中；再次开灯或拉帘时保留其他参数。
- 窗外光晕关联有效透出光，但使用独立效果层；地面反光如需透视贴合，应具有自己的表面几何。

当前版本亮度使用住宅灯光图透明度、色温使用该图的颜色滤镜；窗帘位于其上方，并遮掉下方灯光。调光本身不会改变层级。现有布料尚无对应受光变化。

## 4. 窗帘视觉表现

- 保留当前从右向左拉合及 25%、50%、75%、100% 覆盖档位。
- 拉合过程连续，褶皱随收拢、展开改变，避免仅以矩形擦除表现移动。
- 使用少量共用材质，通过固定的实例差异调整褶皱、下摆和明暗，避免所有窗帘完全一致。
- 微动态以操作后的轻微回摆、停稳为主；不让整栋楼持续同步摆动。减少动态效果模式下可直接呈现最终状态。
- 布料固有颜色与灯光受光效果分开处理。透光率、动画幅度及持续时间属于待验证的美术参数，不作为科学标定结果。

## 5. 资源组织

沿用场景逻辑尺寸 2172×724；各资源保持统一对齐关系。

| 资源 | 内容 |
| --- | --- |
| 场景底图、室内与灯光层 | 可活动区域避免烘焙固定窗帘；室内发光可独立控制 |
| 窗洞与遮挡遮罩 | 明确窗洞、窗框和前景物体边界，不以颜色深浅推断前后关系 |
| 窗帘材质库 | 共用正面材质，不带建筑透视或窗框 |
| 前景水体底图（独立生图） | 单独制作近景水面基础纹理，匹配原场景透视、色调和岸线，不烘焙可控灯光倒影 |
| 背景水体底图（独立生图） | 单独制作背景水域基础纹理，保持远景尺度与层次，不与前景水体合成一张；具体水域边界需按原图标注 |
| 水域遮罩与岸边遮挡 | 前景、背景分别定义可运动范围；岸线、台阶、栏杆等固定结构不随波纹变形 |
| 水面倒影效果层 | 与水体底图分开，按光源或光源组控制，随亮度、色温、开关及窗帘遮挡更新 |
| 表面配置 | ID、四角、轮廓、遮挡引用、材质、拉合方向、实例种子、联动组 |
| 通用表面与窗帘组件 | 负责映射、合成、参数更新及动画，与具体窗口坐标分离 |

有分层源图时可用前景覆盖层；仅有完整背景图时优先评估遮挡遮罩。室内人物和家具通常位于窗帘后，不应直接沿用灯光选区作为窗帘可见区域。

前景、背景水体分别生成并保存，使用参考底图约束构图，合成时对齐统一场景坐标并裁切水域边界。水体底色与倒影共用波动信息，避免只在静态倒影上叠移动波纹；近远景可采用不同纹理尺度与动态幅度，具体参数待验证。清理或覆盖原底图中的固定灯光倒影，防止关灯后残留。减少动态效果模式下保留静态水面与倒影。本轮仅登记资源需求，尚未发起生图。

## 6. 验收与待定事项

先验证正面窗、侧面窄窗、被树遮挡窗三类样例，再批量配置。

验收重点：透视与纹理贴合；窗框遮挡正确；拉合中无漏光；操作先后不改变最终结果；0% 亮度下仍可操作；全景拖动、等比缩放及离线运行保持一致。

水体验收：前景、背景可分别显示与调试；岸线无漂移、接缝和越界变形；波纹与倒影同步运动；关灯后无对应固定灯光倒影残留。

待定：具体绘制技术、编辑与保存入口、逐窗遮挡标注、材质数量、动画参数及布料受光方案。光污染等级、星数模型及科学透光参数仍按正式需求保留待确认。
