# 四档动态星空组件预览

通过根目录服务访问 `/experiments/light-pollution/sky-preview/`，或直接打开 index.html（保留仓库相对目录）。未接入正式页面。

默认仅显示纯星空和右下角调节按钮。点击打开面板，可切换四档、调整星场总数量、星星密度、闪烁强度、旋转速度、天顶/地平线/星光颜色，并暂停或恢复默认。关闭按钮或 Escape 收起面板；四档独立保存：点击“保存当前档位”将该档数量、密度、动态、颜色及暂停状态写入 localStorage；刷新回到最后保存的档位。切档保留本次会话的未保存草稿，刷新只恢复已保存值。“本档恢复默认”只重置当前档草稿，需再次保存才覆盖持久设置。保存仅限当前浏览器和当前站点地址（含端口），不写入源码；存储失败会明确提示。

组件及公开 API 见 `../components/pollution-starfield/README.md`。预览负责 UI 和 16:9 舞台，组件只绘制星空。无流星、建筑、标题或底部工具栏；无网络运行依赖。档位及参数是美术演示，未做科学标定。
