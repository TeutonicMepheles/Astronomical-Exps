# 当前夜天光性能专项约定

遵守根 AGENTS.md 与实验 AGENTS.md。本文件拥有现行性能检查要求，不扩大目录权限；仅 city-night 为维护对象。

## 实现前判断

新增或修改功能前检查动画时钟、事件频率、整景合成、WebGL 绘制、纹理上传/解码、同步计算、DOM 布局、存储写入、缓存容量及资源生命周期。跑测前覆盖与已有动画、面板和整页交互叠加的负载；新增场景不能仅用旧脚本通过代替验证。纯文档或旧版删除可记录无运行开销变化的理由。

## 运行约束

- 沿用统一调度和静态帧缓冲；隐藏/暂停时停止无用推进，恢复时重置时差。不新增独立常驻动画循环。
- 缓存键覆盖源图、灯光、几何和遮挡等实际输出条件，容量有界并有释放路径；静态纹理不每帧上传，资源销毁不得遗留 GPU/CPU 引用。
- 通过 lightingUI、scenePreview 及所属公开接口组合交互，不探查其他组件内部 DOM、不模拟编辑器按钮或猴子补丁。
- 不降低分辨率、删除特效、修改科学参数或削弱断言换取通过。未确认光度参数保持演示值边界。

## 测量与回归

记录实际 commit/dirty 状态、URL 与资源版本，核对 HTTP 源码来自本工作树。GPU 检查串行进行，使用隔离浏览器配置；记录 Chrome 版本、视口/DPR、设备/GPU、前台焦点、采样时长、压力状态。区分冷启动、稳定、连续交互和释放；同时观察 rAF 尾帧、长任务、输入响应、合成、纹理和内存趋势。相同环境/操作/画质下比较，不能只报平均帧率或用后台节流推断回退。

先导出离线包，再按 [现行检查说明](tests/README.md) 运行 verify.cjs、固定住宅、窗灯与资产回归；覆盖全部气泡、全景/特写连续调节、灯罩/高亮/暂停、反复打开关闭、零亮度、固定几何及无重复上传/闲置重绘。离线包必须断网 file:// 实际打开。

保留原始 JSON/截图，输出使用新目录，不覆盖基线。报告说明风险、实际结果及未测项；rAF 不等于合成 FPS，下一帧耗时不是正式 INP，短时内存快照不能排除泄漏。自动、人工美术、白板触控、真实草稿兼容和长期运行分别报告；不许承诺所有设备绝对流畅。

## 本次旧版移除

只删除 city-night 外的废弃代码/资源，保留现行运行与生产资产字节；没有新增纹理、动画、合成或缓存。以删除前后字节/运行清单一致、当前专项和离线回归确认影响，不把清理体积当作性能提升或科学验收。
