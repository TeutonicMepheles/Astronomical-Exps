# 城市光污染与星空演示模型

## 定位

按现有 REQUIREMENTS.md 中已确认的教学方案：光源为输入，波特尔演示等级和实绘星点数为输出。此处不是科学标定、观测星表、真实可见星数、SQM或NELM。波特尔采用原文1—9的等级方向；下述归一化权重及曲线是本页演示设计，不来自波特尔原文的定量关系。

参考：[John E. Bortle, Introducing the Bortle Dark-Sky Scale](https://www.skyandtelescope.org/wp-content/uploads/BortleDarkSkyScale.pdf)。实际等级依赖多种观测现象，不能仅由页面灯光参数精确反推。

## 输入及教学权重

| 光源 | 权重 | 生效条件 |
| --- | ---: | --- |
| 路灯 | 22% | 归一化亮度×灯罩外溢；无遮挡1、顶罩0.75、半遮光0.32、全遮光0.015、熄灯0 |
| 体育场 | 20% | 通宵按亮度；使用时打开为0 |
| 商业综合体 | 18% | 屏幕占75%、窗灯25% |
| 广告牌 | 12% | 归一化亮度 |
| 公共建筑 | 7% | 亮度×（0.25+0.75×灯罩外溢） |
| 居民住宅 | 6% | 窗灯占65%、墙灯35%；墙灯结合遮罩 |
| 公园 | 3.5% | 归一化亮度 |
| 停车场 | 2.5% | 归一化亮度 |
| 远景建筑 | 2.5% | 归一化窗灯亮度；远景资产本身仍不画天空光晕 |
| 车流 | 6.5% | 远光1、近光0.18；持续车流不提供关闭选项 |

权重和为1。多数亮度以200%归一化，公园以上限100%归一化。取各项加权和p并截断到0—1，等级为round(1+8p)。冷暖、月相、天气、空气透明度、暗适应、方位及观测者差异未建模。开发者光晕美术校准不作为用户污染输入。

## 星点及实绘计数

星库6000点、固定种子0x51a7cafe，属于程序化构图，不代表任何天区或真实恒星。位置仅从sky-clean alpha天空内部取样，中心及四向3像素保护点必须为天空，星点不落到山体和建筑。亮度层次、大小和色调固定，不使用时间闪烁或随机重抽。

按L=0.01+0.99×(1-p)^1.65放开固定排序的可见阈值。星点透明度a=clamp((L-rank)/0.008,0,1)，a≤0.02的片元明确丢弃。HUD以同一条件和当前相机边界计数实际提交绘制的星点；不是套用波特尔等级到固定星数表。数字是画布星点计数，不是肉眼可见恒星预测；UI覆盖处仍属于画布实绘。特写不含天空时计数为0。

默认最大光源p=1，演示等级9、59点。所有可调灯光归零、车流近光时p=0.0117，等级1、5885点。车流仍运行且近光仍有非零贡献，因此该状态不是全部人工光源物理消失。

## 渲染与生命周期

原base.png不可变。tooling/build-sky-clean.py 生成单独天空材质，清理烘焙星点，alpha排除山体与城市；新星空不叠加一套未计数的固定大星点。静态合成先应用天空材质与污染天空亮度，再绘制原场景灯光和固定星点。全景和特写使用同一坐标及遮罩。

新增一张2736×1536 RGBA纹理，解码16809984字节；一个静态6000×6×4=144000字节VBO和一个VAO。星空接入后的基线为29张GL纹理；当前默认页加入14张屏幕图集后合计43张。星空只在光源或相机变化引发的静态重建时绘制，沿用唯一rAF；每帧车流复用静态背景。不新增永久动画、每帧星表上传或无界缓存。pagehide释放程序、纹理、星VBO和VAO。

## 验证

verify-sky-link.cjs 从真实用户控件逐一验证10类输入、初始/减光/恢复、独立计算计数与HUD一致、位置固定、近光/时段/灯罩、特写相机、闲置无重绘及释放；在线与断网file重复。原像素回归将授权新增的天空响应范围加入允许变化区，窗户/地面/屋顶保护仍严格保持；不再断言降低光源后天空不变。自动检查不代表白板或长期运行验收。
