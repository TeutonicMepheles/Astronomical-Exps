# 城市光污染与星空演示模型

## 定位

按现有 REQUIREMENTS.md 中已确认的教学方案：光源为输入，波特尔演示等级和实绘星点数为输出。此处不是科学标定、观测星表、真实可见星数、SQM或NELM。波特尔采用原文1—9的等级方向；下述归一化权重及曲线是本页演示设计，不来自波特尔原文的定量关系。

参考：[John E. Bortle, Introducing the Bortle Dark-Sky Scale](https://www.skyandtelescope.org/wp-content/uploads/BortleDarkSkyScale.pdf)。实际等级依赖多种观测现象，不能仅由页面灯光参数精确反推。

## 输入及教学权重

| 光源 | 基础演示权重 | 生效条件 |
| --- | ---: | --- |
| 路灯 | 22% | 归一化亮度×灯罩外溢；无遮挡1、顶罩0.75、半遮光0.32、全遮光0.015、熄灯0 |
| 体育场 | 20% | 通宵按亮度；使用时打开为0 |
| 商业综合体 | 18% | 屏幕占75%、窗灯25% |
| 广告牌 | 12% | 归一化亮度 |
| 公共建筑 | 7% | 亮度×（0.25+0.75×灯罩外溢） |
| 居民住宅 | 6% | 窗灯占65%、墙灯35%；墙灯结合遮罩 |
| 公园 | 3.5% | 归一化亮度 |
| 停车场 | 2.5% | 归一化亮度 |
| 远景建筑 | 2.5% | 归一化远景城市照明 |
| 车流 | 6.5% | 远光1、近光0.18；持续车流不提供关闭选项 |

权重和为1。多数亮度以200%归一化，公园以上限100%归一化。取各项加权和p并截断到0—1，等级为round(1+8p)。冷暖、月相、天气、空气透明度、暗适应、方位及观测者差异未建模。开发者光晕美术校准不作为用户污染输入。

## 星点及实绘计数

星库6000点、固定种子0x51a7cafe，属于程序化构图，不代表任何天区或真实恒星。默认页位置从现行 C 的山脊和高楼轮廓上方取样，中心及四向3像素保护点必须为天空，星点不落到山体和建筑。星点位置与色调固定，尺寸以小星点为主，少数亮星更大。独立相位和频率调制亮度，并轻微调制尺寸；暂停媒体或开启减少动态时停止闪动。

星点和默认页面天空弥散光晕使用单独的污染量 pStar。远景总体占 90%，其中城市照明占 70%、集束光柱占 20%，按独立开关计算。其余光源按上表比例分配剩余 10%。按 L=0.01+0.99×(1-pStar)^1.65 放开固定排序的可见阈值。星点透明度a=clamp((L-rank)/0.008,0,1)，a≤0.02的片元明确丢弃。验证接口以同一条件和当前相机边界计数实际提交绘制的星点；不是套用波特尔等级到固定星数表。数字是画布星点计数，不是肉眼可见恒星预测；UI覆盖处仍属于画布实绘。特写不含天空时计数为0。

默认最大光源p=1，演示等级9、59点。所有可调灯光归零、车流近光时p=0.0117，等级1，星点接近星库上限。车流仍运行且近光仍有非零贡献，因此该状态不是全部人工光源物理消失。

## 渲染与生命周期

原base.png不可变。tooling/build-sky-clean.py 生成单独天空材质，清理烘焙星点，alpha排除山体与城市；新星空不叠加一套未计数的固定大星点。静态合成先应用天空材质与污染天空亮度，再绘制原场景灯光和固定星点。全景和特写使用同一坐标及遮罩。

默认页在原 43 张纹理基础上新增两张远景纹理，每张为 2736 × 1536 RGBA（约 16.0 MiB）。星表使用 144000 字节静态 VBO。星点可见阈值和读数随光源或相机变化更新。星光变化在合成帧绘制，复用静态背景和星点几何。沿用唯一 rAF，pagehide 释放程序、纹理、星 VBO 和 VAO。

## 验证

verify-sky-link.cjs 从真实用户控件逐一验证10类输入、初始/减光/恢复、独立计算计数与验证接口一致、位置固定、近光/时段/灯罩、特写相机、闲置无重绘及释放；在线与断网file重复。原像素回归将授权新增的天空响应范围加入允许变化区，窗户/地面/屋顶保护仍严格保持；不再断言降低光源后天空不变。自动检查不代表白板或长期运行验收。
