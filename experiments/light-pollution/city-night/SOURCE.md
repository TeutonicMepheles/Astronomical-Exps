# 当前夜天光生产资源

场景原生美术由 Seedream 5.5 经 LibTV CLI 生成并配准；本次仅沿用现有本地资产，未提交新生成任务。runtime-manifest.json 是当前加载和离线打包的唯一纹理清单，记录 SHA-256、原生尺寸、上传裁切和场景位置。

住宅使用单一固定暗底，墙灯、草地反射、眩光与窗灯均为独立正向光量；所有状态共用几何和位置。完整拥有住宅、相邻楼和树冠，alpha 仅在道路内部过渡，所有图像外缘透明。未采用独立整景端点或历史候选贴图。

resident-window-response.png 是 1700×1130 派生光图，取 assets/public-pair.png 的玻璃内部明暗并映射至当前 18 个窗孔，保留边框。仅在近窗立面提供轻微受光，不改变人物核心影区与地面。

assets/public-wall-open.png、public-wall-full.png 是公共建筑独立受光通道。assets/car-angles.png 是本地简化轿车几何离线烘焙的 36 水平角×7 俯视角图集，不来自外部模型；运行时四邻帧混合。

历史样稿、失败候选、录屏、旧实验跑测产物和重生成脚本均留在原工作目录，不随本批 PR 导入。亮度、光晕和车辆相机参数为美术教学演示，非物理测量标定。
