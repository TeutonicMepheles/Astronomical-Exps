# 夜天光生产资源

2026-11-13 从独立 2K 城市场景最终实现整合。仅复制 runtime-manifest.json 的生产光层、实际 UI 图标、灯具缩略图与对象预览。当前版已撤回动态广告序列，保留静态屏幕及受光；全局路灯、公园短柱灯、住宅整体遮光/人物、车流及远景天空联动均保留。

原生美术由 Seedream 5.5 经 LibTV CLI 生成，配准后裁切；Tiled 布局见 tiled/scene-layout.tmj。运行时以 sRGB 输入、线性浮点缓冲合成并编码输出。上传裁切与 SHA-256 见 runtime-manifest.json。范围与亮度均为美术教学参数，未做照度、眩光或视觉阈值标定。

原始生成图、失败候选、历次对比图、录屏、ZIP 与撤回的序列帧留在原工作目录，不随工程发布。离线包通过 python build_offline.py 重建，不调用生成服务。
