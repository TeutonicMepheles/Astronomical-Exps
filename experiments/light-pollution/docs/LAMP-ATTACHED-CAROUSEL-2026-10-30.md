# 灯杆与灯罩选择带一体化

用户纠正：灯罩选择带直接连接场景内灯杆，横划切换并同步光效；不是遮挡灯具的独立大弹窗。本轮继续 codex/development-20261030 的未提交工作，仅修改光污染实验；其它 concepts 与 Visual-Spec/DESIGN_PREFERENCES.md 保留。

## 当前交互

- 点按或直接横划任意场景灯头即可进入；不用先打开独立面板。
- 九盏灯采用同一固定灯杆，五种样式只替换杆顶灯罩。选中灯罩的 SVG 与场景灯杆接点重合，原 canvas 在激活灯处不重复绘制灯头；关闭时恢复 canvas 灯头。
- 五款循环滑动，半个选项宽度触发实时预览，松手吸附到杆顶，组内灯具与天空联动。触屏通过 pointer capture 与街景手势隔离；拖动灯杆/空白仍移动街景。
- 一次滑动对应一次场景事务；Esc、pointercancel、lostpointercapture、失焦取消并恢复。点击、空格和方向键保留替代操作。亮度/色温在“调光”里按需展开，默认不显示大参数框。
- 选择带随全景位置、视口尺寸和编辑器视图改变重新定位；边缘允许裁切未选中的备选项，当前灯罩始终贴合灯杆。街景移出视口时关闭；DOM 自动滚动不改变杆顶坐标。

## 模块与资源

features/lamps/carousel.js 负责 UI、定位和手势；controller.js 负责状态、固定灯杆/可换灯头与光效；variants.js 声明颈部接点与灯头轮廓。app/bootstrap 仅传入公开视图查询并在视图变化时调用 syncView。提示轮廓由灯头和固定灯杆合成，不引用组件内部 DOM。

复用现有五张 PNG，没有新增生成素材、远端资源或动画时钟。既有 shade-*.svg 是独立灯罩素材，运行时图片来自同一资源清单。独立 SVG 不是运行时动态光照快照。

## 性能专项检查

适用：pointermove 频率、五个 SVG 节点布局、跨档灯光缓存重建、图片缓存、事务与监听生命周期。

未跨档时只移动五个选项；跨档后重建灯具缓存，整景仍走统一 scheduler 合并。图片在 ready 时加载一次，SVG 在 bind 时创建一次。事件用 runtime.on 登记，ResizeObserver 在 pagehide 释放，无新增 rAF 循环。缓存与原图分辨率未降低。

同机有窗口 Chrome 156.0.8078.74、1600×900、DPR1.5、独立临时草稿、file 离线入口、串行采样。原始数据/源 SHA-256：lamp-variants-integrated-before.json 与 lamp-variants-integrated-after.json。默认合成 P95 1.0→1.3ms，默认 rAF P95 均约 13.4ms，前后各阶段均 0 长任务、0 页面异常、visible/focused。新横划压力阶段 10 次连续拖动，合成 P95 16.7ms、rAF P95 13.4ms、最大 rAF 26.7ms、0 长任务。

调光与点击阶段的 UI 路径改变，不能把它们的耗时差当成严格同操作性能提升。采样发生在最终防自动滚动微调前，最终行为由专项复测覆盖。短采样不证明长期无泄漏或所有设备无卡顿。
