## 验证

最新版本通过 npm run check、npm test、npm run test:browser，及 verify-road-sky-ui、verify-panorama-controls、verify-panorama-traffic 浏览器检查。覆盖两入口隐藏、独立灯罩、单亮度/双模式高架面板、固定色温、取消/撤销/重做、锁定、五灯熄灭后点选、双向车流、编辑冻结、存档迁移、原子拒绝、离线和零远程请求。全暗测试实绘星数从最大照明的 2 颗渐增至 205 颗；数值受视口和过渡时刻影响。

性能适用项：复用既有调度器，不增加独立计时循环；遮挡读取使用独立 willReadFrequently 画布和失效缓存；隐藏页/编辑冻结及减少动态效果行为保留。Chrome 157、1600×900、DPR1，每态4秒采样，最大照明/持续亮度拖动/暗天空平移渲染 P95 分别3.9/15.8/2.8ms，rAF P95 13.4ms，零长任务。短时桌面结果不代表白板、低端或长时间验收。原始报告见 road-sky-performance-20261111.json。

此前比例、暂停及色温控件描述属于历史方案，以本次用户最终确认为准。全量光污染专项套件本轮未重新完整执行，最新变更使用上述针对性检查；根 browser smoke 不等同于视觉验收。
