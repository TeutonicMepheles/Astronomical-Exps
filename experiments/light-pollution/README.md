# 光污染横向街景原型

源码通过根服务启动；独立离线版执行根目录 `npm run export -- light-pollution`。

支持连续街景横向移动：鼠标或触屏拖动、滚轮、触控板、左右按钮、位置滑条；场景获得焦点后支持方向键、Home、End。两端停住，不首尾循环、不分页、不切换场景。16:9 展示区等比适应窗口，非同等比例留边。减少动态效果设置下取消滚动缓动。

前景灯具已全部实例化：7 盏路灯与 6 盏步道灯，共 13 盏，可点击任意灯具后联动修改三种灯罩和色温。默认打开住宅区；点击空白或 Esc 收起面板。拖动超过 6 屏幕像素按移动处理，不误触选中。编辑面板跟随对象，对象移出可视范围自动收起，参数保留。

建筑窗灯、广告牌及远处城市灯点仍是固定底图。天空、固定星场、局部光晕、地面光斑和水面反光为动态层；保持其他光源的基础贡献。光效参数及 2200–6500 K 范围仅用于原型演示，未标定，不输出科学等级或星数。原始底图及局部生成修补仍可能有残余固定受光，需美术验收。

文件分工：index.html 结构；style.css 通用布局；app.js 滚动与输入；lamp-layout.js 灯具清单与坐标；lamps.js 路灯状态、资源定位、轮廓及光效；lamps.css 编辑面板；assets/city-layer-all-lamps.png 移除前景灯具后的透明天空城市层；assets/lamp-sprites.png 三款灯具图集。灯具图集的生成光晕通过运行时 SVG 轮廓裁切排除，描边复用同一轮廓。

shared/affordance.js 与 shared/components.css 原样复用牛顿实验 interaction-preview 内的通用 AffordanceHint；宿主提供路灯轮廓和选中状态，不读取牛顿业务状态。冰蓝 2px 悬停/焦点，暖金 3px 选中。

baseline-scroll/ 保存接入路灯前的 HTML/CSS/JS，可直接打开其 index.html 对比原始纯滚动版本。

lamp-hints.js 接入通用 GestureHint 和扁平手势图标：空闲 900ms 后在可见路灯上显示点击手势，不附加说明文字；拖动时隐藏并在停下后重新定位，首次选中路灯或按 Esc 后本次页面会话不再提示。顶部仅保留“光污染实验”标题。

背景使用内置 image_gen 生成，2026-10-13。提示词意图：3:1 连续滨河街景，住宅、公共建筑、广告牌、路灯从左至右，几何科普插画、蓝紫夜空与暖色灯光、无文字无界面，用于固定比例窗口横移。
