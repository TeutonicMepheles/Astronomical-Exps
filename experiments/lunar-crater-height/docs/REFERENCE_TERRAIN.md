# 用户指定参考地形接入（2026-11-15）

用户要求用 `陨石坑参考/陨石坑形状修正/moon-terraprinter.com.glb` 替换网页坑体，并保留原月面材质。原始 GLB、3MF 保留不改；运行入口仍是根 `index.html`。

## 数据与转换

- 来源：用户提供的 TerraPrinter GLB；SHA-256 为 `49cffe77e19dfe2ce5920fe210012e0f58a68fb94b507cca8243720d15e8c51a`。
- 原文件 500,274 个三角面，提取朝上的 251,326 个地表三角面，排除打印底板与垂直侧壁。以重心插值生成 401 × 401 高度采样。
- 坐标转换为 `(X,Y,Z) = (源 x, 源 z - 55.25308922450233, -源 y) × 1.6`。三个方向统一缩放；高度基准平移取外围地表中位值，不改变高差。不消除源文件自身可能带有的高度夸张。
- 地形渲染、剖面、端点和阴影计算使用同一个高度采样接口；插值三角形对角线与 Three.js 平面网格一致。剖面仍为 200 段，沿用原有测量采样精度。
- 圆形源地表以外仅沿径向延续边缘高度，补齐原观察窗的背景月面；有效性遮罩禁止将此延展区作为测量端点。没有把打印底座当作月面。
- 生成资源 `assets/reference-terrain.js` 为 1,073,587 字节，不在运行时加载或解析约 36 MB 的原始 GLB；普通本地 HTTP 与 `file://` 均可使用。

导出记录中的选区中心为南纬 58.82666°、西经 12.44852°，包含 `ve=3.1` 参数。用户在获知坐标与第谷坑名称存在疑点后，仍明确选择此文件作为形状来源。本次按指定文件接入，不将它认定为已完成地理身份或真实高宽比校准的第谷坑数据；输出继续使用模型单位。

```sh

node experiments/lunar-crater-height/tools/verify-reference-terrain.cjs
node experiments/lunar-crater-height/tools/verify-3d.cjs
```

交互回归样本已按新模型重选，保留受光区与阴影内部拒选、不同阴影段拒选、手动顺序测量、反选一致性、动画取消、减少动态效果、缩放窗口与剖切拖动等断言。

## 性能专项检查

适用项为网格面数、首次解码和交互绘制负载；不增加动画时钟、纹理、网络依赖或逐帧高度场生成。地形高度查询由原来的噪声计算改为常数时间的三角插值。为避免较密地形在测量聚焦时重复生成阴影贴图，初始帧、太阳高度角变化时更新两侧阴影；剖切变化时更新侧视阴影，纯测量动画复用已有贴图。阴影质量、材质和网格采样不降低。

同机 Windows、Playwright Chromium 156.0.8078.4、headless、1600 × 900、DPR 1，串行比较旧地形与新地形。每轮 32 次同时更改剖切位置和太阳高度角，等待两个 rAF 后记录整轮耗时（包含渲染等待，不是 FPS 或正式输入延迟指标）：
