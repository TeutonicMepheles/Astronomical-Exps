# 手动影长换算与高度差计算

选中左侧观察视窗中的山峰 A 后，右下角出现「手动测量」。点击后在左下角填写用直尺量到的水平影长（cm），点 × 放弃读数，点 ✓ 保存并打开「高度计算器」。太阳高度角取自当次光照设置。右下角的「自动测高」仍播放原有高度测量动画。

每张卡片保留确认时的右侧剖面截图、太阳高度角、影长和估算高度差。每页显示三张卡片，使用左右按钮翻页。第三、第四阶段可点击左下角计算器图标直接打开记录，首次测量前显示空状态。记录保留到页面刷新，换点或返回阶段仅清除未确认的读数。

## 比例尺

用实体直尺量「20 km」标尺两端的水平距离，在计算器右下角输入实测厘米数。计算器内的标尺与左侧观察窗的标尺在同一显示状态下等长。月面影长 L = 手量影长 ÷ 标尺实测长度 × 20 km，估算高度差 Δh = L × tan(α)，其中 α 是当次太阳高度角。

未填写有效标尺长度时，卡片以相对厘米显示影长和估算高度差。修改或清空标尺长度会更新所有记录的显示，原始厘米读数保留在本次页面会话中。换设备或缩放后须按新画面重新量标尺，同一次换算使用相同显示条件下测得的影长。

## 性能与回归

确认时绘制一次右侧画面并裁切影长三角形，生成最长边不超过 512 像素的图像。输入和翻页只更新表单或当前可见卡片，不触发额外的场景循环。每次实验的图像保存在当前页面内存中。

运行 tools/verify-manual-calculation.cjs 检查选点门槛、取消、剖面截图、厘米换算、翻页、等比布局和原自动测量流程。
