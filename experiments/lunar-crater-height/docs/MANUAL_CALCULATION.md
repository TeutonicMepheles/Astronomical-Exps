# 手动影长换算与高度差计算

2026-11-16 用户要求在计算高度差时增加手动选项，并预留天文馆 Excel 数字表的尺度换算规则。

## 使用与数据边界

选好 A 后，第三步出现“手动计算”。学生用直尺测量水平影长（不是右侧倾斜 A—B 线的长度），填写 cm 数值与太阳角度；老师设置 `1 cm = k km`。实时计算 `L = cm × k`、`Δh = L × tan(α)`，单位均为 km。显示六位有效数字仅为读数格式，不代表测量精度。高度差为沿用现有投影几何关系的估算，不是参考答案或已标定的第谷坑深度。

高度角 α 以水平面为基准，范围 35°～70°；入射角以法线为基准，范围 20°～55°，α = 90° − 入射角。切换基准会换算已有角度，不改变对应物理量。输入角度不改变三维场景光照。手动结果与原模型单位结果独立，自动计算仍可使用。

比例未配置、影长或比例不为有限正数、角度越界或计算溢出时清除旧结果并提示。Esc/关闭回到原按钮；同一测量重开保留草稿，重新选点/框选/调整光照后清除手量读数并取当前高度角。比例只在当前页面会话保留，不写入浏览器存储，以免其他设备误用。

## 天文馆 Excel 后续接入

当前未收到数字表，不提供示例比例作默认值，也未实现对未知格式 Excel 的上传解析。老师可按已确认数据在弹窗填写比例。正式默认值入口为 [scale-config.js](../src/scale-config.js) 的 `kilometresPerCentimetre`，当前为 `null`。设置有效正数后，离线打开也能预填。

收到 Excel 后需明确：影长列及单位、对应月面长度列及单位、是否统一线性比例、适用的展示画面/纸张/设备及缩放条件、数据来源和版本。若表格并非统一线性比例，应按实际表结构再接入，不能擅自插值或沿用单一系数。手量 cm 不等于 CSS cm；当前模型单位也不自动视为 km。缩放、剖面视角或测量载体改变后应重新核对比例。

## 性能专项检查与验证

本次适用项为输入事件、少量 DOM 文本更新、弹窗布局与重复开关。使用原生 dialog 的焦点约束，不新增动画时钟、轮询、纹理、WebGL 重绘或持久存储。监听器仅初始化一次，重开复用同一弹窗。

`node experiments/lunar-crater-height/tools/verify-manual-calculation.cjs` 覆盖未标定状态、已知算例（仅测试数据）、两种角度定义、非法值/旧结果清除、原自动流程、重新选点失效、重复开关、Esc/焦点返回、1600×900 与 1200×900 等比留边，以及 file:// 离线入口。100 次输入更新实测总耗时 11.1 ms，背景测量 SVG 变更 0 次（本机 Playwright Chromium、headless）；这是同步输入处理采样，不是白板 FPS/INP 验收。
