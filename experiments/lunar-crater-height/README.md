页面仍在本地开发中；目录整理不代表整页验收完成。改动和新资源限定在本实验目录。

月面材质最初参考本目录的 `陨石坑参考/crater-lab-standalone.html`。为避免小纹理重复产生方块感，现按用户提供的细颗粒效果图在 `src/crater-3d.js` 中生成一张覆盖整块地形的非重复颜色与轻微凹凸纹理，供俯视和剖面共用；地形几何、光照方向和测量逻辑仍由本实验控制。

`月面材质测试.html` 是单独的视觉试验副本：参考用户提供的俯视和剖面插画，使用低饱和浅色、浅色坑缘、画布笔触、细颗粒与少量碎石。测试页已移除固定灰色阴影色带，改用暖月壤色区分坑壁、外坡与坑底；实时地形投影仍随太阳高度变化。测试页只保留剖切拖拽和太阳高度调节，不显示测量结果；纹理在页面加载时生成一次，拖动时只更新剖面和光照。这里的配色是演示风格，尚未替换当前测量页面或作为已确认的科学参数。
`月面材质标准受光测试.html` 保留前一测试页供对照。复制版的纹理生成参数（笔触、颗粒、颜色与数量）已恢复为原测试页相同的值；地形仍采用连续受光的 `MeshStandardMaterial`，凹凸尺度保持 0.02，以保留其坡面光影效果。未加回固定灰色阴影贴图；太阳高度、剖切交互和暖色调保持一致。两页可分别调到 85° 对比坑缘与坑壁的明暗层次。
对照页仍只在加载时生成一张 1024×1024 纹理，共用俯视与剖面材质来源；输入时按需重绘，没有增加持续动画。Chromium 离线打开两页后，在 85° 下确认复制版坑壁和坑底的明暗区分更明显；复制版的剖切拖拽与太阳高度输入可用，浏览器未报脚本错误。`node --check` 已通过；仓库的 `npm run check`、`npm test`、`npm run test:browser` 因本机缺少 Python 而未能完成，后者的本地服务退出码为 9009。白板设备性能尚未实测。

性能专项检查：测试页新增一次性 1024×1024 Canvas 纹理、双视图 WebGL 和阴影绘制；渲染请求合并到 `requestAnimationFrame`，没有持续动画循环。已用 Chromium 离线打开并检查剖切范围两端、双视图拖动和太阳高度两端的绘制；长期运行与白板设备负载尚未实测。

## 月面太阳辐照度参考

这里的“光强”指太阳辐照度，即单位面积接收的太阳辐射功率，单位为 W/m²。月球几乎没有大气；在日月距太阳约 1 天文单位时，**垂直于太阳光的受光面**接收的总太阳辐照度约为 **1361 W/m²**。考虑一年中日月距太阳的主要变化，可取约 **1320～1410 W/m²** 作为粗略参考范围；这不是月面每个位置始终接收到的数值。[NASA 月球数据](https://nssdc.gsfc.nasa.gov/planetary/factsheet/moonfact.html)、[NASA 太阳辐照度说明](https://earth.gsfc.nasa.gov/climate/projects/solar-irradiance/science)、[NASA 地球轨道距离数据](https://nssdc.gsfc.nasa.gov/planetary/factsheet/earthfact.html)。

对于**无遮挡的水平月面**，若太阳高度角为 α，直射辐照度近似为 `1361 × sin(α) W/m²`（采用平均日月距离作演示计算）。例如 α = 30° 时约为 681 W/m²；太阳接近地平线时趋近 0。倾斜地面应按光线与局部表面法线的夹角计算；处于环形山投影内的区域没有直射太阳辐照度。此处只讨论直射分量，不代表反射光或地球照的总量。

这些数值是**科学参考资料**，尚未作为本实验的已确认参数或验收要求。当前 `src/crater-3d.js` 中 `DirectionalLight` 的 `2.4` 是画面渲染强度，不是 2.4 W/m²，也不能直接与 1361 W/m² 换算；若后续需要物理标定，应另行明确光谱范围、材质反射率和渲染映射方式。
