## 月面太阳辐照度参考

这里的“光强”指太阳辐照度，即单位面积接收的太阳辐射功率，单位为 W/m²。月球几乎没有大气；在日月距太阳约 1 天文单位时，**垂直于太阳光的受光面**接收的总太阳辐照度约为 **1361 W/m²**。考虑一年中日月距太阳的主要变化，可取约 **1320～1410 W/m²** 作为粗略参考范围；这不是月面每个位置始终接收到的数值。[NASA 月球数据](https://nssdc.gsfc.nasa.gov/planetary/factsheet/moonfact.html)、[NASA 太阳辐照度说明](https://earth.gsfc.nasa.gov/climate/projects/solar-irradiance/science)、[NASA 地球轨道距离数据](https://nssdc.gsfc.nasa.gov/planetary/factsheet/earthfact.html)。

对于**无遮挡的水平月面**，若太阳高度角为 α，直射辐照度近似为 `1361 × sin(α) W/m²`（采用平均日月距离作演示计算）。例如 α = 30° 时约为 681 W/m²；太阳接近地平线时趋近 0。倾斜地面应按光线与局部表面法线的夹角计算；处于环形山投影内的区域没有直射太阳辐照度。此处只讨论直射分量，不代表反射光或地球照的总量。

这些数值是**科学参考资料**，尚未作为本实验的已确认参数或验收要求。当前 `src/crater-3d.js` 中 `DirectionalLight` 的 `1.6` 是画面渲染强度，不是 1.6 W/m²，也不能直接与 1361 W/m² 换算；若后续需要物理标定，应另行明确光谱范围、材质反射率和渲染映射方式。
