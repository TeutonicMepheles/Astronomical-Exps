# 陨石撞击动效设计

整理日期：2026-11-11。本文记录当前实现与后续调整边界。

## 演示流程

点击“开始实验”后，在当前观察视角播放：立体陨石坠落 → 接触闪光 → 向外扩散的尘云 → 尘云消退 → 显示计算生成的陨石坑并记录结果。当前撞击实验已取消剖面视角。

动效采用预设时序，不进行撞击、破碎或流体物理模拟。画面中的速度、大小、时间均为演示表现，不可用于读取实际物理量。

## 时序与画面

| 时间 | 阶段 | 当前表现 |
| --- | --- | --- |
| 开始前 | 未撞击 | 完整地表；俯视窗显示未撞击地表 |
| 0–2.15 秒 | 坠落 | 不规则陨石旋转并加速接近落点；地球场景有暖色光尾 |
| 2.15–2.63 秒 | 接触 | 陨石隐藏；短促闪光扩大并衰减；地面扩散环出现 |
| 2.15–4.40 秒 | 扬尘 | 尘云向外扩散、抬升再渐隐；后半段逐步消退 |
| 4.45 秒起 | 结果 | 隐藏特效，重建并显示坑洞，更新俯视窗、观察比较与实验记录 |

上述时间为动画逻辑阈值；实际显示还受设备渲染与地形生成耗时影响。

## 陨石造型与材质

- 采用 Three.js 二十面体细分网格，对顶点进行多频起伏扰动，形成不规则岩块轮廓。
- 深褐灰至浅棕灰的顶点色表现岩石层次，叠加程序化颗粒贴图与凹凸贴图。
- 表面粗糙度为 0.94，凹凸强度为 0.085；启用平面着色与投影。
- 当前显示尺寸固定为场景尺度 2.1；入射轨迹固定从 `(-15,27,-11)` 到 `(0,1.4,0)`，使用平方进度加速，伴随三轴旋转。
- 模型与贴图均在本地代码中生成，无独立模型下载或运行时网络依赖。

## 特效组成

| 元素 | 实现 | 场景差异 |
| --- | --- | --- |
| 光尾 | 12 个渐变精灵，沿陨石前序位置排列，叠加混合 | 仅地球显示；月球不显示大气烧蚀光尾 |
| 接触闪光 | 暖色径向渐变精灵，扩大并快速消退 | 两场景均显示撞击闪光 |
| 扩散环 | 水平圆环网格，扩大并降低透明度 | 两场景均为示意效果 |
| 尘云 | 28 个柔边精灵，按不同方向、半径和高度展开 | 地球为棕灰尘土，月球为灰色月壤尘埃 |

月球的尘云表示撞击扬起的月壤，不代表大气烟雾。尘云当前为面向相机的精灵组合，没有体积流体求解。

## 交互与结果

- 播放时禁用“开始实验”，避免重复触发。
- 修改实验参数、切换场景或回到基准条件会取消正在播放的动效，恢复未撞击地表；取消的轮次不计入记录。
- 完成后恢复开始按钮，允许重复实验。摄像机不自动切换视角。
- 动效期间俯视窗保持静态，结束后同步新坑形。
- 坑洞与数值沿用页面现有计算模型；动效不参与数值计算。

## 当前限制与后续调整点

当前入射轨迹、陨石显示尺寸和动画时长固定，尚未与实验大小、速度、角度逐档联动。改变参数会影响计算结果和坑形，但不能将当前轨迹当作入射角的准确示意。后续如需调整，应分别确认轨迹方向、显示尺度和演示节奏。

当前实现是在尘云结束时生成结果地形，并非预先生成后揭开遮罩；地形重建可能产生短暂停顿。若后续优化，应在保持未撞击画面的同时预备结果网格，再于揭示阶段切换。

## 2026-11-11 尘土参考更新

以本目录 `陨石砸落尘土飞扬.png` 为视觉参考：浅米色、手绘颗粒边缘与小土块碎屑。采用程序化颗粒纹理，增加 32 个飞散岩块，撤掉明显的硬边扩散环。总演示时长约 5.8 秒。

坑洞改为在尘云完全遮挡并至少绘制两帧之后生成，随后才逐渐降低尘云透明度。遮挡层按当前相机视野自适应，覆盖地形切换区域（包含外围和背景坑），避免看到地表突变。俯视窗在动效结束后更新。此流程取代上文“尘云结束时生成”的旧实现描述。
