### 调试页：喷溅抛射轨迹（2026-11-12）
土块和 720 粒飞砂改用 x=vx·t、z=vz·t、y=y0+vy·t−g·t²/2，代替正弦上升下降。约 45° 附近分布的喷射角采用固定的 35–55° 演示值；以目标演示射程反算速度 v=√(gR/sin(2θ))。场景距离和时间均经过压缩，g=1.4×场景坑半径为视觉系数，不是地球/月球真实重力，也不用于比较两者真实射程；速度、角度和射程不是撞击实验预测值。忽略空气阻力，细砂亦为简化表现。体积烟雾保留原有风格与时序，不当作弹道颗粒。
每轮预计算下降段与最终地形的相交时间，落地后停止平移和旋转，土块短暂渐隐；同参数重播、暂停与跳转不依赖逐帧积分。只改动调试页，未同步实验页。
依据：[OpenStax 抛体运动](https://openstax.org/books/university-physics-volume-1/pages/4-3-projectile-motion)、[NASA Planetary Geology 撞击喷射角示意](https://ares.jsc.nasa.gov/interaction/lmdp/documents/58263main_planetary_geology.pdf)。喷射初始条件为演示选取，并非对所有撞击统一适用的科学常数。
性能：复用粒子缓冲区和临时向量，轨迹与落地点每轮预计算，无新增渲染循环或逐帧几何创建。已通过抛射顶点、恒定加速度、延迟发射、落地停止检查及调试页暂停、前后跳转、地月切换、重置检查；查看了 4.8 秒截图，无脚本/着色器错误。白板性能未实测。根 check/test 因缺少 Python 未通过，test:browser 因服务退出 9009 未通过。
