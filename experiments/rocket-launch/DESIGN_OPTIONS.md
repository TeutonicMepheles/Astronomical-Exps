# 火箭实验 · 供明早选择的设计方案

依据用户 2026-11-11 15:06Z 的最新要求：**每个设计点列三个选择，原型落地最推荐的一种。** 本文件是方案选择的主文档，早期 DESIGN_DECISIONS.md 保留需求梳理与推导背景；若措辞冲突，以本文件的落地列为准。

推荐不是已获用户批准。以下推荐均对应当前网页入口；备选除注明外尚未实现，不冒充第二/第三套成品。所有备选保留必需功能，不用“删除要求”凑选项。

## 快速体验路线
1. 第1步，在场景内按住打气筒、松开；开慢动作重试，拖右侧导向线观察方向关系。
2. 第5步，依次试四档速度；开启叠轨对照；注意第三速度切为太阳参照。
3. 第8步，试逐段引导装配、拖错退回、缺件点火检验；也可切自由装配观察差别。

## 01 全局教学导航
- **A 三章常驻导航 + 每章三个步骤 + 前后退（推荐，已落地）**：教师可随时跳讲，学生仍有明确顺序。代价：需保持跨步状态。
- B 一条九步旅程，章标题只在转场出现：叙事完整；代价：教师跳讲需打开目录。
- C 三章作为三张入口卡，进入后聚焦单章：初屏干净；代价：跨章对照多一次返回。
**选 A**，课堂重讲与跨章查看记录比严格通关更重要。

## 02 单阶段的信息布局
- **A 左任务控件、中央最大场景、结果就地显示（推荐，已落地）**：操作位置稳定；代价：侧栏占约五分之一宽度。
- B 下沿工具带、中央满幅场景、侧边只放结果：主体更大；代价：白板下沿可能被讲师遮住。
- C 场景内热点控件，选中才展开局部工具：空间因果直接；代价：控件会与运动物体争位置。
**选 A**，并把气球主手势移进场景，兼顾稳定路线与直接操作。

## 03 气球充气的操作载体
三种均保留“按住充气、松开发射”，不改成点击档位替代。
- **A 按住场景内打气筒（推荐，已落地）**：手势和物体一一对应；代价：按钮需足够大。
- B 按住气球本体：视线最集中；代价：手指会挡住膨胀过程。
- C 按住下沿长条手柄，同时让泵活塞运动：白板易够到；代价：操作与实验物体较远。
**选 A**，操作位置可见且不会遮气球；活塞细部动效留下一轮，当前按压按钮下沉反馈可体验。

## 04 气球方向探索
- **A 端点拖动改变导向线，两个方向箭头始终相反（推荐，已落地）**：复用光轴“操作线→约束物体”的教学思路；代价：首轮增加一项次要操作。
- B 固定水平线，发射后出现方向问答再揭示箭头：目标最少；代价：对任意方向的迁移理解弱。
- C 三个预设倾角，点击切换后重试：容易比较；代价：不如直接拖线自然。
**选 A**，端点远离打气主操作，首轮可不碰；如课堂测试证明分心，B 是最容易回退的方案。

## 05 慢动作与重试
- **A 慢动作常驻开关 + 独立重新开始（推荐，已落地）**：演示前就能决定节奏；代价：两个次级控件。
- B 每次正常播放后提供“慢放再看”：首屏更简；代价：首次无法直接慢放。
- C 播放后在时间线上拖动：细节观察最好；代价：操作与教学节奏复杂。
**选 A**，最少学习成本，也不把慢动作藏进菜单。

## 06 地球/太空的先预测后观察
- **A 先选能/不能，再同步播放两环境（推荐，已落地）**：预测先于答案，差异可直读；代价：界面需放两条演示带。
- B 先选环境预测，分屏先后揭示结果，可随时切换重播：悬念更强；代价：比较要记住上一段。
- C 一张场景用擦拭分界切换空气/真空，保留同一运动物体：因果强；代价：擦拭可能被理解为改变飞行中环境。
**选 A**，同一喷射条件下同时比较，避免学生把“无空气”误解为“不能推进”。

## 07 推力、自重与载荷输入
- **A 三个三档选择控件，发射一次比较一次（推荐，已落地）**：必需原输入均保留，条件可重复；代价：物理感不如拖拽配重。
- B 推力用三档、质量用可增减配重块：质量更直观；代价：配重会占用场景并与火箭抢焦点。
- C 固定一组基准，选一张“只改变一个条件”的实验卡：更强调控制变量；代价：自由探索需展开额外面板。
**选 A** 作为本轮可比较基线；不是最终控件视觉，B 很值得下一轮触屏试验。

## 08 发射结果与跨章记录
- **A 结果在当前步显示，记录按钮打开抽屉，第二章保留入口（推荐，已落地）**：不让历史列表常驻挤场景；代价：比较需打开抽屉。
- B 右侧常驻最近三次记录，新记录飞入列表：数据去向最清楚；代价：主体变窄。
- C 场景下沿可拖的记录卡，带到第二章对照区：跨章关系最强；代价：拖卡可能变成额外任务。
**选 A**，先保留条件与结果的关联。B/C 的数据迁移动效尚未实现，不能宣称当前已做到“飞入”。

## 09 垂直发射与转向入轨
- **A 同一地球上两色路径同步生长，标转向位置（推荐，已落地）**：统一参照，直接比较；代价：路径重叠时需区分颜色。
- B 左右分屏，同步进度并共享暂停：轨迹互不遮挡；代价：每个地球小一半。
- C 同镜头先直上再转向，保留前一次灰色轨迹：主画面最干净；代价：不是实时同步对照。
**选 A**，暂停/重播共用，转向节点固定高亮。

## 10 宇宙速度的选档
- **A 侧边四张固定速度门票，选中即重播（推荐，已落地）**：速度与名称一起读；代价：占用侧栏高度。
- B 场景下沿四个停靠站，物体拖到哪个站就以哪档发射：空间隐喻强；代价：容易误会速度可连续变化。
- C 四张任务卡，点击卡后明确再按发射：有准备感；代价：每轮多一次点击。
**选 A**，不使用无级速度滑杆。四档包含低速回落、第一、第二、第三宇宙速度。

## 11 宇宙速度轨迹的比较密度
- **A 默认单档聚焦，按需开启地心三档叠轨（推荐，已落地）**：先懂一条再比较；代价：需发现一个次级开关。
- B 默认三档叠轨，点图例只强调一条：比较最快；代价：首次阅读较拥挤。
- C 地心三档并排小多图、统一比例尺：不遮挡；代价：单图较小。
**选 A**，推荐态不是一上来把所有曲线堆满。第三速度不混入同尺度地心叠轨。

## 12 第三宇宙速度的参照切换
- **A 单独太阳参照示意，明确标近似条件（推荐，已落地）**：避免画错地心轨道；代价：镜头转换目前较直接。
- B 主地心图保留，旁边太阳系小窗同步显示：参照联系强；代价：双图增加注意分散。
- C 从地球镜头连续拉远到日地系统，再画逃逸方向：最有表现力；代价：过渡尺度难保持可读，开发量较大。
**选 A** 作为严谨且可用的原型；C 是下一轮最值得投入的镜头探索，尚未实现。

## 13 速度知识配对
- **A 点选速度，再点结果，统一检查（推荐，已落地）**：白板不必持续按压；代价：连线感较弱。
- B 从速度拖一条线到结果，可直接改线：关系更可视；代价：线条交叉与触屏误触要处理。
- C 把速度卡拖进三个结果口袋：空间明确；代价：口袋占用较大。
**选 A**，属于真实配对而不是点击揭示答案；检查前保留选择，错误给出正确对应。逐项正误染色仍待探索。

## 14 结构透视与部件说明
- **A 透视开关 + 部件按钮/场景点选 + 固定说明区（推荐，已落地）**：文字不随物体漂移；代价：物体与说明需一次视线移动。
- B 点击部件后局部放大，其余变暗，说明贴近放大件：焦点突出；代价：反复切换镜头容易迷失整体。
- C 拖动 X 光扫描窗看内部，停在哪显示哪一件：探索感强；代价：可能漏看细小部件。
**选 A**，可按课程需要点选，不依赖悬停；透视图只作教学示意，不标精密结构位置。

## 15 组装的落点表达
- **A 同名可读槽位，按上下级关系排列，真实拖拽吸附（推荐，已落地）**：空间关系与命中目标清楚；代价：比整箭轮廓更“教具化”。
- B 半透明整箭轮廓内直接对齐零件：空间体验最好；代价：细长部件目标难点，放大命中区后要处理互相覆盖。
- C 分两步装上下级，再把两级合体：任务更简单；代价：整体关系在最后才出现。
**选 A**，本轮优先验证任务理解；七类件包含上级、下级、级间段，不能只组装五类概念件冒充两级。

## 16 组装的引导强度
- **A 下一件与对应槽双端高亮，可切自由模式（推荐，已落地）**：让目标靠视觉出现，不靠加长说明；代价：引导会减少试错。
- B 完全自由，只在拖动时高亮可接受区域：探索感强；代价：首次可能不知道从哪里开始。
- C 三段任务卡逐步解锁（上级→下级→附件）：最易管控；代价：教师跳讲和自由比较受限。
**选 A**，仍允许不按提示顺序装配，提示不是硬锁。

## 17 错误、退回与点火检验
- **A 错位退回、缺件列名、完整后点火（推荐，已落地）**：结果及时且能重装；代价：退回动画目前直接，尚不够柔和。
- B 错件保留红色幽灵，点火时集中定位：保留试错现场；代价：错误状态可能被误读为已装好。
- C 随放随检验，最后点火只负责播放：不会积累错误；代价：减少“检验”教学环节。
**选 A**，明确区分“已放置”“已对齐”“可点火”，不让成功反馈只改一句文字。

## 18 多级分离的播放控制
- **A 自动顺序演示 + 暂停/重播 + 当前阶段（推荐，已落地）**：先建立正确时序；代价：学生主动操作较少。
- B 每个阶段出现“现在分离”按钮，错误时机给反馈：有决策感；代价：需先定义合理时机判据。
- C 拖动时间轨查看三阶段，节点吸附：适合反复观察；代价：首次会跳过因果过程。
**选 A**，下级/助推器先走、整流罩后走，剩余上级继续；后续可用 B 作为挑战模式，但不能随意捏造高度/速度阈值。

## 19 画面表现与资产组织
- **A 深蓝实验舞台 + 暖纸色水彩零件 + 青绿/赭金强调（推荐，已落地）**：宇宙背景与部件轮廓对比强；代价：深底会暴露透明抠图瑕疵。
- B 奶白纸面实验桌 + 局部宇宙小窗：更像手绘课程；代价：轨迹和发光元素不如深底突出。
- C 按章从纸面逐步过渡到深空：叙事性最好；代价：需解决章间视觉连续与不同背景下的资产适配。
**选 A**，资产保持一套比例供结构/组装/分级复用。LibTV Seedream 概念只用于笔触配色，不作为功能方案或科学结构依据。

## 20 数据保存范围
- **A 本机保存发射记录，章间共用（推荐，已落地）**：无需登录即可课堂连续操作；代价：不跨设备同步。
- B 仅当前标签页会话保存，并提供导出记录卡：隐私直观；代价：关闭页面需主动导出。
- C 教师主动建立一堂课记录集，多组实验分别收集：利于课堂对比；代价：引入班级/分组管理，超出本轮主线。
**选 A**，读取失败退回内存，不因为存储异常阻塞实验；未实现跨设备能力。

## 21 结构图的点选边界（走查后补充）
- **A 按当前插图 alpha 轮廓命中，透明空白不改变选中（推荐，已落地）**：点到物体才有反馈；代价：羽化边缘需要阈值，当前取 alpha≥24。
- B 每个部件使用扩大矩形命中区：白板更容易点；代价：相邻部件的透明空白也可能被判命中。
- C 场景只展示，所有点选走固定部件列表：最稳定；代价：直接操作感较弱。
**选 A**，外部图与透视图分别使用各自 alpha；保留按钮列表作为替代入口。轮廓内的概念分区仍为教学近似，不把它说成工程精密位置。

## 22 速度怎么给（定稿：档位是控件，连续性由谱提供）
- **A 四个档位就是控件：点它停在它上面，沿着尺拖也只会在档位之间跳（已落地）**：规格 3.2-1 写死「固定速度档位，不做无级拖动」，Cindy 16:04Z 裁定按规格走；速度仍然是量，但操作是离散的；代价：手指给不出连续变化，连续感必须由别的东西承担。
- B 一条连续可拖的速度尺（上一版）：形状连续形变最有说服力；代价：与规格 3.2-1 直接冲突，要动规格就得同时写清是谁批的。
- C 四个文字按钮（更早一版）：最省事；代价：正是甲方否掉的那一版。
**选 A**。连续性改由「背景谱」承担，见 23。

## 23 轨迹怎么呈现（定稿：谱 + 被点亮的那一条）
- **A 26 条同族轨迹铺成背景谱，当前档位那一条点亮成暖色（已落地）**：一眼看到整个「形状家族」，四个档位只是谱上的取样点；代价：谱必须与模型同源，否则就是画了 26 条假曲线。
- B 单条实时轨迹 + 走过的形状留虚线残影（上一版）：代价：残影最多几条，「家族」感出不来。
- C 三档同屏并置：对照直接；代价：没有「同一条曲线在变形」这回事。
**选 A**：谱按 u 等距取 26 条（u = 0.300 + 0.164 i），点亮那条由页面自己的模型现算，逐点同源。

## 24 尺子刻度怎么排（定稿：按 u，不按速度）
- **A 刻度按 u=(v/7.9)² 落位：4.5 / 7.9 / 11.2 / 16.7 = 0% / 16.3% / 40.7% / 100%（已落地）**：刻度间距本身就是「哪一段形状变得快」；代价：读数不均匀，第一眼像尺坏了。
- B 按速度等距：读数直观；代价：把变化最剧烈的一段（u 0.32–1）挤成一团，把几乎不变的一段铺得最开。
- C 不画刻度，只留四个按钮：最干净；代价：形状与数值的位置关系彻底消失。
**选 A**，并且**不在旁边另画一根按速度等距的尺**——两根尺同屏，必有一根在骗人。

## 25 换档怎么反馈
- **A 换档即一次脉冲：选中的刻度亮起、圆环扩散、镜头平滑移到新取景（已落地）**：有反馈，但不多话；代价：连续拖过几个档位时会连发几次脉冲。
- B 音效「咔」：代价：白板课堂常常静音。
- C 只变色不脉冲：代价：换档和静止看起来一样，学生不知道刚才发生了什么。
**选 A**。

## 26 第三宇宙速度的换参照
- **A 日心小窗：独立画框 +「换个参照系：太阳」+「不与主图同尺 · 示意」，16.7 时地心层淡出、它接管同一块画布（已落地）**：不切页、不加按钮，画幅自己换世界；代价：同屏两套比例尺，必须写在窗里。
- B 常驻小窗（视觉侧建议）：随时可对照；代价：低档位在日心图里本就看不出差别，等于长期挂一块空窗。
- C 到 16.7 切页签：干净；代价：破坏「同一门炮、同一件事」的连续感。
**选 A**，窗内保留速度预算条（地球公转 29.8 + 逃出地球余速 12.4 = 42.2，对着门槛 42.1），让 16.7 这个数有来历。

## 26b 炮台高度与归一（这条决定了几何，也决定了一句话）
- **A 炮口放 0.08 R 低塔，并把该高度的环绕速度归一为 7.9（已落地）**：7.9 是精确圆（e=0）、门槛正好落在 u=2（逃逸 7.9√2 = 11.172）、4.5 的落回弧 15.93° 看得见、7.9 的圈离球缘 0.08 R；代价：尺度是示意的，文档里必须写「以发射高度的环绕速度为 7.9 km/s 归一」。
- B 炮口放地表：物理最干净；代价：水平发射在地表是精确退化，4.5 压根没有弧（0.0°），7.9 的圈与球缘完全重合。
- C 炮口抬到 765 km（真实 7.9 的高空口径）：代价：7.9 变成该高度圆速度的 1.057×，「几乎正圆」这句限定语又回来了。
**选 A**（Cindy 16:13Z 裁定 0.08 R、Assets 覆核四档实测）。界面档位仍写教材值 11.2：它是门槛 11.172 的取整（+0.25%），所以这一档的轨迹必须略微开口，不是恰好逃逸。

## 27 逃逸怎么算「看出来了」
- **A 曲线出画 + 端点虚线淡出 + 状态词「逃出地球」（推荐，已落地）**：不靠读数也知道它不回来了；代价：出画后没有更多信息。
- B 视口角落持续给 r 与 v 的读数：信息最全；代价：又回到"看数字"。
- C 镜头无限跟随，永远把飞行器放在画面中央：最直观；代价：地球被甩出画面后就看不出「离地球多远」这件事。
**选 A**。

## 28 速度读数放哪
- **A 左栏一个大数字 + 画布上只留状态词（推荐，已落地）**：数值与形状分工，画布不被数字压住；代价：数字与滑块不在同一处，需要一次目光移动。
- B 数字贴在滑块上方：操纵与读数一体；代价：与左栏标题重复，且滑块附近已经很密。
- C 只在状态词里写"环绕/落回"，不给数字：最干净；代价：三位宇宙速度是必学数值，不能缺席。
**选 A**。

## 29 第一章怎么充气（按钮问题的另一处）
- **A 打气筒本体就是控件，按住压缩、松开弹回，画面上只留一个大百分比（推荐，已落地）**：物品即界面；代价：命中区是图片轮廓，需要 min-height 兜底。
- B 保留一块「按住打气 / 松开发射」的按钮：文案最清楚；代价：正是甲方否掉的那种"文字按钮"。
- C 拖活塞做往复运动：物理感最强；代价：小屏与白板手指下很难做得准，且一次拖拽无法表达"持续打气"。
**选 A**，文字只留一行「按住打气」作功能标签。

## 30 第三章的质量怎么表达
- **A 一根本体质量条，每分离一次肉眼可见地变短，右侧给当前占比（推荐，已落地）**：质量是"看得见的长度"而不是数字；代价：三段比例是示意，不能当工程配比。
- B 只给"满载 / 抛离下级后 / 抛离整流罩后"三行数字读数：精确；代价：仍是看数字。
- C 分离瞬间给一条加速度曲线：最能说明"为什么抛质量能加速"；代价：需要推力、比冲等参数，本轮需求文档里这些仍是待确认项。
**选 A**；C 留作下一轮，参数补齐前不编造推力曲线。

## 31 画风口径
- **A 参考一的质感（深蓝彩雾底 + 加法颗粒 + 冷蓝灰发丝线）+ 参考二的信息秩序（细线分隔、单一暖色强调）（推荐，已落地）**：与既有实验同族，且有素材线实测数值可核；代价：需要重上色贴图，纯 CSS 改不出来。
- B 保留上一版深蓝渐变 + 暖金强调：改动最小；代价：甲方已判"丑得发疯"，是饱和 UI 蓝 + 实心控件块。
- C 换成浅色纸面：更接近手绘课本；代价：与傅科摆、埃拉托色尼等既有实验的暗底页不同族，切换实验会跳。
**选 A**，数值取自 `style/STYLE-RULES.md`（底色 `#1C233F→#0E142A`、颗粒 opacity 0.045、线 `#9FB2CE` 1.4–2.2px、暖色收敛为 `#D8B074` 一处）。

## 32 装配页怎么摆
- **A 散件托盘 + 整箭幽灵轮廓作装配轴 + 槽位虚线（推荐，已落地）**：目标位置一眼可读，孩子能判断"这块该在哪"；代价：槽位仍是矩形，不是真实轮廓。
- B 只有整箭轮廓，按真实 alpha 轮廓吸附：最像装配；代价：轮廓内是空白，第一次做的人不知道从哪块开始。
- C 完全自由摆放，不吸附：最自由；代价：无法判断是否装对，也没有"完成"的时刻。
**选 A**；B 作为下一轮的进阶（轮廓吸附），不是本轮删掉的东西。
