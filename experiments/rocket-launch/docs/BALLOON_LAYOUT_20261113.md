# 气球起点、位移与操作简化 · 2026-11-13

用户要求打气筒下移/左移并与支架平齐，气球移至绳子初端；运动时同步显示 cm 位移，移除慢动作选项而默认开启，重置用图标，下一项使用牛顿望远镜的主按钮视觉。

## 实现与边界

- `main.js`、`style.css`：按画布等比布局放置泵，不再用与支架无关的百分比 bottom。泵向左移动并以其底部对齐支架的逻辑地面 y=620；提示位于把手上方，次数保留在底部。ResizeObserver 随步骤释放，泵按钮在悬停/键盘焦点/打气时不移动，只有把手/活塞活动。
- `balloon-motion.js`：独立的教学位移映射。喷口起点 x=125、滚轮起点 x=330、最大沿绳平移 470 个逻辑像素；气球只向右膨胀/收缩，喷口与滚轮共享同一平移量，充气膨胀不计入位移。充满后的完整轮廓仍避开左支架，放气终点避开右支架。
- 读数与运动共用同一状态，按 `travel / 470 × 100` 显示 cm，停止时保持终值，重置归零。**这是新增的 100cm 满量程教学示意映射，不是图片/真实装置的测量或标定，不宣称真实位移预测**。页面显示“位移（示意）”并保留 cm 单位。
- 气球飞行固定采用 0.25 倍播放速度，完整放气演示约 16 秒；充气行程节奏仍为原来的 0.7 秒，六次充满。移除速度开关，保持 Pointer Events、键盘、触屏、取消和减少动态效果支持。
- 重置为带“重新开始”可访问名称的原生 SVG 图标按钮，清除充气、次数、播放与位移；不用悬停获取核心操作。
- `components/next-action/`：按用户明确要求，在本实验私有目录适配牛顿望远镜 `ken-v123.css` 主按钮的金色渐变、边框、圆角、尺寸及阴影。来源及隔离原因见 SOURCE.md。只应用于气球页的原 `#next`，继续使用现有导航；没有跨实验运行依赖、私有 DOM 访问或 shared 修改。
- `index.html`：加载本地按钮样式，更新本轮预览版本。

入口：`http://127.0.0.1:9013/experiments/rocket-launch/` 的默认气球反作用力页。

## 性能专项与交付边界

适用项为按需位移/文字绘制、只在读数变化时更新隐藏的可访问 output、静态 SVG/CSS 主按钮、泵的 ResizeObserver 布局及生命周期。复用原动画时钟与图像，未新增 RAF/渲染器或运行时外链；示意计算为常数时间，不逐像素处理产品画面。像素分析只在测试中进行。

功能测试的短时采样为无界面 Chromium、包含截图与读回，不能作为独立帧率基准。实体白板触控、设备性能、长期混合运行和用户最终视觉接受仍待验收。未提交、推送、切分支或清理既有改动。
