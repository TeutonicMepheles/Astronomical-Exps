# KIU 原模型比例与接合位置修正

2026-11-16 用户截图指出，整流罩与二级接合、级间段、助推器存在不必要的偏移和缩放。问题成立：首轮生成器将各部件分别映射到旧教学零件的包围盒，三个轴独立缩放，导致原整箭的比例和装配关系被破坏。首轮交互检查通过不能证明外形正确；[首轮接入记录](KIU_MODEL_20261116.md) 的外形结论作废。

## 当前转换规则

`tools/build-kiu-model.py` 已移除逐件包围盒拟合和整流罩额外转角。

1. 从已下载源 `.blend` 中读取整箭各零件的完整世界矩阵，保留原位置、旋转、助推器斜向布置和发动机倾角。
2. 仅整箭共用一个相似变换：平移到芯级轴线/箭底，以 `1.6975222928401255` **统一等比**归一到 53.1 个教学坐标单位。这个全局换算不改变任何部件间的长度比、粗细比或接合关系，不代表实测工程比例标定。
3. 以源几何建立一级、二级、四助推器和整流罩的交互节点。壳体、头锥、发动机等顶点只从源世界坐标变换到这些节点的局部坐标，不再按旧零件的尺寸拉伸。整流罩两半保留源拼缝方向与分离装置。
4. 重定位装配/火焰挂点，并从新的复位姿态重建七段动画。一级所属级间段、五模块装配依赖、自动转场、自动分离、暂停与重播保持当前流程。源内部缺少的教学贮箱与载荷继续使用原示意件。
5. 原色贴图、DDS 翻转、离线图集和笔触 Shader 保持。源引擎减面和共享几何仍保留，不增加动画时钟、材质种类或渲染通道。

源资产、上游固定提交和许可见 [SOURCE.md](../assets/cz7-kiu-20261116/SOURCE.md)。本轮仅修改火箭目录，保留当前分支已有工作，不提交、不推送。

## 几何对照与验证

`source-geometry-reference.json` 记录图集转换、减面和绑定之前的 23 组源部件包围范围、来源实例与唯一全局矩阵。`validate-kiu-model.py` 独立读取最终 GLB 的父子 TRS 和实际顶点，计算组装态世界坐标，与源部件逐一对照，并验证导出层级不存在逐件或逐轴缩放。

当前结构校验 **223 条通过**。源部件边界与最终导出边界的最大差约 0.012 个归一化坐标单位，出现在减面后的一级发动机；壳体组合的最大差约 0.0014。该差异来自减面和浮点转换，不是部件尺寸拟合。几何明细保存在 `assets/cz7-kiu-20261116/validation-structure.json`。

浏览器证据位于 `docs/review/kiu-source-geometry-20261116/`：

- `test-kiu-model.cjs` 通过：原贴图与笔触的真实 GPU 对照、六处内部点选、三视口 15 次拖装、取消、非法依赖、自动转场、分离暂停、累计动画终态、20 次切换、静态不重绘、单次下载和完整纹理/几何释放，无脚本、资源或外部网络错误。
- 已查看实际默认页面的组装态、透视及分离截图。整流罩/二级、级间段接合连续，助推器恢复源相对粗细、长度与位置；没有通过挪相机掩盖错误。
- 项目级 `check`、`test`、`test:browser` 的日志在本轮证据目录。自动检查、截图观察与用户最终视觉认可分别记录。

## 性能专项检查

本轮适用风险为重新绑定后几何共享、离线 GLB 首载、原色图集、装配/扫描叠层、材质副本与重复切换释放。没有新增纹理、每帧计算、RAF 或外部依赖。新的整流罩分离装置增加少量几何，当前整箭 176,633 实例三角面、32 网格、19 个共享几何、1 张 4096² 颜色图；GLB 11,129,016 B。

先前 0.2 版短样本不能作为本轮最终结果。本轮短样本另存于本轮证据目录的 `performance-chrome.json`，GPU 采样与浏览器测试串行运行。白板实机、长期运行、完整 GPU 占用及低端设备仍待验收。

最终结果：npm run check 为 0 errors，npm test 通过，npm run test:browser 通过。有窗口 Chrome / RTX 5080 / 1600×900 / DPR 约 1 的本轮串行短样本约 17.07 秒、1,278 帧，P95/P99 为 13.4/13.5 ms，0 长任务与 0 脚本错误。已刷新当前内嵌浏览器并停留在火箭结构页；用户视觉验收待确认。
