## 性能专项检查

适用项：几何量、贴图解码与上传、Shader 编译、透视/参照叠加、高亮材质副本及纹理生命周期。没有新增动画时钟或 DOM 更新频率。

| 项目 | 原教学模型 | 新 KIU 外观 |
| --- | ---: | ---: |
| 正常外观网格/draw calls | 80 | 32 |
| 实例三角面数 | 33,040 | 172,337 |
| GLB 大小 | 567,780 B | 11,058,556 B |
| 颜色图 | 0 | 1 张 4096²，内嵌 PNG 1,739,201 B |

发动机减面后仍明显增加几何与首载成本，draw calls 减少不等于整体性能提升。图集解码的 RGBA 基础容量约 64 MiB，含 mipmap 的 GPU 开销更高；JS heap 不包含全部图片/GPU 内存。

前后均在本机有窗口 Chrome、1600×900、DPR 约 1、RTX 5080、可见且有焦点条件下串行采样同样的结构选择/透视、组装转场、自动分离及 20 次切换。原版采样约 17.06 秒，P95/P99 为 13.4/13.5 ms，0 长任务；最终新版本样本见 `after/performance-chrome.json`。前后样本不并发运行。

浏览器专项在 20 次结构/装配切换后几何/纹理数量稳定，销毁后为 0。短样本不能证明白板性能、低端设备适配或长期无泄漏；冷启动实际时长、完整 GPU 占用、白板触控和长期运行仍待验证。
