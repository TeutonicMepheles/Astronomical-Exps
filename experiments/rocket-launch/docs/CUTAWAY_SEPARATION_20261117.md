# 透视留白与前半壳剖切 · 2026-11-17

用户指出四个贮箱在透视图中与外壳贴合，要求留出可见间隔。上一轮直接按名义芯径加大箱体、再叠画完整透明外表面，导致网格压在箱体表面且结构关系难辨。本轮按用户要求修正教学展示。

## 真实关系与示意边界

[国家航天局《运载火箭的箭体结构》](https://www.cnsa.gov.cn/n6758968/n6758973/c6771776/content.html)说明，推进剂贮箱通常也构成箭体承力结构；不能默认把它理解成悬空放在另一层独立外壳中的容器。该资料是一般结构说明，不给出本长征七号模型的壁厚、空腔或安装间隙。

因此新增间隔明确为教学辨识留白，不是发现或还原了实箭的环形空腔。当前长征七号详细箱段和安装尺寸仍按 [内部布局核对](INTERNAL_LAYOUT_REVIEW_20261117.md) 的证据边界处理。外形表皮与内部贮箱的双层表示是教学模型的视觉分解，不能作为真实独立双壁结构的证明。

## 本轮改动

- 通过真实 Blender MCP 重建四贮箱，保持轴向端点与同轴位置，将展示筒径3.30收为3.00模型单位，薄连接边最大径向包络由3.312变为3.012。相对3.35名义芯径，单侧名义示意留白约0.169；不作为真实尺寸、壁厚、制造公差或推进剂容积。
- 外壳扫描强度从0.50减至0.28，透视扫描仅保留远离镜头的后半侧，前半侧不绘制；边缘轮廓增强，避免前侧网格继续覆盖箱面。普通完整外壳、完整组装参考材质保持。剖切按相机空间计算，适应已有斜俯视。
- 推力架/尾段、发动机仍沿用原KIU尺寸和安装变换；不人为把与安装结构相连的发动机悬空。上一轮两级箱底/发动机轴向避让保持，发动机进入箱体包络的顶点数仍为0。
- 模型轮廓、统一比例的认识阶段内部侧视图、组装托盘图样、热点和两阶段填充同步更新。
- 不新增按钮、标签、动画循环或运行时远程资源。私有扫描Shader只增加一个静态深度分量及半侧剔除；GLB三角面、网格数、材质数和贴图数不增加。前轮载荷网格/法线/UV/索引散列及源外壳、发动机、层级、全部动画保持。

`interior-layout-policy.json` 的 `visualRadialInset=.175` 明确标为展示参数。检查脚本据用户的新展示要求验证可见留白，而非延用上一轮“尽量贴近名义芯径”的展示约束；实际干涉、源几何保持和交互断言继续保留。外壳切面核对仅使用可见外包络，不能把上游模型内的接头、贴花等所有径向极小点当作工程内壁。
