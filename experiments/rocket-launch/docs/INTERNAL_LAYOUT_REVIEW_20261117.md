## 实现、保留与资源

通过真实 Blender MCP `execute_blender_code` 重新执行 `tools/build-interior-upgrade.py` / `refine-tank-models.py`，仅更换既有内部网格。四箱沿用用户确认的底漆、银色焊接带和PBR贴图。所有节点变换、源发动机与外壳、原始二进制前缀及七段动画定义不变；前轮天舟载荷的网格、法线、UV、索引散列保持。

- `assets/cz7-kiu-20261116/internal-layout-before.json` 与 `internal-layout-audit.json`：独立读取最终GLB的前后记录；发动机顶点计数含glTF导出重复顶点，不代表独立CAD节点数。
- `interior-layout-policy.json`：名义芯径依据及示意避让参数的明确边界。
- `tools/audit-internal-layout.py --require-clear`：最终模型发动机/箱体轴向隔离、箱间隔离、径向范围、2/4机及箱序检查。
- `tools/build-internal-drafting-layout.py`：从原图与原始装配模型校准侧视比例，现行贮箱及载荷统一按绝对装配位置投影；装配托盘仍按各部件展示框拟合。两阶段填充路径分开存储，避免相互覆盖。
- `tools/validate-internal-drafting.py`：核对统一尺度、当前箱体实际轴向范围、热点和两阶段填充。

贮箱专项校验改用当前布局长度匹配、名义径向包络及独立隔离检查，替代此前“所有箱体必须长于其直径”的外观假设；二级煤油箱可呈短筒形。

再生成顺序：MCP运行内部生成器 → transplant-interior.py → 模型/布局校验 → build-selection-contours.cjs → vectorize-selection-contours.py → update-interior-blueprints.cjs → build-internal-drafting-layout.py → rasterize-blueprint-ink.cjs → build-blueprint-fill-contours.cjs → validate-internal-drafting.py。
