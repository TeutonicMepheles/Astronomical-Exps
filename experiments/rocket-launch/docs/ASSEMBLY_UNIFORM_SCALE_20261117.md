# 组装散件统一比例与水平排列 · 2026-11-17

用户要求组装部件缩放一致、不要歪斜。本轮取消上排五组模块和下排十个内部展示件按各自图框计算fit的方式，统一模型单位尺度；不改变GLB几何、材质、源安装比例和动画数据。

## 布局规则

- `build-uniform-assembly-blueprint.cjs` 从当前GLB的实际轮廓生成组装蓝图。五组模块、十个内部展示件统一使用同一个源轮廓比例，图纸约16.068px/模型单位；图框大小随部件真实相对大小改变，不再反过来拉伸部件。
- `Rocket3D.assemblyDisplayScale()` 将同一图纸单位比例转换成运行场景缩放，上下两排共用。安装恢复原源模型节点scale=1；短箱保持短、发动机与箭体关系不因图框大小改变。
- 相机横向偏移由18归零，保留145/110的相对高度/纵深距离，纸面横向基线和五组模块轴线在屏幕中水平。认识和组装保留连续镜头，镜头不横向跳转。发动机组件内部的源安装姿态保留，不改工程数据。
- 重新布置两排图样、标注与热区。助推器作为一个四助推组合图样，四个源助推器仍保留，未减少实体；一级2/二级4台发动机的独立散件图样保持。
- 窗口尺寸变化时，所有未安装模块及内部展示件统一重排；没有新增动画循环或每帧测量。

认识页仍用装配侧视的统一比例图；组装页现在同样使用统一比例，而不再各件拟合。环带10/7/4/2、类型材质、选中排线和中央待装虚线轮廓保持。

## 再生成与资源

相机变化后需依次生成：模型选择轮廓 → 内部图样 → 认识侧视图 → `build-uniform-assembly-blueprint.cjs` → 贮箱图样细节 → 两张PNG → 填充轮廓。`hotspots.json.assemblyLayout` 是共享图纸单位比例和各图样变换的唯一布局记录。

现行蓝图/入口版本为 `assembly-uniform-20261117`；模型版本与GLB散列保持上轮值。组装蓝图对应15个实际图样（5组模块+10内部件），认识页原26个绘制位置保持。原助推器四张分散重复图样合为一个真实组合轮廓，不把clip定义或不可见副本计作新热区。

新蓝图不增加GLB、网格、材质或贴图张数。窗口resize时最多重排五组模块和十个内部展示件，保留统一页面时钟；白板和长时性能仍待实机验收。字体与字号沿用项目现有标准，仅上移组装页“分体蓝图”标题以避开最高部件。
