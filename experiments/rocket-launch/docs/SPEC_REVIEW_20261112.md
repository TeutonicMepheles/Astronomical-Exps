# 火箭 Demo 与页面功能规格核对

核对日期：2026-11-12。依据：[飞书《火箭发射实验-页面功能规格》](https://golajahfarm.feishu.cn/docx/FnvadPU4eo0DHyx2zYqcYE7WnVe)。已通过用户授权完整读取；未修改云端文档。

## 已有内容与剩余差距

当前三章九模块均有入口：气球反作用力、地球与太空、推力与载荷、发射方向、宇宙速度、速度配对、火箭结构、组装火箭、分级分离。有页面不等于已完成文档验收。

| 内容 | 当前实现与差距 | 建议顺序 |
| --- | --- | --- |
| 推力、载荷与记录 | 可调参数、发射、保留记录。本轮补齐第二章三个页面的记录入口和对比表。但计算输出是示意最高高度，并非文档要求的飞行距离；记录在点击发射时保存，尚未形成飞行结束后读取结果的完整流程。距离定义、单位、参数与成功条件待确认，不能直接改标签冒充完成。 | 优先 |
| 结构与组装 | 同一枚基本型长征七号用于外观、透视、横向组装和分离。发动机、贮箱画在图内，尚不能独立点选说明；发动机随级段整体组装，未实现文档所述独立发动机装配。五类整体模块是此前简化操作的取舍，应明确核对课程目标。 | 优先 |
| 分离挑战 | 有连续分离、暂停和重播，本轮增加当前工作级提示。仍是自动演示，缺少学生作出分离操作、得到结果反馈的挑战。时间窗口、错误条件、评分尚未确认，不擅自添加。 | 优先 |
| 高山发射与轨迹 | 速度档位和轨迹存在，但炮台资产未实际绘入场景，高山发射情境不完整。现有太阳参照图是示意曲线；完整轨迹及比例需要科学专项复核，现有自动测试不足以证明轨道科学验收通过。 | 随轨迹专项处理 |
| 宇宙速度与配对 | 本轮补齐第一、第二、第三宇宙速度名称，统一“逃离地球／逃离太阳系”，配对结果逐项显示对错和正确对应。速度值及理想条件仍应按文档标记区分会议明确要求与整理时加入、精度待确认的常数。 | 已补基础表达，待科学复核 |

文档中的质量占比图属于参考建议，声音属于待确认内容；排行榜、计时组装、真实制造参数不是本轮必备项。横向展示来自用户后续明确要求，不能按旧示意的左右布局判作缺失。章节锁定、记录上限、跨设备存储等仍按待确认项处理。

## 本轮文案和呈现调整

- 章节改为“推力与起飞／速度与轨道／结构与组装”，步骤名称用具体实验对象和动作。
- 动作按钮统一为“发射／点火／播放对照／播放轨迹／播放分离”；播放控制与记录入口分别形成语义明确的按钮组。
- 提示直接说明操作或结果，例如“尚未安装：…”、“先装载荷，再装整流罩。”、“推力不大于重力，无法起飞。”，删除重复选择确认和口号式解释。
- 配对先提示操作顺序，再报告完成数量、正确数量及每组正确对应；调整两列选择区，避免反馈和控制越过页脚。
- 记录用表格并列推力、自重、载荷和最高高度，明确“本机”“示意”，未把示意高度改称测量距离。
- 发射方向的环绕轨迹闭合一周；推力演示最高轨迹适配画面。未修改科学参数或太阳参照模型。
