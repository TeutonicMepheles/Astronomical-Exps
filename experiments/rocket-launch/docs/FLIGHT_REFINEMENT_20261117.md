# 飞行喷流、结构细节与全画幅背景 · 2026-11-17

用户指出分离演示喷流过于简陋、外壳和内部件的构造表达草率，允许复用材质；随后明确背景需要全屏，不得在中间场景区生硬裁切。

## 当前实现

- `rocket-exhaust.js` 替换原低面数圆锥和烟球。每个发动机锚点使用一份三交叉片几何和着色器，表达柔边、亮芯、颜色过渡、轴向扰动及渐隐尾部；不使用实体烟球。沿用喷口节点，随原分离层级移动；六个下级/助推喷口与四个上级喷口按课程阶段切换。
- `rocket-hardware.js` 在现有节点下增加封边、隔热外衣接缝与压紧点、推进舱分区框架和设备盖板、对接口环及级间接口环/短支撑。按父模块和现有材质合并为五个附加网格，不创建新材质或贴图；结构认识、组装和飞行共用同一节点树。GLB原网格、安装变换、动画和贮箱/发动机位置保持。小幅表面浮雕不作为名义直径测量值。
- 飞行观察角度略微偏转，改善收拢帆板和环形接口的可见度；载荷镜头垂直半幅由5改为8，留出完整模型的上下空间。仅飞行状态调整照明强度，继续复用现有PBR与工业涂装材质。
- `RocketFlightSky` 挂在完整1600×900画幅根节点，覆盖标题、导航和演示区背后，保持16:9居中留边。260个固定种子星点向下做深度差运动，拉长的尾迹、缓慢下移的薄雾和起始阶段的低层大气明度共同表现上升。装饰速度不用于显示或计算真实速度。背景没有矩形面板边界。

新增接口、外衣闭合与设备细节属于外观层次的教学简化，不是天舟或长征七号的工程重建；不得据此推断真实管路、设备数量或安装尺寸。公开外形依据与既有科学边界沿用[天舟参考载荷](TIANZHOU_PAYLOAD_20261117.md)及[内部布局核对](INTERNAL_LAYOUT_REVIEW_20261117.md)。

## 性能适用项

已在设计和跑测前参照city-night/PERFORMANCE.md的通用项：统一时钟、隐藏/暂停冻结、资源复用、固定容量、释放及叠加交互。这里不套用光污染脚本或指标。

无额外rAF、定时器、GLB请求、运行时网络或逐帧纹理上传。十个喷口各一个绘制网格，三片共18顶点；新增硬件按父节点/材质合批，几何只在模型初次加载时构建。星场沿用单画布，分辨率上限1440逻辑宽；星点数量固定，Canvas梯度为当帧绘制资源。暂停时着色器时间、背景偏移及WebGL帧数保持；减少动态效果时星场和喷流扰动静止。销毁时先卸下并释放喷流，再沿原模型释放几何/材质；共享贴图沿模型统一清理。

## 验证与边界

`test-flight-refinement.cjs` 覆盖1920×1080及1024×768实际页面：背景与整个画幅四边重合，连续分离播放、暂停/继续、重播/返回、喷流冻结/熄灭、载荷完整取景、所有新增硬件复用原材质，以及减少动态效果。保留浏览器实录、截图和原始JSON于`docs/review/flight-refinement-20261117/`。页面及Shader错误为零。

已确认原GLB响应散列和单次加载、两阶段共享内部件，以及15个散件统一比例专项通过。旧`test-recognize-assemble.cjs`仍读取已被当前溶解转场替代的`assemblyMotion.from`，在此处报错；未削弱其断言或覆盖正在进行的转场工作。旧`test-kiu-model.cjs`还指向9026端口及旧模型/旧控件，连接被拒绝，不作为当前模型验收依据；当前接入以`test-approved-interior.cjs`验证。
