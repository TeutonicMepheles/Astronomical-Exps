## 发射记录

参考牛顿第三阶段的“持续入口 + 记录本 + 缩略图卡片”组织方式，火箭目录内独立实现`RocketRecordBook`，不引用牛顿私有运行代码或素材。

参考读取版本：`experiments/newton-telescope/js/observation-recording.js` Git blob `4a8484d869b8d57000b62150887a98976c803b62`；`css/observation-recording.css` Git blob `a312235dc7b8765a642ff5a94c5f33a0c80043f4`。本实验独立命名、样式作用域和配色，字号沿用统一字体规范。

“实验记录 · 次数”在本页持续可用，每次点击发射立即创建一条。三张卡片一页，点击翻页；核心流程不用滚轮或页面滚动。每条内容：

- 发射序号和状态：进行中、完成、未起飞或中断。
- 当前GLB的完整缩略图，以及起飞时的推力上箭头、总重力（自重+载荷）下箭头；使用现有箭头资源。截图立即在同一绘制任务中捕获，避免WebGL缓冲清除后变空，也不使用燃尽后归零的推力。
- 推力、箭体自重、载荷的低/中/高档位。
- 完成时的飞行高度，单位仍为示意格。未起飞也记录；中途离开标为中断，仅记录实际推进到的画面高度。

记录本打开时暂停本次发射，关闭后恢复；完成或中断不重复追加。刷新后保留记录和缩略图，历史距离/旧版值独立标识，不伪装为当前高度或补造历史截图。继续使用`rocket-records-v1`，不自动删除旧记录；写入失败时记录仍可在当前页面查看并显示未持久化提示。没有上传或远程依赖。

## 过渡、选中与顺序

保留现行方块溶解出场/入场；转场期间禁用组装控件并阻止重复进入，退出场景会释放临时材质。进入组装清空认识页选中、悬停、按下、透视和临时高亮。

现行依赖只有**载荷先于整流罩**，其余主模块可自由安排，不新增未经确认的全局装配顺序。退回载荷也会退回依赖它的整流罩。

修复项：

- 已选件存在时，不再叠加另一部件的悬停高亮；内部件查看不显示主模块安装操作。
- 模型点击和拖拽使用相同的部件解析，优先采用明确的蓝图目标。
- 安装和退回同时校验局部选中、适配器选中、主模块身份和转场状态，隐藏或过期操作不能安装别的部件。
- 拖拽松手后阻止该手势生成的后续点击，避免误选目标位置下的另一件。未满足依赖的拖拽返回原散件位置。
- 安装失败的依赖提示不再被同一次点击清除。组装时不再对散放的未选助推器套用认识页的避让淡化。
- 说明框优先选择不挡控件的上下侧位置；中心对齐一侧有空间时可换侧，保留煤油箱说明框横向对齐，避免长斜引线。
