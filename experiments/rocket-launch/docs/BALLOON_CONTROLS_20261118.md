# 气球比例与泵下播放控件 · 2026-11-18

用户确认现有气球资源，要求整体适度缩小，把重播图标放到打气筒下方并重画图标，同时在旁边恢复慢镜头Toggle。

## 改动

- `BALLOON_LAYOUT.displayScale=.78`，气球、滚轮和胶带整体按原尺寸78%绘制，线性缩小22%。保留原单帧资源、九区域形变、刚性滚轮区域、支架与绳索位置、行程和示意厘米读数；喷气位置跟随缩小后的资源喷口，备用气球/小车也统一缩放。资源文件未重生成或修改。
- 重播与慢镜头组成独立`balloon-tools`控件组，重播图标中心对齐打气筒，下放在打气计数之后，慢镜头位于其右侧。通过既有ResizeObserver重新定位，挂在完整逻辑画幅内，不被中间舞台裁切；不依赖悬停、滚轮或滚动。
- 重画24×24描边回转箭头，继续提供“重新开始”可访问名称。点击恢复未充气、0次、0位移和停止状态，保留慢镜头偏好。
- “慢镜头”使用现有公开`markSwitch`接口、`role=switch`与`aria-checked`，默认开启，保留此前四分之一速；关闭为正常速度。播放中切换只改变后续时间倍率，不重置充气量、打气次数、位移或已播放时间。偏好在当前页面切换章节/重播后保留，不新增存储。

## 性能适用项

先检查现行性能约定的通用项：没有新增图片、纹理、每帧解码、定时器或动画循环。仍由页面统一时钟按dirty/playing/holding推进；每帧仍最多九个相邻资源区域绘制。泵下控件只在布局变化时读取边界，离开该页释放Observer并移除控件，不积累重复节点。字体字号使用统一规范，辅助UI未新增远程依赖。
