# Golajah Bot：长征七号教学模型建模任务说明

整理日期：2026-11-12。用途：可直接发送给 Golajah Bot 执行的建模任务说明。

请在你电脑的 Blender 中，为“火箭发射实验”第三阶段制作一套**可编辑、可拆装、可透视查看，并能导入网页实时运行的长征七号教学模型**。

任务需要完成建模、材质、组装与分离动画、GLB 导出及导出后验证。请实际制作并交付文件。

## 1. 项目背景与范围

当前网页：

`http://127.0.0.1:9011/experiments/rocket-launch/`

这是请求方电脑上的本地地址。如果你的电脑无法访问，请说明，不能假定已查看页面。

目前第三阶段使用 PNG 部件在 Canvas 中拼合，包含：

1. 火箭结构：外观、透视开关、部件点选高亮与名称说明。
2. 火箭组装：五模块拖拽或点选安装、吸附对齐、装配检查、点火升空。
3. 分级分离：依次操作助推器分离、一级分离、整流罩分离，随后释放载荷；支持暂停和重播。

以**基本型长征七号、两级芯箭、四枚助推器**为统一结构，三个流程共用同一套模型。

保留简单操作。网页面向 16:9 智慧白板，以点击和拖拽为主，核心流程不依赖悬停、滚轮或自由视角操作。

## 2. 建模依据与精度边界

- 外观参考可靠的长征七号基本型资料，交付时附来源链接。
- 使用工业白、浅灰、深灰、黑色和少量红色标识。
- 比例协调、部件关系清楚，兼顾完整箭体和内部教学观察。
- 内部结构允许教学简化，明确记录简化部分。
- 不编造精确内部尺寸、管路布局、飞行时序或其他科学参数。
- 避免密集铆钉、复杂管线等对课堂观察帮助有限的细节。
- 原 PNG 可辅助理解现有模块，不能将图片中的结构误差直接固化到模型中。

先提交结构拆分清单和预览，随后完成制作；常规建模细节自行判断推进。

## 3. 模型拆分与命名

请采用稳定、唯一的英文对象名称，避免导出后名称随机变化。

建议层级如下，可补充必要子节点：

```text
RocketRoot
├─ Stage1
│  ├─ Stage1Shell
│  ├─ Stage1LOXTank
│  ├─ Stage1FuelTank
│  ├─ Stage1Engine01
│  ├─ Stage1Engine02
│  └─ Interstage
├─ Stage2
│  ├─ Stage2Shell
│  ├─ Stage2LOXTank
│  ├─ Stage2FuelTank
│  ├─ Stage2Engine01
│  ├─ Stage2Engine02
│  ├─ Stage2Engine03
│  └─ Stage2Engine04
├─ Boosters
│  ├─ Booster01
│  ├─ Booster02
│  ├─ Booster03
│  └─ Booster04
├─ Payload
├─ Fairing
│  ├─ FairingLeft
│  └─ FairingRight
└─ Anchors
```

具体要求：

- 四枚助推器沿芯箭周向布置，必须是四个可独立移动的对象。
- 网页组装时四枚助推器仍可作为一个操作模块。
- 载荷位于整流罩内部，整流罩必须有厚度并拆为两瓣。
- 一级、二级外壳与内部贮箱、发动机分开，支持隐藏外壳后观察内部。
- 级间段独立命名，默认随一级离开；不要擅自增加一个必做操作关卡。
- 标识贴花应跟随所属部件，避免分离后悬留在原处。
- 不要把整枚火箭合并为一个网格。

## 4. 材质要求

使用适合 glTF/GLB 的标准 PBR 材质：

- 白色涂装具有适度粗糙度。
- 发动机和喷口有克制的金属质感。
- 内部贮箱可通过少量颜色区分，颜色含义记入说明。
- 外观尽量复用材质；相同助推器尽量复用网格。
- 程序纹理和 Blender 专有节点如影响外观，需要烘焙为本地贴图。
- 贴图尺寸与细节按课堂观看距离控制，不默认使用大量高分辨率贴图。
- 不使用运行时远程素材、字体或 CDN。

**透视模式不要永久烘焙成半透明火箭。** 保留正常不透明材质，由网页控制外壳隐藏、透明度或剖视效果。部件选中高亮也应支持运行时切换。

## 5. 组装状态与动画

学生操作保持五模块：

1. 一级。
2. 二级。
3. 四枚助推器组。
4. 载荷。
5. 整流罩。

要求：

- 提供完整装配状态和散件展示状态。
- 每个模块有确定的装配位置、旋转和吸附参考点。
- 载荷先于整流罩安装。
- 支持单个模块退回散件区，也支持整体重置。
- 部件装回后无明显缝隙、穿插或位置漂移。
- 安装动画短而清楚，表现平移、对齐和就位，不使用夸张弹跳。

**拖拽、吸附判定、缺件检查和点火解锁由网页逻辑完成。** 模型必须暴露独立对象与装配数据，不能仅交付一段不可交互的完整组装动画。

## 6. 点火与分离动画

优先使用对象位移、旋转关键帧，不需要复杂骨骼和物理模拟。

请提供以下动作，动画名称保持稳定：

| 动画 | 内容 |
| --- | --- |
| `AssemblyPreview` | 散件到完整箭体的演示，供预览或自动演示使用 |
| `LaunchPreview` | 完整箭体转为竖直姿态并开始升空 |
| `SeparateBoosters` | 四枚助推器向外脱离并相对箭体落后 |
| `SeparateStage1` | 一级及其所属级间结构脱离，二级与上部继续前进 |
| `SeparateFairing` | 整流罩两瓣向两侧打开并抛离 |
| `ReleasePayload` | 载荷与二级分开 |
| `SeparationPreview` | 完整顺序演示，便于审阅 |

动画接口要求：

- 单步动作可分别播放、暂停、定位到任意进度及重置。
- 连续播放时状态衔接一致，不能出现部件复位或跳变。
- 分离动作只控制相应部件；整箭上升和跟随镜头可由网页另行控制。
- 所有时间都是教学压缩时间，不标注为真实飞行时序。
- 不用无依据的速度瞬间增加解释分级。
- 为一级、二级及助推器提供喷焰挂点。火焰和烟雾可由网页实时生成，避免将 Blender 粒子系统作为交付依赖。
- 相机与灯光可留在 `.blend` 中用于预览，网页 GLB 默认只导出需要的模型、挂点和动画。

## 7. 坐标、原点与挂点

- Blender 工程使用明确的单位设置；记录模型总高及采用的尺寸依据。
- 若使用归一化教学比例，请明确标注，不能伪装成真实尺寸。
- 完整装配状态作为默认姿态。
- `RocketRoot` 原点建议位于芯箭底部轴心，箭体沿 Blender `+Z` 方向竖直向上。
- 导出 GLB 后核对坐标转换，并记录网页中的实际向上方向。
- 各模块原点应便于装配和分离；整流罩使用合理的开合参考点。
- 处理负缩放、法线和非预期变换，避免导出后镜像或动画偏移。

至少提供：

- 五模块的装配挂点。
- 一级、二级和四枚助推器的喷焰挂点。
- 载荷安装挂点。
- 部件标注参考点。
- 整箭镜头观察目标点。

挂点可使用 Empty，但必须确认导出后仍保留为具名节点。

## 8. 网页导出与数据要求

交付至少包含：

```text
cz7-teaching.blend
cz7-teaching.glb
rocket-manifest.json
README.md
previews/
```

`cz7-teaching.glb`：

- 自包含，纹理嵌入，不依赖外部绝对路径。
- 保留对象层级、稳定名称、材质和动画片段。
- 不依赖 Blender 插件、修改器实时计算或专用渲染器。
- 第一版优先使用通用 GLB；额外压缩版需说明解码依赖。
- 网格、材质和动画应能在网页中独立访问。

`rocket-manifest.json` 至少记录：

- 模型版本、单位、尺寸与坐标约定。
- 五模块对应的节点名称。
- 每个可点选部件对应的网格名称和中文名称。
- 装配变换、散件变换及挂点名称。
- 各动画名称、时长和播放先后关系。
- 透视模式需要处理的外壳材质或节点。
- 部件恢复默认状态所需的数据。
- 哪些内部结构属于教学简化。

不要只提供截图、视频或合并后的静态模型。

## 9. 性能与验证

这是网页实时资产，需要主动控制面数、材质数量、贴图内存和透明层叠。

交付时报告实际：

- 三角形数、网格数、材质数。
- 贴图数量、尺寸及 GLB 文件体积。
- 重复部件的资源复用情况。
- 验证使用的设备和查看工具。

不要未经确认将某个帧率、面数或文件大小写成正式验收标准。

导出后重新加载 GLB 验证：

1. 外观、材质、贴图和法线正常。
2. 五模块可独立移动与恢复。
3. 四枚助推器实际存在且分布正确。
4. 隐藏外壳后能看到四个贮箱和两级发动机。
5. 载荷位于整流罩内部。
6. 各动画片段存在，暂停、跳转和重播没有错位。
7. 分离后的剩余箭体结构完整。
8. 挂点、层级与 manifest 对应。
9. 没有外部资源请求。

提供完整箭体、内部结构、散件组装和各分离状态的预览图，以及简短动画预览。
