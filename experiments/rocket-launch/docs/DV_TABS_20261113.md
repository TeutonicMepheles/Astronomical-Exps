# 为什么要分级：左右容器与页签 · 2026-11-13

## 本轮要求与结果

用户要求：火箭与曲线各占一个容器、左右并排；用 Tab 切换三个火箭，播放时曲线同步刷新；三种方案全部结束后显示三条曲线对比。

默认入口仍为 `http://127.0.0.1:9013/experiments/rocket-launch/` → 第三章 → 为什么要分级。

- 左容器只显示当前方案的真实 Dot GLB，三枚模型共享已缓存资产与同一个 renderer，不再横向挤放。各模型保持原始比例，用外层容器等比适配展示空间，不用画面大小推算质量。
- 页签为单级小火箭、单级大火箭、三级火箭。点击或方向键/Home/End 切换；选中状态、键盘焦点与完成勾号明确。切换暂停旧方案，保存其进度、燃料、分离位姿和曲线；返回后由用户继续。
- 右容器播放前只显示当前方案的曲线，燃料、当前质量和累计 Δv 同步。两个单级方案连续燃烧，不在三分之一和三分之二处等待；三级保留燃尽定格、点击空级分离、继续燃烧和暂停。
- 三个方案实际播放到终点后，右容器显示三条完整曲线及 6.11/6.78/8.94 km/s 的结果。单纯拖轴到 100% 不算播放完成。重播某方案时回到该方案曲线，结束后恢复三曲线对比；“全部重来”清空三个方案的进度和完成标记。
- 不自动切换页签，不增加问题、评分或新的科学参数。横轴仍为推进剂消耗比例，非真实飞行时间；理想模型边界与公平比较条件保留在“模型说明”。

## 修改文件

- `staging-model.js`：三个独立播放状态及完成集合；单级/三级不同的等待边界。
- `staging-comparison.js`、`style.css`：两个展示容器、页签、当前曲线与最终对比、缩放定位和生命周期。
- `staging-rig.js`：单模型显隐、等比适配、逐方案材质/动画状态；隐藏方案不参与选取。
- `main.js`：继续持有唯一教学时钟，改用三方案状态容器；空级点选仅作用于当前三级页签。
- `test-staging-model.cjs`、`test-staging-assets.cjs`、`test-staging-browser.cjs`、`test-staging-performance.cjs`：以同等行为断言替换旧三模型同时播放的假设，没有删除填充、累计分离、复位或生命周期检查。

## 性能专项与边界

适用项：单模型显隐和等比放大、扫描/液位材质、曲线重绘、页签 DOM 更新、独立状态缓存和重复挂载。继续采用同一 RAF/renderer，材质与几何缓存复用；页签与完成 DOM 只在状态变化时更新；静止时按需绘制。

无界面 Chrome 157 / RTX 5080、1600×900、DPR 1，保留防后台节流诊断参数，完整播放三个方案并做 20 次往返采样通过：57.79 秒，8285 个 rAF 间隔，p95 7.3ms、p99 7.4ms、最大 34.7ms，未观察到长任务；一个 WebGL canvas、64 个几何，暂停后 renderer 帧数保持。JS 堆 11,120,539 → 17,220,736 bytes，未强制 GC，仅为短时快照，不用它断言长期泄漏与否。原始记录为 performance-chrome.json。此结果不代表有窗口前台或实体白板性能。

本轮资产与画面未新增运行时远程依赖，未改源 GLB/Blend/manifest。自动化、截图检查、短时性能诊断和实体设备验收分开记录；未实测实体白板、低端设备或长期混合运行，不据此宣称已通过。未提交、推送、切分支或清理已有文件。
