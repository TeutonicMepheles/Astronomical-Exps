# 三箭同步升空定性比较

用户确认的课堂流程：三箭同屏 → 一次点火 → 同时升空和自动分离 → 实时高度 → 观察多级方案更高。最新要求只保留气球同款重播图标，无重置；原理通过灯泡按钮点击展开。

## 实现与科学边界

沿用既有三模型、推进剂液面和sampleStaging理想速度/质量模型。单级大火箭与三级方案初始总质量、推进剂、结构质量、载荷一致；小火箭投入较少。未新增重力、阻力、真实飞行高度参数。comparison-flight以现有理想速度随播放时间的积分构成同一尺度的相对位移，并包括两次0.8秒自动分离期间的惯性位移；以三级最终位移统一归一至100，三者共用该分母，未独立归一或人为拉大差距。内部积分表为固定3×385个浮点数，运行时常数时间采样。显示整数相对高度，不将Δv直接更名为真实高度。

三箭起点共用基线，拉远共用同一个相机；横向补偿保持三列对齐，纵向和模型大小统一变换。同步显示推进剂消耗、两次分级抛离和喷流。结束保留各箭位置与读数，无自动结论横幅。

ascent-presentation复用于推力与载荷的相机/箭头跟随，以及分级对照的统一拉远。不改变推力与载荷演示计算与每次记录逻辑。

原理按钮在两页均可点开/关闭，支持Escape及点击外部关闭，离场销毁监听；默认不显示解释。重播按钮与气球通过replay-icon模块、同一CSS类复用，初始点击三箭同时点火，之后点击立即从头播放；不提供拖拽、逐箭选择或分离步骤操作。无运行时外部资源。

## 性能与验证

适用既有性能专项通用项：复用单一页面动画时钟、三维渲染器、原模型几何与材质；无新GLB加载，无额外RAF。图表与文字使用原Canvas。局部读数只在整数变化时更新DOM；没有表格、连续存储写入或无界缓存。灯泡事件使用AbortController离场清理。

专项检查覆盖：一次点击三箭自动完成、两个分离阶段、最终高度排序、相机边界、重播中断重来、灯泡点击/关闭/离场、三种视口；既有升空、气球重播与记录/组装回归继续运行。默认入口原样保留。白板实机与科学/教学人工验收待完成。
