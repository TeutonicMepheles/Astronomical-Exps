# 宇宙速度全屏动效裁切修复 · 2026-11-13

用户截图显示近景山体在演示区左侧和下侧出现矩形切边，要求保持此前的全屏效果。

## 原因与修复

页面已有全页 `#velocity-backdrop`，但旧实现只在此绘制背景山峦。大炮/近景山体合成图、地球、弹丸与轨迹仍在 `#scene` 内绘制，并受到局部 `rect(0,155,1500,425)` 和 stage 边界裁切。背景全屏并不等于整个动效全屏。

`velocity.js` 现在将近景山体、大炮、弹丸、比较轨迹、地球和日心场景统一绘制到既有全页层。保留原投影及 main.js 中的坐标映射，炮口与弹丸没有因换层而跳位；说明、速度轴、交互控件仍在前景。正式页面的动效只受完整 16:9 应用视口边界限制，不再受局部演示矩形裁切。单独使用无 backdrop 的场景 API 继续保持原有局部画布边界。

不改科学模型、速度参数、物理轨迹、时间尺度、源美术或 shared；不新增 canvas、renderer、RAF 或监听器。修改仅在 rocket-launch，保留其他未提交工作，不提交、推送或清理文件。

## 性能专项检查与验收边界

适用风险为全页合成、位图绘制与坐标转换。复用既有全页 canvas、单时钟、纹理及有限轨迹缓存，迁移动效绘制目标，没有新增逐帧计算循环。暂停同时冻结两个图层，离开步骤隐藏背景。

截图已检查近景山体的矩形切边消失，以及地球视角的完整轮廓。自动化截图/像素检查不等于实体白板验收。storyboard 脚本的短时指标包含截图和像素读回开销，不能作为独立性能基准；有窗口前台、白板、低端设备及长时间混合操作仍未实测。
