# 九步控件与交互约束

2026-11-12，按用户本轮审查要求修改。范围仅为火箭实验；保留工作区已有资产、模型和其他未提交工作。未提交或推送。

## 设计原则

按任务组织界面：问题或条件先出现，执行动作靠近操作对象，结果在观察后出现。持续状态、互斥选择、一次性动作使用不同语义。相同用途保持一致，不要求所有控件长得相同。

去掉通用控件组外框、章导航外框以及底部工具区外框；用留白、位置和控件形态分组。保留问题、参数单位、装配进度、部件解释等必要信息。九步导航统一在底部。主操作保留明确强调，重置作为次要操作。

| 步骤 | 当前组织与状态 |
| --- | --- |
| 气球反作用力 | 气泵仍为直接操作对象；慢动作独立开关、重置独立动作。切换慢动作不重建场景、不重置时间。 |
| 地球与太空 | 持续显示题目→预测选项；播放在场景下方。未选禁用播放、播放中锁定预测、观察结束显示结论并提供重播。改选清除上一轮结论。 |
| 推力与载荷 | 条件→发射→独立记录入口；飞行中锁定条件，结束后一次保存。导航回到底部，不再占用场景左侧。 |
| 发射方向 | 主按钮按播放、暂停、继续、结束重播转换；次要重播仅在适用时出现，预留位置避免挤动主按钮。 |
| 宇宙速度 | 速度选择、播放操作、轨迹对比开关分组；发射与重播名称随已有运行状态变化，暂停/继续显示当前动作。 |
| 速度配对 | 任务→速度与运动结果两个选择组→检查→次要重置。未选速度时结果不可点，配齐后才能检查；选中关系可见。 |
| 火箭结构 | 透视开关、外部部件选择、内部部件选择分组；选择内件自动开启透视，持续显示选中与部件说明。 |
| 组装火箭 | 装配进度→点火；五模块完整后才可点火，点火后防止重复提交；重置独立。保留点击和拖拽装配。 |
| 分级分离 | 当前分离动作、播放状态、次要重播分组；未开始隐藏重播，按门槛等待操作，暂停时不能分离，完成后暂停禁用。 |

## 可以自动化到哪一层

实现文件为 `../interaction-contract.js`，测试为 `../test-control-contract.cjs`。

1. **用途声明与类型提示**：`ControlKind` 为 JSDoc 联合类型：`action | choice | toggle | parameters | utility`。组必须有可访问名称和合法种类，构造时校验。当前仓库没有 TypeScript 编译门禁，因此这是编辑器类型提示加运行时校验，不能称为完整静态类型证明。
2. **DOM 语义 lint**：`auditControls(root)` 检查用途声明、组内是否混入不同种类的直接子控件、选择状态及开关状态。专项测试遍历九步调用；另有故意把开关放进动作组的反例，验证检查确实拒绝混用。它不是已经接入根 ESLint 的静态规则。
3. **行为回归**：检查预测先于播放、结论晚于观察、状态切换、未装配不能点火、未配齐不能检查、记录一次保存、三次分离等待等真实交互。
4. **布局回归**：1600×900、1280×960、1024×768 共 27 个页面状态，检查控件重叠、越界、页面滚动、主要动作数量；已有 composition 测试另查中心点命中与容器边界。

不能自动证明：两个业务动作是否属于同一目的、版面是否符合自然阅读顺序、画面是否美观、真实白板触控是否舒适。`aria-label` 写得合法不代表分组合理。必须保留视觉审查与设备试玩，也不能用“所有按钮相同样式”作为一致性的替代。

根目录执行：

```sh
node experiments/rocket-launch/test-control-contract.cjs
node experiments/rocket-launch/tools/perf-controls.cjs
```

## 性能专项检查

适用风险为 DOM 重建、状态事件、布局变更、反复切换装配生命周期。没有新增生产动画时钟、纹理解码、资源缓存或存储写入。慢动作更新单个开关状态，消除原整页重建；状态同步只在操作或阶段结束时执行。

Chrome 157.0.8103.39 有窗口前台、1600×900、DPR 约 1；15 次结构/装配往返、20 次慢动作切换与一次完整对照播放。采样约 6.90 秒、517 帧，rAF 间隔 P95 13.4 ms、P99 13.5 ms、最大 26.8 ms，未观察到长任务或焦点/可见性切换。装配节点最终为 1 个面板、5 个槽位、5 个部件，无重复面板堆积。

这是当前版本短时采样，未建立同环境修改前基线，不能据此宣称性能提升、无内存泄漏或所有设备达标。原始记录为 `review/control-review-20261112/performance.json`。
