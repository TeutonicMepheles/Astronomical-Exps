# 发射场弱化与半透明夹持架 · 2026-11-13

用户指出原写实发射塔喧宾夺主，要求统一半透明材质夹住火箭，周围场景弱化并偏深蓝。

## 修改

- `style.css`：参数发射页与组装发射转场使用深蓝渐变底色；原场景位图只作为低对比背景轮廓，以独立伪元素做灰度、对比/亮度降低与 0.2 不透明度合成。不对整页施加滤镜，火箭白色材质、文字与按钮不受调色影响；原背景文件不改。
- `launch-support.js`：运行时简洁示意夹持架，两个侧架、两层夹爪与底座，共 13 个盒体、5 个共享几何，全部使用同一个透明度 0.28 的蓝灰材质。不是新增真实发射台工程模型，不表达真实夹持尺寸或动力学。
- `rocket-3d.js`：夹持架在 GLB 外层场景中管理，只用于推力与载荷发射页；发射时按已有教学上升进度向两侧退出并淡出；进度复位时归位，进入结构/组装/分离/Δv 页隐藏。独立材质不污染火箭材质；destroy 释放几何与材质并解除场景引用。没有修改源 GLB/Blend/manifest。
- `index.html` 与 `main.js` 仅更新本轮样式/入口/3D 适配层的版本查询参数，让重新打开预览能取得新版；不改教学业务状态。
