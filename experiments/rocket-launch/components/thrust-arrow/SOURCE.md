# 三段伸缩推力箭头

2026-11-13 用户明确要求参考/复用埃拉托色尼实验太阳光照的风格化箭头，并以三宫方式表达衰减。

`shaft-source.png` 是本机 `experiments/earth-circumference/assets/shaft-single.png` 的逐字节副本。参考当前 `textured.html` 与 `js/globe-textured.js` 的 BEAM 素材说明（基线 b37d493、2026-11-13 读取版）。原素材斜向，采用颗粒边缘/实心箭头；不使用包含背景与多个箭头的合成图。

组件只在本实验运行，图片归一化为水平纹理一次、按本实验配色缓存染色副本。三段为固定尾端、可伸缩中段、固定箭头端；不会将整张图片缩短挤扁。小于端帽总长时保持端帽尺寸并淡出，零强度不绘制。角度、位置、长度、强度、颜色和标签由宿主提供；没有物理计算、RAF、计时器或跨实验运行依赖。图片未加载/失败时保留本地矢量后备箭头。

箭头长度仅为归一化教学表达，不是牛顿、质量、速度或真实燃料流量的标定。气球的两个相互作用力使用相同强度与相反方向；长度衰减不代表运动速度同步减小。后续发射场景的推力/载荷档位与衰减均沿用教学表现边界。
