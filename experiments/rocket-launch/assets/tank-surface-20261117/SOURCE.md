# 贮箱表面 · 2026-11-17

最新反馈修订：液氧与煤油采用冷灰蓝/黄绿两套教学材质，独立底色和粗糙度贴图，共享金属度/法线；按模型单位重复一条环带纹理，保持中段环距和环宽一致，封头使用无环纹同色材质。实际执行及验证见 [材质与环距修订](../../docs/TANK_MATERIAL_SPACING_20261117.md)。两种涂装为教学编码，不作为实箭涂装结论；下文同色/整箱归一贴图描述为历史。

最新版本：用户授权通过 Blender MCP 重做四个贮箱。现行生成器为 `tools/refine-tank-models.py`，由 `tools/build-interior-upgrade.py` 在真实 MCP 调用中执行。旧 `build-tank-surface.py` 为首轮历史生成器，不再用于现行资源。

现行贴图是四张1024²原创PNG：底色、粗糙度、金属度以及新增的切线空间法线图。使用较低饱和度的黄绿底漆、较宽的近齐平银色焊接带、轻微边缘变化与哑光金属响应；没有复制照片像素或加入地面工装。几何使用平滑筒段、椭圆封头和薄连接边，不再以鼓起的装饰环表现焊缝。执行与验证详见 [MCP贮箱重建记录](../../docs/BLENDER_MCP_TANKS_20261117.md)。下文三贴图与旧生成器描述为首轮历史。
