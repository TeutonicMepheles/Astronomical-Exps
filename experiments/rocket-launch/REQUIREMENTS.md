## 正式功能、参数与核对项

原文仅给出概述：选择箭体自重、推进动力、载荷质量等实验条件，动画模拟火箭发射高度。“内容与功能”和“可控制/输入的变量”单元格为空。

2026-10-28 会议确认：原有箭体自重、推进动力、载荷质量输入和发射高度实验继续保留，同时把课程扩展为以下三章。三章均为本实验的必做内容；各输入档位、成功判据和仿真模型仍需后续补齐。

### 第一章：为什么火箭能飞

1. 提供气球泵等直观实验，通过观察和操作说明推力如何产生。
2. 实验配有声音和慢动作，让用户看清力的作用过程，并明确展示作用力与反作用力。
3. 提供“地球还是太空”选择任务，判断对应环境中的飞行现象。
4. 提供推力和载荷挑战，让用户通过调整条件观察飞行结果。
5. 记录每次挑战的发射距离，支持前后结果比较。

### 第二章：轨道速度

1. 对比垂直发射和发射后转向水平的入轨路径，说明为什么入轨需要足够的水平速度。
2. 用高海拔大炮演示不同速度档位：约 `4.5 km/s` 时炮弹回落到地面，约 `7.9 km/s` 时形成轨道。
3. 介绍第一、第二、第三宇宙速度及其含义。
4. 提供合理、准确的轨道运行模拟；轨道模型、精度和天文体简化边界仍需确认。

### 第三章：火箭结构

1. 支持透视/X 光查看火箭内部，点击部件显示名称和说明。
2. 支持拖拽组装两级火箭，并在完成后点火。
3. 提供助推器分离、级间段分离和整流罩分离挑战，并用动画表现对应过程和时序。

## 开发和检查

本实验面向智慧白板，采用 16:9 横屏，以点击、拖拽为主；核心流程不依赖悬停或滚动。不使用复杂悬浮和滚动动效，悬停与选中效果一致（选中即悬浮）。详见[共通展示与交互约定](../../Visual-Spec/VISUAL_SPEC.md#展示与交互约定)。

总规范第 11 节的具体设备与浏览器、像素分辨率、性能阈值、科学模型与误差、刷新或跨实验状态、参数变更规则、交付验收条件仍需确认；不自行写入 60 FPS、100 MB 等阈值。

项目工程规范仍适用：资源默认可离线交付、只通过公共 API 使用 shared、独立实验配色、遵循[字体规范](../../shared/typography/README.md)。视觉资料见 [Visual-Spec](../../Visual-Spec/README.md)，其中示例页面的方案不自动成为本实验需求。

在仓库根运行 `npm run check`、`npm test`；实现或修改页面后还需 `npm run test:browser` 和实际试玩。没有页面时不得声称本实验通过了浏览器或视觉验收。

本实验尚未接入启动、导出和协作工具。开始制作前，请维护者补充入口及测试，不能跳过检查交付。
