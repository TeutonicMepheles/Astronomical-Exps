# 公共组件政策

组件需支持触屏点击和拖拽，不能依赖悬停才能显示必要提示或完成操作。悬停和选中使用相同视觉反馈，选中后持续显示，详见[展示与交互约定](../Visual-Spec/VISUAL_SPEC.md#展示与交互约定)。现有组件不一致的行为需后续调整。

唯一实现位于 shared/components；当前版本 0.1.0，六个界面组件和两个渲染组件均为试验中。预览展示当前行为，不代表视觉或功能定稿。

| 需要 | 做法 |
| --- | --- |
| 文案、位置、配色 | 公开参数、公开 CSS 变量 |
| 对接业务 | 本实验 adapters 传递状态与请求 |
| 相机、颜色、网格、材质 | 公开配置或宿主逐帧数据 |
| 光路、焦点、经纬度、科学结果 | 实验计算后通过公开接口传入 |
| 改内部逻辑 | 本实验 components 私有副本 |
| 公共修复或通用扩展 | 维护者专门 PR，验证所有消费者 |

私有副本的 SOURCE.md 必须包含组件名、来源路径、来源 commit、复制日期、修改原因、独立全局名/类名、维护者。副本不自动获得公共修复，不得被其他实验依赖。

组件不决定完成、解锁、导航成功或科学数值；宿主提供状态。共享组件不得引用 experiments、previews、archive 或 prototypes。宿主不得修改内部 DOM 或全局覆盖实现。完整 API 见 [接口说明](../shared/components/README.md) 和源码；阶段完成提示补充见 [组件登记](../shared/README.md)。

渲染组件同样遵守依赖方向。`GlobeShaderRenderer` 只接收宿主提供的贴图与逐帧相机数据，`OpticalBeam` 只接收宿主注入的 Three.js 与线段；两者都不得接管课程状态、测量、光路或反射计算。触屏点击/拖拽条款适用于界面控件；渲染组件必须保证其宿主交互仍提供等价触屏入口。

各实验独立配色。现有组件 CSS 默认色只是默认皮肤；缺少所需公开配色入口时提维护需求或使用私有副本，不增加全站主题色。
