# 学生使用说明

你负责完整制作自己的天文实验网页。平时在自己的工作区开发和备份，整页在本地试玩没问题后，再交给老师审核。你不需要记住 Git 命令。

## 第一次开始

1. 获得老师提供的私有仓库访问权限，确认自己要负责哪个网页。无需在项目中预先登记用户名。
2. 安装 Git、Python 3.10+、Node.js 22+、GitHub CLI 和你使用的 Agent 工具。让 Agent 协助检查；GitHub 登录在官方页面完成，不把密码或令牌发进聊天。
3. 克隆老师提供的仓库，在 Agent 中打开这个项目文件夹。不要下载 ZIP 代替克隆。
4. 对 Agent 说：

> 请使用 astronomical-collab Skill，检查环境并开始我负责的光污染网页。

仓库中的 Skill 位于 [.agents/skills/astronomical-collab/SKILL.md](../.agents/skills/astronomical-collab/SKILL.md)。如果工具没有发现它，直接说“请先阅读这个文件并按其中流程操作”。这套流程不要求安装全局 Skill。

Agent 会准备依赖，根据你选择的网页建立开发分支。GitHub 账号自动读取，用于交付信息，不与人员名单匹配；老师最终在 PR 中检查归属。一个人负责两个网页时，建议分别使用两个项目工作目录，让 Agent 标清各自网页。

## 平时怎么用

| 你要做什么 | 可以直接说 |
| --- | --- |
| 接着做 | “继续开发我的光污染网页。” |
| 留下一个可回退版本 | “保存进度。” |
| 收工，把进度传到 GitHub | “备份今天的进度。” |
| 收到老师的公共更新通知 | “同步项目公共更新。” |
| 网页基本完成 | “帮我进行整页自检，并打开试玩入口。” |
| 整页和离线文件都试玩通过 | “本地整页试玩和离线打开都通过，提交验收。” |
| 老师提出修改意见 | “按这个 PR 的审核意见修改：<PR 链接>。” |
| 返修后再次交付 | “返修已试玩通过，更新这个 PR。” |

**保存文件、保存版本、备份、提交验收是不同的事：**

- 编辑器保存：文件留在电脑上。
- commit：保存一个本地版本，方便追溯。
- push：把版本备份到 GitHub 的网页分支，不代表老师验收。
- PR：整页交给老师审核。只有老师合并后，才进入大家共用的 main。

建议完成一个有意义的步骤就保存版本，每天收工备份。不用等整页完成才备份，也不用每改一点就交 PR。

## 提交信息很简单

Agent 会按模板整理 commit，你核对是否准确即可：

```text
光污染：完成灯具开关

完成内容：
- 增加灯具开关

已知问题：
- 星空效果待调整
```

PR 只需要你说清三个部分：

- **交付信息**：网页、负责人、页面入口。
- **完成内容**：这次整页交付实现了什么。
- **已知问题**：还有什么问题；不知道就写“待检查”，确实没有才写“无”。

测试、分支、提交编号等由工具补充，不需要手填技术清单。

## 什么时候可以提交验收

先让 Agent 运行自检，再亲自从头到尾试玩网页，检查按钮、拖动、流程前进和返回等实际操作，并打开 Agent 导出的离线文件。自动检查通过不代表页面一定正确；科学含义不确定时问老师，不自己猜参数。

只打开 `index.html` 不能代替源码开发服务。让 Agent 运行 `npm run dev -- --experiment <网页目录>`，提供可点击地址。离线交付文件另在 `dist/<网页目录>/index.html`。

本地都没问题后再说“提交验收”。若同步公共更新后行为改变，需要再试玩。老师要求返修时继续更新同一个 PR；不要另外创建第二个。

## 遇到提示不要慌

| 提示 | 怎么办 |
| --- | --- |
| 无法访问私有仓库 | 检查 GitHub 登录状态和仓库权限，必要时联系老师。 |
| 分支不匹配 | 告诉 Agent 要继续哪个网页；不要自己删除文件或强行切换。 |
| 范围外改动 | 让 Agent 列出文件，找老师判断。不要为了检查通过删掉别人的工作。 |
| 有冲突 / 推送被拒绝 | 让 Agent 保留现场、说明原因，联系老师；不要强推。 |
| 网络或登录失败 | 可以先保存本地版本，联网后再备份；“已保存”不等于“已上传”。 |
| 检查失败 | 让 Agent 定位问题，修复后重试，不跳过检查。 |

只修改自己网页目录。公共组件、其他同学网页和项目配置需要调整时找老师。Skill 能减少误操作，不能阻止你绕过它直接操作 Git，因此日常尽量统一使用这些入口。

老师合并后，这次交付结束。下次改进让 Agent 从最新 main 开始新的网页任务分支，旧分支交给老师统一清理。
