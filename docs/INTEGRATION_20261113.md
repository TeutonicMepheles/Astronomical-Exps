## 性能专项检查与验收边界

适用风险包括多视图 Canvas/WebGL、单一动画调度、纹理预载/解码与释放、灯光静态缓存、面板反复开关，以及模型加载/失败重试和销毁。GPU 浏览器检查串行执行。光污染验证当前33个GPU纹理、150帧短采样、120次面板切换不增长纹理/上传/静态重建、暂停后停止绘制，并核对断网离线。当前最新夜景专项在 Chrome / RTX 5080、1920×1080、DPR约1、可见且有焦点下通过：150帧 rAF 中位数13.3ms、P95 13.4ms，静态重复上传/重建均0。采样关闭浏览器后台/遮挡节流，并记录实际焦点状态；这不是性能提升对比或白板性能承诺。

陨石双视图的软件 SwiftShader 专项在结果截图阶段仍出现长任务，采样P95约466.6ms、最大600ms；这不是硬件实机性能结果，不描述为性能验收通过。

所有页面仍是开发版。根检查与自动浏览器通过不能替代正式科学标定、实物智慧白板、低端GPU、长期内存或用户视觉接受。日月食、火箭、光污染等模型/美术增益保持教学示意，不新增未确认科学参数。本轮只创建 PR，维护者审核合并。
