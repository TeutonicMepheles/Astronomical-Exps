# 字体与字号规范

本文件是八个实验字体、字号与数值排版的统一入口，不定义实验主题色。设计资料、现有实现和待确认事项分开记录；归档资料不表示页面已完成迁移或视觉验收。

## 2026-11-16 当前采用方案

用户已确认八个实验统一采用阿里巴巴普惠体 3.0（PR #66 原稿第 1 页）。最终设计与验收画幅为 **1920×1080**，窗口变化时按 16:9 等比缩放、居中留边。

原 PDF 页面尺寸为 1920×1080 PDF 用户单位，标题/正文/数字文本对象的实际尺寸为 48/24/36；本次按原稿整页栅格视觉映射为该画幅下的 48/24/36 CSS 像素，不使用 CSS `pt` 的 4/3 倍单位换算。标题500、副标题300、正文400、数据500、主要操作600、辅助300；正文行高32。辅助信息以标注14为准，原 PDF 示例实际16的差异保留在此。

现有实验内部场景坐标多数为1600×900，仅是几何计算单位；在1920×1080窗口整体缩放1.2倍。实验自己的 typography.css 使用5/6字号单位映射，最终显示尺寸与1920原稿一致；city-night直接以容器宽度/1920映射。不要把1600内部坐标当作产品设计分辨率，也不要只改舞台宽高破坏点击、拖拽与场景投影。全屏目标环境仍须人工验收。

本地字体、来源、授权说明与SHA-256见 [fonts/README.md](fonts/README.md) 和 [manifest.json](fonts/manifest.json)。`typography.css` 为公共字体与字号令牌入口，各实验仅在自身 stylesheet 中映射用途；不新增常驻动画或字体逐帧探测。

### 设计尺寸与页面实现

- 表中单位为原文 pt，不是项目逻辑 px。不得直接将 24pt 写成 24px，也不得仅按浏览器单位换算就认定匹配原稿视觉。
- 实施前明确原稿设计基准、实验逻辑舞台、字号映射及整体缩放比例；16:9 只规定比例，不等于统一分辨率。
- 字体方案确定后，核对字体文件版本、所需字重、授权及离线交付方式，再通过共享公开入口实施；本轮已引入四款本地字体文件，不引入远程运行依赖。
- 字号变化需连同换行、溢出、数值与单位、按钮尺寸检查，并在目标白板观看距离和触屏环境验收。文档整理不代表这些检查已通过。

### 当前验证边界

字体选择、1920×1080设计基准、本地字重和运行映射已落实。寒蝉方案的字体对应关系不属于本轮迁移。字号增大后的真实白板观看距离、触控与长期运行仍待验收。

本轮修改覆盖八个默认入口、各实验独立字号映射、活动 Canvas 标签字体及两个受支持的离线导出。没有修改科学参数、场景几何、纹理或动画调度。主要操作、正文、读数按用途分级；场景局部投影、公式和图标保留各自几何尺度，不把关闭图标或场景符号误当正文。

性能适用项：新增完整字体首次加载约20.6 MiB，浏览器按字重缓存；不裁字库、不增加远程运行依赖、逐帧字体检查、常驻动画或纹理上传。city-night 按专项检查了11个气泡×4种窗口尺寸、120次面板切换、84组灯光状态、窗灯响应、不可变资产及断网离线渲染；通过，未出现新增纹理上传或闲置重绘。短时检查不代表长时内存或白板性能验收。

验证证据保存在本地忽略目录 artifacts/typography-20261116/，包含1920×1080截图、字体实际加载记录、参数/章节面板及离线字体检查。参数弹窗、路灯/住宅/车流、火箭轨道/结构和牛顿第一阶段已补查；未宣称逐一完成全部教学分支与设备验收。

## 现有运行约定与旧字号基线

以下保留原 v0.1 约定作为迁移前历史基线，不与上文当前方案叠加为两套强制要求；现行用途和字号映射以上文为准。

这是共同排版约定，不定义八个实验的主题色。以下系统字体约定是迁移前历史基线；现行使用本地普惠体，无远程字体依赖。

- 中文正文与控件：`--font-ui`，系统无衬线字体。
- 正文默认 16 逻辑像素、行高 1.6；辅助信息 12–14，控件 14–16，段落标题 20–24，页面标题 32–40。具体舞台密度需视觉验证，不把这些值机械替换进在研页面。
- 常用字重 400/500/600/700，避免每个组件另设字体栈。
- 读数使用 tabular-nums；数值与单位间留空格，单位不混入可计算数据。
- `--font-display` 仅供已确认的展示标题使用；是否采用衬线标题仍由具体实验设计决定。

typography.css 提供共享本地字体、用途字号令牌和公共组件字体入口；具体字号与布局由各实验样式映射，不改主题色。新增页面引用该文件，不以当前 Demo 作为标准模板。
