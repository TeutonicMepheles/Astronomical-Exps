# 字体规范 v0.1

这是共同排版约定，不定义八个实验的主题色。默认使用设备系统字体，无远程字体依赖，跨系统字形差异属于已知限制。

- 中文正文与控件：`--font-ui`，系统无衬线字体。
- 正文默认 16 逻辑像素、行高 1.6；辅助信息 12–14，控件 14–16，段落标题 20–24，页面标题 32–40。具体舞台密度需视觉验证，不把这些值机械替换进在研页面。
- 常用字重 400/500/600/700，避免每个组件另设字体栈。
- 读数使用 tabular-nums；数值与单位间留空格，单位不混入可计算数据。
- `--font-display` 仅供已确认的展示标题使用；是否采用衬线标题仍由具体实验设计决定。

typography.css 提供共享字体栈和公共组件字体入口，不强改现有字号、位置或主题色。新增页面引用该文件。现有 CSS 内遗留字体声明逐步维护，不以当前 Demo 作为标准模板。
