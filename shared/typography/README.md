### 设计尺寸与页面实现

- 表中单位为原文 pt，不是项目逻辑 px。不得直接将 24pt 写成 24px，也不得仅按浏览器单位换算就认定匹配原稿视觉。
- 实施前明确原稿设计基准、实验逻辑舞台、字号映射及整体缩放比例；16:9 只规定比例，不等于统一分辨率。
- 字体方案确定后，核对字体文件版本、所需字重、授权及离线交付方式，再通过共享公开入口实施；本次未引入字体文件或远程依赖。
- 字号变化需连同换行、溢出、数值与单位、按钮尺寸检查，并在目标白板观看距离和触屏环境验收。文档整理不代表这些检查已通过。

### 待确认事项

1. 全站选用哪套字体，或是否有明确的实验适用范围。
2. 原稿设计基准及 pt 到各实验逻辑舞台的映射规则。
3. 寒蝉德黑体的 `45 Light`、`ConMedium` 与实际字体文件的对应关系。
4. 字体版本、授权和本地交付资源；页面迁移批次及白板验收结果。

## 现有运行约定与旧字号基线

以下保留原 v0.1 约定作为迁移前基线，不与上述待选表叠加为两套强制要求。新方案未确认前维持现有运行入口；旧数值不是新方案已批准的替代值。

这是共同排版约定，不定义八个实验的主题色。默认使用设备系统字体，无远程字体依赖，跨系统字形差异属于已知限制。

- 中文正文与控件：`--font-ui`，系统无衬线字体。
- 正文默认 16 逻辑像素、行高 1.6；辅助信息 12–14，控件 14–16，段落标题 20–24，页面标题 32–40。具体舞台密度需视觉验证，不把这些值机械替换进在研页面。
- 常用字重 400/500/600/700，避免每个组件另设字体栈。
- 读数使用 tabular-nums；数值与单位间留空格，单位不混入可计算数据。
- `--font-display` 仅供已确认的展示标题使用；是否采用衬线标题仍由具体实验设计决定。

typography.css 提供共享字体栈和公共组件字体入口，不强改现有字号、位置或主题色。新增页面引用该文件。现有 CSS 内遗留字体声明逐步维护，不以当前 Demo 作为标准模板。
