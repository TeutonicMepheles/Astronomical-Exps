# 视觉规范

各实验采用一致的科普插画风格，分别设计主题色；字体遵循[字体规范](../shared/typography/README.md)。牛顿望远镜和光污染都在开发中，现有画面不作为完工模板。

八个实验统一面向智慧白板，使用 16:9 横屏，以点击、拖拽为主；不使用复杂悬浮和滚动动效，悬停与选中反馈一致。完整规则见[展示与交互约定](VISUAL_SPEC.md#展示与交互约定)。

设计要求与现有实现分开阅读。牛顿的配色、三阶段场景和模型参数不自动成为其他实验的要求。新增实验应记录自己的配色和代表画面。

本目录于 2026-10-12 根据当时的牛顿页面及[实验视觉说明](../experiments/newton-telescope/VISUAL_SPEC.md)整理，后续补充了独立配色约定。文档整理不代表视觉验收；实际效果仍需在页面中检查。

参考原图保存在 `references/`，分类预览仅为缩小拼排。图片作者和授权信息尚不完整，目前用于画风研究；用于发布资源前需核对授权。
