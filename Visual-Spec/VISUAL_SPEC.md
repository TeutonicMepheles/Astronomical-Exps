# 视觉规范

## 1. 整体方向

**全站统一科普插画风格，各实验建立独立主题色；配色随内容变化，造型、材质、细节密度和交互表达保持一致。**

本原则适用于全部实验页面的背景、天体、地形、建筑、人物、仪器、图标、装饰及动态效果。每个实验可选择自己的主色调，深蓝星空不是全站必选背景。参考图索引见 [画风参考](REFERENCES.md)。

已明确方向：安静、有探索感的科普插画。以几何概括的形体、清晰轮廓、大色块及克制的明暗建立识别，用少量颗粒或纸感增加质感；可以有浅立体空间，但保持插画化表现。实验对象、光路和读数是视觉重点。原参考图一提供细颗粒、简化物件和冷暖点缀，原参考图二提供空间层次、细轨道线与编辑式信息组织，详见 [画风参考](REFERENCES.md)。

参考图片按用途组织：颜色参考用于研究配色，画风参考用于提炼造型与质感，创意参考用于借鉴构图和科学意象，元素参考用于借鉴图形表达。不同图片不要求逐张混搭；其中商标、封面标题、装饰文字和水印不属于页面必备元素。

### 全站一致与实验差异

| 维度 | 全站保持一致 | 实验可自行变化 |
| --- | --- | --- |
| 造型 | 几何概括、结构清楚、细节有取舍 | 天体、仪器、城市、地貌等题材和轮廓 |
| 材质 | 插画化色块、柔和明暗、克制纹理，同一画面光源协调 | 玻璃、岩石、金属、烟尘的必要材质差异 |
| 色彩 | 清楚的主次关系、可读对比、稳定的信息语义 | 主色、辅助色、局部强调色、背景明暗 |
| 空间 | 实验对象突出，背景和装饰退后 | 俯视、侧视、空间模型、分屏等任务所需构图 |
| 科学图形 | 轨迹、引线、刻度及标注保持清晰，实际含义可辨 | 对应各实验的图形内容和必要线型 |
| 控件 | 字体体系、组件形态、状态逻辑与反馈方式一致 | 与主题协调的表面色和强调色 |

三维模型也应匹配同一插画表现：控制材质反射、纹理密度与光照强度，避免设备照片、写实渲染和简化插画在同一页面中无规则混用。真实阴影、折射和形变只在有助于实验理解时保留。

层级依次为背景氛围、实验对象与动态光路、说明与操作。背景颗粒不能污染文字与控件边缘；避免高光塑料外壳、厚重浮雕、霓虹描边和密集装饰星点。设备仍应具备足够的夹具、厚度和支架细节，保证对象可识别。

## 2. 色彩

全站按颜色角色组织配色：背景、场景主体、面板、主文字、次文字、交互强调与状态提示。各实验可替换主题色，并按背景明暗配套调整文字、边框和面板，不能仅替换一个主色而破坏可读性。完成、警告、选择、焦点等语义及其形状/文字提示保持一致；实验物理信息的颜色不随主题任意改义。

具体实验配色尚未逐项定稿，不在此指定八套强制色值。后续每个实验应记录主题色板及一张代表画面，再检查它与共用画风、控件和可读性要求的一致性。

下表是**牛顿望远镜实验的现有建议色板**，并非全站强制色板，也不是从参考图片精确采样或当前 CSS 全部采用的值。实际令牌另见 [实现基线](IMPLEMENTATION_BASELINE.md)。

| 角色 | 设计色值 | 使用要求 |
| --- | --- | --- |
| 星空底色 | `#080D27` | 主背景 |
| 背景过渡 | `#171D46` | 局部低饱和蓝紫层次 |
| 面板底色 | `#202E4D` | 与场景有可辨层级 |
| 雾蓝 | `#7693BA` | 边缘、次要物件 |
| 薰衣草蓝 | `#ACAEDB` | 插画明暗、少量装饰 |
| 冰蓝 | `#C4E3F1` | 镜面、高亮边缘、焦点轮廓 |
| 主文字 | `#F0F3FA` | 标题、控件名称 |
| 次文字 | `#ACBBD1` | 说明，避免过低透明度 |
| 暖金 | `#F4CB83` | 主动作、选择、关键光学点 |
| 薄荷 | `#96D5CC` | 已观察、已完成 |
| 珊瑚 | `#D996A1` | 少量提示或天体点缀 |

牛顿光学实验的实光路采用暖黄实线与传播方向提示；虚焦点延长线采用蓝色虚线。颜色必须与线型、名称或状态标记共同表达含义。其他实验按自身科学内容定义颜色语义，不要求把所有动态效果都画成暖黄光线。

## 3. 构图与排版

当前页面采用 **1600 × 900、16:9 固定逻辑舞台**，按窗口可用宽高的较小比例整体缩放、居中留边，不纵向重排，不单独拉伸模型或前景。此为牛顿望远镜页面基线，不自动扩展为所有未来实验的移动端方案。

三个阶段复用 `.introduction` 标题结构及 `ExperimentHeading`，仅更新内容；字号、间距、横线、颜色统一沿用第三阶段。第一阶段不得恢复独立标题卡片或另设标题字号。

设计目标：中文正文使用清晰黑体，14–16px、行高 1.5–1.7，辅助说明不小于 12px；数值使用等宽数字。展示标题可探索宋体或衬线体，但海报衬线字尚不是现有页面的实现要求。文字保持为可编辑界面内容，不烘焙进资源图。

间距以 8px 为基准，常用 8/16/24/32px；说明区保持稳定网格与留白，引线或轨道约 1px，装饰线低对比。以上尺寸为设计目标或逻辑像素，固定舞台缩小后的实际屏幕可读性需另行验证。

## 4. 控件与状态

沿用已有规范：面板圆角 12–16px、按钮 8–12px，细边框、微弱内侧高光和柔和短阴影；减少多层套框与厚重底部浮雕。三阶段共用同一套按钮、标记和面板样式，第一阶段只调整导航排列。

| 状态 | 视觉要求 |
| --- | --- |
| 默认 | 低对比雾蓝边框，名称清晰 |
| 悬停 | 底色稍亮，保持尺寸稳定 |
| 选择 | 暖金边框与明确状态标记；阶段导航当前项现用蓝色高亮 |
| 键盘焦点 | 独立可见的冰蓝轮廓 |
| 完成 / 已观察 | 薄荷勾选或完成标记，与选择状态区分 |
| 禁用 / 锁定 | 降低对比，保留可读名称与语义状态 |
| 可放置目标 | 虚线入口或暖金目标边界，与静态装饰区分 |

设计目标：可点击目标至少 44 × 44px，状态过渡约 150–200ms，支持减少动态效果。现有小按钮、圆角和浮雕并未全部统一，见实现基线，不应宣称已经达标。

## 5. 三阶段场景

### 认识镜面

- 正视、固定视角的光学实验场景：深蓝网格、刻度主光轴、发射器及带夹具/支架的镜面侧视图。移除早期房间、桌腿、屏幕和场景内托盘。
- 网格覆盖整个阶段背景，四周柔和暗角、底部环境遮蔽和细颗粒，中部设备及光路清楚。Viewport 为透明交互层，不套独立网格框；拖放反馈边界仍可显示。
- 第一阶段隐藏星空、山景和右侧说明卡，导航在顶部横向排列；镜片集中于下方操作台，与场景使用同组设备美术。
- 光源固定在 **−126 cm**；镜面沿主轴拖动或通过 **−30～144 cm** 位置滑块移动。焦距、镜面位置与光路实时同步，不能把光线烘焙进背景。
- 暖黄实光路用细亮芯叠加高斯衰减柔光，沿路径轻微改变散射强度；避免均匀硬边光束柱，移动光点保持小而克制。虚延长线继续使用蓝色虚线。
- 文具插画仅局部出现在边缘：蓝灰笔记本、淡光学草图纸、木色铅笔与橡皮。降低亮度与饱和度、自然裁切，中央留空，位于设备与文字后方，不接收指针事件。
- 文具资源按 960 × 540 基准在四个边缘区域局部显示，不能整幅拉伸到舞台尺寸。

### 组装望远镜

保留星空、透明山景前景与三维望远镜的空间布局；左侧阶段进度、中央装配区域、右侧说明与底部操作台各司其职。主镜、副镜安装位以可见目标提示引导；选件特写、恢复整体视角和入位动画应维持对象识别与光路连续性。

### 参数观测

沿用共享标题、星空山景、透明镜筒、镜片及支架。保留右侧目镜预览、底部参数台和观测记录区。模型可适度夸张镜片比例与光束宽度以辅助教学；天体预览属于示意图，不表达真实观测精度。

## 6. 美术资源

独立位图物件使用透明 PNG；同组保持视角、对象占比、光源、色盘与纹理强度一致，轮廓留安全边距。不同实验可使用不同主题色，同类元素的造型与细节密度仍需协调。以下镜面形体、冰蓝玻璃及设备组要求仅适用于牛顿实验。通用镜面图标用正方形画布；第一阶段侧视设备允许按完整支架与出光口的需要使用不同长宽比，不应强制裁方。

通用镜面辨识：平面镜是平整薄圆盘，凹面镜是内凹浅碗，凸面镜是外鼓浅穹顶。小图优先保证曲率与轮廓；仍用名称与实验光路辅助说明。

材质后续修订已明确为透亮的抛光光学玻璃：冰蓝/蓝紫、半透明内面、清晰厚度边缘、折射及克制高光；玻璃正面不加纸面颗粒，避免摄影式环境倒影。该美术表达不改变反射镜课程的物理类别。

资源不包含名称、按钮底板、选择边框或完成勾选。第一阶段采用 `assets/optical/` 设备组；`assets/mirrors/*-v2.png` 为通用镜面组，不能混淆两组用途。文字、刻度、状态与光路由运行时绘制。

## 7. 后续验收标准

1. 在真实深色背景检查透明边缘、白边及同组对象一致性；在 64–96px 检查镜面辨识。
2. 检查文字对比目标 4.5:1、关键控件轮廓 3:1；不要仅凭色值表判断达标。
3. 检查悬停、选择、完成、锁定、键盘焦点与拖放目标，不只检查静态默认状态。
4. 在 16:9 与非 16:9 窗口确认等比缩放、留边、文字可读性和有效点击尺寸。
5. 三阶段切换时检查共享标题一致、光路和设备对齐、装饰不遮挡操作；开启减少动态效果后检查行为。
6. 跨实验并排检查：即使主色与背景明暗不同，物件造型、纹理强度、线条层级和控件仍呈现同一套科普插画风格。检查所有画面元素，不只检查背景。
