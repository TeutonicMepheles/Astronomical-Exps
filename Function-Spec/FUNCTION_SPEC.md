## 2. EXP-01 傅科摆

### 功能与流程

1. 显示可拖动旋转的灰白手绘风抽象地球，不绘制详细地图，约每 `10°` 绘制一条纬线；预设地点标注名称和经纬度。
2. 快捷地点覆盖上海、赤道附近、南极点、北极点及南、北半球代表地点；同时支持输入任意纬度。
3. 点选地点后镜头自动转到该地点便于观察摆平面进动的斜侧视角，并在附近显示傅科摆；摆锤方向与当地地表垂直。
4. 从三档摆长、三档摆锤尺寸中选择参数，点击“开始模拟”。
5. 在摆锤下方生成平滑的投影轨迹，轨迹可覆盖完整 `0–360°` 摆动并清楚显示进动；不得出现闪烁或擦除式锯齿伪影。
6. 模拟过程中同时显示摆动周期和进动周期；摆长或摆锤质量变化不得改变进动周期。模拟使用虚拟时间并提供合理的默认快进。
7. 模拟中可选择两种加速方式和加速倍率；偏转角度为开始模拟至当前时刻的旋转角度差值。

### 参数与输出

| 项目 | 类型 | 原文明确值 / 行为 | 待确认 |
| --- | --- | --- | --- |
| 地点 | 预设选择 + 纬度输入 | 快捷覆盖上海、赤道、两极及南北半球代表点；可输入任意纬度 | 最终快捷点清单、默认地点、纬度输入范围和精度 |
| 摆长 | 三档 | 三档可选 | 三档数值、单位、默认值 |
| 摆锤质量 / 外观 | 三档 | 三档摆锤尺寸；进动周期不受摆长或质量影响 | 质量数值、默认值，以及质量对摆动周期和外观的具体作用 |
| 加速方式 | 二选一 | 时间整体加速；仅加速地球自转 | 两种方式的时钟与读数口径 |
| 加速倍率 | 档位 | ×1、×10、×100、×1000 | 默认档位、切换连续性 |
| 摆动周期与进动周期 | 输出 | 模拟过程中同时显示 | 公式、单位、特殊纬度处理、显示精度 |

核对项：抽象地球拖转、快捷地点与任意纬度输入、斜侧镜头定位可用；摆锤方向符合当地重力方向；轨迹平滑且进动可见；摆动周期和进动周期同时更新；改变摆长或质量不改变进动周期；两种加速方式和四档倍率均可选。暂停、重置及参数变更后的状态处理未明确。

## 3. EXP-02 月面环形山高度测量

### 功能与流程

1. 俯视图与侧剖面图联动，单屏展示月面环形山。
2. 点击环形山测量点后，显示该点对应的剖面切片；俯视测量位置与剖面地形保持对应。
3. 可拖拽滑块或直接输入数值改变太阳高度角，俯视图阴影与剖面图同步变化。
4. 点击“测量影长”后，从高度特征的垂直投影位置画到阴影端点，并以厘米和比例尺显示影长。
5. 点击“计算高度”，把当前影长和太阳高度角代入公式并展示环形山高度。
6. 采用灰白手绘月面，显示平行太阳光线但不绘制太阳图标；核心流程不滚动。

环形山剖面数量、可选测量点数量仍待确认，不把性能候选方案写成正式限制。

| 项目 | 类型 | 已明确 | 待确认 |
| --- | --- | --- | --- |
| 太阳高度角 | 滑块 | 改变照射角度，沿 Y 轴转动 | 坐标系、角度基准、范围、步长、默认值 |
| 测量起点 / 终点 | 拖点 | 测量两点距离 | 有效区域、吸附规则、比例尺 |
| 影长 | 输出 | 自动显示 | 自动影长与手动测距的关系、单位、精度 |
| 环形山高度 | 计算输出 | 根据影长及入射角度计算 | 公式、地形假设、采用哪组影长 |
| 实际高度 | 答案输出 | 点击“显示答案”显示 | 具体数值、数据来源、是否可再次隐藏 |

核对项：俯视与剖面联动；选择测量点后显示对应切片；滑块和数值输入同步改变两视图光照；点击“测量影长”可得到带比例的厘米读数；点击“计算高度”可用当前测量数据得到结果；平行光线与测量关系可读；单屏无滚动。原文同时使用“入射角度”与“太阳高度角”，实现前须统一定义，不直接假定两者同义。旧“显示答案”入口是否保留待确认。

## 5. EXP-04 埃拉托色尼地球周长测量

2026-11-03 用户确认单观测点模型为正式需求。页面保留“地面正午观测”和“地球定位与经线测距”两个视图，但只进行一次真实杆影观测；另一个位置是根据日期和太阳位置计算出的同经度参考点。

1. 学生选择观测地点和日期，并输入一根立杆的长度。
2. 地面视图显示当地正午的立杆、平行太阳光线、影长和杆影角。
3. 地球视图使用抽象地球，显示观测点和根据日期计算出的太阳直射纬度；用户不能直接设置太阳直射纬度。
4. 参考点取太阳直射纬度与观测点经线的交点，因此参考点和观测点处于同一经线。
5. 学生沿同一经线完成测距，获得观测点到参考点的经线距离。2026-11-09 确认操作是依次点击观测点和太阳直射点，系统沿共同经线连线后显示距离。
6. 用户点击计算，将经线距离和太阳角或纬度差代入公式，展示计算过程和地球周长。
7. 核心流程在 16:9 单屏内完成，不依赖页面滚动、悬停或滚轮。

1. 教学流程分为“简单光学原理—组装经典牛顿望远镜—固定剖面观察”三个阶段，并直接体现主镜口径对集光能力的影响。

6. 进入观察模式时打开镜筒前端盖；调焦座可只做视觉表现。第二阶段组装完成后，点击可触发望远镜自动 `360°` 展示。
