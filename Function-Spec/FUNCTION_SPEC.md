依据用户提供的《天文实验课》互动网页技术需求整理，来源信息见 [目录说明](README.md)。载体明确为 HTML5 互动网页，共 8 个实验。本文记录需求，不推定已有实现、开发优先级或完成状态。

| 编号 | 实验 | 核心结果 |
| --- | --- | --- |
| EXP-01 | 傅科摆模拟实验 | 摆的投影轨迹、旋转周期、相对起始时刻的偏转角度 |
| EXP-02 | 月面环形山高度测量实验 | 影长、计算高度与实际高度对比 |
| EXP-03 | 陨石坑撞击模拟实验 | 撞击动画、坑形、坑径和深度 |
| EXP-04 | 埃拉托色尼地球周长测量实验 | 两地正午杆影与地球周长计算过程 |
| EXP-05 | 光污染与夜天光测量实验 | 光源及星空变化、光污染等级、可见星数量 |
| EXP-06 | 日月食原理演示实验 | 日地月关系、地影/月影与多视角食象过程 |
| EXP-07 | 牛顿反射式望远镜光学实验 | 动态反射光路、焦距变化对应的视场及天体 |

## 2. EXP-01 傅科摆

### 功能与流程

1. 显示可拖动旋转的地球模型，预设城市标注名称、经度和纬度。
2. 点选地点后镜头聚焦对应点，并在附近显示傅科摆。
3. 设置摆长、摆锤质量，点击“开始模拟”。
4. 在摆锤下方生成投影轨迹，模拟过程中显示摆旋转周期和偏转角度；偏转角度为开始模拟至当前时刻的旋转角度差值。
5. 模拟中可选择加速方式和倍率。

### 参数与输出

| 项目 | 类型 | 原文明确值 / 行为 | 待确认 |
| --- | --- | --- | --- |
| 地点 | 预设选择 | 数个城市，显示名称与经纬度 | 城市清单、默认城市、坐标精度 |
| 摆长 | 输入 / 调节 | 可设置 | 单位、范围、步长、默认值 |
| 摆锤质量 | 输入 / 调节 | 可设置 | 单位、范围、步长、默认值及模拟作用 |
| 加速方式 | 二选一 | 时间整体加速；仅加速地球自转 | 两种方式的时钟与读数口径 |
| 加速倍率 | 档位 | ×1、×10、×100、×1000 | 默认档位、切换连续性 |
| 旋转周期 | 输出 | 模拟过程中显示 | 周期定义、单位、特殊纬度处理 |
| 偏转角度 | 输出 | 当前与起始时刻的旋转角度差 | 正负方向、累计或取模、精度 |

核对项：地球拖转、城市选择与镜头定位可用；轨迹和两项读数随模拟更新；两种加速方式和四档倍率均可选。暂停、重置及参数变更后的状态处理未明确。

## 3. EXP-02 月面环形山高度测量

### 功能与流程

1. 固定俯视环形山，允许拖动起点与终点测量两点距离。
2. 通过滑块改变太阳照射角度，固定沿 Y 轴转动，阴影实时变化。
3. 自动显示影长，并根据光源入射角度计算环形山高度。
4. 点击“显示答案”显示实际高度，与计算结果对比。

| 项目 | 类型 | 已明确 | 待确认 |
| --- | --- | --- | --- |
| 太阳高度角 | 滑块 | 改变照射角度，沿 Y 轴转动 | 坐标系、角度基准、范围、步长、默认值 |
| 测量起点 / 终点 | 拖点 | 测量两点距离 | 有效区域、吸附规则、比例尺 |
| 影长 | 输出 | 自动显示 | 自动影长与手动测距的关系、单位、精度 |
| 环形山高度 | 计算输出 | 根据影长及入射角度计算 | 公式、地形假设、采用哪组影长 |
| 实际高度 | 答案输出 | 点击“显示答案”显示 | 具体数值、数据来源、是否可再次隐藏 |

核对项：固定视角不受拖点影响；角度调节同步改变阴影；测距与高度结果可读；答案能用于对比。原文同时使用“入射角度”与“太阳高度角”，实现前须统一定义，不直接假定两者同义。

## 4. EXP-03 陨石坑撞击

固定镜头显示月面局部。选择质量、速度和角度后，点击“开始模拟”，播放陨石飞向月球、撞击扬尘、烟尘散去的过程，再显示对应陨石坑图片、坑径和深度。完成后可点击“重新开始”再模拟。

| 参数 / 指标 | 原文明确要求 | 待确认 |
| --- | --- | --- |
| 撞击物质量 | 3 选 1 | 三档数值、单位、默认档 |
| 撞击速度 | 3 选 1 | 三档数值、单位、默认档 |
| 撞击角度 | 3 选 1 | 三档角度、参考方向、默认档 |
| 输入组合总数 | 3 × 3 × 3 = 27 | 每一组合的数据映射 |
| 结果形态数 | 不超过 27 种 | 是否复用图片、具体资源清单 |
| 坑径、深度 | 结果必须显示 | 每组值、单位、精度、数据依据 |

核对项：27 种输入组合均有结果映射；动画顺序完整；烟尘散去后结果与所选参数一致；可重新模拟。“不超过 27 种”不等于必须提供 27 张不同图片。未要求实时地形物理仿真，不能自行将其作为交付指标。

## 5. EXP-04 埃拉托色尼地球周长测量

左右分屏展示两个测量地点，各自显示所选日期当地正午的立杆、投影及影长。改变日期可动画展示影长变化；点击计算，将测量数据代入公式并展示地球周长的计算过程和结果。

| 项目 | 已明确 | 待确认 |
| --- | --- | --- |
| 两个测量点 | 从固定城市列表选择 | 城市清单、坐标、默认组合、允许的配对 |
| 日期 | 可选择 | 日期范围、精度、默认日期、日历控件 |
| 杆长 | 可选择，两地统一 | 单位、范围、步长、默认值 |
| 两地影长 | 对应当前日期的正午并显示数值 | 单位、精度、太阳位置模型 |
| 计算过程 | 点击计算，展示数据代入公式 | 公式、两地距离来源与计算方式 |
| 地球周长 | 自动计算结果 | 单位、精度、参考值和误差要求 |

核对项：同一杆长同步作用于两地；日期或地点变化对应更新杆影；计算过程能追溯到当前测量数据。原文概述“自动计算”，详细功能明确“点击计算”，据此整理为按钮触发自动计算；是否还需实时计算待确认。任意城市组合能否直接使用同一简化公式尚未约定。

## 6. EXP-05 光污染与夜天光

固定镜头显示城市夜景、建筑和星空。面板列出光污染源及可控参数；调节参数后，光源、夜空同步变化，并更新光污染等级和可见星数量。

| 光源 | 色温 | 亮度 | 其他控制及明确档位 |
| --- | --- | --- | --- |
| 住宅窗灯 | 可调 | 可调 | 按 25%、50%、75%、100% 比例拉上窗帘 |
| 公共建筑灯光 | 可调 | 可调 | 按 25%、50%、75%、100% 比例开关 |
| 霓虹灯与广告牌 | 未要求 | 可调 | 按 25%、50%、75%、100% 比例开关 |
| 路灯 | 可调 | 未要求 | 选择不同灯罩 |

输出：各光源视觉变化、星空可见性变化、光污染等级、可见星数量。

原文建议省略乡村和沙漠场景，理由是光源较少、可探索内容有限；记录为范围建议，不写成已批准删除。以城市为明确场景。

待确认：色温与亮度的范围、单位、默认值；灯罩类型；百分比指开启比例还是关闭比例；窗帘比例如何映射遮光程度；是否有 0% 或独立全关；光污染分级标准、星表及可见星数量模型。不得自行增加路灯亮度或霓虹色温为必需功能。

核对项：四类光源按上述控制矩阵可操作；四个比例档位可选；调节后光源、夜空、等级和星数保持关联。

## 7. EXP-06 日月食原理演示

### 场景与模式

日地月大小和距离允许为教学演示调整，**不追求精确仿真**。演示三者位置关系，并动画呈现地影、月影的范围。

| 窗口 | 内容 | 交互边界 |
| --- | --- | --- |
| 窗口 1 | 日地月关系 | 原文总则允许旋转、推拉镜头 |
| 窗口 2 | 地球观察视角 | 自由模式可点选窗口 3 观察点；演示模式旋转角度固定 |
| 窗口 3 | 地球表面观察视角 | 原文总则允许旋转、推拉；演示模式地表观察点固定 |

演示模式的明确限制优先于“三个窗口均可旋转推拉”的总述；固定观察点是否还允许局部转向和缩放，需要确认。

| 模式 | 控制 | 行为 |
| --- | --- | --- |
| 自由探索 | 地球公转轨道位置滑块 | 改变日地月位置关系 |
| 自由探索 | 月球公转轨道位置滑块 | 改变日地月位置关系 |
| 自由探索 | 沙罗周期滑块 | 改变原文所述“沙罗周期”参数，具体含义待确认 |
| 自由探索 | 地球自转开关 | 控制地球自转 |
| 自由探索 | 在窗口 2 点击地球 | 设置窗口 3 观察点 |
| 日食演示 | 播放 / 暂停 / 重启 | 播放一次特定日食的完整过程；窗口 2 旋转角度及窗口 3 观察点固定 |
| 月食演示 | 播放 / 暂停 / 重启 | 播放一次特定月食的完整过程；相同视角限制 |
| 两类演示 | 速度 ×1、×5、×10 | 调整播放速度 |

待确认：两次特定食象的日期与类型；轨道位置滑块的单位、范围、默认值；“沙罗周期”控制的是时间、周期内进度还是其他教学参数；地影/月影模型；各窗口缩放范围；模式切换是否保留状态。

核对项：三个窗口与三种模式齐全；自由模式位置、自转和观察点控制有效；两类演示完整播放且可暂停、重启；三个倍率可选；固定视角限制按模式生效。

## 11. 共通交付约定与待确认指标

2026-10-16 补充确认：八个实验面向智慧白板大屏，16:9 横屏，以点击、拖拽为主；核心流程不依赖悬停、滚轮或页面滚动，不使用复杂悬浮和滚动动效。悬停与选中效果一致，即“选中即悬浮”。该约定来自后续确认，完整说明见[展示与交互约定](../Visual-Spec/VISUAL_SPEC.md#展示与交互约定)。

原文仅明确 HTML5 载体，没有规定以下交付阈值；不得自行填入 60 FPS、若干秒加载时间或特定精度并作为已确认要求。

- 运行环境：具体智慧白板型号、浏览器、最低配置、像素分辨率和触屏兼容性测试范围。画面比例与主要交互方式已按上述约定确认；资源按项目要求支持离线交付。
- 性能：加载时间、包体上限、帧率、交互延迟、内存和显存预算。
- 科学计算：各实验公式、适用假设、数据来源、单位、显示精度和误差容限。
- 状态与数据：刷新后保留、跨实验进度、记录导出、账号及后台是否需要。
- 交互边界：参数可否在运行中修改、修改后继续或重置、非法输入、无结果和极端值处理。
- 交付与验收：源码和资源交付清单、测试设备矩阵、验收人员及通过标准。

共通展示与交互按上述后续确认执行。视觉规范中的牛顿专用场景、逻辑像素尺寸和模型参数仍仅适用于牛顿实验，不扩展为其他实验的要求。
