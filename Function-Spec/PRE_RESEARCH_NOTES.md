# 前期功能研究补充

本文记录早期功能研究，尚未批准为正式需求。来源包括 SpaceHTML 的脚本、设计文档 v1.1 和会议对照报告；会议报告为二次整理，未核对原始转录。

SpaceHTML 文件于 2026-10-15 保存到[历史备份](../archive/spacehtml/README.md)，未接入正式页面。备份不作交互、视觉或代码参考，旧注释也不是当前指令。正式需求见 [FUNCTION_SPEC.md](FUNCTION_SPEC.md)，冲突见 [OPEN_DECISIONS.md](OPEN_DECISIONS.md)。

| 编号 | 可保留的功能信息 | 限制与后续确认 |
| --- | --- | --- |
| EXP-01 | 区分摆动周期与偏转周期；分别研究纬度、摆长、质量的影响；赤道作为边界案例 | 模型及恒星日/24h 近似须审核；旧默认与倍率不替代现需求 |
| EXP-01 | 地点候选：赤道、新加坡、广州、开罗、南京、北京、巴黎、莫斯科、摩尔曼斯克、北极点；摆长 10/30/67 m，质量 5/28/50 kg | 经纬度、数值、默认值均为预研候选，未科学复核；缺南半球案例 |
| EXP-02 | 分开记录学生测得影长、依据测量计算的高度、模型设定高度与偏差 | 不把模型设定值冒充测量结果；0°/90°列为边界测试候选；公式适用条件待审核 |
| EXP-03 | 参数组合到预设结果的映射适合检查覆盖率 | 不采用旧文档 36 组合或不显示尺寸的要求；避免缺项静默回退 |
| EXP-04 | 两地测量、角度、地表距离、计算结果需来源可追溯 | 旧 earthCalc 将角度乘 111.2，再乘 360/角度，非零时恒得 40032 km；不可当独立测量模型 |
| EXP-05 | 灯罩、色温、等级及可见星数的关系可列入研究问题 | 旧固定星数表及灯罩系数未见标定依据，不能作为正式科学读数 |
| EXP-06 | 全食、环食、偏食、未发生食作为候选案例；遮挡比例、本影/半影、观察点计算可独立测试 | solar-eclipse-3d.js 只提供研究线索，未验证正确性；不照搬界面、相机或交互 |
| EXP-07 | 旧望远镜功能与当前在研实现重叠 | 以当前实验及确认需求继续迭代，不回退到旧方案 |
| EXP-08 | 当前 prototypes 综合 HTML 已有推重比、推进剂、最高高度、曲线和单变量比较的功能研究 | 不是 SpaceHTML 独有增量，不代表正式火箭范围或模型已获确认 |

历史报告还提到有限选项、纸笔计算、前端优先、不依赖外部服务、课堂使用等背景；这些应作为范围确认问题。100 MB 等旧指标不能未经确认写成 CI 阈值。
