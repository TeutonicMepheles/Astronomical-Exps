# 功能需求

八个实验的正式功能、参数和验收核对项统一记录在 [FUNCTION_SPEC.md](FUNCTION_SPEC.md)。各实验的 `REQUIREMENTS.md` 按实验摘录，入口见[实验目录](../README.md#实验目录)。需求调整时，由维护者同步更新两处。

## 查阅顺序

1. 先读自己实验的 `REQUIREMENTS.md`。
2. 遇到未确定的数值、模型或范围，查[待确认问题](OPEN_DECISIONS.md)，再请维护者确认。
3. 需要追溯时，查[前期研究](PRE_RESEARCH_NOTES.md)；其中的候选方案不增加正式验收要求。

[牛顿实现记录](NEWTON_BASELINE.md)记录 2026-10-12 的页面情况，不是原始需求，也不代表当前功能验收通过。两个已有实验仍在开发中。画风与资源要求见[视觉规范](../Visual-Spec/README.md)。

## 需求说明

本目录保留实验开发所需的功能与参数说明。原始需求附件和内部讨论材料由维护者在仓库外保存，不随项目发布。

未确认的范围、单位、公式、默认值和精度保留为待确认，建议与明确要求分开记录。文档中的核对项表示需要检查的内容，不表示已经实现或通过检查。
