## 一、总体设计原则

### 1.1 学生认知特点

| 学段 | 认知水平 | 设计策略 |
|------|---------|---------|
| 5–6年级 | 具体运算阶段→形式运算阶段过渡；能理解比例关系、角度概念；对"为什么"有强烈好奇心；注意力持续约 8–12 分钟 | 大量可视化动画；用"玩"代替"学"；避免抽象公式堆砌，先展示现象再揭示原理；控件少而精（每页 3–5 个可调参数） |
| 7–9年级 | 形式运算阶段；能理解函数关系、比例推理、初步物理公式；开始接触几何光学、力学 | 可在现象基础上引入定量计算面板；支持"预测→验证"探究式学习流程；可增加图表（如高度-时间曲线） |

### 1.2 通用设计规范

#### 视觉风格
- **配色**：深空背景（`#0a0a1a` → `#0d1b2a` 渐变）+ 亮色点缀（`#ffcc00` 金色、`#4fc3f7` 天蓝、`#ff6e40` 暖橙）
- **字体**：中文优先 "PingFang SC" / "Microsoft YaHei" / "Noto Sans SC"，数字用等宽 `'JetBrains Mono', 'Consolas', monospace`
- **布局**：桌面端左侧控制面板（320px 宽）+ 右侧动画画布；平板端上下布局（控制面板在上，画布在下）
- **圆角**：卡片 `border-radius: 12px`，按钮 `border-radius: 8px`
- **阴影**：`box-shadow: 0 4px 20px rgba(0,0,0,0.5)` 增加层次感

#### 交互组件统一风格
- **滑块（range input）**：自定义 CSS 样式，带刻度标记和数值气泡
- **按钮**：渐变背景 + `hover` 缩放动画（`transform: scale(1.05)`）+ 涟漪点击效果
- **选择器**：大号卡片式按钮组（比原生 `<select>` 更适合触摸操作）
- **数值显示**：大字号、高对比度、带单位标签

### 2.3 交互功能详细设计

#### 2.3.1 地理位置选择器
- **实现方式**：一组卡片按钮，每张卡片包含地球图标 + 城市名 + 纬度
- **预设选项**：
  - 赤道（0°）— 不偏转

  - 巴黎（48.9°N）— 约 11.25°/小时（傅科原实验）
  - 摩尔曼斯克（69°N）— 约 14°/小时
  - 北极（90°N）— 15°/小时
- **自定义模式**：一个纬度滑块（0°–90°N），精确到 0.1°
- **交互反馈**：切换位置时，偏转速率数字平滑过渡（`requestAnimationFrame` 插值）

#### 2.3.2 参数滑块
| 参数 | 范围 | 默认值 | 步长 | 备注 |
|------|------|--------|------|------|
| 摆长 L | 5–70 m | 30 m | 0.1 m | 影响摆动周期 T = 2π√(L/g) |
| 摆锤质量 m | 5–50 kg | 28 kg | 0.1 kg | 不影响周期（展示"质量无关"这一物理结论） |
| 初始摆角 θ₀ | 2°–30° | 10° | 0.5° | 小角度近似（<5°）时周期最准，大角度时周期略增（展示非线性效应） |

#### 2.3.3 动画引擎

**俯视图（摆尖轨迹玫瑰图）**
- 用半透明轨迹线记录摆尖投影位置
- 颜色渐变表示时间流逝（新轨迹亮色，旧轨迹渐淡）
- 每隔 5 个完整摆动周期打一个标记点，让学生看到图案在缓慢旋转
- 可切换显示/隐藏网格线和角度参考线

**侧视图（摆动动画）**
- Canvas 渲染：固定锚点（穹顶）→ 摆线（直线段）→ 摆锤（带阴影的实心圆）
- 摆锤下方有模糊阴影（模拟地面投影），阴影缓慢旋转
- 地面绘制刻度盘，展示初始摆动方向与当前方向的夹角
- 时间加速倍率可选：1×（实时）、60×（1分钟=1小时）、3600×（1秒=1小时）

**物理模型（JavaScript 伪代码）**
```javascript
// 傅科摆物理模型
class FoucaultPendulum {
  constructor(latitude, length, mass, initialAngle) {
    this.phi = latitude * Math.PI / 180;       // 纬度（弧度）
    this.L = length;                             // 摆长 (m)
    this.m = mass;                               // 质量 (kg)
    this.theta0 = initialAngle * Math.PI / 180; // 初始摆角（弧度）
    this.g = 9.81;                               // 重力加速度

    // 地球自转角速度 (°/h → rad/s)
    this.omega_earth = (360 / 24) * (Math.PI / 180) / 3600; // rad/s

    // 傅科摆偏转角速度: Ω = ω_earth * sin(φ)（仅北半球）
    this.Omega = this.omega_earth * Math.sin(this.phi);

    // 摆动周期: T = 2π * √(L/g)（小角度近似）
    this.swingPeriod = 2 * Math.PI * Math.sqrt(this.L / this.g);

    // 偏转一周所需时间: T_total = 24h / sin(φ)
    this.rotationPeriodHours = 24 / Math.sin(this.phi);
  }

  // 获取 t 时刻的摆动角度（考虑阻尼）
  getSwingAngle(t) {
    const damping = Math.exp(-0.0001 * t); // 微弱阻尼
    const omega_swing = 2 * Math.PI / this.swingPeriod;
    return this.theta0 * damping * Math.cos(omega_swing * t);
  }

  // 获取 t 时刻摆动平面的偏转角度
  getPlaneRotation(t) {
    return this.Omega * t; // rad
  }
}
```

#### 2.3.4 教育性功能
- **"我的预测"模式**：先让学生猜测"在赤道摆会偏转吗？""在北极呢？"，再展示动画验证
- **对比模式**：同时显示两个不同纬度的摆，直观对比偏转速度差异
- **速度挑战**：设一个计时器，让学生拖动纬度滑块，使摆在 10 秒内（模拟时间加速后）恰好偏转 45°

### 2.4 关键数学关系（供教师参考）
- 偏转角速度：`Ω = (360°/24h) × sin(φ)`
- 赤道 sin(0°) = 0 → 不偏转
- 北极 sin(90°) = 1 → 24小时偏转一整圈
- 摆动周期（小角度）：`T = 2π√(L/g)`
- 注意：摆锤质量 **不影响** 周期 — 这是伽利略的重要发现

### 3.3 交互功能详细设计

#### 3.3.1 太阳入射角调节
- **主控件**：一个大弧形滑块（类似量角器），直观展示太阳在天空中的位置
- **伴随动画**：太阳图标沿弧形轨道移动，光线方向实时改变
- **快捷按钮**：日出（5°）、上午（30°）、正午（60°）、下午（45°）
- **数值气泡**：拖拽时在滑块上方显示当前角度值

#### 3.3.2 剖面模拟图渲染
- Canvas 绘制月面剖面：平坦月面 + 环形山凸起（高斯函数轮廓 `h·exp(-x²/(2σ²))`）
- 光线从太阳方向射来，射线追踪法计算阴影区域
- 阴影部分用半透明暗色填充
- 环形山内壁被照亮一侧用浅灰色，背光面用深灰色，增加立体感
- 影长用带箭头的双端标尺显示，标尺上标注数值

#### 3.3.3 手动测量模式
- 学生可在画布上拖拽两个测量点（影子的起点和终点）
- Canvas 上显示临时标尺线

- 精度评分：误差 < 5% 获得 ⭐⭐⭐，5–15% 获得 ⭐⭐，> 15% 获得 ⭐

### 3.4 数学与物理模型

**核心公式**：当太阳高度角为 α 时，高度为 h 的物体投下的影子长度 s 满足：
```
h = s × tan(α)
```

在月面上，太阳高度角 = 太阳入射角（太阳光线与月面的夹角）。

**阴影计算（剖面模型）**：
```javascript
// 环形山剖面：高斯轮廓
function craterProfile(x, height, radius) {
  // height: 环形山边缘到月面的高度
  // radius: 环形山的特征半径（轮廓半宽）
  return height * Math.exp(-(x * x) / (2 * radius * radius));
}

// 判断点 (x, y) 是否在阴影中
function isInShadow(x, profileFn, sunAngle) {
  const y = profileFn(x);
  // 从点 (x, y) 向太阳方向（角度 sunAngle）追踪
  // 光线方程: Y = y + tan(sunAngle) * (X - x)
  // 检查光线是否与环形山另一侧相交
  for (let X = x + 0.1; X < maxRange; X += step) {
    const Y = y + Math.tan(sunAngle) * (X - x);
    if (profileFn(X) > Y) return true; // 光线被挡住
  }
  return false;
}
```

### 4.3 交互功能详细设计

#### 4.3.1 三重参数联动

**撞击物质量**
- 对数滑块（1 t → 10 t → 100 t → 1000 t），因为质量跨越 3 个数量级
- 伴随图示：小石块 → 小汽车 → 大型小行星（视觉化质量变化）

**撞击速度**
- 范围：1–30 km/s（典型小行星撞击速度 15–20 km/s，彗星可达 50+ km/s）
- 快捷按钮：低速（5 km/s，类似陨石坠落）、中速（17 km/s，典型小行星）、高速（30 km/s，高速撞击）
- 速度指示器：类似车速表的弧形仪表盘

**撞击角度**
- 半圆形选择器：90°（垂直正撞，坑最圆最深）→ 0°（擦边而过，坑最浅最扁）
- 实时预览：角度指示器上的箭头方向和撞击物朝向联动
- 角度 < 15° 时，撞击物"擦过"月面，不产生明显坑（模拟真实情况）

#### 4.3.2 撞击动画四阶段

**阶段1：接近（2秒）**— 小行星从上方快速接近月面，带运动模糊残影

**阶段2：接触（0.3秒）**— 接触点产生高亮闪光（模拟撞击瞬间能量释放）
- 粒子系统：100–500 个粒子从撞击点溅射，颜色从白→黄→橙→红→暗（温度递减）
- 粒子轨迹受角度影响（正撞均匀四散，斜撞偏向前方）

**阶段3：扩展（1.5秒）**— 冲击波扩散动画
- 圆形（正撞）或椭圆形（斜撞）冲击波从撞击点向外扩散
- 月面网格顶点被推开，形成坑的雏形
- 物质抛射：坑内物质被抛向空中，形成抛物线轨迹

**阶段4：稳定（1秒）**— 坑形态最终确定
- 坑壁轻微回弹动画
- 中央峰可能出现（高能量正撞时）
- 表面冷却颜色变化

#### 4.3.3 撞击坑形态计算模型
```javascript
// 简化的撞击坑尺寸模型（基于施密特-霍尔萨普尔标度律的简化版）
function calculateCrater(mass, velocity, angle, targetDensity, gravity) {
  const kineticEnergy = 0.5 * mass * velocity * velocity; // 动能
  const verticalVelocity = velocity * Math.sin(angle);    // 垂直分量

  // 坑直径（简化模型：D ∝ E^(1/3.4) × (sinθ)^(1/3)）
  const diameter = 1.8 * Math.pow(kineticEnergy, 1/3.4) *
                   Math.pow(Math.sin(angle), 1/3) *
                   Math.pow(1 / gravity, 0.17);

  // 坑深度
  const depth = diameter * 0.2 * Math.sin(angle);

  // 椭圆度（斜撞时坑拉长）
  const ellipticity = 1 + (1 - Math.sin(angle)) * 0.5;

  return { diameter, depth, ellipticity, kineticEnergy };
}
```

#### 5.3.3 阴影锥实时渲染

```javascript
// 阴影锥几何计算
class ShadowCone {
  constructor(sunRadius, bodyRadius, distance) {
    // 本影锥：太阳完全被遮挡的区域
    // 锥顶角计算（相似三角形）
    this.umbraLength = (bodyRadius * distance) / (sunRadius - bodyRadius);
    this.umbraAngle = Math.atan2(bodyRadius, this.umbraLength);

    // 半影锥：太阳部分被遮挡的区域
    this.penumbraLength = (bodyRadius * distance) / (sunRadius + bodyRadius);
    this.penumbraAngle = Math.atan2(bodyRadius, this.penumbraLength);
  }

  // 判断某个点 (dist, y) 是否在本影中
  isInUmbra(distFromBody, yOffset) {
    const coneRadius = (this.umbraLength - distFromBody) * Math.tan(this.umbraAngle);
    return Math.abs(yOffset) <= Math.abs(coneRadius) && distFromBody < this.umbraLength;
  }

  // 判断是否在半影中
  isInPenumbra(distFromBody, yOffset) {
    const coneRadius = (this.penumbraLength - distFromBody) * Math.tan(this.penumbraAngle);
    return Math.abs(yOffset) <= Math.abs(coneRadius) && distFromBody < this.penumbraLength;
  }
}
```

- 天空颜色随之变化（低色温→偏红橙天空，高色温→偏蓝白天空）

#### 9.3.2 飞行动力学模型

```javascript
// 一维（垂直方向）飞行模拟
class RocketSimulation {
  constructor(params) {
    this.m_body = params.m_body;       // 箭体质量 (kg)
    this.m_fuel_initial = params.m_fuel; // 初始燃料质量 (kg)
    this.m_payload = params.m_payload;   // 载荷质量 (kg)
    this.F_thrust = params.F_thrust;     // 推力 (N)
    this.Isp = params.Isp || 300;        // 比冲 (s)
    this.g0 = 9.81;                      // 地面重力加速度 (m/s²)

    // 初始状态
    this.m_fuel = this.m_fuel_initial;
    this.altitude = 0;                   // 高度 (m)
    this.velocity = 0;                   // 速度 (m/s)
    this.acceleration = 0;              // 加速度 (m/s²)
    this.time = 0;                       // 飞行时间 (s)
    this.fuelDepleted = false;
    this.maxAltitude = 0;
    this.maxVelocity = 0;
  }

  // 每秒推进一个时间步长
  step(dt) {
    const currentMass = this.m_body + this.m_fuel + this.m_payload;

    // 重力（随高度衰减：g = g0 * (R/(R+h))²）
    const earthRadius = 6371000;
    const gravity = this.g0 * Math.pow(earthRadius / (earthRadius + this.altitude), 2);

    // 重力 = 质量 × 重力加速度
    const weight = currentMass * gravity;

    // 推力（燃料耗尽后为0）
    let thrust = 0;
    if (!this.fuelDepleted) {
      thrust = this.F_thrust;
    }

    // 空气阻力（简化模型：与速度平方和空气密度成正比）
    const airDensity = this.getAirDensity(this.altitude);
    const dragCoeff = 0.5;  // 阻力系数
    const crossSection = 10; // 截面积 (m²)
    const drag = 0.5 * airDensity * dragCoeff * crossSection *
                 this.velocity * Math.abs(this.velocity);

    // 合外力 = 推力 - 重力 - 阻力（向上为正）
    const netForce = thrust - weight - drag;

    // 加速度 = 合外力 / 当前质量（牛顿第二定律）
    this.acceleration = netForce / currentMass;

    // 更新速度和高度（欧拉积分）
    this.velocity += this.acceleration * dt;
    this.altitude += this.velocity * dt;

    // 消耗燃料
    const fuelRate = this.F_thrust / (this.Isp * this.g0);
    if (!this.fuelDepleted) {
      this.m_fuel -= fuelRate * dt;
      if (this.m_fuel <= 0) {
        this.m_fuel = 0;
        this.fuelDepleted = true;
      }
    }

    this.time += dt;

    // 记录最大值
    this.maxAltitude = Math.max(this.maxAltitude, this.altitude);
    this.maxVelocity = Math.max(this.maxVelocity, this.velocity);
  }

  getAirDensity(h) {
    // 简化的气压高度模型（0–100 km）
    if (h > 100000) return 0;
    if (h < 0) return 1.225;
    const scaleHeight = 8500; // m
    return 1.225 * Math.exp(-h / scaleHeight); // kg/m³
  }
}
```

#### 9.3.3 发射动画

**画布元素**：
- 天空背景：从海平面蓝色渐变 → 深蓝 → 黑色（随火箭高度变化）
- 地面：发射台细节（塔架、支撑臂，随火箭起飞可动态收回）
- 火箭箭体：按比例绘制的多级火箭外形
- 火焰粒子系统：
  - 黄色/橙色/红色粒子从喷嘴向下高速喷射
  - 粒子数量和大小与当前推力成正比
  - 高空时火焰形状因空气稀薄而扩散
- 高度标尺：左侧带刻度的动态标尺，当前高度用高亮标记

**飞行阶段视觉效果**：
1. **点火**：火焰从小到大，伴随屏幕轻微震动
2. **上升**：火箭缓慢加速上升（真实比例）
3. **Max-Q**（最大动压）：标注提示
4. **燃料耗尽**：火焰熄灭，火箭继续惯性上升
5. **最高点**：火箭短暂停留
6. **下落**（可选）：如果速度不足以入轨，火箭开始下坠

- 使用 Canvas 绘制，横轴为时间（s），纵轴为高度（km）

- 关键节点标注：
  - 🔥 点火点（原点）
  - ⛽ 燃料耗尽点
  - ⭐ 最高点（max altitude）

- 背景星空粒子单独缓存在 offscreen canvas
- 图表曲线使用分段存储（最多保留 1000 个数据点）

### 11.1 课堂使用流程（45 分钟课时）

| 环节 | 时长 | 活动 |

| 挑战环节 | 7 min | 学生完成挑战模式，获得即时反馈 |

### 11.2 推荐实验顺序
1. 实验五（埃拉托色尼）— 引入"地球是圆的"，建立天文学思维方式
2. 实验一（傅科摆）— 深化"地球在运动"
3. 实验四（日月食）— 天体运动的具体表现

5. 实验三（陨石撞击）— 了解月球表面形成
6. 实验七（望远镜）— 我们如何观测
7. 实验六（光污染）— 观测条件的影响
8. 实验八（火箭）— 人类如何探索太空

### 11.3 差异化教学建议

**5–6年级侧重**：
- 预设场景探索为主
- 定性观察优先（"影子变长了还是变短了？"）

- 知识卡片小故事
- 允许自由玩耍参数

- 公式推导步骤图
- 数据记录表格

- 跨实验关联（如实验二的三角测量用于实验五）
