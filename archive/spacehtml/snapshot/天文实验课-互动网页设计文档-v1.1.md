## 一、总体设计原则

### 1.1 核心设计理念：模拟实验，非科普动画

本项目8个互动网页的定位是**模拟实验工具**，而非被动的科普演示动画。每个实验遵循统一的"实验循环"模式：

```
┌──────────────────────────────────────────────────────┐
│  ① 设置实验条件  →  ② 开始实验  →  ③ 观察现象       │
│                                                    │
│  ⑥ 重复多次实验  ←  ⑤ 查看答案  ←  ④ 记录/计算     │
└──────────────────────────────────────────────────────┘
```

**关键设计含义**：
- 学生**主动输入**参数（而非被动观看）
- 实验结果是**需要观察和记录的**（而非自动展示全部数据）
- 答案用于**核对验证**而非直接告知
- 鼓励**多次实验对比**（不同参数组合 → 不同结果 → 发现规律）

### 1.2 学生认知特点

| 学段 | 认知水平 | 设计策略 |
|------|---------|---------|
| 5–6年级 | 具体运算阶段→形式运算阶段过渡；能理解比例和角度概念；好奇心强；注意力约 8–12 分钟 | 大量可视化；现象先于原理；每页 3–5 个可调参数；避免抽象公式直接展示 |
| 7–9年级 | 形式运算阶段；能理解函数关系、比例推理；接触几何光学和力学基础 | 可引入定量计算环节（手算验证）；支持"预测→验证"探究流程 |

### 1.3 通用设计规范

#### 视觉风格（待定，由开发方提供参考方案后确认）

**初步方向**：
- 深色背景为主，亮色功能点缀
- 简洁、专业，不幼稚、不卡通
- 整体统一风格，8 个实验视觉一致

**参考约束**：
- 地球贴图不得出现国境线（审查要求）
- 天体表现介于抽象示意和写实渲染之间

#### 布局规范

```
┌──────────────────────────────────────────────┐
│  顶部：实验标题 + 实验步骤引导条               │
├─────────────────┬────────────────────────────┤
│  控制面板       │       动画/模拟画布          │
│  (约320px)     │       (剩余宽度)             │
│                │                              │
│  ▸ 实验条件    │   ┌──────────────────┐      │
│    (参数选择)  │   │                  │      │
│  ▸ 开始/重置   │   │  Canvas 动画区   │      │
│  ▸ 查看答案    │   │                  │      │
│    (默认隐藏)  │   └──────────────────┘      │
│  ▸ 知识卡片    │   ┌──────────────────┐      │
│    (可折叠)   │   │  测量/记录提示区   │      │
│                │   └──────────────────┘      │
└─────────────────┴────────────────────────────┘
```

#### 交互组件规范

- **选择器**：大号卡片式按钮组（适配触屏），替代原生 `<select>`
- **滑块**：仅在核心连续变量（如太阳角度）使用，带刻度标记
- **按钮**：清晰可辨的点击区域，hover + 点击反馈
- **数值显示**：大字号、高对比度，答案区域默认隐藏，点击后展示

#### 响应式要求
- 主适配：16:9 教室大屏（1920×1080）
- 兼顾：16:9 / 16:10 普通电脑显示器
- 单屏展示全部信息，无需纵向滚动

## 二、实验一：傅科摆模拟实验

### 2.1 教学目标

| 学段 | 目标 |
|------|------|
| 5–6年级 | 观察摆动平面缓慢旋转，理解"不是摆在转，是地球在转"；发现不同纬度偏转速度不同 |
| 7–9年级 | 定性理解偏转角速度与纬度的关系（纬度越高偏转越快）；可在教师引导下了解公式 `Ω = (360°/24h) × sin(φ)` |

### 2.2 实验流程

```
步骤① 选择城市（纬度）→ 步骤② 点击"开始实验" → 步骤③ 观察摆动动画

```

| 6 | 北京 | 39.9°N | ≈37h | 中纬度 |

| 8 | 莫斯科 | 55.8°N | ≈29h | 中高纬度 |

### 2.4 动画与输出

#### 动画区域
- **主视图**：侧视角摆动动画。Canvas 渲染摆线、摆锤、弧形地面（示意地球曲面）。摆动平面随时间缓慢旋转
- **辅助视图**（可选小窗）：俯视轨迹玫瑰图，展示摆尖在地面的投影轨迹缓慢旋转
- **时间加速**：提供加速倍率选择（60× / 3600×），使数小时的偏转在数秒内可见

#### 数据输出
- **直接显示**：当前城市名、纬度
- **实验记录区**：提示学生记录摆动周期和偏转周期
- **查看答案按钮**（默认隐藏内容）：点击后展开显示偏转角速度和偏转周期

### 2.5 技术实现

```javascript
// 简化的运动学模型（非完整动力学仿真）
class FoucaultPendulumSimple {
  constructor(latitude, length) {
    this.latitude = latitude;                          // 纬度（度）
    this.swingPeriod = 2 * Math.PI * Math.sqrt(length / 9.81); // 摆动周期 (s)
    this.rotationPeriodHours = 24 / Math.sin(latitude * Math.PI / 180); // 偏转周期 (h)
    this.rotationSpeed = 360 / (this.rotationPeriodHours * 3600); // 偏转角速度 (°/s)
  }
  getPlaneAngle(elapsedSeconds) {
    return this.rotationSpeed * elapsedSeconds; // 偏转角度
  }
}
```

## 三、实验二：月面环形山高度测量实验

### 3.1 教学目标

| 学段 | 目标 |
|------|------|
| 5–6年级 | 理解"同一物体、不同光照角度→影子长度不同"；用相似三角形思想解决测量问题 |
| 7–9年级 | 掌握三角测量法 `h = s × tan(α)`；理解"无法直接测量高度时可通过影长间接求得" |

### 3.2 实验流程

```
步骤① 调节太阳角度 → 步骤② 观察影子变化 → 步骤③ 拖拽标尺测量影长
步骤④ 纸笔计算高度 → 步骤⑤ 点击"查看答案"核对 → 步骤⑥ 换角度重测，验证一致性
```

### 3.3 输入参数

#### 太阳高度角（连续滑块 + 快捷按钮）

| 控件 | 说明 |
|------|------|
| 弧形滑块 | 太阳沿弧形轨道移动，角度 0°–90°（水平→天顶） |
| 快捷按钮 | 日出(5°) / 上午(30°) / 正午(60°) / 下午(45°) |

> 太阳角度是本实验的核心教学变量，因此保留连续可调。光源仅改变高度角，不做水平方位角变化。

#### 环形山模型选择（3个抽象模型）

| 模型 | 特征 | 实际高度 | 适用场景 |
|------|------|---------|---------|
| 模型A | 简单对称碗形坑 | 3.0 km | 最易测量，影子清晰 |
| 模型B | 略不对称山形 | 4.5 km | 中等难度 |
| 模型C | 复杂多峰轮廓 | 2.5–5.0 km | 较高难度 |

> 模型为抽象的3D渲染简化地形，不标注真实环形山名称，避免学生误认为数据完全真实。

### 3.4 动画与输出

#### 3D简模渲染
- Canvas 或轻量 WebGL 渲染月面剖面：平坦月面 + 环形山凸起地形
- 太阳光从上方以当前角度照射，实时计算并渲染阴影
- 阴影区域用半透明暗色标记
- 可参考的简化方案：使用竖直杆+水平地面替代环形山进行演示，让三角关系更直观

#### 测量工具
- 学生使用鼠标/手指在画布上**拖拽标尺**测量影长
- 类百度地图测距的交互方式：点击起点→拖动→释放终点
- 画布实时显示标尺和测得的影长数值
- 不限制测量起止点（学生自由选择测量位置）

#### 数据输出
- **直接显示**：当前太阳角度、学生测得的影长
- **默认隐藏**（查看答案按钮）：
  - 环形山的实际高度
  - `h = s × tan(α)` 的公式代入过程
  - 学生测量值与真实值的偏差百分比

## 四、实验三：陨石坑撞击模拟实验

### 4.1 教学目标

| 学段 | 目标 |
|------|------|
| 5–6年级 | 直观感受撞击能量越大→坑越大；了解月球环形山主要由撞击形成；初步理解质量、速度、角度对结果的影响 |
| 7–9年级 | 定性理解动能大小取决于质量和速度；理解正撞（深圆坑）与斜撞（浅椭圆坑）的区别 |

### 4.2 实验流程

```
步骤① 选择撞击参数（3个维度） → 步骤② 点击"发射" → 步骤③ 观看撞击动画
步骤④ 观察生成的坑的形态 → 步骤⑤ 记录结果 → 步骤⑥ 换参数重做，对比不同组合的结果
```

### 4.3 输入参数（每参数3–4个离散档位）

#### 撞击物大小（4档）

| 档位 | 描述 | 示意图标 |
|------|------|---------|
| 小型 | 约10 t 级 | 小石块图标 |
| 中型 | 约100 t 级 | 大石块图标 |
| 大型 | 约1000 t 级 | 小行星图标 |
| 巨型 | 约10000 t 级 | 大小行星图标 |

#### 撞击速度（3档）

| 档位 | 速度 | 说明 |
|------|------|------|
| 低速 | ~5 km/s | 类似陨石自然坠落 |
| 中速 | ~17 km/s | 典型小行星撞击速度（默认） |
| 高速 | ~30 km/s | 高速撞击 |

#### 撞击角度（3档）

| 档位 | 角度 | 预期结果 |
|------|------|---------|
| 正撞 | 90°（垂直） | 圆形深坑，飞溅物均匀 |
| 斜撞 | 45° | 略椭圆坑，飞溅物偏向前方 |
| 掠射 | 15° | 极浅椭圆坑，或擦边无明显坑 |

### 4.4 动画与输出

#### 撞击动画（简化三段式）

| 阶段 | 时长 | 内容 |
|------|------|------|
| 接近 | ~1.5 s | 撞击物从上方快速接近月面 |
| 撞击 | ~1.0 s | 接触闪光 + 粒子溅射效果（方向受角度影响） |
| 成坑 | ~1.5 s | 月面稳定，展示最终坑形态 |

#### 结果展示：预设坑类型

根据参数组合，匹配到预设的坑形态（约 4×3×3 = 36 种组合→归纳为约 10–15 种典型坑类型）：

- 展示方式：**3D简模静态图**，倾斜视角（约30°俯角），可见月面弧形地平线
- 差异维度：坑大小、深浅、圆椭、有无辐射纹、有无中央峰
- 风格：介于示意图和写实渲染之间

#### 定性数据

- 直接显示：本次实验的参数组合（如"中型 + 中速 + 斜撞"）
- 可查看：坑的大致形态描述（"这是一个中等大小的椭圆形坑，有明显的飞溅物"）
- **不显示精确数值**（直径、深度、能量等），保持定性演示定位

### 4.5 技术实现

```javascript
// 参数组合 → 预设坑类型映射（非实时物理计算）

### 5.1 教学目标

### 5.3 预设事件（非通用模拟器）

> **重要设计决策**：本实验**不作为通用的日月食模拟器**。天文历算极其复杂，实时轨道力学模拟在网页端既不精确也不可行。采用"预设典型事件→预计算时间轴→网页端播放动画"的方案。

| 序号 | 事件 | 类型 | 关键特征 |

| 2 | 日环食示例 | 日环食 | 月球在远地点，留一圈光环 |
| 3 | 日偏食示例 | 日偏食 | 月球偏离日地连线，部分遮挡 |

### 5.4 三视角系统

#### 视角1：太空俯视图（主画布）

- 日地月位置示意（**不按真实尺寸比例**，太阳/地球/月球均为示意大小）
- 地球围绕太阳的轨道 + 月球围绕地球的轨道（椭圆形简化表示）
- 可拖动时间轴（或自动播放），天体沿预设轨道运动
- 显示本影锥/半影锥的示意范围

#### 视角2：地球近景影锥扫过（降级优先）⚠️

- 凑近地球视角，展示月球影子在地球表面的移动轨迹
- 地球模型为抽象球体（**无国境线**），有明暗面和大气光晕
- 显示半影（浅灰）和本影（深色）在地表的投影
- **标注**：此视角技术复杂度较高，如资源不足可降级为静态关键帧图

#### 视角3：地面观察者视角（小窗）

- 从地球表面观察天空
- 日食时：太阳被月球圆盘逐渐遮挡的过程
- 月食时：月球逐渐进入地球阴影、变暗变红的过程
- 小窗叠加在主画布角部，与时间轴联动

#### 三视角同步

- 三个视角**仅通过时间轴同步**（同一时刻 = 同一画面），不要求空间关系的精确匹配
- 各视角的动画数据独立预计算，网页端仅做时间轴驱动的插值播放

## 六、实验五：埃拉托色尼地球周长测量实验

### 6.1 教学目标

| 学段 | 目标 |
|------|------|

| 7–9年级 | 掌握埃拉托色尼的几何推理：圆心角=两地太阳高度角之差；比例 `C : 弧长 = 360° : θ` |

```

### 6.3 输入参数

#### 日期选择（关键日期 + 滑块）

| 控件 | 说明 |
|------|------|
| 关键日期快捷按钮 | 春分(3/20) / 夏至(6/21) / 秋分(9/22) / 冬至(12/21) |
| 日期滑块 | 1月1日—12月31日，步长1天 |

> 日期影响太阳直射纬度：`δ = 23.5° × sin(360°/365 × (284 + day))`

#### 城市B选择（城市A固定为太阳直射点正下方的位置）

| 序号 | 城市 | 纬度 | 与直射点纬度差 |
|------|------|------|-------------|
| 1 | 亚历山大 | 31.2°N | ~7.2°（夏至） |
| 2 | 北京 | 39.9°N | ~16.4°（夏至） |
| 3 | 莫斯科 | 55.8°N | ~32.3°（夏至） |
| 4 | 新加坡 | 1.3°N | ~24.8°（冬至） |
| 5 | 自定义 | 可调 | — |

> 城市A根据日期自动确定：日期对应的太阳直射纬度处（如夏至=23.5°N，此处假设为"锡耶纳"位置）。

### 6.4 动画与输出

#### 地球剖面可视化

- Canvas 绘制地球圆弧剖面（非完整圆，为大曲率弧线）
- 平行太阳光从上方射下（等间距虚线）
- 城市A：太阳直射，无影子（或井中直射阳光）
- 城市B：立杆投射影子，标注太阳高度角和影长
- 标注圆心角 θ = 两地纬度差

#### 几何推导面板

逐步展示计算逻辑：

```
已知：
  两地纬度差 θ = ___°（= 城市B的太阳高度角与90°之差）
  两地弧长 d = ___ km（沿经线的地面距离）

推导：
  C / d = 360° / θ
  C = d × (360° / θ)
```

#### 数据输出

- **直接显示**：当前日期、太阳直射纬度、两地位置、城市B的太阳高度角
- **默认隐藏**（查看答案按钮）：计算出的地球周长、与真实值（40075 km）的偏差

### 6.5 技术实现

```javascript
function getSolarDeclination(dayOfYear) {
  // 太阳赤纬（近似公式）
  return 23.5 * Math.sin((360 / 365) * (284 + dayOfYear) * Math.PI / 180);
}

function calculateEarthCircumference(arcDistance, centerAngleDeg) {
  // C = d × 360 / θ
  return arcDistance * (360 / centerAngleDeg);
}
```

- **直接显示**：实时高度、实时速度、剩余燃料比例
- **实验完成后显示**：最大高度、燃烧时间
- 可查看：当前参数对应的理论 Δv（供7–9年级参考）

### 9.5 技术实现

```javascript
// 简化飞行模型（一维垂直，欧拉积分）
function step(dt, state, params) {
  const currentMass = state.mass;
  const gravity = 9.81 * Math.pow(6371000 / (6371000 + state.altitude), 2);
  const thrust = state.fuel > 0 ? params.thrust : 0;
  const drag = estimateDrag(state.velocity, state.altitude); // 简化阻力模型

  const acceleration = (thrust - currentMass * gravity - drag) / currentMass;
  state.velocity += acceleration * dt;
  state.altitude += state.velocity * dt;
  if (state.fuel > 0) state.fuel -= fuelBurnRate * dt;
}
```

### 11.1 课堂使用流程（45分钟课时）

| 环节 | 时长 | 活动 |

### 11.2 推荐教学顺序

1. **实验五**（地球周长）— 引入"大地是球形的"和天文学思维方式
2. **实验一**（傅科摆）— 深化"地球在运动"
3. **实验四**（日月食）— 天体运动的具体表现
4. **实验二**（环形山高度）— 从地球转向月球，引入三角测量
5. **实验三**（陨石撞击）— 定性了解月球表面形成
6. **实验七**（望远镜）— 我们如何观测天体
7. **实验六**（光污染）— 观测条件与暗夜保护意识
8. **实验八**（火箭）— 人类如何探索太空

### 11.3 差异化使用建议

**5–6年级**：
- 重视重复实验→记录→对比的完整循环

- 知识卡片的故事化叙述

**7–9年级**：
- 可独立完成定量计算（实验二、五）
- 鼓励"预测→验证"探究模式
- 可布置跨实验的归纳任务（如"实验二和实验五都用了什么共同的数学方法？"）
